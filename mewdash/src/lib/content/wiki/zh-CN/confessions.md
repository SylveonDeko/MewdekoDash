## 功能介绍

成员在服务器中运行 `/confess`，或私信机器人发送 `.confess <server id> "text"`，机器人就会在忏悔频道中发布他们的消息，标题为 "Anonymous confession #N" 的嵌入。发送者的名字永远不会出现在该频道中。发送者会收到一条仅自己可见的确认消息，并且每次忏悔编号都会增加一。

工作人员可以设置一个单独的日志频道。每条忏悔都会复制到该频道，并附带发送者的标签和 ID、忏悔编号，以及指向已发布消息的跳转链接。每条忏悔的页脚都会告诉成员如何发送忏悔，确认消息中也会告知他们可以举报滥用该功能的服务器。

工作人员还可以将个别成员加入黑名单，使其忏悔被拒绝，也可以在仪表板中删除忏悔，删除时同时会删除 Discord 中的消息。

## 为什么要使用它

- 倾诉或“吐槽”频道，让成员可以在不署名的情况下畅所欲言。
- 不记名的赞美或感谢频道。
- 任何需要匿名、但工作人员仍需要追查骚扰行为的频道。

## 忏悔帖子

每条忏悔都是忏悔频道中的一个嵌入：

| 部分 | 内容 |
| --- | --- |
| 作者行 | 带有服务器图标的 `Anonymous confession #N` |
| 描述 | 忏悔文本 |
| 图片 | 如果发送了附件，则显示该附件 |
| 页脚 | `Do /confess or dm me .confess <server id> yourconfession to send a confession!` |
| 时间戳 | 发布时间 |

编号从 1 开始，并接续最后一条已存储忏悔的编号。删除忏悔不会重新编号其他忏悔。

两种方式都支持附件：使用 `/confess` 时通过 `attachment` 选项附加文件，或在使用文字命令时将文件附加到私信中。只会使用第一个附件。

## 日志频道

设置 **日志频道** 后，每条忏悔还会在该频道中生成一个红色嵌入，包含 **用户**（标签和 ID）、**Confession N**（忏悔内容）、**Message Link**（消息链接），以及一条关于滥用的警告。这是唯一能看到发送者身份的地方，因此请只开放给你信任的人。

> [!WARNING]
> 日志频道的存在是为了让工作人员能够处理骚扰行为。泄露忏悔发送者的身份，可能会导致机器人所有者将该服务器加入黑名单。成员可以使用 `/confessions report` 举报滥用行为。

## 黑名单

`confessionblacklist` 会将成员加入服务器的黑名单，`confessionunblacklist` 则将其移出。被加入黑名单的成员会收到 "you are blacklisted" 的提示，而不是发布忏悔。检查依据是用户 ID。

仪表板中显示 **身份组黑名单**，并将身份组 ID 存储在同一列表中。但机器人只会在收到忏悔时将发送者的用户 ID 与列表进行比对，因此目前在仪表板中选择的身份组并不会阻止任何人。如需屏蔽特定成员，请使用命令。

## 设置

**忏悔** 页面包含三个标签页：**配置**、**忏悔** 和 **统计**。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 表白频道 | 无 | 匿名忏悔的发布位置；未设置时忏悔功能关闭 |
| 日志频道（显示用户 ID） | 无 | 每条忏悔的可识别副本的发送位置 |
| 身份组黑名单 | 无 | 参见上方的黑名单部分 |

**忏悔** 列出所有已存储的忏悔，按最新排序，并显示编号和日期。忏悔内容默认隐藏，展开后才会显示。点击 **删除忏悔** 会从数据库中删除该条记录，如果 Discord 中的消息仍然存在，也会一并删除。

**统计** 显示 **忏悔总数**、**本月**、**今天** 和 **最新编号**。

## 设置步骤

1. 创建一个频道，机器人需要拥有 发送消息 和 嵌入链接 权限，成员应当可以阅读，最好不能发言。
2. 在仪表板中打开 **忏悔**，并将该频道选为 **表白频道**。
3. 可选：选择一个仅工作人员可见的私密频道作为 **日志频道**。
4. 点击 **保存配置**。
5. 使用普通成员账号运行 `/confess`，并确认嵌入显示为 `#1`。
6. 如果有人滥用该功能，请在日志频道中找到其身份，并运行 `confessionblacklist @user`。

## 命令

使用服务器的前缀运行这些命令（如果你未更改，则为 `.`）。斜杠命令位于 `/confessions` 下，但 `/confess` 是顶级命令。

| 命令 | 别名 | 所需权限 | 用途 |
| --- | --- | --- | --- |
| `confess <server id> <"text">` | | 无 | 仅限私信。在指定服务器中发布忏悔；多个单词的文本请使用引号包裹 |
| `confessionchannel [#channel]` | `confesschannel` | 管理频道 | 设置忏悔频道，不带频道则关闭忏悔功能 |
| `confessionlogchannel [#channel]` | `confesslogchannel`, `confessionlogchnl` | 管理员 | 设置日志频道 |
| `confessionblacklist <@user>` | `confessblacklist`, `confessbl` | 管理频道 | 禁止成员发布忏悔 |
| `confessionunblacklist <@user>` | `confessunblacklist`, `confessunbl` | 管理频道 | 允许被加入黑名单的成员再次发布忏悔 |

`/confessions report <server id> <description>` 会将某个服务器滥用忏悔功能的举报发送给机器人所有者。此功能没有文字命令版本。

## 提示与注意事项

- 机器人需要在忏悔频道和日志频道中都拥有 发送消息 和 嵌入链接 权限。频道命令在权限不足时会发出警告，但仍会保存设置。
- 文字版 `confess` 命令仅在私信中有效，并将忏悔内容作为单个参数处理，因此 `confess 123456789 "I like pineapple on pizza"` 可以正常工作，而不加引号的版本则只会发布第一个单词。在服务器中使用 `/confess` 对成员来说更简单。
- 通过私信使用 `confess` 时，仅适用于你与机器人共享的服务器；其他服务器 ID 会被拒绝。
- 文字版 `confessionlogchannel` 命令如果不带频道参数，会清除的是忏悔频道，而不是日志频道。如需清除日志频道，请改在仪表板中操作。
- 即使没有设置日志频道，忏悔也会与发送者的用户 ID 一同存储，仪表板可以查询单条忏悔的发送者。请将仪表板的访问权限仅限于工作人员。
- 在仪表板中删除忏悔会移除已存储的记录，因此日志频道中的副本将是你唯一保留的痕迹。
