## 功能简介

设置页面包含一些同时影响所有模块的选项，而不是某一个功能专属的选项。在这里，你可以修改成员在命令前输入的前缀、机器人回复所使用的语言、用于提醒和定时消息的时区，以及记录命令使用情况和警告的频道。

此外，这里还包括静音身份组的名称、被禁言的成员是否会失去其他身份组、警告的保留时长，以及两个聊天实用功能：消息查看和消息链接预览。

大多数设置都有对应的文字命令，因此工作人员也可以在 Discord 中进行修改。少数额外设置只能通过命令完成：工作人员身份组、成员身份组，以及按频道设置的命令消息删除。

## 适用场景

- 你的服务器已将 `.` 用于其他机器人，而你希望 Mewdeko 使用 `!` 或 `m!`。
- 你的社区使用英语以外的语言，而你希望机器人的回复与之匹配。
- 提醒和定时发布的消息应该显示当地时间，而不是 UTC。
- 版主希望有一个频道记录每一条已执行的命令和每一次警告。
- 警告应在设定的天数后自动失效，而不是无限期累积。
- 成员应当能够使用 `snipe` 查看已删除的消息，或者在繁忙的聊天中关闭链接预览。

## 前缀

前缀是成员在命令前输入的文字，默认为 `.`。任何人都可以不带参数运行 `prefix` 来查看当前前缀。管理员可以使用 `prefix <new>` 修改前缀，也可以在仪表板中修改 **命令前缀** 输入框。斜杠命令不受前缀影响。

## 语言

每个服务器都可以使用 `languageset <code>` 选择自己的回复语言，例如 `languageset de`，或使用仪表板上的 **语言** 下拉菜单。`languageset default` 会清除服务器的覆盖设置，使其跟随机器人的默认语言。`languageslist` 会列出所有受支持的语言代码。不带参数运行 `langsetdefault` 会显示机器人的默认语言；修改默认语言则是机器人拥有者的操作。

## 时区

服务器时区会影响提醒、定时消息以及所有时间显示。单独运行 `timezone` 会显示当前值（如果未设置，则为 UTC）。`timezone <id>` 使用 IANA 或 Windows 时区标识符设置时区，例如 `Europe/London`；`timezones` 会分页列出机器人接受的时区标识符。在仪表板中，**服务器时区** 会在你选择后立即保存，无需等待 **保存更改**。

## 日志频道

**命令日志频道** 记录命令的使用情况。使用 `commandlogchannel #channel` 设置；不带频道运行该命令即可关闭日志记录。

**警告日志频道** 记录版主命令发出的警告。此项需在仪表板中设置。

## 警告

**警告过期时间** 以小时为单位存储。设为零表示警告永不过期。`warnexpire` 命令则以天为单位，并需要第二个参数：`warnexpire 30 clear` 会将超过 30 天的警告标记为已清除，`warnexpire 30 delete` 会将其删除。可接受的范围为 0 到 366 天，`warnexpire 0` 会关闭过期功能。

## 静音身份组与身份组移除

**静音身份组** 是静音命令和处罚所应用的身份组名称。如果服务器中不存在该名称的身份组，机器人会自动创建它。在 Discord 中，`muterole @role` 可将该设置指向一个已有身份组；除非你是服务器所有者，否则该身份组必须低于你自己的最高身份组。不带参数运行 `muterole` 会显示当前的静音身份组。

**禁言时移除其他身份组** 会在禁言期间移除成员的其他身份组，并在禁言结束后将其归还。命令形式为 `removeonmute y` 或 `removeonmute n`。

## 聊天实用功能

| 设置 | 命令 | 效果 |
| --- | --- | --- |
| 消息查看 | `snipeset enable` 或 `snipeset disable` | 允许成员使用查看命令找回最近被删除或编辑的消息。默认关闭。 |
| 消息链接预览 | `previewlinks y` 或 `previewlinks n` | 当有人发送 Discord 消息链接时，机器人会显示该消息的内容。 |

## 仅命令可用的设置

这些设置同属管理模块，但在仪表板中没有对应的控件。

**工作人员身份组**（`staffrole @role`）标记的身份组，其成员可豁免词语、链接和邀请过滤器，以及建议的刷屏检查。不带身份组运行 `staffrole` 会显示当前的工作人员身份组，运行 `staffroledisable` 则会将其清除。

**成员身份组**（`memberrole @role`）为服务器存储一个身份组。该设置会被记录，但目前没有任何功能使用它。

**命令执行后删除消息**（`delmsgoncmd`）会在命令运行后删除触发该命令的消息：

| 形式 | 效果 |
| --- | --- |
| `delmsgoncmd` | 切换整个服务器的删除设置 |
| `delmsgoncmd list` | 显示服务器设置以及每个频道的覆盖设置 |
| `delmsgoncmd channel enable [#channel]` | 在该频道始终删除（省略时为当前频道） |
| `delmsgoncmd channel disable [#channel]` | 在该频道从不删除 |
| `delmsgoncmd channel inherit [#channel]` | 跟随服务器设置 |

## 设置项

以下所有设置都位于单一的 **机器人设置** 页面中。编辑后请点击 **保存更改**；只有 **服务器时区** 会自行保存。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 命令前缀 | `.` | 输入命令前的文字 |
| 命令日志频道 | 无 | 记录命令使用情况的频道 |
| 货币表情 | 无 | 服务器货币所使用的表情 |
| 警告日志频道 | 无 | 记录警告的频道 |
| 警告过期时间 | 0（永不） | 警告在多少小时后过期 |
| 语言 | 机器人默认值 | 该服务器的回复语言 |
| 服务器时区 | UTC | 定时消息、提醒和时间显示所使用的时区 |
| 静音身份组 | Muted | 静音和处罚所应用的身份组名称 |
| 禁言时移除其他身份组 | 关闭 | 在禁言期间移除其他身份组 |
| 消息查看 | 关闭 | 允许使用查看命令 |
| 消息链接预览 | 关闭 | 展开 Discord 消息链接 |

> [!NOTE]
> 该页面只包含共享的基础设置。日志、管理、星标板及其他功能都有各自的页面和设置。

## 设置流程

1. 在仪表板中打开 **设置**。
2. 如果 `.` 与其他机器人冲突，请设置 **命令前缀**。
3. 选择 **语言** 和 **服务器时区**。
4. 选择一个只有工作人员可以查看的 **命令日志频道** 和 **警告日志频道**。
5. 以小时为单位设置 **警告过期时间**，例如 `720` 表示三十天，或保持为 0。
6. 确认 **静音身份组** 的名称与版主正在使用的身份组一致，或保持为 `Muted`，让机器人自行创建。
7. 如有需要，开启 **消息查看** 或 **消息链接预览**。
8. 点击 **保存更改**。
9. 在 Discord 中运行 `staffrole @YourStaffRole`，使过滤器和建议限制跳过你的团队。

## 技巧与注意事项

- `delmsgoncmd` 需要机器人拥有 **管理消息** 权限，否则该命令会拒绝运行。
- 仪表板以小时为单位存储警告过期时间，而 `warnexpire` 以天为单位。`warnexpire 1` 与仪表板中的 `24` 是同一个值。
- `muterole` 会将你提供的身份组与你自己的最高身份组进行比较。如果出现权限不足的错误，请询问所有者或选择更低的身份组。
- 斜杠命令完全忽略前缀，因此修改前缀只影响文字命令。
- 工作人员身份组的豁免仅适用于过滤器和建议刷屏检查，并不授予命令权限；如需设置命令权限，请使用权限模块。
