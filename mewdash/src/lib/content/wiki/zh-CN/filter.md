## 功能简介

过滤器会在其他模块处理之前检查成员发送或编辑的每条消息。如果消息在某个已启用过滤器的位置包含被过滤的词、Discord 邀请或链接，机器人就会将其删除。你也可以让机器人通过管理系统发出警告，并私信成员说明删除了什么内容。

第二份名单是自动封禁词，规则更为严格。消息如果匹配自动封禁词，就会被删除，发送者会立即被封禁；如果机器人可以发送私信，还会附上原因。

服务器管理员，以及持有服务器工作人员身份组（通过 `staffrole` 设置）的成员，永远不会被过滤。机器人发出的消息同样不会被检查。

## 适用场景

- 在没有版主在线的情况下，阻止侮辱性词语和其他屏蔽词出现在聊天中。
- 阻止成员通过发送邀请链接来宣传其他服务器。
- 让某个频道只允许文字：删除任何包含 URL 的消息，例如不含媒体的公告频道。
- 对发布已知诈骗话术或突袭特征的账户立即封禁。

## 过滤器类型

| 过滤器 | 适用范围 | 结果 |
| --- | --- | --- |
| 词语过滤 | 仅限词语过滤器频道列表中的频道 | 删除消息；若启用了 **发送被过滤词时警告**，则发出警告并私信 |
| 邀请过滤 | 服务器开关开启且频道列表为空时全服生效；列表有内容时仅在所列频道生效 | 删除消息；若启用了 **发送邀请链接时警告**，则发出警告并私信 |
| 链接过滤 | 服务器开关开启时全服生效，另加其列表中的任何频道 | 删除消息，不发出警告 |
| 自动封禁词 | 全服生效 | 删除消息，私信发送者并将其封禁 |

这三个频道列表即为仪表板上的 **频道覆盖**。注意，词语过滤完全由其频道列表决定：必须将某个频道加入列表，才会在该频道检查词语。

## 词语匹配方式

被过滤的词和自动封禁词会被视为正则表达式，并针对转为小写的消息内容进行测试。普通词语（例如 `example`）会作为子字符串匹配，因此 `examples` 也会被捕获。无法编译的模式会被自动从名单中移除。每个模式的匹配超时时间为 250 毫秒。

被过滤的词会以小写形式存储，并以不区分大小写的方式匹配。自动封禁模式则按输入的原样存储，并与转为小写的文字进行匹配，因此请以小写形式编写。

> [!WARNING]
> 自动封禁模式威力很大。像 `ban` 这样的短模式会在较长的单词内部匹配，从而封禁输入 "banana" 的人。请先将模式当作被过滤词进行测试。

## 警告

开启 **发送被过滤词时警告** 或 **发送邀请链接时警告** 后，机器人会通过管理模块添加一条警告，原因为 "Warned for Filtered Word" 或邀请警告对应的原因，然后私信该成员。管理页面上配置的任何警告处罚都会照常生效，因此如果警告设置为这样，三次过滤命中就可能升级为禁言或踢出。

自动封禁会使用管理模块中 "Filter" 操作的封禁清除设置，以决定删除多少天的消息。

## 设置

消息过滤页面共有四个标签页：**过滤器**、**被过滤的词**、**自动封禁词** 和 **频道覆盖**。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 词语过滤 | 关闭 | 在 **过滤器** 标签页中显示的全服开关 |
| 邀请过滤 | 关闭 | 删除 Discord 邀请链接；邀请频道列表要生效就需要此项开启 |
| 链接过滤 | 关闭 | 全服删除任何包含 URL 的消息 |
| 发送被过滤词时警告 | 关闭 | 删除被过滤的词时添加警告并私信成员 |
| 发送邀请链接时警告 | 关闭 | 删除邀请时添加警告并私信成员 |
| 被过滤的词 | 无 | 位于 **被过滤的词** 标签页的列表，可逐个移除；提供 **全部清空** 按钮，效果与 `fwclear` 相同；超过十个词后会出现搜索框 |
| 自动封禁词 | 无 | 位于 **自动封禁词** 标签页的列表 |
| 词语过滤频道 | 无 | 强制执行词语列表的频道 |
| 邀请过滤频道 | 无 | 非空时，将邀请过滤限制在这些频道内 |
| 链接过滤频道 | 无 | 即使服务器开关关闭，仍会删除链接的额外频道 |

页面顶部会显示被过滤词、自动封禁词和频道覆盖的数量。

## 设置流程

1. 在仪表板中打开 **消息过滤**。
2. 在 **被过滤的词** 标签页中，添加每个词或短语并点击添加。
3. 在 **频道覆盖** 中，将所有应当应用词语列表的频道添加到 **词语过滤频道** 下。
4. 回到 **过滤器**，如果希望全服删除邀请，请开启 **邀请过滤**；如果希望邀请算作一次警告，请开启 **发送邀请链接时警告**。
5. 可选：在 **自动封禁词** 标签页中添加一些高度可靠的模式。
6. 运行 `staffrole @Moderators` 让你的团队免受过滤，然后用普通账户发送一个被过滤的词，确认它被删除。

## 命令

以下命令需使用服务器前缀运行（默认为 `.`，除非你已更改）。

| 命令 | 别名 | 所需权限 | 用途 |
| --- | --- | --- | --- |
| `filterword <word>` | `fw` | 无 | 将词添加到过滤名单；若已存在则移除 |
| `lstfilterwords` | `lfw` | 无 | 分页浏览被过滤词名单 |
| `fwclear` | | 管理员 | 移除所有被过滤的词，清空词语过滤频道列表，并关闭服务器开关 |
| `srvrfilterwords` | `sfw` | 无 | 切换全服词语过滤开关 |
| `chnlfilterwords` | `cfw` | 无 | 切换当前频道在词语过滤频道列表中的状态 |
| `srvrfilterinv` | `sfi` | 无 | 切换全服邀请过滤 |
| `chnlfilterinv` | `cfi` | 无 | 切换当前频道在邀请过滤频道列表中的状态 |
| `srvrfilterlin` | `sfl` | 无 | 切换全服链接过滤 |
| `chnlfilterlin` | `cfl` | 无 | 切换当前频道在链接过滤频道列表中的状态 |
| `fwarn <y or n>` | `filteredwarn` | 管理员 | 开启或关闭被过滤词的警告 |
| `invwarn <y or n>` | `invitewarn` | 管理员 | 开启或关闭邀请链接的警告 |
| `autobanword <pattern>` | `autobanw` | 管理员 | 将模式添加到自动封禁名单；若已存在则移除 |
| `autobanwordlist` | `autobwlist` | 管理员 | 分页浏览自动封禁名单 |

> [!PERMISSION]
> 过滤器开关和 `filterword` 本身不带权限检查。请使用权限模块对其进行限制，或通过仪表板管理过滤器，此时将适用仪表板的访问规则。

## 提示与注意事项

- 机器人需要在每个被过滤的频道中拥有 **管理消息** 权限，并在自动封禁词中拥有 **封禁成员** 权限。
- 编辑过的消息会被重新检查，因此把链接编辑进旧消息仍会被删除。
- 过滤器不适用于管理员、工作人员身份组或机器人。不要用管理员账户进行测试。
- `fwclear` 的作用不止清空名单：它还会移除所有词语过滤频道覆盖设置。
- 无效的正则表达式会被静默丢弃。如果某个词消失了，请检查它是否包含未转义的字符，例如 `(`、`[` 或 `*`。
- 如果想记录过滤器删除了哪些内容，请使用日志功能记录消息删除。
