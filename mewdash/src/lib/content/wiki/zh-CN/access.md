## 功能简介

默认情况下，只有服务器所有者和拥有 管理员 权限的成员可以在仪表板中打开服务器。仪表板访问功能可以扩大这一范围。你可以选择一名成员或一个身份组，指定其可访问的仪表板板块，并为每个板块设置 **查看** 或 **管理** 权限。此后，该服务器会出现在对方的仪表板服务器列表中，其被授权的板块也可以正常使用；其他内容则会被拒绝访问。

权限检查发生在机器人的 API 端，而不仅仅是网页中。每个指定服务器的请求都会携带已登录用户的身份信息。如果对方是所有者或管理员，则请求直接通过。否则，机器人会查找该请求所属的板块，将读取操作视为 **查看**，将任何更改视为 **管理**，并与该用户直接拥有或通过其任一身份组获得的最高权限级别进行比较。

服务器所有者还决定谁可以编辑访问列表本身。默认情况下只有所有者可以。所有者可以指定特定的访问管理员，也可以通过一个开关，允许拥有 管理员 或 管理服务器 权限的任何人来操作。

## 适用场景

- 社区团队无需在 Discord 中拥有管理员权限，即可通过仪表板管理抽奖、建议和工单。
- 版主身份组对 **管理** 和 **日志** 拥有 **管理** 权限，对其他所有板块拥有 **查看** 权限，因此他们可以查看但无法更改不属于其职责范围的设置。
- 机器人助手可以编辑 XP 和货币，但无法修改任何与安全相关的设置。
- 所有者将访问列表的维护工作委派给一个联合所有者身份组，同时不将仅限所有者的控制权交出。

## 访问级别

| 级别 | 允许的操作 |
| --- | --- |
| 无 | 该板块没有任何权限；该板块不会被授予 |
| 查看 | 仅允许读取请求，例如打开页面和加载其数据 |
| 管理 | 包括 查看 允许的全部操作，以及创建、编辑和删除 |

当某个成员匹配多个授权时，例如既有个人授权又有身份组授权，每个板块都以最高的级别为准。拥有至少一个板块授权的成员可以在仪表板服务器切换器中看到该服务器；完全没有授权的成员则看不到。

所有者和管理员会完全绕过授权设置，始终拥有完整权限。

## 板块

板块与仪表板侧边栏一致。选择器中的每个功能都对应机器人 API 的一个或多个区域，因此授予 "管理" 也会同时覆盖管理和防护端点，授予 "Moderation" 同样涵盖防护。选择器会按侧边栏分类对板块进行分组。性能等属于机器人全局基础设施、而非按服务器划分的数据的功能，不可被授权。

当一项授权覆盖的功能对应多个区域时，选择器会显示这些区域共享的最低级别；设置整个分组时，会一次性设置其所有区域。

## 谁可以管理访问列表

| 角色 | 可执行的操作 |
| --- | --- |
| 服务器所有者 | 全部操作：委派开关、管理员列表以及所有授权 |
| 指定的访问管理员 | 添加、编辑和移除授权 |
| 拥有 管理员 或 管理服务器 权限的成员 | 仅在委派开关开启时，可添加、编辑和移除授权 |
| 其他所有人 | 看到 "您无法在此管理仪表板访问权限" |

访问管理员可以是成员，也可以是身份组。只有所有者可以查看或更改管理员列表和委派开关；API 会拒绝其他任何人的此类请求。

> [!WARNING]
> 无法为仪表板访问板块授予 **管理** 权限，因为访问控制器不受板块检查约束。如需将访问列表的控制权交给他人，请使用管理员列表或委派开关。

## 设置

所有设置都位于同一个 **仪表板访问** 页面中。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 允许管理员和“管理服务器”权限成员管理仪表板访问权限 | 关闭 | 位于 **委派设置** 下。开启后，拥有 管理员 和 管理服务器 权限的成员可以编辑授权。仅限所有者。 |
| 访问管理员 | 无 | 被指定可编辑授权的成员或身份组。仅限所有者。 |
| 访问授权 | 无 | 每个成员或身份组对应一条记录，列出每个板块的级别。由管理员和所有者查看。 |

**授予受限访问权限** 表单需要选择对象类型（用户或身份组）、对象，以及每个功能分组的级别。为同一对象再次保存授权时，会替换原有授权。编辑现有授权时，会打开与 **编辑访问授权** 相同的表单。

## 设置步骤

1. 以服务器所有者身份，在仪表板中打开 **仪表板访问**。
2. 决定由谁维护该列表。可以在 **委派设置** 下开启委派开关，也可以在 **访问管理员** 中添加一名成员或身份组。
3. 在 **授予受限访问权限** 下，选择 **身份组**，然后选择你的工作人员身份组。
4. 对日常负责的功能设置 **管理**，对只需查看的功能设置 **查看**，其余保持 **无**。
5. 点击 **授予访问权限**。该授权会显示在 **访问授权** 下。
6. 请该身份组的成员登录仪表板。此时服务器应出现在他们的列表中，并且只有被授权的页面可以正常使用。

## 命令

仪表板访问仅能在仪表板中配置，没有对应的机器人命令。

## 提示与注意事项

- 授权会根据机器人缓存的成员列表进行检查，因此成员必须在服务器中，并且对机器人可见，其授权才会生效。
- 身份组授权会跟随成员当前拥有的身份组。移除该身份组会立即取消访问权限。
- 所有板块都设为 **无** 的授权会被视为没有授权，并被删除，成员也会在切换器中失去该服务器。
- 无论授权如何设置，管理员始终拥有完整权限。如需限制某人，请先在 Discord 中移除其管理员身份，然后在此处授予所需权限。
- 仪表板代理会为每个请求附加一个共享的 API 密钥，但仅凭该密钥无法访问任何服务器；始终需要已登录用户的身份信息。
- 不与特定服务器关联的端点（例如全局命令列表）不受板块检查约束，受限用户仍可正常使用。
