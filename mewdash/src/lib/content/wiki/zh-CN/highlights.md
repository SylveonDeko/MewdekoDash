## 功能介绍

成员使用 `highlight add` 添加一个词语或短语。此后，只要服务器中的消息包含该词语，机器人便会向其发送一条私信。私信会说明事件发生在哪个服务器和频道，显示匹配消息之前的五条消息以及匹配的那条消息，并附带一个 **跳转到消息** 按钮。

高亮词是个人设置。每位成员管理自己的列表，选择要忽略的频道和用户，并可以在不删除高亮词的情况下将其关闭。工作人员无法替他人添加高亮词，但仪表板允许他们查看正在被关注的词语并将其删除。

成员只会收到其能够查看的频道中的私信。如果成员正在服务器中输入消息，则视为其处于在线状态，高亮词通知会为其暂停两分钟。

## 适用场景

- 当有人提到你的名字、昵称或项目，而没有实际 @ 你时，也能收到提醒。
- 在大型服务器中关注某个话题，例如“抽奖”或“更新日志”。
- 工作人员可以监控“帮助”或“举报”等词语，而无需阅读每个频道的全部内容。
- 管理员可以查看成员正在关注的词语，并清理辱骂或垃圾高亮词。

## 匹配规则

机器人会将服务器中每条非空消息与该服务器中的每个高亮词进行比对。

- 高亮词按完整单词或短语匹配。`cat` 不会匹配 “category”，但会匹配 “the cat sat”。
- 匹配区分大小写。如果同时需要 `Cat` 和 `cat`，请分别添加。
- 在同一服务器中，每位成员两分钟内最多收到一条私信，无论有多少个词语匹配。
- 在服务器中的任何输入都会开始同样的两分钟暂停，因此你不会收到关于你正在参与的对话的私信。
- 来自被忽略用户的消息以及被忽略频道中的消息，会在该成员的通知中被跳过。
- 如果成员无法查看该频道，或关闭了私信，则不会发送私信。
- 消息会通过一个队列进行检查，该队列每两秒处理一条消息。在非常繁忙的分片上，部分消息可能会从队列中丢失。

`highlight match some text` 会将你自己的列表与一个示例句子进行比对，并告诉你哪些词语会匹配。该检查忽略大小写，因此它只是一个大致的参考，而非实时规则的精确复制。

## 成员个人设置

每位成员都有一条设置记录，在其首次切换任何选项时创建。

| 设置 | 默认值 | 控制内容 |
| --- | --- | --- |
| 高亮词已启用 | 开启 | `highlight toggle false` 会暂停你在此服务器中的所有高亮词 |
| 忽略的频道 | 无 | 这些频道中的词语永远不会触发私信 |
| 忽略的用户 | 无 | 这些用户的消息永远不会触发你的高亮词 |

## 设置

仪表板中的高亮词页面供工作人员使用。它不能添加高亮词，只能查看和删除。

| 标签页 | 显示内容 |
| --- | --- |
| 所有高亮词 | 服务器中的所有高亮词，按成员分组，每个词语旁有删除按钮，并可一键删除某位成员的全部词语 |
| 搜索 | 在所有成员中查找包含某个词语的高亮词；搜索不区分大小写 |
| 已禁用的用户 | 已关闭高亮词的成员，以及他们忽略的频道和用户数量 |
| 统计 | 高亮词总数、活跃用户、最热门词语、最活跃成员，以及最常被高亮的词语和最近的高亮词 |

## 设置指南

无需启用任何功能。只要机器人在服务器中，高亮词即可使用。

1. 作为成员，在任意频道中执行 `highlight add yourname`。
2. 执行 `highlight list`，确认已保存。
3. 请其他人在另一个频道中提到你的名字。稍等几秒钟后，检查你的私信。
4. 如果收到的提醒过多，执行 `highlight toggleignore #busy-channel` 或 `highlight toggleignore @user`。
5. 工作人员：打开仪表板中的 **高亮词**，在 **所有高亮词** 标签页中检查并删除不需要的词语。

## 命令

请使用服务器的前缀运行以下命令（如未更改，默认为 `.`）。相同的操作也可通过单一斜杠命令 `/highlights manage` 完成，其 `action` 选项包括 `Add`、`List`、`Delete`、`Match`、`ToggleUser`、`ToggleChannel` 和 `ToggleGlobal`，并分别带有 `words`、`user` 和 `channel` 选项。

| 命令 | 别名 | 所需权限 | 用途 |
| --- | --- | --- | --- |
| `highlight add <word>` | `highlights`、`hl` | 无 | 关注某个词语或短语 |
| `highlight list` | `highlights`、`hl` | 无 | 翻页查看你的高亮词，每页十条 |
| `highlight delete <number or word>` | `highlights`、`hl` | 无 | 按列表编号或完整词语删除；`remove` 的效果相同 |
| `highlight match <text>` | `highlights`、`hl` | 无 | 显示你的哪些词语出现在该文本中 |
| `highlight toggleignore <#channel or @user>` | `highlights`、`hl` | 无 | 将频道或用户加入或移出你的忽略列表 |
| `highlight toggle <true or false>` | `highlights`、`hl` | 无 | 开启或关闭你在此服务器中的所有高亮词 |

## 小贴士与注意事项

- 机器人需要能够读取某个频道，才能在其中进行匹配；而你需要允许服务器成员向你发送私信，才能收到提醒。
- 如果已添加的词语重复，添加会被拒绝。重复检查忽略大小写，但实时匹配则区分大小写。
- 按编号删除时，使用的是 `highlight list` 中显示的位置，而每次删除后位置都会变化。
- 高亮词列表和设置会在每个服务器中缓存三十分钟。通过命令或仪表板添加或删除单个词语会立即更新缓存；但在仪表板中删除某位成员的全部词语后，可能需要最多三十分钟才会停止发送私信。
- 当机器人离开服务器时，其高亮词和设置会在机器人下次重启时被清理。
