## 功能介绍

每当机器人被移出服务器或自行离开服务器时，都会向该服务器的所有者发送一条简短的私信。私信包含一个常见原因的下拉菜单、一个 **Write something** 按钮（用于打开文本框），以及一个 **No thanks** 按钮。回答是可选的，私信中也会注明这一点。

每条回答都会与服务器名称、成员数量、所有者，以及机器人在该服务器中待了多长时间一起保存。如果设置了举报频道，还会在该频道发布一条汇总嵌入消息；如果所有者之后补充评论，该消息也会随之更新。

这是机器人级别的功能。没有按服务器的设置，并且仪表板页面仅对机器人所有者显示。

> [!NOTE]
> 只有机器人所有者可以看到退出反馈页面。其他仪表板用户在侧边栏中看不到该页面，也无法打开它。

## 使用场景

- 了解服务器离开是因为缺少功能、设置困惑，还是可靠性问题。
- 识别那些仅为测试而添加机器人的服务器，从而忽略它们的离开。
- 联系留下评论并提供了联系方式的所有者。
- 追踪所有者有多少人愿意回答。

## 提示内容

私信标题为 "Sorry to see me go!"，并说明机器人刚刚被移出所指定的服务器。下拉菜单按以下顺序提供原因：

| 原因键 | 向所有者显示的内容 |
| --- | --- |
| `not_needed` | We didn't need it anymore |
| `confusing` | Too confusing to set up |
| `missing_features` | Missing features we wanted |
| `unreliable` | It was broken or unreliable |
| `other_bot` | We switched to another bot |
| `temporary` | Temporary, I'm adding it back |
| `testing` | Just testing something |

选择某个原因后会立即保存，并再次提供文本框。文本框是一个单段落输入框，标题为 "What could we have done better?"，最多可输入 1000 个字符。点击 **No thanks** 会将记录标记为已忽略，且该记录永远不会被汇报。

为避免打扰用户，设有以下规则：

- 同一服务器在三十天内最多只会被询问一次，无论它添加和移除机器人的次数如何。
- 如果所有者关闭了私信，则不会保存任何内容。
- 功能关闭时，不会发送任何内容。

## 状态

每条记录最终会处于以下三种状态之一，仪表板可以按这些状态进行筛选。

| 状态 | 含义 |
| --- | --- |
| 已回复 | 所有者选择了原因或撰写了评论 |
| 已忽略 | 所有者点击了 **No thanks** |
| 无响应 | 私信已发送，但尚未收到任何回复 |

## 设置

页面包含两个标签页：**回复** 和 **设置**。

| 设置 | 默认值 | 控制内容 |
| --- | --- | --- |
| 询问所有者机器人被移除的原因 | 开启 | 是否发送该私信 |
| 举报频道 ID | 空 | 接收每条回答汇总嵌入消息的频道。为空时回退到机器人的加入/离开日志频道。 |

在 **举报频道 ID** 字段下方，页面会显示该 ID 解析到的频道和服务器，以及机器人是否可以访问该频道。

**回复** 标签页包含六个统计数据：**已发送提示**、**已回复**、**含评论**、**已忽略**、**无响应** 和 **回复率**，还有一个 **给出的原因** 分类统计，以及一个表格，其列为 **离开**、**服务器**、**原因** 和 **状态**。你可以按原因和状态进行筛选（状态筛选还提供“留下了评论”选项），可以按服务器名称或评论内容进行搜索，可以展开某一行阅读完整评论，也可以删除记录。**回复率** 将已回复和已忽略的提示合并计算。

## 设置示例

1. 使用机器人所有者的账号登录仪表板，并打开 **退出反馈**。
2. 在 **设置** 标签页中，确认 **询问所有者机器人被移除的原因** 已开启。默认即为开启。
3. 将频道 ID 粘贴到 **举报频道 ID** 中，然后点击 **保存频道**；或将其留空以使用加入/离开日志频道。
4. 从你拥有的测试服务器中移除机器人，并回复私信。
5. 在 **回复** 标签页和举报频道中查看该条记录。

## 命令

该功能仅通过仪表板提供，没有机器人命令。所有者通过私信中的按钮和下拉菜单进行回答。

## 小贴士与注意事项

- 机器人只会私信 Discord 中列出的服务器所有者，而不会私信执行移除操作的人。
- 三十天冷却期以服务器为单位计算，因此如果某服务器在该期间内重新添加并再次移除机器人，则不会再次被询问。
- 汇总嵌入消息会发送到已配置的频道；如果未设置，则发送到机器人凭据中配置的加入/离开日志频道。如果两者都不存在，回答仍会被保存，并可在页面中查看。
- 从仪表板删除记录，并不会删除已在举报频道中发布的嵌入消息。
