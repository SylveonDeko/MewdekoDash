## 功能介绍

重复消息是机器人在同一个频道中反复发布的一条消息。最常见的用法是定时提醒，例如每六小时发布一次“请阅读规则”。每次触发时，机器人都会先删除上一条副本，因此频道不会堆满重复内容，消息也始终位于底部附近。

重复消息有五种触发模式。除了固定间隔外，它还可以在其他人发言时立即触发（即真正的置顶消息）、在发送一定数量的消息后触发、在频道繁忙时触发，或在频道安静时触发。可选的时间段可将触发限制在服务器时区的工作时间、晚间或周末；论坛类型的重复消息还可以自动发布到每个新帖子中。

消息支持完整的嵌入构建器、纯文本、组件以及通用占位符，因此重复消息既可以是一行文字，也可以是丰富的公告。提及只有在创建者拥有提及 @everyone 权限时才会保留，否则会被无效化。

## 为什么要使用它

- 在繁忙频道的底部固定规则或“如何获取帮助”的通知。
- 每天服务器时间 18:00 发送活动提醒。
- 按标签筛选，在每个新的论坛帖子中发布发帖指南。
- 当频道安静一小时后，用一个话题引子带动讨论。
- 仅在工作时间内、且仅在未来七天内开展促销。

## 触发模式

| 模式 | 发布时机 |
| --- | --- |
| 时间间隔 | 每隔一段时间发布，可选择与某个每日开始时间对齐。默认模式。 |
| 立即 | 发布一次，之后每当其消息不再是频道中的最后一条时重新发布。 |
| 消息数后 | 自上次触发后，频道中发送的消息达到阈值时发布。 |
| 有活动时 | 频道繁忙时发布：阈值与时间段内的近期消息量进行比较。 |
| 无活动时 | 整个时间段内频道没有任何消息时发布。 |

基于活动的模式每分钟检查一次，并且需要服务器启用消息计数。间隔必须在五秒到 25000 分钟之间。默认为五分钟；如果只设置了每日时间而未设置间隔，则默认为一天。**活动阈值**默认为 5 条消息，**时间段**默认为五分钟，时间段范围为三十秒到六小时。

## 条件与限制

- **若消息已是频道中的最后一条则不重复**（冗余检查）：如果其最后一条副本仍是最新消息，机器人将跳过本次运行。
- **对话检测**：如果过去一分钟内收到三条或更多消息，本次运行将被延迟，并在三十秒后重新检查。
- **时间计划**：`business` 指周一至周五 09:00 至 17:00，`evening` 指每天 18:00 至 23:00，`weekend` 指周六和周日全天。时间以服务器时区为准；请先设置时区，否则机器人将默认使用 UTC 并提醒你。
- **自动删除时间**和**最大展示次数**：重复消息会在达到最长存在时间或发布次数后自行删除。
- **隐藏通知**：消息以静默方式发送，不会推送提醒到任何人的设备。
- **优先级**按重复消息单独保存，范围为 0 至 100，默认为 50，并显示在列表中。

## 帖子与论坛

- **在新帖子中自动创建**：当在重复消息所在频道下创建新帖子时，机器人会将消息发布到帖子中，并在成员回复时保持其位于底部。
- **仅帖子模式**：重复消息从不在父频道中发布，只在帖子中发布。目标为论坛频道时必须开启。
- **论坛标签筛选**：必须包含和禁止使用的标签，决定哪些论坛帖子会获得置顶消息。

## 占位符

消息会经过通用占位符处理。由于没有人会触发重复消息，用户类占位符指向机器人自身。常用的占位符如下：

| 占位符 | 值 |
| --- | --- |
| `%server%`、`%server.name%` | 服务器名称 |
| `%server.members%` | 缓存的成员数 |
| `%server.id%`、`%server.icon%` | 服务器 ID 和图标 URL |
| `%channel%`、`%channel.name%` | 重复消息所在频道的提及和名称 |
| `%bot.name%`、`%bot.avatar%` | 机器人的名称和头像 |
| `%server.time%`、`%time.day%` | 服务器时间和当前星期 |

`%huggif%` 等表情 GIF 占位符同样会被替换。`%user%` 等触发者占位符会解析为机器人。

## 设置

重复消息页面有三个标签页：**概览**、**管理重复消息**和**新建**。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 目标频道 | 无 | 发布消息的文字频道或论坛频道 |
| 论坛标签筛选 | 无 | 必须包含和禁止使用的标签，仅适用于论坛频道 |
| 消息内容 | 无 | 打开嵌入构建器 |
| 触发模式 | 时间间隔 | 五种模式之一 |
| 重复间隔 | 5 分钟 | 从 1 分钟到每天的预设，或自定义 `HH:MM:SS` |
| 若消息已是频道中的最后一条则不重复 | 关 | 冗余检查 |
| 允许 @everyone 和 @here 提及 | 关 | 保留消息中的全体提及，而不是将其无效化 |
| 优先级（0-100） | 50 | 列表中显示的优先级值 |
| 队列位置 | 0 | 保存的排序值 |
| 开始时间（HH:MM） | 无 | 将时间间隔重复消息对齐到的每日时间 |
| 对话检测 | 关 | 在人们交谈时延迟发布 |
| 隐藏通知 | 关 | 静默发送 |
| 在新帖子中自动创建 | 关 | 帖子置顶，仅适用于论坛频道 |
| 仅帖子模式 | 关 | 跳过父频道，仅适用于论坛频道 |
| 自动删除时间（天） | 无 | 最长存在时间，格式为 `d.hh:mm:ss`，例如 `7.00:00:00` |
| 最大展示次数 | 不限 | 删除前的发布次数 |
| 时间计划 | 无 | 预设按钮或自定义计划 |
| 活动阈值 / 所需消息数 | 5 | 活动模式所需的消息数 |
| 时间段 | 00:05:00 | 活动模式的统计时间段 |

**概览**显示总数、活跃数量、总展示次数、触发模式分布以及最活跃的重复消息。**管理重复消息**列出每条重复消息，并提供**编辑**、**立即触发**和**删除**操作，以及对间隔、阈值、最长存在时间和最大触发次数的快速编辑。

## 设置步骤

1. 在仪表板中打开**重复消息**，选择**新建**。
2. 选择**目标频道**。如果是论坛，请勾选**仅帖子模式**，并设置所需的**论坛标签筛选**。
3. 点击**消息内容**框，在嵌入构建器中编辑消息。
4. 选择**触发模式**。若要置顶，选择立即；若要做提醒，选择时间间隔并设置**重复间隔**预设。
5. 如需冗余检查、静默发送、时间计划或过期设置，请打开**高级选项**。
6. 点击**创建重复消息**，然后在管理标签页中使用**立即触发**进行测试。

> [!NOTE]
> 时间计划需要设置服务器时区。在启用工作时间、晚间或周末时段之前，请先使用时区命令进行设置。

## 命令

请在命令前加上服务器的前缀（默认为 `.`，除非你已更改）。以上所有命令均需要管理消息权限。重复消息通过 `repeatlist` 列出的编号进行引用。

| 命令 | 别名 | 所需权限 | 用途 |
| --- | --- | --- | --- |
| `repeat [time] [interval] <message>` | | 管理消息 | 在当前频道创建重复消息，例如 `repeat 6h Read the rules` 或 `repeat 18:00 Event tonight` |
| `repeatlist` | `replst`, `replist`, `repli` | 管理消息 | 列出重复消息，包括频道、模式、间隔和下次执行时间 |
| `repeatinvoke <index>` | `repinv` | 管理消息 | 立即触发重复消息并重新开始计时 |
| `repeatremove <index>` | `reprm` | 管理消息 | 删除重复消息 |
| `repeattoggle <index>` | `reptoggle`, `reptog` | 管理消息 | 启用或禁用，不删除 |
| `repeatmessage <index> <message>` | `repmsg` | 管理消息 | 替换消息内容 |
| `repeatchannel <index> [#channel]` | `repchan` | 管理消息 | 移至文字频道或论坛频道 |
| `repeatredundant <index>` | `repeatredun`, `repred` | 管理消息 | 切换冗余检查 |
| `repeattriggermode <index> <mode>` | `reptriggermode`, `repmode` | 管理消息 | `timeinterval`、`immediate`、`aftermessages`、`onactivity` 或 `onnoactivity` |
| `repeatactivity <index> <threshold> <window>` | `repactivity`, `repact` | 管理消息 | 设置活动阈值和时间段，例如 `10 5m` |
| `repeatpriority <index> <0-100>` | `reppriority`, `repprio` | 管理消息 | 设置优先级 |
| `repeatschedule <index> <preset>` | `repschedule`, `repsched` | 管理消息 | `business`、`evening`、`weekend`，或使用 `none` 清除 |
| `repeatconversation <index>` | `repconversation`, `repconv` | 管理消息 | 切换对话检测 |
| `repeatsuppressnotifications <index>` | `repsuppressnotif`, `repsilent`, `repsuppress` | 管理消息 | 切换静默发送 |
| `repeatthreadautosticky <index>` | `repthreadauto`, `repthreads` | 管理消息 | 切换是否在新帖子中发布 |
| `repeatthreadonly <index>` | `repthreadonly`, `reptonly` | 管理消息 | 切换仅帖子模式 |
| `repeatforumtags <index> <add/remove/clear/list> [required/excluded] [tags]` | `repforumtags`, `repftags` | 管理消息 | 通过标签 ID 管理论坛标签筛选 |

## 注意事项与提示

- 机器人需要在频道中拥有发送消息、嵌入链接和管理消息权限，因为它需要在重新发布前删除上一条副本。
- 如果频道被删除或机器人失去访问权限，重复消息会自行删除。
- 机器人启动后会稍后加载重复消息。在加载完成之前，命令不会有任何响应。
- 立即模式会在其他人每发送一条消息时重新发布，因此在消息非常频繁的频道中请避免使用，或将其与对话检测搭配使用。
- 只有拥有提及 @everyone 权限的成员才能创建会提及所有人或某个身份组的重复消息；否则提及会被转义。
- 基于活动的模式依赖消息计数。切换模式前请先启用它，否则命令会被拒绝。
- “最大展示次数”会统计每一次发布，包括你手动触发的发布。
