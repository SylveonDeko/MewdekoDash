## 功能简介

工作人员可以添加一段或多段要监听的文本，例如 `discord.gg/yourserver` 或 `playing minecraft`。机器人会监听在线状态更新。当成员的自定义状态开始包含该文本时，机器人会移除 **要移除的身份组** 中列出的身份组，添加 **要添加的身份组** 中列出的身份组；如果设置了频道和消息，还会在该频道发送通知。

当状态中不再包含该文本时，两个开关会决定后续操作。**移除已添加的身份组** 会收回之前被添加的身份组。**重新添加已移除的身份组** 会归还之前被移除的身份组。两者默认均为关闭，因此在不做任何更改的情况下，成员会保留最终拥有的身份组。

机器人只检查自定义状态，即你在 Discord 中 "设置自定义状态" 下输入的文本。游戏、Spotify 和直播活动会被忽略。离线或隐身的成员会被跳过。匹配采用普通的子串检查，因此 `mewdeko` 可以匹配 `I love mewdeko`，但区分大小写。

每个服务器可以设置任意数量的状态身份组条目，每个条目都有各自的身份组、频道和消息。命令通过索引来指代条目，即 `liststatusroles` 显示的编号。

## 适用场景

- 为在状态中放置你的专属邀请链接的成员提供支持者身份组及其权益。
- 在某人于状态中宣传 "正在直播" 或 "想找人一起玩" 时赋予相应身份组，并在其停止宣传后移除。
- 当成员开始在状态中为服务器宣传时，在频道中发出通知，方便工作人员致谢。
- 在某个状态生效期间替换身份组，例如当成员显示特定状态时，将其移出 "禁止提醒" 身份组。

## 匹配与身份组变更

| 情况 | 机器人的操作 |
| --- | --- |
| 状态中新出现了监听文本 | 移除 **要移除的身份组**，添加 **要添加的身份组**，并发送已配置的通知 |
| 状态中仍包含监听文本 | 不做任何操作，该变更只会处理一次 |
| 状态中不再包含监听文本，且 **移除已添加的身份组** 已开启 | 移除成员仍拥有的 **要添加的身份组** |
| 状态中不再包含监听文本，且 **重新添加已移除的身份组** 已开启 | 归还成员已不再拥有的 **要移除的身份组** |
| 成员变为离线或隐身 | 不做任何操作，身份组保持原样 |

机器人会将每次在线状态更新与其为该用户缓存的上一次状态进行比较，因此成员修改状态中无关的部分不会被重复处理。同一服务器中监听的文本必须唯一；命令方式最多允许 128 个字符，仪表板则没有此限制。

## 通知消息

如果某个条目同时设置了 **通知频道** 和 **通知消息**，每当成员的状态开始匹配时，机器人都会在该频道发送该消息。文本会经过嵌入消息解析器处理，因此嵌入消息生成器能够生成的内容都可以使用，包括纯文本、最多十个嵌入消息以及组件。状态不再匹配时，不会发送任何消息。

### 占位符

消息会按照成员、通知频道和服务器的标准替换规则进行处理。最常用的占位符如下；完整列表请参阅占位符页面中的用户、服务器、频道、机器人和时间部分。

| 占位符 | 值 |
| --- | --- |
| `%user.mention%` | 成员的提及 |
| `%user.name%` | 成员的用户名 |
| `%user.fullname%` | 带有识别码的用户名 |
| `%user.avatar%` | 成员头像的 URL |
| `%user.id%` | 成员的用户 ID |
| `%server.name%` | 服务器名称 |
| `%server.icon%` | 服务器图标的 URL |
| `%channel.mention%` | 通知频道的提及 |
| `%server.time%` | 服务器所设时区的当前时间 |

> [!NOTE]
> 仪表板的编辑器列出了 `%status%` 占位符，但机器人不会替换它。请自行将状态文本写入消息中。

> [!EXAMPLE]
> `%user.mention% is now repping the server in their status, thank you!`

## 设置

所有内容都位于 **状态身份组** 页面，该页面有三个标签页：**状态身份组**、**新建** 和 **统计**。列表中的每个条目展开后会显示其设置。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 要监听的状态文本 | 无 | 成员的自定义状态必须包含的文本；仪表板无长度限制，通过命令设置时最多 128 个字符 |
| 要添加的身份组 | 无 | 状态匹配时授予的身份组 ID，以空格分隔；保存时会替换整个列表 |
| 要移除的身份组 | 无 | 状态匹配时收回的身份组 ID，以空格分隔；保存时会替换整个列表 |
| 通知频道 | 无 | 接收通知消息的频道 |
| 通知消息 | 无 | 发送到该频道的文本或嵌入消息，可使用占位符 |
| 移除已添加的身份组 | 关闭 | 状态不再匹配时，收回已添加的身份组 |
| 重新添加已移除的身份组 | 关闭 | 状态不再匹配时，归还已移除的身份组 |

**统计** 标签页显示条目总数、会更改身份组的条目数，以及设置了通知频道的条目数。

## 设置步骤

1. 在仪表板中打开 **状态身份组**，进入 **新建** 标签页。
2. 输入要监听的文本，然后点击 **添加状态身份组**。
3. 切换到 **状态身份组** 标签页，展开新建的条目。
4. 点击 **编辑设置**，将身份组 ID 粘贴到 **要添加的身份组** 和 **要移除的身份组** 中，如需通知，请选择 **通知频道** 并填写 **通知消息**，然后点击 **保存**。
5. 使用条目上的两个切换按钮开启 **移除已添加的身份组**；如有需要，再开启 **重新添加已移除的身份组**。
6. 测试：将你自己的自定义状态设为该文本，确认身份组已添加；然后清除状态，确认身份组已被移除。

## 命令

使用服务器的前缀运行以下命令（除非你更改过，否则为 `.`）。所有命令都需要 **管理服务器** 权限。`<index>` 即 `liststatusroles` 显示的编号，从 1 开始。斜杠命令版本位于 `/statusroles` 下。

| 命令 | 别名 | 所需权限 | 用途 |
| --- | --- | --- | --- |
| `addstatusrole <text>` | `asr` | 管理服务器 | 添加要监听的状态文本 |
| `removestatusrole <index>` | `rsr` | 管理服务器 | 删除一个条目 |
| `liststatusroles` | `lsr` | 管理服务器 | 分页查看每个条目及其编号和设置 |
| `setaddroles <index> <@role...>` | `sar` | 管理服务器 | 将身份组添加到状态匹配时授予的列表中 |
| `setremoveroles <index> <@role...>` | `srr` | 管理服务器 | 将身份组添加到状态匹配时收回的列表中 |
| `removeaddroles <index> <@role...>` | `remar` | 管理服务器 | 将身份组从 "要添加的身份组" 列表中移除 |
| `removeremoveroles <index> <@role...>` | `rmremoveroles` | 管理服务器 | 将身份组从 "要移除的身份组" 列表中移除 |
| `setstatusrolechannel <index> <#channel>` | `statusrolechannel`、`ssrc` | 管理服务器 | 设置通知频道 |
| `setstatusroleembed <index> [text]` | `statusroleembed`、`asre` | 管理服务器 | 设置通知消息；如果不填写文本，则预览当前消息 |
| `toggleremoveadded <index>` | `togglerma` | 管理服务器 | 切换 **移除已添加的身份组** |
| `togglereaddremoved <index>` | `togglermrm` | 管理服务器 | 切换 **重新添加已移除的身份组** |

`setaddroles` 和 `setremoveroles` 是追加到现有列表中，而不是替换。如需移除身份组，请使用 `remove...` 系列命令。仪表板编辑器的逻辑则相反：保存时输入框中的内容会成为完整列表，但被清空的输入框会被忽略，因此要完全清空列表，必须使用 `remove...` 系列命令。

## 提示与注意事项

- 机器人需要 **管理身份组** 权限，并且其最高身份组必须位于它所添加或移除的每个身份组之上。失败只会记录在日志中，成员不会看到任何提示。
- 机器人必须拥有在线状态意图才能看到自定义状态。如果你更改状态后没有任何反应，请首先检查这一点。
- 匹配区分大小写，并会在状态文本的任意位置查找。请尽量让监听文本简短且独特。
- 机器人只检查成员在线状态中的第一个活动。Discord 通常会将自定义状态排在最前，但如果其他活动排在它前面，则不会识别到该状态。
- 身份组仅在状态发生变化时才会更改。如果成员在你创建条目时状态中已包含该文本，则在其状态再次变化之前不会被处理。
- 每次状态开始匹配时都会发送通知，因此如果成员反复切换状态，就会触发重复的消息。
- 仪表板使用的是身份组 ID，而不是名称。请在 Discord 中开启开发者模式，然后右键点击身份组即可复制其 ID。
