## 功能介绍

管理人员可以为大多数成员看不到的频道设置一道“入口”。成员点击 **Apply for access** 按钮，或运行 `channelaccessapply`，然后填写一份最多五个问题的简短表单。申请会以嵌入消息的形式发布到审核频道，并附带 **批准**、**拒绝**，以及可选的 **Abstain** 和 **明细** 按钮。

已经能看到该频道的人会参与投票。申请获得足够的赞成票后，申请者就会被允许进入，方式可以是授予一个身份组，也可以是在该频道上为其设置个人权限覆盖。达到足够的反对票，或投票时间窗口结束，申请就会被拒绝。管理人员可以随时强制执行任一结果。

如果入口允许，申请者会通过私信得知结果。被拒绝的申请者必须等待冷却时间结束后才能再次申请。所有操作都会记录到可选的日志频道中。

## 为什么要使用它

- 仅限成员的休息室或“内部圈子”，由现有成员决定谁可以加入。
- 已验证成年人的频道，由一小群可信成员为新人担保。
- 交易或市场频道，希望在有人发言前进行一次审查。
- 任何希望收到书面申请、又不想让管理人员亲自阅读每一份申请的频道。

## 入口

入口由一个频道及其规则组成。每个频道只能有一个入口。创建入口时指定身份组，即为 **role gate**（身份组入口）；不指定身份组，则为 **direct gate**（直接入口）。

| 授予方式 | 仪表板标签 | 访问权限的授予方式 | “已在内”的判定 |
| --- | --- | --- | --- |
| 身份组 | 授予他们一个身份组 | 访问身份组会被添加到申请者身上 | 拥有访问身份组的任何人 |
| 频道权限 | 直接将他们添加到频道 | 为该成员写入一条 View Channel 允许覆盖 | 当前能看到该频道的任何人 |

通过的成员不会被自动移除。如需撤销，请自行移除身份组或删除该覆盖。

## 申请

在申请开放之前，机器人会按以下顺序进行检查：入口是否正在接受申请、成员是否已拥有访问权限、是否被禁止、账号和服务器加入时间是否足够久、该入口是否已有未处理的申请，以及重新申请的冷却时间是否已过。任何一项未通过，都会收到一条仅本人可见的消息，说明原因。

如果入口设有问题，将打开一个表单，每个问题对应一个输入框。由于 Discord 表单的限制，问题最多 45 个字符。回答框分为单行（200 个字符）或多行（1000 个字符），可以设为必填。没有问题的入口会直接提交。

审核消息会发送到 **审核频道**（审核频道）；如果未设置，则发送到受限频道本身。消息会显示申请者、账号创建时间和加入服务器的时间、每个问题及其回答、实时投票统计，以及一个页脚，显示投票何时结束。如果开启了 **在投票结束前隐藏申请者**（在投票结束前隐藏申请者），则在待处理期间，名称会被替换为 “Hidden until the vote closes”。

### 状态

| 状态 | 含义 |
| --- | --- |
| 待处理 | 开放中，正在投票 |
| 已通过 | 已通过，已授予访问权限 |
| 已拒绝 | 通过投票、过期或管理人员拒绝 |
| 已撤回 | 申请者通过 `channelaccesswithdraw` 撤回了申请 |
| 已过期 | 当前的过期规则不再使用；保留用于历史记录 |

## 投票

谁可以投票取决于入口设置。如果设置了 **投票身份组**（投票身份组），则只有拥有该身份组的成员可以投票。否则，任何已经有该频道访问权限的人，以及拥有管理身份组权限的人，都可以投票。申请者永远不能对自己的申请投票。

点击按钮即记录一票。点击另一个按钮会更改投票。再次点击同一按钮会撤销投票。每次改动后，消息上的统计都会更新。

当赞成票达到 **所需通过票数**（所需通过票数）或反对票达到 **所需拒绝票数**（所需拒绝票数）时，申请即刻结案。将任一阈值设为 0 即可禁用该方向，因此当 **所需拒绝票数**（所需拒绝票数）为 0 时，只能由管理人员或过期规则拒绝申请。

**明细** 会显示每人的投票方向，仅对投票者可见。若开启了 **隐藏每人的投票方向**（隐藏每人的投票方向），则只有拥有管理身份组权限的成员可以查看。

### 投票窗口结束时

后台每分钟会检查一次超过 **Voting window**（投票时间窗口）的申请。结束时的处理方式由每个入口单独设置：

| 选项 | 仪表板标签 | 结果 |
| --- | --- | --- |
| Deny | 拒绝该申请 | 申请被拒绝。默认值。 |
| Majority | 以票数较多的一方为准 | 若赞成票多于反对票则通过，否则拒绝 |
| StayOpen | 留给管理人员处理 | 在管理人员处理之前不会发生任何事情 |

将 **Voting window**（投票时间窗口）设为 0 即表示没有时间限制。

## 封禁申请者

管理人员可以在单个入口或整个服务器的所有入口中禁止某位用户申请。被禁止的用户在尝试申请时会看到 “You are blocked from applying for this channel”。封禁可附带可选原因，并会显示在黑名单中。

## 设置

**频道访问**（频道访问）页面有三个标签页：**入口**（入口）、**申请**（申请）和 **已禁止**（已禁止）。

**入口**（入口）会列出每个入口，并提供 **接受申请**（接受申请）开关；展开后可看到其设置、**申请问题**（申请问题）和 **申请面板**（申请面板）发布器。下表中的默认值适用于新建的入口。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| Locked channel（锁定频道） | 必填 | 设置门槛的频道 |
| How people get in（成员如何进入） | 授予他们一个身份组 | 身份组入口或直接入口 |
| Role granted on approval（通过后授予身份组） | 无 | 访问身份组，适用于身份组入口 |
| Approvals needed（所需通过票数） | 3 | 达到该票数即通过；0 表示禁用 |
| Denials needed（所需拒绝票数） | 3 | 达到该票数即拒绝；0 表示禁用 |
| Voting window (hours)（投票时间窗口，小时） | 72 | 过期规则执行前的时间；0 表示无限制 |
| When the window closes（时间窗口结束时） | 拒绝该申请 | 三种过期选项之一 |
| Review channel（审核频道） | 受限频道本身 | 申请发布以供投票的位置 |
| Log channel（日志频道） | 不记录日志 | 记录新申请和结果的位置 |
| Voter role（投票身份组） | 拥有访问身份组的所有人 | 将投票限制为某一身份组 |
| Ping role on new applications（新申请时提及身份组） | 不提及 | 申请到达时提及的身份组 |
| Min account age (days)（最短账号年龄，天） | 0 | 拒绝比该值更新的账号 |
| Min time in server (days)（最短加入服务器时间，天） | 0 | 拒绝加入时间比该值更短的成员 |
| Reapply cooldown (hours)（重新申请冷却时间，小时） | 168 | 拒绝或过期后再次申请前需等待的时间 |
| Offer an abstain button（提供弃权按钮） | 开 | 在审核消息中添加 Abstain 按钮 |
| Hide the applicant until the vote closes（在投票结束前隐藏申请者） | 关 | 待处理期间匿名显示申请者 |
| Hide who voted which way（隐藏每人的投票方向） | 关 | 投票明细仅对拥有管理身份组权限的人可见 |
| DM the applicant on a decision（决定后私信通知申请者） | 开 | 通过私信发送结果 |

**申请**（申请）标签页会按入口和状态筛选申请，并为待处理的申请显示投票统计以及 **批准** 和 **拒绝** 按钮。**已禁止**（已禁止）标签页会按范围列出被禁止的用户，并可以为某个入口或 **每个入口**（每个入口）禁止某人，同时可附带原因。

## 设置步骤

1. 在 Discord 中将频道设为私密；如果是身份组入口，请创建可以看到该频道的身份组。
2. 在仪表板中打开 **频道访问**（频道访问），使用 **为频道开放申请**（为频道开放申请）。选择 **锁定频道**（锁定频道），选择 **成员如何进入**（成员如何进入），并在需要时选择身份组。
3. 展开该入口。设置 **审核频道**（审核频道），使申请不会直接发到受限频道中；如果需要记录，还可以设置 **日志频道**（日志频道）。
4. 根据预期的投票人数，调整 **所需通过票数**（所需通过票数）、**所需拒绝票数**（所需拒绝票数）和 **Voting window**（投票时间窗口）。
5. 在 **申请问题**（申请问题）下最多添加五个问题。按需勾选 **必填**（必填）和 **多行回答**（多行回答）。
6. 在 **申请面板**（申请面板）下选择按钮的位置，然后点击 **发布面板**（发布面板）。
7. 用测试账号提交申请，由已有访问权限的成员投票，并确认申请者能够成功进入。

## 命令

请使用服务器的前缀运行这些命令（除非你更改过，否则为 `.`）。斜杠命令版本位于 `/channelaccess` 下。

| 命令 | 别名 | 所需权限 | 作用 |
| --- | --- | --- | --- |
| `channelaccesssetup <#channel> [@role]` | `casetup` | 管理身份组 | 创建入口；省略身份组则为直接入口 |
| `channelaccessremove <#channel>` | `caremove` | 管理身份组 | 删除入口及其问题和历史记录 |
| `channelaccesslist` | `calist` | 无 | 列出入口、阈值、时间窗口和状态 |
| `channelaccessconfig <#channel> [setting] [value]` | `caconfig` | 管理身份组 | 更改一项设置；不指定设置则显示列表 |
| `channelaccesspanel <#channel> [#target]` | `capanel` | 管理身份组 | 发布申请按钮，默认在当前频道 |
| `channelaccessquestionadd <#channel> <question>` | `caqadd` | 管理身份组 | 添加一个必填的多行问题 |
| `channelaccessquestionremove <#channel> <position>` | `caqremove` | 管理身份组 | 按列出的编号移除一个问题 |
| `channelaccessquestionlist <#channel>` | `caqlist` | 管理身份组 | 按顺序显示问题 |
| `channelaccessapply <#channel>` | `caapply` | 无 | 为自己发布申请按钮 |
| `channelaccesswithdraw <id>` | `cawithdraw` | 无 | 撤回自己未处理的申请 |
| `channelaccesshistory [@user]` | `cahistory` | 无 | 你的申请历史；查看其他用户需要管理身份组权限 |
| `channelaccesspending [#channel]` | `capending` | 无 | 列出未处理的申请，可选择某个入口 |
| `channelaccessapprove <id> [reason]` | `caapprove` | 管理身份组 | 无视投票直接通过 |
| `channelaccessdeny <id> [reason]` | `cadeny` | 管理身份组 | 无视投票直接拒绝 |
| `channelaccessblacklistadd <@user> [#channel]` | `cabladd` | 管理身份组 | 禁止某个入口的申请；不指定频道则禁止所有入口 |
| `channelaccessblacklistremove <@user> [#channel]` | `cablremove` | 管理身份组 | 解除禁止；需指定设置禁止时的同一频道 |
| `channelaccessblacklist` | `cablacklist` | 管理身份组 | 列出被禁止的用户 |

`channelaccessconfig` 接受的设置有 `enabled`、`approvals`、`denials`、`votehours`、`onexpiry`（`deny`、`majority`、`stayopen`）、`reviewchannel`、`logchannel`、`voterrole`、`pingrole`、`anonymousapplicant`、`anonymousvotes`、`allowabstain`、`minaccountage`、`minserverage`、`reapplycooldown` 和 `dmondecision`。

> [!EXAMPLE]
> `caconfig #inner-circle approvals 5`，然后 `caconfig #inner-circle onexpiry majority`。

## 技巧与注意事项

- 身份组入口需要机器人拥有管理身份组权限；直接入口需要管理频道权限（并能够编辑该频道的权限覆盖）。机器人的最高身份组必须高于访问身份组。
- 如果未设置 **审核频道**（审核频道），申请将发布在受限频道内。这适用于“由成员投票决定新人能否加入”的场景；如果希望由管理人员投票，请设置单独的频道。
- 通过命令添加的问题始终为必填和多行。如需将问题设为可选或单行，或为其添加占位提示，请使用仪表板。
- 删除入口会永久删除其问题、申请和投票。
- 成员在投票结束前离开服务器，即使获得通过也不会被授予访问权限。
- 只有通过和拒绝的结果会私信通知；已撤回的申请不会发送私信。
- 被禁止的用户必须以设置封禁时相同的范围解除封禁。服务器范围的封禁不会因指定频道的解除命令而解除。
