## 功能介绍

成就是成员通过使用你的服务器所达成的目标：发送第一条消息、累计 250 条消息、加入语音频道、用多种不同的表情做出反应、在服务器停留数月，或为服务器加成。每个成就都有一个等级，每个等级对应一定的点数，点数决定成员的成就等级。成员可以在个人资料卡片上佩戴最多四枚徽章，展示自己获得的成就。

开启成就功能后会立即统计历史数据。成员会静默地解锁其已存储的消息、语音时长、反应、邀请、等级以及在服务器中的停留时间所对应的全部成就，不会发送任何公告。

## 与 XP 的关系

成就和 XP 是两个独立运行的系统。两者互不依赖，关闭其中一个不会影响另一个。

| | XP | 成就 |
| --- | --- | --- |
| 获得方式 | 每条消息和每分钟语音 | 达成一次目标 |
| 提升方式 | 等级，按 XP 曲线计算 | 成就等级，从新人到冠军 |
| 衡量单位 | XP | 每次解锁的等级所对应的点数 |
| 奖励 | 等级身份组和货币 | 各成就对应的身份组、货币和 XP |

两者仅在以下两处相互连接：

1. **等级可以解锁成就。** “社区”分类中包含达到 XP 等级的成就，因此升级即可解锁它们。
2. **成就可以发放 XP（可选）。** 默认不发放任何奖励。你可以为单个成就设置 XP 奖励，或在 **设置** 标签页中设置 **每点数对应的 XP**，使每次解锁都根据其点数发放 XP。例如，黄金成就价值 50 点，若每点对应 2 XP，则可获得 100 XP。

成就等级并不等同于 XP 等级。一位成员可以是 40 级但处于青铜等级，也可以是 3 级但处于黄金等级，因为前者衡量的是其聊天量，后者衡量的是其完成过多少种不同的事项。

| 等级 | 点数 |

| 紫水晶 | 250 |

点数累计后会形成成就等级：

| 成就等级 | 所需点数 |

自定义成就可以使用任意等级，并可覆盖默认点数。

## 分类

内置成就分为“消息”、“语音”、“反应”、“邀请”、“命令”、“忠诚度”、“加成”和“社区”几个分类。你可以关闭整个分类，也可以添加自己的分类，并设置其名称、描述和图标。在 **分类** 标签页中拖动分类，即可更改成员在各处看到的顺序。

## 自定义成就

| 类型 | 解锁条件 |
| --- | --- |
| 目标 | 某个计数达到指定数值，例如 1000 条消息或在服务器中停留 30 天 |
| 短语 | 成员说出某个短语 |
| 反应 | 成员使用某个表情做出反应 |
| 手动 | 由工作人员发放 |

每个自定义成就都需要设置名称、描述、等级、图标（可以是表情符号、服务器表情、Font Awesome 图标或上传的图片），以及可选的奖励：身份组、货币和 XP。你可以将某个成就设为保密，在解锁之前隐藏其名称和目标。

## 公告

| 模式 | 解锁通知发送位置 |
| --- | --- |
| 自动 | 如果设置了日志频道则发送到日志频道，否则发送到事件发生的频道 |
| 此处 | 事件发生的频道 |
| 日志频道 | 仅发送到日志频道 |
| 仅私信 | 成员的私信 |
| 静默 | 不发送到任何地方 |

同时解锁的多个成就会共用一条消息。公告会附带一张使用服务器颜色的图片卡片。在频道中，公告默认会在 5 秒后自动删除，除非你选择更长的时间或“从不”。私信永远不会被删除。成员可以为自己关闭解锁私信、服务器消息和提及。

有两条规则可以防止解锁通知出现在不适合的频道中：

| 规则 | 作用 |
| --- | --- |
| 静默频道 | 你选择的频道，例如公告频道。成员仍会在这些频道中获得成就，但解锁通知永远不会发送到这些频道 |
| 仅在成员可发言的地方发送 | 默认开启。如果成员无法在某个频道中发送消息（例如其反应所在的只读频道），则不会在该频道发送解锁通知 |

当任一规则阻止了一条通知时，如果你设置了日志频道，解锁通知会发送到日志频道，否则直接跳过。日志频道本身永远不会被跳过。如果要让某个频道完全不计入统计，请改用 **设置** 标签页中的排除频道功能。

## 卡片

**卡片** 标签页是解锁图片的设计工具。你可以拖动并调整标题、图标、等级、进度、头像等元素，添加形状、文字、图片和图标，并使用服务器颜色作为令牌，使卡片能够跟随新的图标自动调整。每个服务器最多可保存二十个设计，可以将其中一个设为默认，并将其他设计分配给某个分类或单个成就。以最具体的设计为准。

## 成员设置

成员可以选择谁能查看其个人资料卡片、已解锁列表、徽章和排行榜位置，选择佩戴哪些徽章，以及希望如何接收通知。所有这些设置也位于 iOS 和 Android 应用的 **我** 标签页中。

## 小贴士与注意事项

- 奖励同样会发放给历史数据。如果你在开启成就功能之前设置了每点数 XP 或添加了奖励，首次扫描会为成员已获得的所有成就发放奖励。如果只想奖励新的解锁，请在开启后再进行设置。
- 成就带来的 XP 可能使成员升级，而新的等级又可能解锁等级成就，从而带来更多 XP。由于每个成就只能解锁一次，这一过程总会结束。
- 拥有被排除身份组的成员，或在被排除频道中活动的成员，将无法从中获得任何成就。
