## 功能介绍

嵌入构建器是一个可视化的 Discord 消息编辑器。你可以填写标题、描述、颜色、字段、图片，以及可选的按钮或选择菜单，实时查看预览，最后获得一段 JSON。这段 JSON 是机器人通用的消息格式。将它粘贴到 `say` 中即可发送，也可以保存为命名模板，或放入任何接受自定义消息的功能中，例如欢迎语、聊天触发器、AFK 回复、订阅更新，或抽奖的中奖私信。

模板可以是个人模板，即仅你自己可见，并适用于所有服务器；也可以与某个服务器共享，使任何工作人员都能加载。仪表板还可以直接将完成的消息发送到频道，也可以通过自定义名称和头像的 Webhook 发送，这种身份称为人设。

成员不会与构建器直接交互，他们只会看到它生成的消息。

## 为什么要使用它

- 撰写格式规范的规则或信息公告，之后可以使用 `edit` 进行更新。
- 设计一次欢迎消息，然后将 JSON 粘贴到欢迎语功能中。
- 保存一套公告模板，让工作人员发布外观一致的更新。
- 添加运行聊天触发器的按钮，或通过触发器分配身份组的选择菜单。
- 以自己的头像发布为“服务器新闻”，无需授予任何人 Webhook 权限。

## JSON 格式

解析器会查找文本中的第一个 `{`，并读取到与之匹配的 `}`。如果没有 JSON 对象，或者无法解析，则整段文本会被视为纯文本内容。属性名不区分大小写。

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `content` | 字符串 | 显示在嵌入上方的纯文本 |
| `embed` | 对象 | 单个嵌入。如果存在，将忽略 `embeds` |
| `embeds` | 数组 | 最多十个嵌入对象 |
| `components` | 数组 | 按钮和选择菜单 |

嵌入对象支持 `title`、`description`、`url`、`color`、`author`（`name`、`url`、`icon_url`）、`footer`（`text`、`icon_url`）、`thumbnail`（`url`）、`image`（`url`），以及 `fields`（包含 `name`、`value`、`inline` 的数组）。`color` 可以是数字，也可以是 `#5865F2` 这样的字符串。字段名称会被截断为 256 个字符，字段值则截断为 1024 个字符。任何不是完整绝对地址的 URL 都会被丢弃，而不会导致整条消息失败。`timestamp` 键可以被接受，但不会显示。

组件包含 `row`（所在的行）、`displayName`，以及链接按钮的 `url` 或绑定聊天触发器的按钮的 `id` 二者之一。`style` 取值为 1 到 4，对应 Discord 的四种按钮样式，`emoji` 可选。将 `isSelect` 设为 true 即表示选择菜单，然后提供 `options`（每项包含 `id`、`name`、`description`、`emoji`），以及取值范围为 0 到 25 的 `minOptions` 和 `maxOptions`。违反规则的组件会被渲染为禁用的红色按钮，其标签即为错误信息，便于你在 Discord 中查看问题所在。

> [!EXAMPLE]
> `{"content": "Welcome %user.mention%!", "embeds": [{"title": "Read the rules", "description": "See %channel.mention%", "color": "#57F287"}]}`

### 占位符

构建器中的 **%** 按钮可以插入占位符，占位符列表位于占位符页面（用户、服务器、频道、机器人、时间等）。仪表板本身不会替换占位符：从 **发送** 标签页发出的消息会保留占位符的原始文本。当 JSON 经过命令或功能处理时，机器人才会替换占位符，例如 `say`、`embedpreview`、欢迎语和触发器。每个功能还会在通用占位符之外添加自己的占位符，例如 `%afk.message%` 或 `%giveawayitem%`。

## 模板

模板由名称和 JSON 组成。共有两种范围。

| 范围 | 可见对象 | 创建方式 |
| --- | --- | --- |
| 个人 | 仅你自己，适用于任何服务器和私信 | `embedsave`，或在仪表板中点击 **保存** 且不勾选共享 |
| 服务器共享 | 在该服务器中有权限的任何人 | `guildembedsave`（需要 管理消息），或在仪表板中点击 **保存** 并勾选 **与服务器中所有人共享** |

同一范围内的名称必须唯一。`embedpreview <name>` 会先查找你的个人模板，再查找服务器的共享模板，替换占位符，然后在当前频道中发送。

某些命令可以接受模板引用来代替原始 JSON：将消息写为 `{template:name}` 或 `{t:name}` 即可。`multigreetmessage` 支持此功能。系统保存的是解析后的 JSON，而不是引用，因此之后对模板的修改不会更新已设置的欢迎语。

## 仪表板页面

页面标题为 **Discord 嵌入生成器**，包含六个标签页，并在旁边提供 **实时预览** 和 **问题** 面板。页面顶部有 **撤销**、**重做**、**取消编辑** 和 **复制 JSON** 按钮。

| 标签页 | 用途 |
| --- | --- |
| 模板 | 从模板库中选择起始模板，或选择 **从头开始** |
| 编辑器 | **消息内容** 以及最多十个嵌入。每个嵌入包含标题、描述、URL、颜色、作者、页脚、最多 25 个字段、缩略图和图片，并带有字符计数。 |
| 组件 | 最多五行、25 个组件。可添加按钮（文字、样式、表情符号、URL 或触发器）和选择菜单（占位文字、带触发器绑定的选项）。 |
| JSON | 原始数据。**从编辑器刷新** 会重新生成 JSON；**应用到编辑器** 会加载粘贴的 JSON，可以是完整数据，也可以是单个嵌入对象。 |
| 已保存 | 输入名称并勾选共享复选框后，点击 **保存当前嵌入**；列表包括 **服务器共享** 和 **我的嵌入**，每项都有 **加载** 和 **删除** 按钮 |
| 发送 | 选择频道，检查你在该频道的权限，可选择通过 Webhook 以人设或自定义名称和头像 URL 发送，然后点击 **发送消息** |

### 发送与人设

**发送** 标签页只会列出你和机器人都能发言的频道。发送嵌入需要你和机器人都拥有 嵌入链接 权限。如果你没有 提及 @everyone、@here 和所有身份组 权限，消息中的 everyone、here 和身份组提及会被移除，并且该标签页会给出警告。

通过 Webhook 发送需要你和机器人都拥有 管理 Webhook 权限。**人设** 是保存的名称和头像，可以是个人的，也可以与服务器共享；点击 **管理** 可打开人设列表。带有上传图片的人设会在每个频道中拥有自己的 Webhook，因此一个频道最多只能有十五个这样的人设。**自定义** 选项则需要填写显示名称和头像链接。每次发送都会记录到仪表板的审计日志中。

其他仪表板页面（如欢迎语、触发器等）中也会以弹窗形式打开同一个构建器，但只显示 **编辑器**、**组件**、**JSON** 和 **已保存** 标签页。

## 设置

构建器没有服务器设置，所有内容都针对单条消息或单个模板。

## 设置步骤

1. 在仪表板中打开 **嵌入**，选择一个模板或 **从头开始**。
2. 在 **编辑器** 中填写内容和嵌入。留意 **问题** 面板中 Discord 可能拒绝的内容。
3. 如有需要，在 **组件** 中添加按钮或菜单，并将每个按钮或菜单绑定到聊天触发器或 URL。
4. 进入 **已保存**，为其命名，如果希望工作人员使用，请勾选 **与服务器中所有人共享**，然后点击 **保存**。
5. 如需立即发送，打开 **发送**，选择频道，然后点击 **发送消息**。如需在其他功能中使用，请点击 **复制 JSON**，并粘贴到其他功能中。
6. 在 Discord 中，`embedpreview <name>` 会发送一个已保存的模板，并自动填入占位符。

## 命令

使用服务器的前缀运行这些命令（如果你未更改，则为 `.`）。

| 命令 | 别名 | 所需权限 | 用途 |
| --- | --- | --- | --- |
| `say [#channel] <text or JSON>` | | 管理消息 | 以机器人身份发送文本或嵌入 JSON，并替换占位符。`.txt` 附件也可以作为消息内容。 |
| `edit #channel <message id> <text or JSON>` | | 管理消息 | 替换机器人发送过的消息的内容 |
| `embedsave <name> <JSON>` | `esave` | 无 | 保存个人模板 |
| `embedlist` | `elist` | 无 | 列出你的个人模板 |
| `embeddelete <name>` | `edel`, `edelete` | 无 | 删除一个个人模板 |
| `guildembedsave <name> <JSON>` | `gesave`, `gembedsave` | 管理消息 | 保存与本服务器共享的模板 |
| `guildembedlist` | `gelist`, `gembedlist` | 无 | 列出服务器的共享模板 |
| `guildembeddelete <name>` | `gedel`, `gembeddelete` | 管理消息 | 删除一个共享模板 |
| `embedpreview <name>` | `epreview`, `eprev` | 无 | 在当前频道中发送已保存的模板 |

## 提示与注意事项

- `say` 会沿用你自己的提及权限：如果你没有 提及 @everyone、@here 和所有身份组 权限，机器人也不会替你提及所有人或身份组。
- 只有标题而没有其他内容的嵌入仍然可以发送，但仪表板会要求至少有标题、描述、字段或内容之一，才允许复制或发送。
- 绑定触发器的按钮只能在其引用的触发器 ID 所属的服务器中使用。在其他服务器中加载共享模板时，这些按钮会失效。
- 格式错误的图片、缩略图、作者和页脚 URL 会被静默丢弃。如果图片没有显示，请检查 URL 是否以 `https://` 开头。
- Discord 对每条消息的限制为十个嵌入、每个嵌入 25 个字段、五行组件，以及每行五个按钮。构建器也执行相同的数量限制。
- 删除人设不会删除它在各频道中创建的 Webhook。如有需要，请在频道的整合设置中手动清理。
