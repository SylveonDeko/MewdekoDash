## 功能简介

工作人员在仪表板上创建表单，包括名称、一组问题，以及关于谁可以回答和之后如何处理的规则。发布表单后会生成一个长期有效的分享链接。成员打开链接后使用 Discord 登录，逐页填写问题，检查回答并提交。他们输入时进度会自动保存为草稿，之后可以随时回来继续填写。

每份提交都会以嵌入消息的形式发送到你选择的频道。如果表单需要审核，嵌入消息上会附带 **批准** 和 **拒绝** 按钮。审核人员可以在 Discord 中点击按钮，也可以在仪表板的 **回复** 标签页中处理。提交者会收到一条私信，告知处理结果和备注，并且随时可以在状态页面上查看进度。

表单分为三种类型。普通表单面向成员。封禁申诉表单面向当前被封禁的人，批准后会解除其封禁。加入申请表单面向不在服务器中的人，批准后会发送一个一次性邀请，并在其加入时自动分配等待中的身份组。

表单没有文本命令或斜杠命令。除了两个审核按钮外，所有操作都在仪表板上完成。

## 适用场景

- 员工、合作伙伴或活动申请，使用正式的审核队列，而不是堆积在私信里。
- 封禁申诉流程，包含等待期、尝试次数限制，并在批准后自动解除封禁。
- 封闭式社区，申请人在收到邀请前需要经过审核。
- 反馈调查，设有回复数量上限并支持导出 CSV。

## 表单类型

| 类型 | 谁可以提交 | 批准后 |
| --- | --- | --- |
| 普通表单 | 成员；如果开启了 **允许服务器外的人员提交**，则任何人都可以提交 | 仅在已配置时更改身份组 |
| 封禁申诉 | 当前被服务器封禁的人 | 解除封禁 |
| 加入申请 | 不在服务器中的人 | 创建邀请；如果设置了 **加入时等待分配的身份组**，则会保存为身份组状态，在此人加入时自动分配 |

表单类型在创建后不可更改。封禁申诉和加入申请始终需要审核；普通表单仅在开启 **回答需要批准** 时才需要审核。

## 问题

在构建器的 **问题** 下添加问题。问题类型如下：

| 类型 | 回答形式 | 选项 |
| --- | --- | --- |
| 短文本 | 单行 | 最小和最大长度，最多 5000 |
| 长文本 | 多行 | 长度限制相同 |
| 单选 | 从列出的选项中选择一个 | 最多 25 个选项 |
| 复选框 | 选择多个选项 | 最多 25 个选项；**最小值** 和 **最大值** 用于限制可勾选的数量 |
| 下拉菜单 | 从列表中选择一个选项 | 最多 25 个选项 |
| 数字 | 一个数字 | 最小和最大值 |
| 电子邮件 | 有效的电子邮件地址 | |
| URL | `http` 或 `https` 地址 | |
| 分节符 | 无内容；开始新的一页，可包含标题和介绍 | |

问题文本最多 500 个字符，占位符最多 200 个字符，任何回答最多 4000 个字符。每个问题可以设置图片链接，也可以标记为必填。问题还可以设置为仅当之前的某个回答满足条件时才必填。

### 回答引用

为问题开启回答引用，然后在其文本或占位符中写入 `{{Q12}}`，其中 12 是之前某个问题的 ID。系统会插入该问题的回答，并截取到 100 个字符。如果该问题未被回答，则会改为显示方括号中的问题文本。问题只能引用其上方的问题。

### 条件

每个问题可以设置为仅当某个条件成立时才显示。被隐藏的问题会在页面中跳过，服务器也会丢弃为这些问题提交的回答。

| 条件类型 | 显示条件 |
| --- | --- |
| 基于回答 | 之前的某个回答满足：**等于**、**不等于**、**包含**、**大于** 或 **小于** |
| 基于身份组 | 成员拥有所选身份组中的 **任一满足**、**全部满足** 或 **均不满足** |
| 服务器时长 | 成员在服务器中的时间至少为 N 天，或其账号年龄至少为 N 天 |
| 助力/Nitro | 成员正在为服务器助力。Nitro 检查是根据头像和助力数据做出的推测。 |
| 基于权限 | 成员拥有所有所选权限 |
| 多个条件 | 组合多行条件。同一组中的行必须全部成立（且）；任一组成立即显示该问题（或）。 |

文本比较不区分大小写。Greater than 和 Less than 用于比较数字。

## 谁可以提交

表单会按以下顺序拒绝提交者，并给出原因：仍为草稿、未接受回复、尚未到达 **开放时间**、已超过 **关闭时间**、账号年龄小于 **最短 Discord 账号年龄**、**接受的回复总数** 上限已满、此人已回答且未开启多次回答、缺少 **提交所需身份组** 的身份组，最后是上述类型规则。

开启 **允许被拒绝的人再次尝试** 后，被拒绝的回复不再计为“已回答”。如果开启了 **需要验证码**，则会在审核步骤显示 Cloudflare Turnstile 验证。

封禁申诉还可以在 **申诉限制** 下设置额外限制：封禁后的等待时间（以封禁的审核日志条目为准）、最大申诉次数、两次申诉之间的冷却时间，以及 **一次拒绝即为最终结果**。尚未处理的申诉会阻止提交新的申诉。

## 填写表单

公开页面需要 Discord 登录。在最后一次按键后约一秒半，以及切换到下一页时，回答会自动保存为草稿。30 天内回到页面会恢复草稿，并显示“我们恢复了您已经填写的内容”横幅和 **重新开始** 按钮。

进度条会显示已回答的问题。最后一页以 **检查并继续** 结束，列出每个回答并附带 **编辑** 链接，然后是 **确认并提交**。提交后页面会显示你设置的 **提交后的提示信息**（或每种类型的默认提示）以及 **查看您的状态** 链接。状态页面还会链接到 `/forms/submissions` 处的 **我的提交**，其中列出已登录用户在各服务器中提交的所有非匿名回复。

在回复仍处于待处理状态、表单非匿名且尚未关闭时，提交者可以从状态页面编辑自己的回答。旧回答会保留为修订版本。提交者无法撤回回复。

## 提交时会发生什么

1. 授予 **提交时授予的身份组** 和 **等待审核时的身份组** 中的身份组。
2. 如果设置了 **回答发布位置**，则会在该频道发布一条嵌入消息，显示用户（或“Anonymous (login required)”）、时间，以及最多 20 个回答，并提醒 **收到回复时提醒** 中的身份组。表单审核时会附加 Approve 和 Reject 按钮。
3. 如果设置了 **发送至 Webhook**，则会将同一条嵌入消息发送到该 Webhook，且不附带按钮。之后回复被批准或拒绝时，结果、审核人和原因会以第二条消息的形式也发送到该 Webhook。该 URL 必须是 Discord Webhook；其他 URL 会被忽略，并在机器人日志中给出警告。Webhook 失败也不会阻止提交。
4. 回复会出现在 **回复** 标签页中，状态为待审核。

匿名表单不保存用户 ID，因此无法更改身份组，其回复也无法编辑。

## 审核流程

回复会从待审核变为已批准或已拒绝。**谁可以批准或拒绝** 用于指定一个身份组；拥有“管理服务器”或“管理员”权限的人始终可以做出决定。如果未设置审核身份组，则拥有批准身份组的人也可以做出决定。

在 Discord 中，**批准** 会立即生效。**拒绝** 会打开一个要求填写原因的弹窗，原因为必填，因为它会发送给提交者。无论哪种方式，嵌入消息都会更换颜色，新增 **已批准** 或 **已拒绝** 字段（包含审核人和时间）、原因（如有），并移除按钮。在仪表板上，则通过回复队列中的 **给提交者的备注** 文本框做出同样的决定。

做出决定后，机器人会：

- 添加和移除 **批准时添加**、**批准时移除**、**拒绝时添加** 和 **拒绝时移除** 中的身份组，并始终移除等待审核的身份组。如果某个身份组同时出现在两侧，则会被移除。
- 为获批的封禁申诉解除该用户的封禁，或为获批的加入申请创建邀请。
- 向提交者发送私信，内容为“Your response was approved”或“Your response was not accepted”，附带备注、批准时的 **提交后的提示信息**，以及邀请。如果私信发送失败，嵌入消息和队列中都会注明。

审核按钮的表情来源依次为：表单设置、**设置** 标签页中的 **服务器默认值**，最后是普通的勾号和叉号。

## 版本

每次保存表单都会保留一个版本，最多保留最近 20 个。**版本历史** 会显示每个版本，包括设置和问题的差异，并附带 **恢复** 按钮。恢复时会使用新的 ID 重新创建问题，并重写条件和回答引用以保持一致。

## 设置

**表单** 页面包含 **表单**、**创建** 和 **设置** 标签页，选中某个表单后还会显示 **编辑** 和 **回复**。创建和编辑标签页共用同一个设置面板。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 名称 | 空，必填 | 表单标题，最多 255 个字符 |
| 描述 | 空 | 显示在标题下方以及 Discord 链接预览中 |
| 回答发布位置 | 无 | 提交嵌入消息的频道；留空则回答仅保存在仪表板上 |
| 提交后的提示信息 | 无 | 确认页面和批准私信中的文本 |
| 草稿 | 新表单默认开启 | 草稿无法提交 |
| 接受回复 | 开启 | 关闭以停止收集而不删除表单 |
| 提交所需身份组 | 服务器中的任何人 | 按身份组限制 |
| 最短 Discord 账号年龄 | 无限制 | 天数 |
| 允许服务器外的人员提交 | 关闭 | 仅适用于普通表单 |
| 允许匿名提交 | 关闭 | 不记录提交者 |
| 开放时间、关闭时间 | 无 | 开放时间段；公布开放的通知需要设置开放时间 |
| 接受的回复总数 | 无限制 | 所有人的总数上限 |
| 允许每人提交多份回答 | 关闭 | |
| 允许被拒绝的人再次尝试 | 关闭 | |
| 需要验证码 | 关闭 | 在审核步骤显示 Turnstile 验证 |
| 开放公告所在频道、公告提醒、公告文本 | 无 | 开放通知嵌入消息，附带关闭倒计时，会在 **开放时间** 前后约一分钟内发送，或在发布时发送 |
| 收到回复时提醒 | 无 | 每次提交时提及的身份组 |
| 提交时授予的身份组 | 无 | 立即授予 |
| 等待审核时的身份组 | 无 | 做出决定后移除 |
| 发送至 Webhook | 无 | Discord Webhook URL，同时接收每条提交嵌入消息以及每次批准或拒绝的结果 |
| 回答需要批准 | 关闭 | 为普通表单增加审核步骤 |
| 谁可以批准或拒绝 | 仅管理服务器 | 审核身份组 |
| 批准按钮表情、拒绝按钮表情 | 服务器默认 | |
| 批准时添加/移除、拒绝时添加/移除 | 无 | 做出决定时的身份组变更 |
| 一次拒绝即为最终结果、封禁后等待、允许申诉、申诉间隔 | 关，无等待，不限次数，无等待 | 仅适用于封禁申诉 |
| 邀请可使用次数、邀请过期时间（秒）、加入时等待分配的身份组 | 1，86400，无 | 仅适用于加入申请 |

与表单类型不符的设置会在保存时被移除。

## 设置步骤

1. 在仪表板中打开 **表单**，然后点击 **创建**。
2. 选择 **表单类型**。之后无法更改。
3. 填写 **名称** 和 **描述**，并选择 **回答发布位置**。
4. 在 **问题** 下添加问题，标记必填项，并使用 **添加页面** 将较长的表单拆分为多页。
5. 设置谁可以提交；如果需要审核步骤，请开启 **回答需要批准** 并选择 **谁可以批准或拒绝**。
6. 点击 **保存表单**。可以在表单卡片上使用 **预览**，以管理员身份预览整个流程。
7. 在卡片上点击 **发布**，然后点击 **复制链接**，并将链接发布到申请人能找到的地方。
8. 查看 **回复** 标签页或提交频道，并处理每条回复。

## 命令

表单没有文本命令或斜杠命令。唯一的 Discord 交互是每条提交嵌入消息上的 **批准** 和 **拒绝** 按钮。

## 提示和注意事项

- 机器人需要“管理身份组”权限，并且其身份组必须位于表单授予或移除的每个身份组之上。位于机器人之上的身份组、受管理的身份组以及 everyone 会被静默跳过。
- 封禁申诉的“封禁后等待”检查需要“查看审核日志”权限。解除封禁需要“封禁成员”权限，加入申请的邀请需要在所有人可见的频道中具备“创建邀请”权限。
- 提交嵌入消息最多显示 20 个回答；完整回复请在仪表板中查看。
- **回复** 标签页中的 **导出 CSV** 会为每个问题生成一列，多选回答以分号分隔。
- 回复的筛选条件和页码都包含在 URL 中，因此你可以收藏“仅待审核”页面，并分享给审核人员。
- 草稿从不会被验证，因此恢复的草稿在提交时仍可能验证失败。
- 过期的表单会由每分钟运行一次的检查自动关闭；提交时也会再次检查资格，确保两次检查之间不会出现漏洞。
