## 功能介绍

员工粘贴直播 URL 并选择一个 Discord 频道。机器人随后会轮询该主播所在平台的状态，当直播从离线变为在线时，在所选频道中发布开播消息。默认情况下，这是一个嵌入，包含主播名称（链接到直播）、直播标题、游戏或分类、观看人数、主播头像以及预览图。

你可以用自己的消息替换默认嵌入。服务器范围内有一个全局模板，适用于所有关注的直播；每个直播也可以设置自己的开播消息和下播消息。所有这些消息都支持下方列出的 `%stream.*%` 占位符，并且可以是纯文本，也可以是在仪表板嵌入编辑器中构建的完整嵌入。

下播通知默认关闭。开启后，机器人还会在所关注的直播结束时发布消息：如果设置了该直播的下播消息则使用它，否则使用服务器模板，再否则使用显示“Offline”的默认嵌入。

> [!NOTE]
> 直播提醒会将其他人的直播推送到你的 Discord 中。独立的 Twitch Bot 功能则会将机器人连接到你自己的 Twitch 聊天，用于命令、定时器和事件。相关内容请参阅 Twitch Bot 文章。

## 为什么要使用它

- 社区服务器希望有一个“正在直播”频道，每当其中某位创作者开始直播时就会亮起提示。
- 主播自己的 Discord 希望自动发布带标题和分类的提醒，无需手动发帖。
- 电竞或赛事服务器希望在一个地方关注多个 Twitch 和 Kick 赛事频道。
- 服务器希望有一条清晰的“直播已结束”通知，使开播帖子不会显得过时。

## 支持的平台

机器人会根据你提供的 URL 选择平台。只有匹配以下格式之一的 URL 才能被关注。

| 平台 | URL 格式 | 说明 |
| --- | --- | --- |
| Twitch | `twitch.tv/username` | 使用 Twitch Helix API。标题、游戏、观看人数、头像和预览图均会填充。 |
| YouTube | `youtube.com/@handle` 或 `youtube.com/channel/ID` | 通过抓取频道的直播页面读取，因此数据可能不如 Twitch 完整。频道 ID 形式的 URL 会被转换为 handle。 |
| Kick | `kick.com/slug` | 使用 Kick 公开 API。头像占位符会填充为频道横幅图片。 |
| Picarto | `picarto.tv/name` | 使用 Picarto API。 |

Trovo 和 Facebook 会出现在仪表板的平台列表和已存储的数据中，但当前代码中没有可用的 Trovo URL 匹配器，也没有 Facebook 提供程序，因此尝试关注这些 URL 时会被拒绝。

## 检查机制

机器人为每个平台维护一个跟踪器，并在循环中向平台查询每个已关注频道的状态，每轮之间暂停三秒。直播第一次从离线被检测为在线时，即会发布开播通知。

下播的处理更为谨慎，因为 Twitch 有时会在直播过程中短暂报告离线。直播必须在连续两次检查中都被检测为离线，才会发送下播通知。如果期间它又恢复在线，则不会发布任何内容。

每三十分钟，机器人会查找平台查询已失败超过十二小时的直播（例如已删除或重命名的频道），并将其从所有关注它的服务器中移除。

如果某个已关注直播的通知频道已被删除，则下次有人运行 `streamlist` 时，该直播会被移除。

## 消息的发送方式

直播状态变化时，机器人会按以下顺序选择消息：

1. 直播自己设置的 **开播消息** 或 **下播消息**（与新状态对应的那个）。
2. 服务器范围的 **全局直播消息** 模板。
3. 内置嵌入。

不是有效嵌入 JSON 的单个直播消息，会以纯文本形式显示在内置嵌入上方发送。不是嵌入 JSON 的全局模板，则会以纯文本形式单独发送。有效的嵌入 JSON（即仪表板嵌入构建器生成的内容）会按设计原样发送，包括按钮。

内置嵌入的标题是主播名称（带链接），作者行显示直播标题，**状态** 字段显示“在线”或“离线”，**观众** 字段显示观看人数，**直播中** 字段显示游戏或分类，头像作为缩略图，预览图作为大图。直播中为绿色，离线时为红色。

### 占位符

直播消息中只会替换以下占位符。占位符页面中的通用服务器和用户占位符在此不可用。

| 占位符 | 值 |
| --- | --- |
| `%stream.name%` | 主播的显示名称，或 `Unknown` |
| `%stream.username%` | 主播的登录名或 handle |
| `%stream.url%` | 直播的直接链接，始终以 `https://` 开头 |
| `%stream.title%` | 当前直播标题，或 `No title` |
| `%stream.game%` | 游戏或分类，或 `No category` |
| `%stream.viewers%` | 带千位分隔符的观看人数，离线时为 `-` |
| `%stream.platform%` | 平台名称，例如 `Twitch` 或 `Youtube` |
| `%stream.avatar%` | 主播头像链接 |
| `%stream.preview%` | 直播预览图或缩略图链接 |
| `%stream.status%` | `Online` 或 `Offline`，前面各带一个彩色圆点 |
| `%stream.channelid%` | 平台特定的频道 ID（如果平台提供） |

> [!EXAMPLE]
> 一个简单的全局模板：`%stream.name% is live on %stream.platform% playing %stream.game%: %stream.title% %stream.url%`

## 设置

“直播通知”页面有四个标签页：**直播**、**关注直播**、**设置** 和 **统计**。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 通知频道 | 无 | 新直播的提醒发送到的频道，在 **关注直播** 中选择 |
| 直播 URL | 无 | 要关注的链接，在 **关注直播** 中填写 |
| 开播消息 | 无 | 直播开始时的单独消息，在 **直播** 中该直播的卡片上编辑 |
| 下播消息 | 无 | 直播结束时的单独消息，在同一卡片上编辑 |
| 全局直播消息 | 无 | 直播没有自己的消息时使用的服务器模板，在 **设置** 中配置 |
| 下播通知 | 关 | 关注的直播下播时机器人是否发送消息，在 **设置** 中配置 |

**直播** 会列出所有关注的直播，显示其平台、频道和添加日期；每张卡片上都有删除按钮，并提供 **全部清除** 按钮。**统计** 会显示直播总数、不重复主播数、已开启通知的频道数、正在使用的平台，以及按平台的细分。

每个服务器最多可以关注十个直播。添加第十一个会失败。

## 设置步骤

1. 在仪表板中打开 **直播提醒**，进入 **关注直播** 标签页。
2. 选择 **通知频道**，粘贴 **直播 URL**，然后点击 **关注直播**。
3. 在 **设置** 中，使用上面的占位符在嵌入编辑器中构建 **全局直播消息**，然后点击 **保存消息**。如果希望保留内置嵌入，可跳过此步骤。
4. 如果还希望发布“直播已结束”消息，请开启 **下播通知**。
5. 回到 **直播**，打开某个直播的卡片，如果它需要与全局模板不同的内容，可为其设置单独的 **开播消息** 或 **下播消息**。
6. 使用 `streamcheck <url>` 测试，确认机器人能够读取该直播，然后等待下一次开播。

## 命令

使用服务器的前缀运行这些命令（如果你未更改，则为 `.`）。

| 命令 | 别名 | 所需权限 | 用途 |
| --- | --- | --- | --- |
| `streamadd <url>` | `sta`, `stadd` | 管理消息 | 关注直播，并将其提醒发送到当前频道 |
| `streamremove <index>` | `strm` | 管理消息 | 取消关注 `streamlist` 中该位置的直播 |
| `streamsclear` | `stclear` | 管理员 | 取消关注服务器中的所有直播 |
| `streamlist` | `stl`, `streamslist` | 无 | 分页列出关注的直播及其编号、平台和频道 |
| `streamoffline` | `sto`, `stoff` | 管理消息 | 切换下播通知 |
| `streammessage <index> <message>` | `stm`, `stmsg` | 管理消息 | 设置直播的开播消息；留空则重置 |
| `streamofflinemessage <index> <message>` | `stofmsg`, `stoffline` | 管理消息 | 设置直播的下播消息；留空则重置 |
| `streamtemplate [template]` | `stt`, `sttemplate` | 管理消息 | 显示全局模板和占位符、设置新模板，或使用 `reset` 清除 |
| `streamcheck <url>` | `stc` | 无 | 报告直播当前是否在线及其观看人数 |

## 提示与注意事项

- `streamadd` 使用你运行该命令时所在的频道。如果想选择其他频道，请使用仪表板。
- 直播编号来自 `streamlist`，从 1 开始。删除直播后编号会变化，因此按编号删除前请先检查列表。
- 机器人需要在通知频道中拥有发送消息和嵌入链接权限。发送到其无法看到的频道的提醒会被跳过，并记录日志。
- 如果你的服务器已连接 Twitch Bot，并且为同一 Twitch 频道设置了开播频道，则由该集成接管，直播提醒不会对其发送内容，因此不会出现两条重复消息。
- YouTube 数据是通过抓取而非 API 读取的。标题、分类和观看人数可能缺失，或显示为 `Live Stream`。
- 查询持续失败十二小时的直播会被自动移除。如果主播重命名了频道，请关注新的 URL。
