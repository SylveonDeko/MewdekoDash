## 功能介绍

成员可以运行 `afk` 并附带可选消息。此后，每当有人提及他们，机器人都会在该频道中回复该消息以及对方已离开的时长。当成员回来时，状态会被清除，并发出一条简短的 "welcome back" 通知，该通知会在五秒后删除，同时昵称也会恢复。

成员离开期间，机器人还会尝试将其昵称改为 `[AFK] name`，并裁剪至 Discord 的昵称长度限制内，使状态在成员列表中可见。

不带消息运行 `afk` 会切换状态：如果你当前不在挂机状态，则会以空白消息开启挂机；如果已在挂机状态，则会关闭挂机。

## 使用场景

- 在繁忙的服务器中，成员不会再被那些没看到他们说“brb”的人反复提及。
- 管理人员可以一眼看出谁在线、谁不在。
- 定时挂机适用于“两小时后回来”这类场景，无需有人记得手动清除。

## 状态如何结束

**AFK 类型**决定机器人将何种行为视为回归。它是本页最重要的设置。

| 类型 | 状态清除时机 |
| --- | --- |
| 自行关闭 | 仅当成员再次运行 `afk`，或管理人员将其移除时。没有任何自动清除。 |
| 发送消息时 | 成员在服务器的任意位置发送消息时。 |
| 输入时 | 成员在任意频道开始输入时。 |
| 两者皆可 | 以先发生的消息或输入为准。 |

**AFK 超时**是从设置状态时开始计算的宽限期。在该时间窗口内，输入或发送消息不会清除状态，这样可以避免“afk, brb”这条消息本身立即结束挂机状态。默认值为 0，即没有宽限期；可以使用 `afktimeout` 命令设置，或在仪表板的 **高级设置** 标签页中设置。

定时挂机则不同：它会一直持续到计时结束，无论类型如何。期间的发言不会结束它。计时结束时，状态会被清除，昵称会恢复，但不会在频道中发出通知。

在消息发送后五分钟内编辑消息，与发送新消息的效果相同。

## 对提及的回复

当有人提及一位离开的成员时，机器人会检查每条消息中最多五位被提及的用户，忽略机器人和自我提及，忽略以命令前缀开头的消息，并跳过已禁用的频道。对于找到的每位离开成员，机器人都会发送一条回复。

默认回复为一个嵌入消息：作者行显示 "user is currently away" 及其头像，描述为其挂机消息，页脚显示其离开的时长。如果机器人配置了显示邀请按钮，则会附带该按钮。

你可以使用 `customafkmessage` 命令或仪表板中的 **自定义 AFK 嵌入消息** 编辑器，将其替换为你自己的消息或嵌入消息。文本会经过嵌入解析器处理，因此嵌入构建器生成的任何内容都可以使用。将其设置为 `-` 可恢复为默认嵌入消息。

### 占位符

这些占位符会在自定义 AFK 消息中被替换。占位符页面中的通用占位符在此不可用，仅可使用以下这一组。

| 占位符 | 值 |
| --- | --- |
| `%afk.message%` | 挂机消息，已将提及内容无效化，并截断至最大长度 |
| `%afk.user%` | 离开成员的用户名 |
| `%afk.user.mention%` | 离开成员的提及 |
| `%afk.user.avatar%` | 离开成员的头像 URL |
| `%afk.user.id%` | 离开成员的用户 ID |
| `%afk.triggeruser%` | 提及他们的人的用户名 |
| `%afk.triggeruser.mention%` | 提及他们的人的提及 |
| `%afk.triggeruser.avatar%` | 提及他们的人的头像 URL |
| `%afk.triggeruser.id%` | 提及他们的人的用户 ID |
| `%afk.time%` | 已离开的时长，以“2 hours”等文字表示 |

> [!EXAMPLE]
> 纯文本回复：`%afk.user.mention% is away (%afk.time%): %afk.message%`

## 设置

以下所有设置都位于挂机系统页面的 **基础设置** 和 **高级设置** 标签页下。

| 设置 | 默认值 | 控制内容 |
| --- | --- | --- |
| 自动删除时间 | 0（从不） | 机器人对提及的回复在多少秒后自行删除 |
| 最大消息长度 | 128 | 成员可设置的最长挂机消息，范围为 1 至 4096；超出长度的消息会被拒绝 |
| AFK 类型 | 自行关闭 | 上述四种类型之一 |
| AFK 超时 | 0（无） | 设置挂机后的宽限期，最长两小时 |
| 已禁用的频道 | 无 | 在这些频道中提及离开成员将不会收到回复 |
| 自定义 AFK 嵌入 | 默认嵌入消息 | 你自己的回复内容，可使用上述占位符 |

> [!TIP]
> 建议将自动删除时间设置为三十秒左右。提及者仍能看到回复，同时频道也不会因过期的挂机通知而变得杂乱。

**用户管理** 标签页会列出当前所有离开的成员，并允许管理人员为一位或多位成员同时清除状态。

## 设置示例

1. 在仪表板中打开 **挂机系统**。
2. 选择 **AFK 类型**。“发送消息时”是最安全的默认值；“两者皆可”最为便捷。
3. 将 **自动删除时间** 设置为 30。除非你希望状态更长，否则将 **最大消息长度** 保持为 128。
4. 在 **高级设置** 中，将机器人命令频道和公告频道添加到 **已禁用的频道**。
5. 可选地使用上述占位符，在嵌入编辑器中构建自定义回复。
6. 进行测试：运行 `afk testing`，用另一个账号提及你自己，然后发送一条消息，观察状态是否被清除。

## 命令

请使用服务器的前缀执行以下命令（除非你修改过，默认为 `.`）。

| 命令 | 别名 | 所需权限 | 用途 |
| --- | --- | --- | --- |
| `afk [message]` | | 无 | 设置你的挂机消息，或在不带消息时切换挂机的开启与关闭 |
| `timedafk <time> <message>` | `tafk` | 无 | 会自行结束的挂机，例如 `timedafk 2h dinner` |
| `getactiveafks` | `activeafks` | 无 | 列出当前所有挂机的成员 |
| `afkview [@user]` | `viewafk` | 管理消息 | 显示某位成员当前的挂机消息 |
| `afkremove @user...` | `afkrm` | 管理消息 | 清除一位或多位成员的状态 |
| `afkdel [seconds]` | `afkdelete` | 管理服务器 | 显示或设置回复的自动删除时间 |
| `afklength <number>` | `maxafklength` | 管理员 | 限制挂机消息的长度 |
| `afktype <type>` | | 管理员 | `selfdisable`、`onmessage`、`ontype` 或 `either` |
| `afktimeout <time>` | | 管理员 | 设置宽限期，例如 `30s` |
| `afkdisable #channel...` | | 管理频道 | 将频道添加到不回复名单 |
| `afkundisable #channel...` | | 管理频道 | 将频道从不回复名单中移除 |
| `afkdisabledlist` | | 管理频道 | 显示不回复名单 |
| `customafkmessage <text>` | `afkmessage` | 管理员 | 设置自定义回复，或使用 `-` 重置 |

## 小贴士与注意事项

- 没有命令可以只清除你自己的状态。请再次运行不带消息的 `afk`，或等待类型规则将其清除。
- 修改昵称需要机器人的身份组位于成员最高身份组之上，并且拥有“管理昵称”权限。服务器所有者的昵称永远无法由机器人修改，因此所有者会保留原有名称，但状态依然有效。
- 挂机服务会在机器人启动后不久加载其缓存。在此之前，命令会回复 AFK 仍在启动中。
- 挂机消息中的提及在回复中会被无效化，因此成员无法借助其状态来提及身份组或 everyone。
