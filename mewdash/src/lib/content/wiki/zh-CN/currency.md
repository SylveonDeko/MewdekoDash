## 功能介绍

每位成员都有一个钱包；如果你开启了银行功能，每位成员还会有一个银行余额。成员可以通过领取每日奖励、在冷却时间后执行 `work` 和 `crime`、赢得游戏或收到其他成员的转账来获得货币。他们可以在你的商店中用货币购买身份组、收藏品或文字物品，也可以在二十一点、轮盘、老虎机、Crash 和基诺等游戏中下注。

员工可以决定经济系统的运行方式：是否开启赌博、下注上下限、庄家优势、工作和犯罪的收益、是否允许抢劫、转账税、银行利息以及每日连续签到奖励。这些选项都位于 **配置** 标签页中，或可通过 `economyset` 命令的键进行设置，无需修改游戏本身即可调整经济。

机器人会将每一笔收入和支出记录为一条交易，因此成员可以查看自己的钱花在了哪里。**分析** 标签页则会显示货币供应量、货币的分布情况，以及哪些游戏的支出超过了收入。

## 为什么要使用它

- 让活跃成员有地方花掉他们的积分，例如彩色身份组、自定义头衔，或游戏频道中的一点乐趣。
- 通过设置下注上限、每日亏损上限和庄家优势，确保游戏频道保持公平。
- 使用 `modifybalance` 或 **调整余额** 工具奖励帮助过社区的成员，并让他们在商店中自由选择。
- 查看 **游戏表现** 表格，了解每个游戏的实际返还率，并依据数据而非猜测来调整 `payoutmultiplier`。

## 余额、银行与转账

`cash` 显示你的钱包余额；如果你有银行存款，还会显示银行余额和总资产。`bank` 可以查看任何成员的余额，并领取其应得的利息。`deposit` 和 `withdraw` 用于在钱包与银行之间转移货币，两者都支持 `all` 作为金额。存入银行的货币无法被抢劫，**银行容量** 用于限制可存入的最大金额（0 表示不限）。

利息会在成员执行 `bank` 时发放：如果距离上次发放利息的时间已超过设定的间隔，银行余额将按 **利息（%）** 获得一次利息。如果没有人查询，利息就不会发放。

`pay` 会将钱包中的货币转给其他成员，并扣除 **转账税（%）**，同时受 **最低转账额** 和可选冷却时间限制。机器人无法接收转账。

`transactions` 可查看你或其他成员最近的 250 条记录，每页 10 条。`cashleaderboard` 则按钱包加银行的总额对成员进行排名。

## 赚取货币

| 命令 | 默认值 | 说明 |
| --- | --- | --- |
| `dailyreward` | 员工执行 `setdaily` 前未设置 | 每个冷却周期发放一次每日奖励。开启连续签到后，每次连续领取都会额外增加 **每日奖励** 乘以超出第一天的连续天数，并受 **最高奖励** 限制。错过一个完整的冷却周期会重置连续天数。 |
| `work` | 50 至 250，每 30 分钟一次 | 在设定范围内随机发放收益，必定成功。 |
| `crime` | 200 至 800，成功率 45%，每小时一次 | 成功时按犯罪收益范围发放；失败时罚款 100 至 500，且最多扣至钱包中的余额。 |
| `rob @user` | 关闭 | 开启后：有 35% 的几率抢走目标钱包中最多 20% 的货币。钱包中少于 100 的目标受保护。失败时会损失自己钱包中的 15%。每小时只能尝试一次。 |

## 游戏

每次下注都会经过相同的检查：必须开启赌博、下注额需在 **最低下注** 与 **最高下注** 之间、成员在过去 24 小时内未触发 **每日亏损上限**，并且（如设置了）游戏冷却时间已结束。赌注会预先扣除。赢得的金额为 `stake plus profit`（赌注加利润），其中利润部分会乘以 **赔付倍率**。例如，倍率为 0.9 会使每次获胜的利润缩水 10%，而平局时仍会全额退还赌注。

| 游戏 | 赔付方式 |
| --- | --- |
| `coinflip <bet> heads/tails` | 猜对即按 1 赔 1 |
| `highlow higher/lower [bet]` | 显示一个 1 至 10 的数字，猜下一个数字的大小。按 1 赔 1，数字相同则退还赌注。默认下注 100 |
| `spinwheel [bet]` | 加权转盘，各区间收益从下注额的负 10% 到正 30% 不等。默认下注 10 |
| `blackjack <bet>`，然后使用 `hit` 和 `stand` | 庄家会摸牌至 17 点。获胜按 1 赔 1，平局则退还赌注 |
| `slot [bet]` | 两个相同图案赔 2 倍。三个相同图案赔 3 倍，葡萄 5 倍，七 7 倍，钻石 10 倍。默认下注 10 |
| `roulette <bet> <type>` | 押中 0 至 36 中的一个数字赔 35 倍。`red`、`black`、`even` 或 `odd` 按 1 赔 1；押颜色和单双时若结果为零，则输掉赌注 |
| `rps <choice> [bet]` | 与机器人进行石头、剪刀、布、蜥蜴、斯波克的对决。按 1 赔 1，平局退还。下注可选 |
| `war <bet>` | 大牌获胜，按 1 赔 1。平局时需追加一份赌注，再多翻一张牌，赔率翻倍 |
| `craps <bet> [pass/dontpass/field/any]` | Pass 与 Don't Pass 按点数规则以 1 赔 1 结算。Field 赔 1 倍，若开出 2 或 12 则赔 2 倍。Any Seven 赔 4 倍 |
| `scratchcard [bronze/silver/gold/diamond]` | 固定费用的刮刮卡，价格分别为 10、50、200 或 1000，中奖率分别为 30%、25%、20% 和 15%，奖金范围最高分别为 50、200、1000 和 5000 |
| `russianroulette <bet> [bullets]` | 六个弹膛中装有一至五颗子弹。存活后按子弹数量获得 1.2 倍、1.5 倍、2 倍、3 倍或 5 倍的利润 |
| `baccarat <bet> [player/banker/tie]` | 押闲家或庄家赔 1.95 倍，押和局赔 8 倍 |
| `minesweeper <bet> [small/medium/large]` | 存活率分别为 70%、60% 或 50%，对应赔率为 1.5 倍、2.5 倍或 4 倍 |
| `lottery [tickets]` | 每张彩票 50，最多 10 张。买得越多，中奖率（最高 40%）和奖金倍率就越高 |
| `crash <bet> [target]` | 选择 1.1 倍至 10 倍之间的兑现目标。如果爆炸点不低于该目标，即可赢得目标倍率 |
| `keno <bet> <numbers>` | 从 1 至 80 中选择 1 至 10 个数字，开出 20 个号码。奖金从猜中一个赔 3 倍，到五个全中赔 800 倍不等 |
| `plinko <bet> [rows]` | 5 至 10 行。落在中心赔 0.5 倍，落在边缘最高赔 10 倍 |
| `wheelfortune <bet> [classic/risky/balanced]` | 倍率转盘。风险型的倍率范围从 0.1 倍到 20 倍 |
| `duckrace <bet>` | 五只鸭子，你的鸭子随机分配。第一名赔 4 倍，第二名 2 倍，第三名 1.2 倍 |
| `bingo <bet> [small/large]` | 40% 的几率赔 2 倍，或 25% 的几率赔 3.5 倍 |
| `diceduel @user <bet>` | 对手会看到接受与拒绝按钮；双方都必须能够承担赌注 |
| `memory <bet> [easy/medium/hard]` | 按顺序复述 4、6 或 8 个图案，分别赔 1.5 倍、2 倍或 3 倍 |
| `horserace <bet>` | 十秒内最多可有十名成员加入；空位由 AI 赛马补齐。奖池的 50%、30% 和 20% 分别发放给前三名 |
| `triviachain <bet> [category]` | 连续回答 OpenTDB 的问题；每答对一题，倍率增加 0.5 倍。分类包括：general、science、history、sports、entertainment |

> [!NOTE]
> `horserace` 接受任何大于零的下注：它直接收取赌注，不受共享下注上下限或赔付倍率的限制。

## 每日挑战

每位成员每天都会获得一个随机挑战：玩五局游戏、赢得三局、花费 500、赚取 300，或某个指定游戏玩三次。奖励为基础金额加上最多 50 的额外奖励。`dailychallenge` 用于查看挑战，`claimchallenge` 用于领取奖励，`challengeleaderboard` 则按过去 30 天内完成的挑战数对前十名进行排名。

> [!WARNING]
> 目前游戏不会向挑战追踪器上报进度，因此挑战进度始终显示为 0，暂时无法领取。

## 商店

物品可以在 **商店** 标签页中添加，也可以通过 `shopadditem` 和 `shopaddrole` 添加。每个物品都有 **名称**、**价格**、**描述**、**类型**、**库存**（留空或填 -1 表示不限）、**每位用户的限购数量**、可选的 **所需身份组**（购买者必须拥有该身份组）以及 **排序**。

| 类型 | 购买后 |
| --- | --- |
| 身份组 | 机器人会为购买者添加该身份组。默认每位成员限购一个。 |
| 收藏品 | 进入购买者的库存；属于消耗品，因此使用 `use` 会移除一个。 |
| 文字 | **发送的文字** 会通过私信发送给购买者，使用 `use` 时会再次发送。 |

`buy <name>` 会检查物品是否启用、购买者是否拥有所需身份组、库存是否充足、是否负担得起，以及是否未超过每位用户的限购数量。付款后若出现任何失败，都会自动退款。`inventory` 可列出成员拥有的物品。`shoptoggle` 会隐藏物品但不会删除已售出的副本；`shopremove` 则会删除该物品及所有副本。

## 设置

仪表板共有四个标签页：**分析**、**配置**、**商店** 和 **排行榜**。**排行榜** 标签页还包含 **调整余额**，可为成员增加或扣除货币，并在账本中记录原因。

| 设置 | 默认值 | 控制内容 |
| --- | --- | --- |
| 启用赌博 | 开启 | 开启或关闭所有下注类游戏 |
| 最低下注 | 1 | 最小赌注 |
| 最高下注 | 0（不限） | 最大赌注 |
| 赔付倍率 | 1.0 | 仅缩放赢得的部分，范围 0.1 至 5.0 |
| 每日亏损上限 | 0（关闭） | 成员在 24 小时内亏损达到此金额后将被限制下注 |
| 游戏冷却时间（秒） | 0 | 每位成员两次下注之间的间隔秒数 |
| 启用工作 | 开启 | `work` 命令 |
| 工作收入下限 / 上限 | 50 / 250 | 工作收益范围 |
| 工作冷却时间 | 1800 秒 | `workcooldown`，仅限命令设置 |
| 启用犯罪 | 开启 | `crime` 命令 |
| 犯罪收益下限 / 上限 | 200 / 800 | 犯罪收益范围 |
| 犯罪成功率（%） | 45 | 犯罪获得收益的几率 |
| 犯罪罚款下限 / 上限 | 100 / 500 | 失败时的罚款金额 |
| 犯罪冷却时间 | 3600 秒 | `crimecooldown`，仅限命令设置 |
| 启用银行 | 开启 | `bank`、`deposit`、`withdraw` |
| 银行容量 | 0（不限） | 成员最多可存入银行的金额 |
| 利息（%） | 0 | 每个间隔按银行余额发放的利息 |
| 利息结算间隔（小时） | 24 | 利息可领取的频率 |
| 启用转账 | 开启 | `pay` 命令 |
| 转账税（%） | 0 | 从每笔转账中扣除的比例 |
| 最低转账额 | 1 | 最小转账金额 |
| 转账冷却时间 | 0 | `paycooldown`，仅限命令设置 |
| 启用抢劫 | 关闭 | `rob` 命令 |
| 成功率（%） | 35 | 抢劫成功的几率 |
| 最高偷取比例（%） | 20 | 抢劫成功时可从目标钱包中夺取的比例 |
| 失败罚款（%） | 15 | 抢劫失败时抢劫者钱包损失的比例 |
| 保护线以下 | 100 | 低于此金额的目标无法被抢劫 |
| 抢劫冷却时间 | 3600 秒 | `robcooldown`，仅限命令设置 |
| 启用连续签到 | 开启 | 连续领取每日奖励可获得额外奖励 |
| 每日奖励 | 0 | 每超出第一天的连续签到天数所增加的金额 |
| 最高奖励 | 0（不限） | 连续签到奖励的上限 |

每日奖励的金额和冷却时间通过 `setdaily` 设置，不能在仪表板中修改。`economyconfig` 会列出所有键及其当前值，`economyreset` 则会将全部设置恢复为默认值。

## 设置流程

1. 运行 `setdaily 500 24h`，让成员有奖励可以领取。
2. 打开仪表板中的 **货币**，进入 **配置**。在开设游戏频道之前，先设置 **最高下注** 和 **每日亏损上限**。
3. 只有在成员接受失去钱包中的货币时，才开启 **启用抢劫**；保持银行开启，以便成员保护自己的存款。
4. 在 **商店** 中添加几个身份组物品和一个收藏品。对于仅限成员购买的物品，请设置 **所需身份组**。
5. 使用 **调整余额** 或 `modifybalance` 为部分成员设置初始余额。
6. 一周后检查 **分析**，如果游戏的赔付超过了收入，请降低 **赔付倍率**。

## 小贴士与注意事项

- 请先设置 **最高下注**。如果保持为 0，一位运气好的成员可能在一下午内耗尽整个经济系统。
- 每日亏损上限统计的是过去 24 小时内的净亏损，因此提前获胜的成员可以玩得更久。
- 身份组物品要求机器人的最高身份组高于要出售的身份组，并拥有管理身份组权限；否则付款后购买会因身份组授予错误而失败。
- 文字物品和 `use` 会通过私信发送内容；若成员关闭了私信，会看到错误提示，但仍然拥有该物品。
- 二十一点每位成员只在内存中保留一局游戏；只有在执行 `blackjack` 之后，`hit` 和 `stand` 才能使用。
- 赛马会等待十秒让其他成员加入，然后由 AI 赛马补齐队伍并开始比赛。
- 问答连锁游戏在十分钟无操作后会超时，且每位成员同时只能进行一局。
- 当机器人以全局货币模式运行时，余额在所有服务器之间共享，且 `modifybalance` 仅限机器人所有者使用。
