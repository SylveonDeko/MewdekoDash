## 功能简介

身份组菜单是频道中的一条消息，下方带有一个**下拉菜单**或一排**按钮**。每个选项对应一个身份组。成员选择某个选项即可获得该身份组，再次选择则会移除。这样，服务器可以让成员自行选择代词、颜色、提醒或地区，而无需请工作人员处理。

每个菜单都有名称（仅工作人员可见，并作为默认消息的标题）、频道、消息，以及最多 25 个选项。每个选项包括一个身份组、菜单上显示的名称、可选的表情和可选的描述。描述会显示在每个下拉选项下方以及默认消息中。按钮还可以设置颜色：蓝紫色、灰色、绿色或红色。

消息可以是嵌入构建器能生成的任何内容：纯文字、一个或多个嵌入，或两者兼有。如果留空，机器人会发布菜单的名称，并为每个选项列出一行。

## 可多选或单选

- **可多选** 允许成员分别开启或关闭每个身份组。两个限制决定他们最多可以持有多少：**至少需保留** 会阻止成员在选定后数量低于某个数字，**最多可持有** 则限制他们从该菜单中可拥有的数量（默认无限制）。
- **单选** 会替换身份组：选择新选项时，会移除他们原先的选项。开启 **选定后保留一个** 后，成员可以切换，但不能清除已选的内容。

## 限制

| 限制 | 值 |
| --- | --- |
| 每个服务器的菜单数 | 50 |
| 每个菜单的选项数 | 25 |
| 每行按钮数 | 5 |
| 菜单名称 | 100 个字符 |
| 菜单上的名称 | 80 个字符 |
| 描述 | 100 个字符 |
| 下拉菜单提示文字 | 150 个字符 |
| 纯文字消息 | 2000 个字符 |

每个身份组在同一菜单中只能出现一次。机器人只能分配低于其自身最高身份组、且未被任何集成管理的身份组；工作人员只能提供低于其自身最高身份组的身份组。

## 所需身份组

菜单可以要求一个身份组。没有该身份组的成员会收到一条私密提示，告知他们需要该身份组，且不会有任何变更。

## 确认

开启 **告知成员具体更改** 后，成员会收到一条只有他们自己可见的私密提示，列出新增和移除的身份组。关闭此项时，菜单会静默运行；但如果出现问题，例如达到限制或机器人无法分配某个身份组，成员仍会收到一条私密提示。

## 编辑、暂停与重新发布

保存编辑会在原位重建同一条消息。只有在频道更改或原消息已不存在时，才会发布新消息。

**暂停** 会使 Discord 中的下拉菜单或按钮变灰，直到菜单恢复。**重新发布** 会发布一份新副本并删除旧消息，适用于菜单已滚动到视线之外或被手动删除的情况。如果菜单所在的频道被删除，请编辑菜单，选择新频道并保存，即可重新发布。

删除菜单也会删除其消息。成员已选择的身份组会保留。

## 迁移旧设置

较早的表情身份组设置需要成员在某条消息下添加表情以获得身份组。**迁移旧设置** 标签页会列出这些设置。迁移某个设置会创建一个身份组菜单，包含相同的身份组和表情，可选择下拉菜单或按钮形式，并可放在原频道或其他频道。它可以复制旧消息的文字和嵌入内容，还可以停用旧设置，即停止它并清除其表情。如果原消息由机器人发布，停用时会删除该消息。原本只允许成员持有一个身份组的设置，会变为单选菜单。

## 命令

| 命令 | 作用 |
| --- | --- |
| `rolemenus` | 列出每个菜单，包括其频道、类型、选项数量和状态。 |
| `rolemenuinfo 3` | 显示某个菜单的全部信息。 |
| `rolemenucreate #roles dropdown @Role @Role` | 发布一个新菜单，每个身份组对应一个选项。 |
| `rolemenuadd 3 @Role [emoji] [name]` | 向菜单添加一个身份组。 |
| `rolemenuremove 3 @Role` | 从菜单中移除一个身份组。 |
| `rolemenuname 3 Pronouns` | 重命名菜单。 |
| `rolemenumessage 3 [message\|clear]` | 显示、设置或清除菜单上方的消息。 |
| `rolemenustyle 3 dropdown\|buttons` | 在下拉菜单和按钮之间切换。 |
| `rolemenumode 3 multi\|exclusive` | 在可多选和单选之间切换。 |
| `rolemenulimits 3 0 2` | 设置成员必须保留和最多可持有的身份组数量。 |
| `rolemenurequire 3 [@Role]` | 设置或清除所需身份组。 |
| `rolemenureply 3 private\|silent` | 开启或关闭私密提示。 |
| `rolemenupause 3` | 暂停菜单；若已暂停则恢复。 |
| `rolemenurepost 3 [#channel]` | 发布一份新副本并删除旧消息。 |
| `rolemenudelete 3` | 删除菜单及其消息。 |
| `rolemenuimport messageId [dropdown\|buttons]` | 将较早的表情身份组设置迁移到新菜单。 |
