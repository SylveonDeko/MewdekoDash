## 功能简介

仪表板发送给机器人的每一个与你服务器相关的请求，都会记录在登录的 Discord 账号名下。审核日志页面会将这些记录整理为时间线：谁打开了经验值设置、谁编辑了欢迎消息、谁删除了聊天触发器，以及修改前后的具体数值。

它独立于 Discord 自身的审核日志，也独立于日志功能。Discord 的日志记录的是在 Discord 内部发生的操作。Mewdeko 的日志功能会将加入、编辑和身份组变更等服务器事件发布到你选择的频道。仪表板的审核日志则只记录仪表板中的操作。

无需任何开启步骤。当有人登录仪表板并打开你的服务器时，记录便会开始写入，并在九十天后过期。

## 适用场景

- 有多人拥有仪表板访问权限，而你想知道上周是谁关闭了反突袭防护。
- 某项设置被更改，但没有人承认。
- 在将仪表板访问权限交给更大范围的工作人员之前，你希望留下可追溯的记录。
- 你需要确认你请别人做的更改确实已经完成，并且它替换了什么内容。

## 记录内容

每条记录包含：

- **时间**：请求发出的时间，以 UTC 存储，并在页面上以你所在的时区显示。
- **用户**：从仪表板登录信息中获取的 Discord 用户名和 ID，而非用户输入的任何内容。
- **操作**：下表中的一种操作。
- **分区**：仪表板的功能区域，以易读的名称显示，例如 "AFK System"、"Triggers" 或 "Protection"。
- **端点**：确切的请求，例如 `PUT Afk/123/settings`，显示在分区名称下方的小字中。
- **更改内容**：对于查看以外的操作，显示被发送或更改的值。点击 **详情** 即可展开查看。

机器人还会为每条记录存储浏览器的用户代理字符串。

### 操作

操作类型由仪表板所发出请求的类型决定。

| 操作 | 记录时机 |
| --- | --- |
| 查看 | 仪表板读取了数据（GET 请求）。每次加载页面都会产生此类记录。 |
| 创建 | 添加了内容（POST 请求）。 |
| 更新 | 修改了已有内容（PUT 或 PATCH 请求）。 |
| 删除 | 移除了内容（DELETE 请求）。 |
| 访问 | 为仪表板会话开始保留。筛选器中提供此项，但当前版本从不写入此操作的记录。 |

### 变更集

查看操作不存储更改数据。对于其他所有操作，机器人会存储以下两种文档之一：

- **修改前后对比**：当仪表板分区在更改设置前对其进行了快照，记录只列出发生变化的字段，并显示每个字段的旧值和新值。大多数设置页面都采用这种方式。
- **请求内容**：当没有进行快照时，记录会保存仪表板所发送的内容，但没有旧值。

名称中包含 `token`、`secret`、`password`、`apikey`、`api_key`、`authorization` 或 `clientsecret` 的任何字段，在存储前都会被替换为 `[redacted]`，因此凭据不会被写入日志。

在页面上，布尔值显示为 开 和 关，列表显示为 "3 items"，空字符串显示为 "empty"，缺失的值显示为 "none"。字段名称会被转换为易读的标签。

> [!NOTE]
> "查看" 记录是日志中的大多数，因为每个仪表板页面在打开时都会读取设置。如果你在查找更改，请按 创建、更新 或 删除 进行筛选。

### 不记录的内容

- 在 Discord 中执行的命令操作。这些操作会显示在 Discord 的审核日志中（如果机器人执行了相应操作），并在已配置的日志功能中显示。
- 未关联已登录仪表板用户的请求。
- 打开审核日志页面本身、留下反馈、以及一些基础设施和轮询端点，例如机器人状态、性能、系统信息和实例管理。
- 一些被明确排除的端点：提供给嵌入构建器的人设头像图片、设置向导的“是否应显示”检查，以及仪表板页面浏览信标。

## 阅读页面

在仪表板中，打开 **安全** 分类下的 **审核日志**。列表按最新优先显示记录，每页五十条，并提供 **上一页** 和 **下一页** 按钮，以及记录总数。

列表上方有两个筛选器：

| 筛选器 | 作用 |
| --- | --- |
| **操作** | 仅显示 查看、创建、更新、删除 或 访问 的记录。 |
| **分区** | 仅显示某一个仪表板功能区域。选项根据当前已加载记录中出现的分区生成。 |

**刷新** 会重新加载列表。更改筛选器会将页面跳回第一页。

在桌面端，每条记录显示为一行；如果记录包含更改数据，则会显示 **详情** 按钮。在手机上，记录以卡片形式显示，并带有 **显示详情** 按钮。

> [!EXAMPLE]
> 将 **操作** 筛选为 更新，**分区** 筛选为 Protection，即可查看每次有人更改防护系统的记录；展开某一行，即可看到哪些字段发生了变化，以及从什么值改为什么值。

## 保留时长

记录会保留 **九十天**。清理任务每天运行一次，在机器人上线五分钟后开始，并删除超过保留期的记录。目前没有导出功能，因此如果你需要超过该时间窗口的记录，请在其过期前保存。

## 谁可以查看

只有能够登录仪表板且是你服务器成员的人才能访问此页面。服务器所有者以及拥有管理员权限的人始终可以打开它。其他人需要在 **仪表板访问权限** 下对 **审核日志** 分区至少拥有 **查看** 权限，该权限可按用户或按身份组授予。

> [!PERMISSION]
> 由于用户信息取自仪表板的登录令牌，因此任何人都无法让记录显示为他人名下的操作。

## 技巧与注意事项

- 分区筛选器只列出你当前所看页面上出现的分区。如果某个分区不在下拉菜单中，它可能仍然存在于后续页面中；请清除操作筛选器并翻页查找，或先按操作缩小范围。
- 时间戳以查看页面的浏览器所在时区显示，而不是管理设置中的服务器时区。
- "创建" 记录表示发出了一次 POST 请求，仪表板也会将其用于某些开关和更新。请阅读端点信息和详情，以了解实际发生的事情。
- 如果记录的详情只显示值而没有旧值，说明该分区没有对其先前状态进行快照。你可以看到发送了什么，但无法看到它替换了什么。
- 日志按服务器分别记录。在仪表板中切换服务器时，日志也会随之切换。
