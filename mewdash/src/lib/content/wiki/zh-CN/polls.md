## 功能简介

工作人员可以发布一个包含两到二十五个选项的问题。机器人会发送一个嵌入消息，每个选项对应一个按钮；选项超过五个时则使用选择菜单。成员点击即可投票。嵌入消息会实时显示每个选项的票数和百分比。选项下方有三个管理按钮：**统计**、**关闭**和**删除**。

成员可以点击其他选项来更改投票，也可以再次点击同一选项来取消投票，除非该投票关闭了更改投票功能。机器人对每次点击的回复都仅投票人可见，因此频道保持整洁。

投票可以手动关闭，也可以在设定时长后自动过期，还可以定时在未来某个日期发布。模板可以保存问题及其选项，以便之后用一条命令再次发布同一投票。仪表板还提供分析、CSV 和 JSON 导出，以及投票之间的并排对比。

## 适用场景

- 为下一次社区活动选择日期或游戏。
- 修改规则前进行快速的是 / 否确认。
- 匿名提出敏感问题，确保没有人能看到谁投了什么。
- 让只有管理身份组或助力者身份组的成员为与其相关的决定投票。
- 使用模板每周一发布同一个投票，或提前定时安排。

## 投票类型

| 类型 | 投票方式 |
| --- | --- |
| 是 / 否 | 两个固定选项：是和否。通过 `poll` 和 `/poll yesno` 创建。 |
| 单选 | 每位成员只能选择一个选项。`pollc`、模板和仪表板的默认类型。 |
| 多选 | 成员可以选择多个选项。选项达到六个或以上时，选择菜单允许多选。 |
| 匿名 | 投票会被存储，但统计和导出中不显示投票人。 |
| 限定身份组 | 只有持有允许身份组的成员可以投票。其他人会收到仅自己可见的 "not allowed" 回复。仅限仪表板。 |

每个投票还有以下单独开关，默认全部开启：**允许更改投票**、**显示实时结果**和**显示进度条**。

## 投票、关闭与过期

- 对已关闭或已过期投票的投票会被拒绝，并收到仅自己可见的消息。
- 如果关闭了更改投票，第二次点击会被拒绝，并提示 "already voted"。
- **关闭**和**删除**按钮仅对投票创建者和拥有「管理消息」权限的成员有效。删除时需在确认表单中输入 `DELETE`，然后删除投票及其消息。
- **统计**会仅向点击者显示总票数、独立投票人数以及每个选项的明细。
- 投票过期每五分钟检查一次。投票过期后，按钮会被移除，页脚会改为显示已过期。
- 定时投票每分钟检查一次。定时时间必须在未来，且不超过三十天后。定时投票可以设置以分钟计的时长，发布后的投票会在时长结束时过期。

## 模板

模板保存名称、问题及其选项。`polltemplate <name>` 会将其作为单选投票发布。可以通过 `polltemplates` 列出模板，通过 `/poll create-template` 和 `/poll delete-template` 创建和删除，或在仪表板的**模板**标签页中管理，该标签页还支持将模板导出和导入为文件。一个模板最多包含二十五个选项。

## 设置

投票页面有五个标签页：**投票**、**创建**、**定时**、**模板**和**分析**。

| 设置 | 默认值 | 控制内容 |
| --- | --- | --- |
| 问题 | 无 | 投票标题 |
| 投票类型 | 单选 | 上述五种类型之一 |
| 频道 | 无 | 投票的发布位置 |
| 选项 | 两个空白选项 | 两到二十五个选项，每个最多 100 个字符。是 / 否类型中隐藏 |
| 允许投票的身份组 | 无 | 仅在限定身份组投票中显示 |
| 时长（分钟） | 直到手动关闭 | 1 到 20160 分钟。定时发布时生效 |
| 定时发布 | 无 | 日期和时间。留空则立即发布 |
| 允许更改投票 | 开启 | 成员能否切换或取消投票 |
| 显示实时结果 | 开启 | 投票进行中是否显示计数 |
| 显示进度条 | 开启 | 是否在计数旁绘制进度条 |
| 同时保存为模板 | 关闭 | 将问题和选项保存在**模板名称**下 |

**投票**标签页列出投票，并带有**包含已关闭的投票**复选框。展开某个投票可查看独立投票人数、参与度、高峰时段和创建时间，并提供**关闭投票**按钮。**定时**标签页可以**取消投票**待发布的投票。**分析**标签页显示本月投票数、已投票数、每个投票的平均票数、最常用类型，以及每日创建投票数的图表。

## 设置步骤

1. 在仪表板中打开**投票**，进入**创建**标签页。
2. 输入**问题**，选择**投票类型**和**频道**。
3. 填写**选项**。使用删除按钮移除多余选项；至少需要两个选项。
4. 如果是限定身份组投票，请选择**允许投票的身份组**。
5. 可选勾选**同时保存为模板**并为其命名。
6. 点击提交按钮。投票会立即发布；如果设置了时间，则会排入**定时**标签页。
7. 在**投票**标签页查看结果，完成后点击**关闭投票**。

> [!TIP]
> 快速进行频道投票不需要使用仪表板。`poll Should we add a movie night?` 几秒钟内即可发布一个是 / 否投票。

## 命令

请使用服务器的前缀运行以下命令（默认为 `.`，除非你修改过）。

| 命令 | 别名 | 所需权限 | 用途 |
| --- | --- | --- | --- |
| `poll <question>` | `ppoll` | 管理消息 | 发布是 / 否投票 |
| `pollc <question;option1;option2;...>` | | 管理消息 | 发布包含两到二十五个选项的单选投票 |
| `pollm <question;option1;option2;...>` | | 管理消息 | 发布多选投票 |
| `polla <question;option1;option2;...>` | | 管理消息 | 发布匿名投票 |
| `polltemplate <name>` | `ptemplate` | 管理消息 | 从已保存的模板发布投票 |
| `polltemplates` | `ptemplates` | 无 | 列出服务器的模板 |

`/poll` 下的斜杠命令包括 `create`（最多十个选项，可设置匿名和多选开关）、`close`、`stats`、`list`、`create-template` 和 `delete-template`。`close`、`create-template` 和 `delete-template` 需要「管理消息」权限。

## 注意事项

- 机器人需要在投票频道中拥有「发送消息」和「嵌入链接」权限。文字命令还会删除你的命令消息，因此机器人需要「管理消息」权限。
- 选项以分号分隔，因此选项中不能包含分号。
- 按钮标签仅在选项文字不超过十二个字符时显示文字；较长的选项只显示编号，完整文字在嵌入消息中显示。
- 时长由定时程序应用。立即发布的投票会一直保持开启，直到有人关闭它；如果需要自动过期，请将其定时到一分钟之后。
- 勾选**包含已关闭的投票**后，仪表板仍可查看和导出已关闭的投票；已删除的投票则无法找回。
- 限定身份组投票会在投票时检查身份组，因此失去身份组的成员将无法再投票，但之前的投票仍会保留。
