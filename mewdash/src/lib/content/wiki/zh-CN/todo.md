## 功能介绍

待办列表会为你的服务器提供存放在机器人中的任务列表。成员可以创建列表、添加项目、标记完成，并授予他人查看或处理同一列表的权限。拥有管理服务器权限的员工可以创建服务器范围的列表，所有成员都能查看。

每个项目都包含标题、可选描述、1 到 4 的优先级、可选标签、可选截止日期和可选提醒时间。项目带有位置信息，因此你可以对其重新排序。已完成的项目会记录完成者和完成时间。

列表分为两种类型。个人列表属于某一位成员，除非所有者授予权限，否则其他人无法看到。服务器列表属于整个服务器，默认公开，任何人都可以查看，但只有获得明确权限的人才能添加或修改项目。

列表会以嵌入消息的形式显示在 Discord 中，也会以卡片形式显示在仪表板上。仪表板还会针对你当前打开的列表显示进度、逾期数量和完成率。

## 适用场景

- 管理团队将待办事项集中在一个服务器列表中，而不是依赖一条容易过时的置顶消息。
- 活动组织者共享一份清单，并在完成时逐项勾选。
- 成员在服务器中保存一份私人列表，记录需要跟进的事项。
- 项目频道需要标签和优先级，让“紧急”项目与“低”优先级项目一目了然。

## 列表与权限

每个列表都有所有者，即创建该列表的人。所有者可以对该列表执行任何操作。其他人需要通过权限获得访问权限，权限可通过 `todogrant` 按成员授予。

| 权限 | 允许的操作 |
| --- | --- |
| `view` | 查看列表及其项目 |
| `add` | 添加新项目 |
| `edit` | 编辑、标记标签、重新排序以及设置他人项目的日期 |
| `complete` | 完成他人的项目 |
| `delete` | 删除他人的项目 |
| `manage` | 修改列表设置、删除列表，以及授予和撤销访问权限 |
| `all` | 以上所有权限 |

可以使用逗号分隔的字符串传入多个权限，例如 `todogrant 12 @user view,add,complete`。再次授予权限会替换该成员之前的权限。`todorevoke` 会移除其全部权限。

无论权限如何设置，以下两条规则始终适用：创建项目的人始终可以编辑、完成和删除自己的项目；列表所有者始终可以执行任何操作。

谁可以查看列表：

| 列表类型 | 是否公开 | 可查看的人 |
| --- | --- | --- |
| 个人列表 | 任意 | 所有者，以及获得 `view` 权限的人 |
| 服务器列表 | 是（默认） | 服务器中的所有成员 |
| 服务器列表 | 否 | 所有者，以及获得 `view` 权限的人 |

`todotoggleprivacy` 可在公开和私有之间切换列表。只有所有者或拥有 `manage` 权限的人才能执行此操作。

## 项目

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| 标题 | 必填 | 在列表中以粗体显示 |
| 描述 | 无 | 显示在标题下方，以斜体呈现 |
| 优先级 | 通过命令为 1（低），仪表板上为中 | 1 低、2 中、3 高、4 紧急。超出 1 到 4 范围的值会被修正为范围内的值 |
| 截止日期 | 无 | 以相对 Discord 时间戳的形式显示在标题旁 |
| 提醒时间 | 无 | 保存在项目上，使用 `todosetreminder` 设置 |
| 标签 | 无 | 不区分大小写；添加已存在的标签不会产生任何变化 |
| 位置 | 列表末尾 | 使用 `todoreorder` 更改 |

`todoshow` 会按位置、优先级和创建时间依次排序，列出待办项目。传入 `true` 作为第二个参数，还会显示最多五个已完成的项目及其完成时间。`todosetdue` 和 `todosetreminder` 的日期解析较为宽松，`2026-10-01 18:00` 和 `October 1 2026` 都可以使用。

`todosearch` 会在待办项目的标题、描述和标签中搜索关键词，最多显示十条结果。`todofilter` 可以按单个标签（`todofilter 12 tag bug`）或优先级（`todofilter 12 priority 4`）筛选列表。

每个列表都可以设置十六进制颜色，使用 `todosetcolor 12 #ff8800` 设置，该颜色用于嵌入消息的边框。默认颜色为 `#7289da`。

## 设置

服务器范围内没有统一设置，所有选项均针对单个列表或单个项目。

待办列表页面只有一个视图。左侧会列出你可以查看的所有列表，并提供 **搜索待办列表…** 输入框、**显示已完成事项** 开关，以及 **排序方式**（优先级、截止日期、创建时间、标题）和排序顺序选择器。选中某个列表后，会显示其项目，并提供 **添加项** 和 **删除列表** 按钮、包含 **优先级** 和 **截止日期** 的项目编辑器，以及每个列表的 **管理权限** 按钮。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 列表名称和描述 | 名称必填，描述无 | 通过 **创建列表** 按钮创建列表时设置 |
| 优先级（项目） | 中 | 项目的优先级，以彩色标签显示 |
| 截止日期（项目） | 无 | 用于统计逾期数量的截止时间 |
| 显示已完成事项 | 关闭 | 是否在列表视图中显示已完成的项目 |

> [!NOTE]
> 在仪表板中创建的列表始终为服务器列表。如需创建个人列表，请在 Discord 中使用 `todocreatelist`。

## 设置步骤

1. 在仪表板中打开 **待办列表**，然后点击 **创建列表**。
2. 输入名称和可选描述。该列表会被创建为公开的服务器列表。
3. 点击该列表，然后点击 **添加项**。填写 **需要完成什么？**、可选描述和优先级。
4. 使用列表卡片上的 **管理权限** 查看谁有访问权限。在 Discord 中使用 `todogrant <listId> @user add,complete` 授予访问权限，以便这些人可以处理列表中的项目。
5. 在 Discord 中运行 `todolists` 获取列表 ID，然后运行 `todoshow <listId>` 检查显示是否正常。
6. 使用 `todocomplete <itemId>` 标记项目完成；项目 ID 会在 `todoshow` 中以反引号显示。

## 命令

请使用服务器的前缀运行以下命令（默认为 `.`，除非你已更改）。列表 ID 和项目 ID 可通过 `todolists` 和 `todoshow` 获取。

| 命令 | 别名 | 所需权限 | 用途 |
| --- | --- | --- | --- |
| `todocreatelist <name> [description]` | `tcl` | 无 | 创建个人列表 |
| `todocreateserverlist <name> [description]` | `tcsl` | 管理服务器 | 创建服务器范围的列表 |
| `todolists [includeServer]` | | 无 | 列出你可以查看的列表；传入 `false` 则只显示个人列表 |
| `tododeletelist <listId>` | `tdl` | 无 | 删除列表及其所有项目（需为所有者或拥有 `manage` 权限） |
| `todoshow <listId> [includeCompleted]` | `ts` | 无 | 显示列表中的项目 |
| `todoadd <listId> <title> [description]` | `ta` | 无 | 以低优先级添加项目 |
| `todoaddpriority <listId> <priority> <title> [description]` | `tap` | 无 | 添加优先级为 1 到 4 的项目 |
| `todoedit <itemId> <title> [description]` | `te` | 无 | 修改项目的标题和描述 |
| `todocomplete <itemId>` | `tc` | 无 | 将项目标记为完成 |
| `tododelete <itemId>` | `td` | 无 | 删除项目 |
| `todoreorder <itemId> <position>` | `tr` | 无 | 将项目移动到从 1 开始计数的位置 |
| `todosetdue <itemId> <date>` | `tsd` | 无 | 设置截止日期 |
| `todocleardue <itemId>` | `tcd` | 无 | 移除截止日期 |
| `todosetreminder <itemId> <date>` | `tsr` | 无 | 设置提醒时间 |
| `todoclearreminder <itemId>` | `tcr` | 无 | 移除提醒时间 |
| `todoaddtag <itemId> <tag>` | `tat` | 无 | 添加标签 |
| `todoremovetag <itemId> <tag>` | `trt` | 无 | 移除标签 |
| `todosearch <listId> <query>` | `tsearch` | 无 | 按标题、描述或标签搜索未完成的项目 |
| `todofilter <listId> <tag or priority> <value>` | `tf` | 无 | 按单个标签或单个优先级筛选未完成的项目 |
| `todosetcolor <listId> <#hex>` | `tsc` | 无 | 设置嵌入消息的颜色 |
| `todotoggleprivacy <listId>` | `ttp` | 无 | 在公开和私有之间切换列表 |
| `todogrant <listId> @user <perms>` | `tg` | 无 | 授予以逗号分隔的权限 |
| `todorevoke <listId> @user` | `trv` | 无 | 移除某成员的全部权限 |
| `todopermissions <listId>` | `tp` | 无 | 显示谁拥有哪些权限 |

“无”表示不进行 Discord 权限检查，命令是否成功由列表自身的权限决定。相同的命令也以斜杠命令的形式存在于 `/todo` 下。

## 小贴士与注意事项

- 提醒时间会保存在项目上，但目前机器人不会在提醒时间到达时发送提醒。目前请将其视为备注。
- 如果你没有 `view` 权限，即使列表 ID 正确，`todoshow` 也会提示找不到该列表。
- 同一所有者和同一类型下，列表名称必须唯一。因此两位成员可以各自拥有一个“购物”个人列表，但同一位成员不能拥有两个同名列表。
- `todoreorder` 会为列表中的每个项目重新编号，因此位置始终保持连续。
- 所有人都可以读取公开的服务器列表，但在你授予 `add` 权限之前，除所有者外无人可以添加项目。
- 如需完整的权限设置，请在 Discord 中使用 `todogrant`；仪表板中的 **管理权限** 视图仅用于查看谁拥有访问权限。
- 删除列表会一并删除其权限和项目，且无法撤销。
