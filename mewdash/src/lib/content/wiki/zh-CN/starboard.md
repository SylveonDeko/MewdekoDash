## 功能介绍

星标板是一个频道，机器人会将获得足够多指定表情反应的消息转发到其中。成员对有趣或有用的内容添加反应；当反应数达到阈值后，机器人会将该消息复制到星标板频道，并附上作者名称、文本、图片或视频、当前各表情的反应数，以及一个 **Jump to Message** 按钮。

随着反应的增减，帖子内容会持续更新。如果反应数低于阈值，帖子可以被移除。如果原消息被删除或其反应被清除，帖子同样可以被移除。

一个服务器可以同时运行多个星标板，每个星标板拥有自己的频道、表情或表情组、阈值以及规则。例如，一个“最佳表情包”星标板监控一种表情，另一个“有用的回答”星标板监控另一种表情，两者可以并存。

## 适用场景

- 让社区自行推选优质内容，无需工作人员手动筛选。
- 保留一个长期存在的精彩消息频道，方便新成员浏览。
- 为幽默、艺术或有用的回答分别设置不同的星标板，使用不同的表情。
- 限制哪些频道可以向星标板提供内容，避免机器人刷屏或离题内容混入。

## 多个星标板与表情

每个星标板都有一个数字 ID，可通过 `liststarboards` 或仪表板列表查看。命令的第一个参数即为该 ID。

星标板创建时包含一个表情，也可以添加更多表情。任何一个表情的反应都会计入同一总数，帖子中会分别显示每个表情的数量。同一服务器中，一个表情只能属于一个星标板；如果重复使用，会提示“emote already in use”。星标板至少需要保留一个表情，因此无法删除最后一个表情。

自定义表情与 Unicode 表情均可使用。机器人会通过对你的命令消息添加反应来测试表情，因此该表情必须是机器人可以使用的。

## 阈值与计数

**星标阈值** 是消息被转发前需要达到的反应数。命令中的默认值为 1；仪表板要求至少为 1。

计数时，机器人会：

- 忽略机器人账号的反应。
- 将该星标板所有表情的反应数相加。
- 计入作者自己的反应，不存在禁止自星的规则。
- 仅对包含文本或附件的消息作出反应；两者都没有的消息会被跳过。

如果总数低于阈值且已存在帖子，并且 **低于阈值时移除** 已开启，则该帖子会被删除。否则帖子保持原样。

## 机器人消息

默认情况下，机器人编写的消息永远不会被转发。开启 **允许机器人消息** 后才会包含它们。对于机器人消息，如果消息包含嵌入内容，则文本取自第一个嵌入的描述，否则取自普通内容；图片取自第一个附件或第一个嵌入的图片。允许机器人消息后，机器人的反应也会计入帖子中各表情的数量。

## 转发阈值

通常情况下，每当计数变化时，机器人会直接编辑已有的星标板帖子。当某个星标板非常活跃时，该帖子可能已经滚动到频道上方，没有人能看到更新后的计数。

**转发阈值** 可以解决这个问题。将其设置为数字 N 后，每次更新时机器人会查看星标板频道中最近的 N 条消息。如果已有帖子在其中，则直接编辑；如果它已滚动到更靠前的位置，则删除旧帖子，并在底部重新发送一条新帖子。设置为 0 则禁用转发，始终原地编辑。

## 频道过滤

每个星标板都有一个频道列表和一种模式：

| 模式 | 效果 |
| --- | --- |
| 白名单（默认） | 仅考虑列表中频道的消息。列表为空则表示所有频道。 |
| 黑名单 | 忽略列表中频道的消息，其余消息均会被考虑。 |

`starboardchtoggle <id> #channel` 可将频道添加到列表或从列表中移除。仪表板中的 **管理频道** 操作功能相同。

## 星标板帖子

帖子由组件构建，而非传统嵌入：

- 在容器上方显示一行，包含各个表情及其数量。
- 作者名称，链接至其个人资料。
- 消息文本。
- 图片和视频附件的媒体库。
- 最多三个其他附件，会重新上传到星标板频道。如果下载失败，则显示文件名和大小。
- 一个 **Jump to Message** 链接按钮。

转发文本中的提及会被抑制，因此被加星的消息不会再次提醒任何人。

## 移除规则

| 规则 | 默认值 | 触发时机 |
| --- | --- | --- |
| 删除时移除 | 开启 | 原消息被删除。机器人需要在源频道中拥有 **管理消息** 权限。 |
| 清除反应时移除 | 开启 | 管理员清除原消息的所有反应。 |
| 低于阈值时移除 | 开启 | 移除一个反应后，总数低于阈值。 |

## 统计

`starboardstats` 显示服务器的整体数据：加星消息数、总星标数、星标最多的成员、最活跃的频道以及最活跃的加星者。`starboarduserstats [@user]` 显示某位成员的加星消息数、获得的星标数、给出的星标数、其热门帖子、给其加星最多的人，以及其加星最多的对象。两者对所有人开放。

## 设置

星标板页面分为两个部分：**创建新星标板** 和 **管理星标板**。列表中的每一项都会显示其频道、表情、阈值和转发阈值，并提供 **星标板设置**、**管理频道** 和 **删除** 按钮。

在 **星标板设置** 中：

| 设置 | 默认值 | 控制内容 |
| --- | --- | --- |
| 星标阈值 | 创建时设置 | 消息被转发前所需的反应数 |
| 转发阈值 | 0（禁用） | 转发到底部前需要搜索的最近消息数量 |
| 星标表情 | 创建时使用的表情 | 添加或移除对该星标板生效的表情 |
| 允许机器人消息 | 关闭 | 包含机器人编写的消息 |
| 删除时移除 | 开启 | 原消息被删除时移除帖子 |
| 清除反应时移除 | 开启 | 反应被清除时移除帖子 |
| 低于阈值时移除 | 开启 | 数量低于阈值时移除帖子 |
| 频道模式 | 白名单 | 频道列表为白名单还是黑名单 |

> [!TIP]
> 在活跃的服务器上，建议将阈值设为 3 到 5。如果阈值为 1，那么每一次偶然的反应都会变成一条帖子。

## 设置指南

1. 创建一个用于精彩消息的频道，并确保机器人可以在该频道中发送消息、嵌入链接和上传文件。
2. 在仪表板中打开 **星标板**。
3. 在 **创建新星标板** 下，选择频道，从快速选项中选择表情或输入自定义表情，设置 **阈值（所需反应数）**，然后点击 **创建星标板**。
4. 打开新条目的 **星标板设置**。在 **星标表情** 下添加其他表情；如果该星标板将会非常活跃，可将 **转发阈值** 设置为 20 左右。
5. 使用 **管理频道** 将可以向星标板提供内容的频道加入白名单，或将 **频道模式** 切换为黑名单，并列出需要排除的频道。
6. 对一条测试消息添加足够数量的指定表情以达到阈值，检查帖子是否出现。

## 命令

请使用服务器的前缀运行以下命令（如未更改，默认为 `.`）。`<id>` 为 `liststarboards` 中显示的星标板 ID。

| 命令 | 别名 | 所需权限 | 用途 |
| --- | --- | --- | --- |
| `createstarboard #channel <emote> [threshold]` | `addstarboard`、`newstarboard` | 管理频道 | 创建星标板，阈值默认为 1 |
| `deletestarboard <id>` | `removestarboard`、`delstarboard` | 管理频道 | 删除星标板配置 |
| `liststarboards` | `starboardlist`、`starboards` | 无 | 翻页查看所有星标板及其设置 |
| `setstarthreshold <id> <number>` | `starthreshold` | 管理频道 | 设置所需反应数 |
| `setrepostthreshold <id> <number>` | `starboardrepost`、`repostthreshold` | 管理频道 | 设置转发检索范围，0 为禁用 |
| `addstarboardemote <id> <emote>` | `addstaremote`、`starboardaddemote`、`asbe` | 管理频道 | 为星标板添加表情 |
| `removestarboardemote <id> <emote>` | `removestaremote`、`starboardremoveemote`、`rsbe` | 管理频道 | 移除表情，无法移除最后一个表情 |
| `starboardallowbots <id> <true or false>` | `starbots`、`starbotsallow`、`starbab` | 管理频道 | 允许机器人编写的消息 |
| `starboardremoveondelete <id> <true or false>` | `starboarddelete`、`stardelete`、`srod` | 管理频道 | 原消息删除时移除帖子 |
| `starboardremoveonreactionsclear <id> <true or false>` | `starboardreactionclear`、`starclear` | 管理频道 | 反应被清除时移除帖子 |
| `starboardremoveonbelowthreshold <id> <true or false>` | `starboardbelowthreshold`、`starbelow`、`srobt` | 管理频道 | 低于阈值时移除帖子 |
| `starboardwlmode <id> <whitelist or blacklist>` | `starboardmode`、`starboardwhitelist`、`swm` | 管理频道 | 设置频道列表的处理方式 |
| `starboardchtoggle <id> #channel` | `starboardchannel`、`togglestarboardchannel`、`scht` | 管理频道 | 将频道添加到列表或从列表中移除 |
| `starboardstats` | `starstats`、`starboardstatistics`、`sbstats` | 无 | 全服务器的星标板统计数据 |
| `starboarduserstats [@user]` | `staruserstats`、`userstarstats`、`sbuserstats` | 无 | 某位成员的统计数据 |

斜杠命令等效版本位于 `/starboard` 下。

## 小贴士与注意事项

- 如果机器人无法在星标板频道中发送消息，它会静默地不做任何操作。请先检查频道权限。
- 只有当机器人在原消息所在的频道中拥有 **管理消息** 权限时，“删除时移除”才会生效。
- 来自机器人的反应永远不会计入阈值，因此其他自动添加反应的机器人无法把消息推上星标板。
- 删除星标板只会删除其配置，频道中已有的帖子会保留。
- 同一个表情不能在两个星标板之间共用，请为每个星标板选择不同的表情。
- 过大的附件可能无法重新上传；此时帖子会改为列出文件名。
