## 功能介绍

XP 等级身份组是单向的：获得后将永久保留。统计身份组则会按计划重新评估：符合条件的成员会获得该身份组，不再符合条件的成员则会失去它。因此，“活跃成员”身份组表示的是*当前*的活跃状态。如果希望保留旧的行为，可以将其设为永久；如果希望标记不活跃的成员，则可以将判定反转。

## 判定条件

每个统计身份组都会在一段时间内衡量一项指标，并应用一种限制。

| 指标 | 统计内容 |
| --- | --- |
| 消息 | 时间段内的消息数，可选择仅统计指定频道 |
| 语音分钟数 | 时间段内在语音频道中的时长，并遵守你在活跃统计中排除的语音状态 |
| 游戏分钟数 | 时间段内游玩某个指定游戏或应用的时长，或任意游戏的时长。需要开启游戏追踪 |
| 邀请 | 成员的净邀请总数 |
| 服务器加入天数 | 自成员加入服务器以来的天数 |
| 账号年龄 | 自账号创建以来的天数 |

| 限制 | 符合条件的成员 |
| --- | --- |
| 阈值 | 介于最小值与可选的最大值之间 |
| 排名 | 排名位于两个名次之间，例如前 10 名 |
| 百分比 | 位于已排名成员的前 X%，例如前 5% |
| 连续天数 | 在时间段内至少 N 天，每天都达到每日最低值，例如在最近 7 天中有 7 天每天至少 5 条消息 |

时间段为 1 到 90 天，或全部时间（连续天数限制除外）。并列成员享有相同的排名。

## 过滤器与选项

| 选项 | 作用 |
| --- | --- |
| 仅在频道中统计 | 将消息或语音统计限制在指定频道 |
| 所需身份组 | 成员至少需要拥有其中一个，才会被纳入考虑 |
| 排除身份组 | 拥有其中任意一个的成员永远不会被纳入考虑 |
| 忽略的成员 | 这些成员永远不会被授予或移除该身份组 |
| 分组 | 共享同一分组的统计身份组只保留成员符合条件的最高等级，因此青铜、白银和黄金不会叠加 |
| 永久 | 获得后永远不会被移除 |
| 反转 | *不*符合条件的成员获得该身份组 |
| 包含机器人 | 将机器人账号纳入统计 |
| 评估频率 | 规则的运行频率，最短为每 10 分钟一次，默认为每 3 小时一次 |
| 在以下频道公告 / 私信成员 | 在授予或移除身份组时发送消息，可使用 `%user%`、`%role%`、`%action%`（获得或失去）、`%value%` 和 `%stat%` |

## 仪表板

**统计身份组** 标签页会列出每条规则，包括其判定条件、运行计划和上次运行时间，并允许你启用、禁用、编辑、删除、**预览** 或 **运行** 每条规则。预览会显示哪些成员将获得或失去该身份组，但不会做出任何更改。运行会立即应用规则；手动运行的频率限制为每个服务器每 10 分钟一次。

**创建 / 编辑** 标签页用于设置上述所有选项。

## 命令

请使用服务器的前缀运行以下命令（默认为 `.`，除非你已更改）。每个命令也可以通过 `/statrole` 使用。

| 命令 | 别名 | 所需权限 | 用途 |
| --- | --- | --- | --- |
| `statroleadd <@role> <stat> <minimum> [days] [name]` | `sradd` | 管理身份组 | 阈值规则 |
| `statroletop <@role> <stat> <topEnd> [days] [name]` | `srtop` | 管理身份组 | 排名规则，适用于第 1 名到 topEnd 名 |
| `statrolepercent <@role> <stat> <percent> [days] [name]` | `srpercent` | 管理身份组 | 百分比前列规则 |
| `statrolestreak <@role> <stat> <perDay> <requiredDays> [days] [name]` | `srstreak` | 管理身份组 | 每日连续天数规则 |
| `statrolelist` | `statroles` | 无 | 列出所有规则 |
| `statroleinfo <id>` | `srinfo` | 无 | 显示单条规则的完整信息 |
| `statroleset <id> <setting> <value>` | `srset` | 管理身份组 | 修改名称、最小值、最大值、回溯时长、topstart、topend、天数、永久、反转、机器人、分组、频率、通知频道、通知私信、消息或活跃度 |
| `statrolefilter <id> <#channel, @role [true], or @user>` | `srfilter` | 管理身份组 | 切换频道过滤器、所需身份组（传入 `true` 则为排除身份组），或忽略的成员 |
| `statroletoggle <id>` | `srtoggle` | 管理身份组 | 启用或禁用 |
| `statrolepreview <id>` | `srpreview` | 管理身份组 | 显示哪些成员将获得或失去该身份组 |
| `statrolerun <id>` | `srrun` | 管理身份组 | 立即应用 |
| `statroleremove <id>` | `srremove` | 管理身份组 | 删除规则；成员保留已获得的身份组 |

## 小贴士与注意事项

- 机器人的最高身份组必须高于要管理的身份组，并且需要 管理身份组 权限。
- 每个 Discord 身份组只能由一条统计身份组规则管理。在将新规则指向同一身份组之前，请先删除旧规则。
- 最小值为 0 且没有最大值的规则会匹配所有人；请设置最大值，或有意使用反转功能。
- 选择退出活跃统计的成员没有消息、语音或游戏时长记录，因此他们永远不会符合这些指标的条件。
- 在大型服务器上启用规则前，请先进行预览。身份组变更会分散进行，以遵守速率限制，因此影响数千名成员的规则需要几分钟才能全部生效。
