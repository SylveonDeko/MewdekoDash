## 功能简介

服务器管理模块在没有管理员值守时，帮你维持服务器秩序。它的防护系统会监控成员加入和消息发送，一旦发现疑似突袭、刷屏、小号、批量提及、把诈骗链接粘贴到每个频道、在蜜罐频道发言，或发布已知诈骗图片的情况，就会自动处罚。每个系统都相互独立，拥有各自的处罚方式，并可单独开启或关闭。

同一模块还负责身份组自动化：加入时分配身份组、成员用 `iam` 自行领取身份组、反应身份组、与语音频道绑定的身份组，以及会封禁获得它的人的陷阱身份组。你还可以修改某个命令需要的 Discord 权限、设置其他功能依赖的工作人员和成员身份组、为命令设置速率限制，并清理命令消息。

遇到糟糕的时候，可以使用批量操作：封禁或踢出最近几分钟内加入的所有人、按名称规则、身份组或头像封禁、清理长期不活跃的成员，还有一个服务器恢复流程，可以把管理员身份组交还给已验证的服务器所有者。

所有设置都位于仪表板的 **服务器管理** 页面，分为五个选项卡：**概览**、**防护系统**、**身份组与权限**、**自动化与设置** 和 **高级操作**。几乎每项设置都有对应命令。

## 适用场景

- 加入突袭或机器人潮通常发生在凌晨三点，你希望在有人醒来之前就处理好。
- 一个被盗的账号正在把同一个钓鱼链接粘贴到十个频道。
- 成员应该能自行选择颜色、地区或通知身份组，而不需要工作人员协助。
- 你希望拥有“管理消息”权限的人也能使用 `ban`，而不必修改 Discord 的身份组设置。
- 某个命令在 general 频道被刷屏，需要设置冷却。
- 有管理员移除了所有者的身份组，你需要一种方法重新取得权限。

## 处罚方式

每个防护系统都有一个**处罚方式**。部分方式还需要设置**时长**或**身份组**。

| 方式 | 效果 |
| --- | --- |
| Mute | 添加服务器的静音身份组（文字和语音） |
| ChatMute | 仅限文字的静音身份组 |
| VoiceMute | 在语音中对成员进行服务器静音 |
| Kick | 将成员移出服务器，对方可以重新加入 |
| Softban | 封禁后立即解封，以清除近期消息 |
| Ban | 封禁；若设置了时长则为临时封禁 |
| Timeout | Discord 原生禁言，需要设置时长，最长 28 天 |
| AddRole | 添加你选择的身份组，例如隔离身份组 |
| RemoveRoles | 移除所有身份组 |
| Warn | 通过管理模块添加一条警告 |
| Delete | 仅删除违规消息 |
| None | 记录触发情况，但不采取任何行动 |

只有 Ban、Mute、ChatMute、VoiceMute、AddRole 和 Timeout 接受时长，其他方式会忽略时长。时长以分钟为单位。仪表板中，反突袭、反刷屏、反批量提及和反模式最长可设为 10080 分钟（一周），反批量发帖、反发帖频道和反图片哈希最长为 1440 分钟（一天），小号防护最长可设为一年。处罚会从队列中每秒执行一次，Discord 审计日志中的原因显示为类似 "Raiding Protection" 或 "ImageHash Protection" 的英文文字。

> [!WARNING]
> 反突袭、小号防护和反模式在成员加入时运行，如果处罚方式为 Warn，这三个系统会完全跳过检查。这三项请选择 Kick、Ban、Timeout 或某个身份组。

拥有管理员权限的成员会豁免所有基于消息的防护。机器人会被基于加入的防护和反刷屏忽略；其他系统则有 **忽略机器人** 开关。

## 防护系统

**防护系统** 选项卡中，每个系统都有一张卡片，显示 **已启用** 或 **已禁用** 按钮；启用后还会出现 **配置** 按钮，用来打开其设置。在仪表板中启用时会应用一套初始配置，依赖之前请先打开 **配置** 检查处罚方式。**概览** 选项卡会显示七个系统中有多少处于运行状态，并列出每一个系统。

### 反突袭防护

统计在滚动时间窗口内加入的成员数量。当某次突发中的人数达到 **用户阈值**，并且处于 **时间窗口**（秒）之内时，该突发中统计到的所有人会一起受到处罚。命令接受 2 到 30 的阈值和 2 到 300 秒的窗口；仪表板接受 1 到 50 和 1 到 300。此处不支持 AddRole。机器人加入不会被计入。

> [!EXAMPLE]
> `antiraid 10 10 Ban` 表示十秒内有十个账号加入时，封禁所有人。`antiraid 10 10 Timeout 1h` 则会把他们禁言一小时。

### 反刷屏防护

统计同一成员连续发送的相同消息，比较时不区分大小写。当计数达到 **消息阈值**（命令为 2 到 10，仪表板为 1 到 20）时，该成员会受到处罚，计数随即重置。发送不同的消息会重置计数；每条被计数的消息在三十分钟后失效。位于 **忽略的频道** 列表中的频道会被跳过，这适合机器人命令频道。若要改为分配身份组，请使用 `antispam <count> <action> <role>` 并搭配 AddRole。

### 小号防护

检查每个加入账号的年龄。账号年龄小于 **最小账号年龄**（单位为分钟；`antialt 3d Kick` 也可以）的，会立即受到处罚。它只在加入时运行，因此开启后不会扫描现有成员。仪表板的初始值为 1440 分钟，即一天。

### 反批量提及

统计用户和身份组提及。单条消息中的提及数达到 **提及阈值** 会立即受到处罚。未达到时，会按成员在 **时间窗口**（秒）内的提及数累加，超过 **时间窗口内最大提及数** 即触发处罚。**忽略机器人** 决定是否计入机器人发送的消息。

### 反模式防护

为每个新成员的账号评分，判断其是否为一次性账号或机器人账号；分数达到 **最低分数** 时进行处罚。它在加入时运行，检查的是账号本身，而不是消息。

| 信号 | 分数 | 设置 |
| --- | --- | --- |
| 账号创建时间在最大年龄之内 | 5 | **检查账号年龄**、**最大账号年龄（月）** |
| 账号创建后不久即加入 | 1 小时内为 10 分，6 小时内为 7 分，否则为 3 分 | **检查加入时间**、**最大加入时长（小时）** |
| 同一小时内创建的其他成员账号 | 每个账号 1 分，最多 10 分 | **检查批量创建** |
| 加入时显示为离线 | 2 | **检查离线状态** |
| 账号早于新账号截止时间 | 3 | **检查新账号**、**新账号天数** |
| 用户名匹配你设置的某个正则模式 | 15 | 模式中开启 **检查用户名** |
| 显示名称匹配你设置的某个模式 | 12 | 模式中开启 **检查显示名称** |

模式匹配时，只要当前总分达到最低分数即会立即处罚；单靠其他信号也可能达到该分数。模式为正则表达式，匹配时不区分大小写，并针对小写名称进行比对。仪表板的初始值为：最低分数 15、六个月、48 小时、七天，所有检查均开启。在仪表板中，卡片上的 **模式** 按钮会打开模式列表，每个模式包含名称、正则表达式以及两个名称检查复选框。

使用命令时，`patternadd <regex> [name] [checkUsername] [checkDisplayName]` 可添加一个模式，`patternconfig <setting> <value>` 可调整 `accountage`、`maxaccountage`、`jointiming`、`maxjoinhours`、`batchcreation`、`offlinestatus`、`newaccounts`、`newaccountdays` 或 `minimumscore`。单独运行 `patternconfig` 会显示当前数值以及该系统触发的次数。

### 反批量发帖

用于发现成员在短时间内向多个频道发布相同或相似内容的情况，也就是“到处粘贴诈骗链接”这类做法。由于消息分散在不同频道，反刷屏通常无法识别。

机器人会为每个成员保留 **时间窗口**（10 到 600 秒）内的最近五十条消息。新消息会与之前的消息比较，编辑距离相似度至少为 80%（不区分大小写）即视为相似。当相似消息出现在至少 **频道阈值**（2 到 20）个不同频道中时，该成员会受到处罚。少于二十个字符的消息会被忽略。

**仅检查链接** 默认开启：只有包含链接的消息才会被跟踪。被忽略的用户、身份组和频道都会被跳过。默认情况下，触发的消息会被删除，并私信该成员说明原因。

### 反发帖频道防护

用于设置**蜜罐频道**。将一个或多个真实成员没有理由发言的频道标记为蜜罐，通常隐藏在频道列表底部，并使用带有警告意味的名称。在这些频道发言的任何人都会被视为机器人或被盗账号：消息会被删除，发言者会收到私信，并执行处罚。管理员可豁免，你还可以按 ID 添加 **忽略的身份组** 和 **忽略的用户**。

机器人还会在状态频道中维护一条**状态嵌入**：可以是你运行 `antipostchannel` 的频道，也可以是在仪表板中启用时，第一个捕获到违规者的蜜罐频道。嵌入会显示处罚方式、蜜罐频道数量、捕获总数，以及最近十名被捕获的成员。

### 反图片哈希防护

根据图片的外观屏蔽特定图片，因此即使被缩放、重新压缩、调亮、翻转或加上边框，重新上传的副本仍会被匹配。每张被屏蔽的图片都会以感知哈希的形式保存，同时保存其镜像，如果有纯色边框，还会保存去除边框后的副本。发布的附件（如果开启了 **检查嵌入**，还包括嵌入内容）会以相同方式计算哈希并进行比对。

- **匹配容差**（0 到 64，默认 31）表示发布的图片与被屏蔽图片相差多少仍视为匹配。如果误伤无辜图片，请调低；只有在诈骗图片漏过时才调高。
- **拦截带边框的副本** 会在匹配前去除发布图片的纯色边框。镜像副本始终会被拦截。
- 过于简单、无法可靠识别的图片不会被匹配，也不会被接受为屏蔽对象，否则会误匹配无关图片。
- 超过 8 MB 的图片不会被下载或计算哈希。该上限可通过 API 设置为 1 到 32 MB，但仪表板卡片和命令都不提供此选项。
- 每张被屏蔽的图片可以设置自己的处罚方式、时长和身份组，覆盖系统默认值。**仅删除** 会删除图片，但不处罚发布者。
- 被忽略的身份组和频道会被跳过；默认情况下，发布者会收到私信。

**屏蔽已知诈骗图片** 会启用随机器人附带的预设列表，目前包含近期在 Discord 上流传的假冒加密赌场和 MrBeast 抽奖图片。卡片会显示列表中的图片数量，以及它在你的服务器中拦截了多少条帖子。

如果要在仪表板中屏蔽你自己的图片，请拖放或上传文件，或粘贴其链接，为其添加名称，可选择为该图片设置单独的处罚方式，然后保存。使用命令时，在附加图片、回复包含该图片的消息或粘贴链接的同时运行 `blockimage [action] [name]`。`blockedimages` 会列出所有被屏蔽图片及其命中次数，`unblockimage <id>` 用于移除一张，`imagehash` 则可以在不屏蔽的情况下查看图片的哈希。

> [!TIP]
> 请先开启反发帖频道防护和已知诈骗图片列表。两者在正常聊天中都不会产生误报，结合使用可以拦截大部分自动化诈骗活动。

### 反外部应用

成员可以在自己的 Discord 账号中添加应用，并在任何服务器中使用，即使该服务器从未添加过此应用。这些应用发出的消息会以应用名称显示，因此其他防护（它们检查的是消息发送者）无法看到背后的成员。反外部应用会读取是哪位成员运行了应用，并针对该成员采取行动。

以下情况会被视为违规：

- 提及的用户和身份组数量达到 **提及上限**（默认 5），或者提及了 everyone 或 here，
- 开启了 **移除邀请链接** 时，消息中包含 Discord 邀请链接，
- 或者成员在时间窗口内运行应用的次数超过 **允许的应用消息** 数量（默认在 10 秒内 5 次）。

将某项限制设为 0 即可关闭该检查。消息违规时会被删除，运行应用的成员会受到处罚，默认为一小时禁言。**仅删除** 会删除消息但不处罚任何人。直接添加到服务器中的应用不受影响，服务器管理员也不受影响。

> [!TIP]
> Discord 的 **使用外部应用** 权限与此功能配合得很好。没有该权限的成员仍可使用自己的应用，但只有他们自己能看到回复。可以对 `@everyone` 拒绝该权限，仅对可信或达到等级的身份组开放，这样新账号或一次性账号将无法通过应用发帖。

## 身份组

这些卡片位于 **身份组与权限** 选项卡中。

### 自动分配身份组

每位成员加入时会自动获得的身份组，机器人用户则有单独的列表。仍在完成成员验证筛选的成员会在通过后获得身份组。如果身份组状态设置为对拥有已保存身份组状态的成员跳过自动分配，则回归成员会保留原有身份组。`autoassignrole <role>` 可切换列表中的某个身份组；单独运行可查看列表。

### 可自助领取的身份组

成员可以用 `iam <role>` 给自己添加身份组，并用 `iamnot <role>` 移除。身份组会被归入编号的**分组**（第 0 组为“未分组”），分组可以命名。**互斥模式** 是服务器范围的开关：开启后，从某个分组中领取身份组会自动移除你在该分组中持有的其他身份组，非常适合颜色或地区。身份组可以要求最低经验值**等级**。**移除 iam 消息** 会在三秒后删除命令和回复，保持频道整洁。

### 反应身份组

在已有消息上为身份组附加表情。成员点击表情即可获得身份组，取消点击即可移除。每条消息可以标记为**互斥**，使成员只能持有其中一个身份组。Discord 每条消息最多允许二十个反应，仪表板会为你统计数量。为已有反应身份组的消息添加新组合时，会扩展现有设置。

使用命令时，`reactionroles [messageId] [excl] <role> <emoji> ...` 用于设置配对；省略消息 ID 时，将使用你命令正上方的消息。`reactionroleslist` 会列出所有设置及其索引，`reactionrolesremove <index>` 可删除其中一项。

### 语音频道身份组

将某个身份组绑定到语音频道。成员加入该频道时获得身份组，离开时失去。可用于只向当前正在通话的人开放某个文字频道。

### 自动封禁身份组

此列表中的任何身份组都是陷阱：成员一旦获得它，就会被立即封禁。除非你使用 `autobanrolereason` 设置了原因，否则默认原因为 "Auto-ban role assigned"。可以把它与隐藏消息上的反应身份组搭配使用，用来捕获会自行领取身份组的机器人。被删除的消息天数跟随管理模块的封禁清理设置。

## 权限覆盖与命令权限

**权限覆盖** 会替换某个命令通常检查的 Discord 权限。为 `ban` 添加一个要求“管理消息”的覆盖后，任何拥有“管理消息”的人都可以运行它；若要求“管理员”，则只有管理员能运行。若列出多个权限，用户需要全部具备。使用命令时，`dpo <command> <permission> [permission...]` 用于设置覆盖，`dpo <command>` 不带权限则移除覆盖，`dpol` 列出所有覆盖，`dpor` 在确认后清除全部覆盖。自定义聊天触发器的名称同样可以使用。

同一选项卡中的 **命令权限** 卡片是基于规则的命令权限系统：可以按身份组、频道、分类或整个服务器，为用户允许或拒绝某个命令、某个模块或全部功能，并从上到下依次评估。它有独立的文章，请参阅 `permissions`。

## 服务器设置

这些卡片位于 **自动化与设置** 选项卡中。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **工作人员身份组** | 无 | 其他功能视为工作人员的身份组 |
| **成员身份组** | 无 | 视为“成员”的身份组；`prunemembers` 可以包含拥有该身份组的人 |
| **服务器时区** | UTC | 机器人显示本地时间时使用的时区 |
| **命令冷却** | 无 | 每个命令的速率限制，单位为秒，范围 1 到 90,000 |
| **权限覆盖** | 无 | 每个命令所需的 Discord 权限（见上文） |
| **游戏语音频道** | 无 | 当该语音频道中的成员开始玩游戏时，机器人会将其移动到名称与游戏匹配的语音频道 |
| **命令执行后删除消息** | 关闭 | 命令运行后删除触发命令的消息，可为各频道单独设置开启、关闭或继承 |
| **统计退出** | 已加入 | 停止为本服务器收集命令使用统计；**删除统计数据** 会清除已存储的数据 |

## 高级操作

**高级操作** 选项卡包含三张卡片。每个批量操作都会先要求确认，然后直接执行，不再进行其他检查。

### 自定义封禁消息

成员被封禁时通过私信收到的消息，在嵌入编辑器中编写。它与管理模块的封禁命令使用相同的模板。

### 服务器恢复

当某个被盗的管理员移除了所有者的管理员身份组时，可用它将管理员身份组交还给所有者。服务器会保存两项机密：**恢复密钥** 和 **二次验证密钥**。

- 服务器所有者在尚未设置时运行 `/serverrecovery server-recover`，会生成两者：恢复密钥通过私信发送给你，身份验证器的密钥则以二维码显示。输入身份验证器应用中的验证码即可完成设置。
- 设置完成后，任何人运行 `/serverrecovery server-recover`，输入恢复密钥并提供有效的身份验证器验证码后，即可获得一个名为 "Recovered Server Owner Role" 的新身份组，拥有管理员权限，并位于机器人最高身份组下方。
- `/serverrecovery clear-server-recover` 会在确认后删除已保存的密钥，仪表板中的 **移除恢复设置** 同样如此。

仪表板卡片也可以直接保存密钥：生成或输入至少十六个字符的恢复密钥，以及一个二次验证密钥。机器人会将验证码与该二次验证密钥比对，作为身份验证器（TOTP）的密钥，因此请输入你已添加到身份验证器应用中的 base32 密钥，而不是普通密码。

> [!PERMISSION]
> 机器人本身必须拥有管理员权限，恢复才能运行；并且它的最高身份组必须足够高，使紧邻其下的身份组仍然高于你要恢复的对象。

### 批量操作

| 操作 | 作用 |
| --- | --- |
| **清理未活跃用户** | 使用 Discord 的成员清理功能，移除指定天数（1 到 30）内未活跃的成员 |
| **批量封禁用户** | 以一个原因封禁粘贴的用户 ID 列表；消息删除跟随管理模块的封禁清理设置 |
| **批量改名用户** | 将每位成员的昵称设置为某种格式，其中 `{username}` 会被替换为其用户名，例如 `[AFK] {username}`；机器人无法改名的成员会被跳过 |
| **清理至指定消息** | 逐条删除某频道中指定消息 ID 之后的所有消息 |

命令提供了更多选择封禁对象的方式：`banunder 10m` 封禁最近十分钟内加入的所有人（`-p` 会先预览列表，`-accage 1d` 还要求账号年龄小于一天）；`kickunder` 用同样的方式执行踢出；`nameban <regex>` 在预览后封禁用户名匹配某个模式的用户；`baninrole <role>` 封禁拥有某个身份组的所有人；`banbyhash <avatarHash>` 封禁使用指定头像的所有成员。所有这些命令都会要求你确认。

## 设置流程

1. 在仪表板中打开 **服务器管理**，进入 **防护系统**。
2. 启用 **反突袭防护**，点击 **配置**，并根据你平时的加入速度设置阈值和时间窗口。处罚方式选择 Kick 或 Ban。
3. 创建一个只有机器人会发言的隐藏频道，启用 **反发帖频道防护**，并将其添加到 **蜜罐频道** 下。
4. 启用 **反图片哈希防护**，然后点击 **屏蔽已知诈骗图片**。
5. 启用 **反批量发帖防护**，使用默认的 60 秒内三个频道，并仅检查链接。
6. 在 **身份组与权限** 下，将你的成员身份组添加到 **自动分配身份组** 中供普通用户使用，然后通过 **添加可自助领取的身份组** 设置一个颜色分组，并开启 **互斥模式**。
7. 在 **自动化与设置** 下设置 **工作人员身份组**、**成员身份组** 和 **服务器时区**。
8. 在 **高级操作** 下，趁一切平静时设置 **服务器恢复**。
9. 查看 **概览**：它会列出每个防护系统及其是否处于运行状态。

## 技巧与注意事项

- 机器人的身份组必须高于它分配、移除或封禁的任何身份组，并且需要拥有封禁成员、踢出成员、管理身份组或禁言成员等权限，以匹配你选择的处罚方式。静音处罚需要静音身份组，机器人会在首次使用时创建该身份组。
- 反突袭和反刷屏的时长命令最多只接受一天（`1d`），禁言时长则永远不能超过 28 天。
- 反刷屏只统计相同内容的重复消息。成员快速发送十条不同的消息，在它看来不算刷屏；这种情况由反批量发帖和反批量提及负责。
- 开启 **仅检查链接** 的反批量发帖会忽略所有不含链接的消息。关闭它可以拦截复制粘贴的文字，但在繁忙的服务器中会产生更多误报。
- 反模式的批量创建检查在每次加入时都会获取整个成员列表，在超大型服务器中会比较慢。
- 通过哈希而非图片本身添加的屏蔽图片，只能拦截完全相同的副本；请用图片重新添加，以覆盖镜像和带边框的版本。
- 在仪表板中启用防护会应用初始值。请打开 **配置** 并确认处罚方式，尤其是选择封禁之前。
- 自动分配、自助领取和反应身份组的命令会拒绝等于或高于你自己最高身份组的身份组，除非你是服务器所有者。
- 如果消息被删除，反应身份组也会失效；`reactionroleslist` 会显示哪些设置指向已删除的消息。
- 批量改名会影响机器人能够改名的每一位成员，包括低于其身份组的工作人员。请提前准备好将名称改回的方案。
- `delete` 和 `edit` 只能作用于机器人可以看到的消息，而 `edit` 只能作用于机器人自己发送的消息。
