## 功能介绍

这不是投票功能。投票功能会统计你的服务器在 top.gg 上收到的票数，并奖励投票的成员。当 top.gg 通知 Mewdeko 有人投过票时，机器人会记录该票数，在你的投票频道中发布感谢消息，并显示该成员的累计票数，同时发放你配置的任何投票奖励身份组。

从成员的角度看：他们在 top.gg 上为服务器投票后，投票频道中会出现一条提及他们的消息，并显示他们已投票的次数。如果你设置了投票身份组，他们会同时获得这些身份组，可以是永久的，也可以是设定时长的。

从员工的角度看：你需要设置一个投票频道、一个 Webhook 密码、一条可选的自定义消息，以及最多十个奖励身份组。此后，机器人会自动处理每一次投票。`votes` 和 `votesleaderboard` 命令可供任何人查询票数。

top.gg 与你的服务器之间的联系是投票密码。top.gg 会在其 Webhook 调用的 Authorization 请求头中发送该密码，Mewdeko 会将该请求头与每个服务器保存的密码进行匹配，从而判断这票属于哪个服务器。

## 为什么要使用它

- 你在 top.gg 上列出了你的服务器，希望每次有人投票时都能看到一条感谢消息。
- 你希望为投票者发放“投票者”身份组，或在十二小时后过期的临时福利身份组。
- 你希望每月生成一份投票排行榜，用于发放“最佳投票者”奖励。
- 你希望成员无需询问员工，即可自行查询自己的投票次数。

## 投票的处理流程

1. top.gg 会向机器人的 `/votes/` Webhook 端点发送请求，其中包含投票者的 Discord ID，并在 Authorization 请求头中附带你的密码。
2. 机器人查找保存的投票密码与之匹配的服务器。如果没有匹配项，该票将被丢弃。
3. 投票连同投票者的 ID 和时间一起保存。
4. 如果设置了投票频道，机器人会在该频道发布感谢消息。若未设置投票频道，则不会发布任何消息，也不会发放身份组。
5. 将每个投票身份组添加给该成员。带有计时的身份组会在计时结束后被移除，使用的是与禁言相同的计时身份组系统。

> [!WARNING]
> 密码是将投票与你的服务器关联起来的唯一纽带。知道密码的人都可以发送虚假投票。请勿将其粘贴到公开频道中；机器人为此通过私密弹窗来设置密码。

## 感谢消息

默认情况下，机器人会发送一条提及投票者的消息，以及一个标题为“感谢为 <server> 投票”的嵌入，其中包含一行其累计投票次数，并以其头像作为缩略图。

你可以使用 `votemessage` 命令或仪表板上的**自定义投票公告**框，将其替换为你自己的文字或嵌入。内容会经过嵌入解析器处理，因此嵌入构建器生成的任何内容都可以使用。在命令中将其设为 `-`，或在仪表板中清空该框，即可恢复为默认消息。

### 占位符

自定义消息支持通用占位符集（来自占位符页面的用户、服务器、频道、机器人和时间占位符），以及两个投票专用占位符。

| 占位符 | 值 |
| --- | --- |
| `%votestotalcount%` | 该成员的总投票次数 |
| `%votesmonthcount%` | 该成员在当前自然月内的投票次数 |
| `%user.mention%`、`%user.name%`、`%user.id%`、`%user.avatar%` | 投票者 |
| `%server.name%`、`%server.id%`、`%server.icon%`、`%server.members%` | 你的服务器 |

> [!EXAMPLE]
> `Thanks %user.mention% for voting! That is vote number %votestotalcount% (%votesmonthcount% this month).`

不带文字运行 `votemessage`，会以你自己的投票次数预览当前消息的显示效果。

## 投票身份组

每位投票者都会获得投票身份组。每个身份组可以设置可选的时长（以秒为单位）；`0` 表示永久。

- 每个服务器最多可设置十个投票身份组。
- 无法添加 `@everyone` 身份组。
- 同一身份组不能重复添加；如需更改时长，请使用 `voteroleedit`。
- 带时长的身份组会在时长到期后自动移除。
- 如果机器人无法分配某个身份组（例如该身份组位于机器人最高身份组之上），机器人会静默跳过该身份组。

## 投票次数与排行榜

`votes` 会显示某位成员本月和总计的投票次数，并附带其头像。`votesleaderboard` 会按总票数对服务器中的所有成员进行排名，每页十二人。传入 `true` 可仅按本月票数排名。两项“本月”数据均以自然月为准，而非最近三十天。

## 设置

投票页面有三个标签页：**配置**、**投票身份组**和**统计**。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 投票公告频道 | 无 | 感谢消息的发布位置。未设置时不会有任何动作 |
| API 密码（用于 Webhook） | 无 | top.gg 必须在 Authorization 请求头中发送的密钥 |
| 自定义投票公告 | 默认嵌入 | 你自己的消息，可使用上述占位符。留空则使用默认消息 |
| 要授予的身份组 | 无 | 授予每位投票者的身份组（投票身份组标签页） |
| 时长（秒，0 表示永久） | 0 | 投票身份组在被移除前的持续时间 |

**统计**标签页显示总票数、投票身份组数量、最高投票者的票数，以及前十名排行榜。

## 设置步骤

1. 在仪表板中打开**投票**，并停留在**配置**标签页。
2. 选择**投票公告频道**。若未设置，投票仍会被记录，但不会发布任何消息，也不会发放身份组。
3. 输入 **API 密码**。请使用足够长的随机字符串，并像对待 API 密钥一样妥善保管。
4. 可选地使用上述占位符编写**自定义投票公告**，然后点击**保存配置**。
5. 在 top.gg 的服务器页面中打开 Webhook 部分。将 Webhook URL 设置为机器人的 `/votes/` 端点，并将 Authorization 值设置为相同的密码。
6. 在**投票身份组**中选择**要授予的身份组**和**时长**，然后点击**添加投票身份组**。最多可重复添加十个身份组。
7. 确保机器人的身份组在身份组列表中位于所有投票身份组之上。
8. 使用 top.gg 的测试 Webhook 按钮，或等待一次真实投票，然后检查投票频道。

## 命令

请在命令前加上服务器的前缀（默认为 `.`，除非你已更改）。

| 命令 | 别名 | 所需权限 | 用途 |
| --- | --- | --- | --- |
| `votechannel <#channel>` | | 管理服务器 | 设置感谢消息的频道 |
| `votemessage [text]` | `votemsg` | 管理服务器 | 预览、设置，或重置（`-`）自定义消息 |
| `votepassword` | `votepass` | 管理服务器 | 通过私密弹窗设置 Webhook 密码 |
| `voteroleadd <@role> [time]` | `vra` | 管理服务器 | 添加投票身份组，可选设置时长，例如 `voteroleadd @Voter 12h` |
| `voteroleedit <@role> <time>` | `vre` | 管理服务器 | 更改投票身份组的持续时间 |
| `voteroleremove <@role>` | `vrr` | 管理服务器 | 移除一个投票身份组 |
| `voteroleslist` | `vrl` | 管理服务器 | 列出投票身份组及其时长 |
| `voterolesclear` | `vrc` | 管理服务器 | 确认后移除所有投票身份组 |
| `votes [@user]` | | 无需权限 | 显示成员的本月和总投票次数 |
| `votesleaderboard [true]` | `voteslb` | 无需权限 | 按总票数排名，传入 `true` 则按本月票数排名 |

相同的命令也以斜杠命令的形式存在于 `/votes` 下。

## 注意事项与提示

- 仅支持 top.gg 上的服务器投票。不支持其他机器人列表的集成，此功能也不会创建投票。
- 没有投票频道时，既不会发送消息，也不会发放身份组，但该票仍会被计入。
- 机器人需要拥有管理身份组权限，且其身份组必须位于所有投票身份组之上，否则身份组奖励会静默失败。
- 带时长的投票身份组使用与限时禁言相同的计时身份组系统，并会在审计日志中以“Vote Role”为原因记录。
- `voteroleedit` 仅通过身份组 ID 查找身份组，因此请只对你确实在本服务器中添加过的身份组使用该命令。
- 更改密码不会使已有的投票失效，但在你同时更新 top.gg 端的请求头之前，新的投票将无法匹配。
