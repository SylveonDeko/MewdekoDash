## 기능 소개

멤버는 `highlight add`로 단어나 문구를 추가해요. 그 뒤로 서버의 메시지에 그 단어가 들어 있으면 봇이 해당 멤버에게 DM을 보내요. DM에는 어떤 서버와 채널에서 일어났는지, 일치한 메시지 바로 앞의 메시지 다섯 개와 일치한 메시지, 그리고 **메시지로 이동** 버튼이 표시돼요.

하이라이트는 개인별로 관리돼요. 각 멤버는 자기 목록을 관리하고, 무시할 채널과 사람을 고르고, 삭제하지 않고 하이라이트를 끌 수도 있어요. 스태프는 다른 사람의 하이라이트를 추가할 수 없지만, 대시보드에서 어떤 단어가 감시되고 있는지 보고 항목을 삭제할 수 있어요.

멤버는 자신이 볼 수 있는 채널의 DM만 받아요. 서버에서 입력 중인 멤버는 대화에 있는 것으로 간주되어, 2분 동안 하이라이트 알림이 멈춰요.

## 이런 분께 추천해요

- 정확한 @멘션이 없어도 내 이름, 닉네임, 프로젝트 이름이 언급되면 알림을 받고 싶은 분
- 대형 서버에서 "giveaway"나 "patch notes" 같은 주제를 계속 따라가고 싶은 분
- 모든 채널을 읽지 않고도 "help"나 "report" 같은 단어를 살펴보고 싶은 스태프
- 멤버가 어떤 단어를 추적하는지 확인하고, 불쾌하거나 스팸성인 항목을 정리하고 싶은 모더레이터

## 일치 방식

봇은 비어 있지 않은 모든 메시지를 서버의 모든 하이라이트와 비교해요.

- 하이라이트는 단어 또는 문구 단위로 일치해요. `cat`은 "category"와 일치하지 않지만, "the cat sat"과는 일치해요.
- 대소문자를 구분해요. `Cat`과 `cat`을 모두 원하면 따로 추가하세요.
- 한 멤버는 서버에서 2분마다 최대 한 번만 DM을 받아요. 여러 단어가 일치해도 마찬가지예요.
- 서버 어디에서든 입력하면 같은 2분 대기 시간이 시작되므로, 이미 참여 중인 대화에 대한 DM은 받지 않아요.
- 무시한 사용자의 메시지와 무시한 채널의 메시지는 해당 멤버에게 건너뛰어요.
- 멤버가 채널을 볼 수 없거나 DM이 꺼져 있으면 DM을 보내지 않아요.
- 메시지는 대기열을 거쳐 2초에 하나씩 확인해요. 샤드가 아주 바쁠 때는 일부 메시지가 이 대기열에서 누락될 수 있어요.

`highlight match some text`는 내 목록을 샘플 문장과 비교해서, 어떤 단어가 일치했을지 알려 줘요. 이 확인은 대소문자를 구분하지 않으므로 대략적인 기준이며, 실제 알림 규칙과 완전히 같지는 않아요.

## 멤버별 설정

각 멤버에게는 처음 무언가를 바꿀 때 만들어지는 설정 행이 있어요.

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| 하이라이트 켜기 | 켜짐 | `highlight toggle false`를 실행하면 이 서버의 내 하이라이트가 모두 일시 정지돼요 |
| 무시할 채널 | 없음 | 내 단어가 있어도 DM을 보내지 않을 채널이에요 |
| 무시할 사용자 | 없음 | 이 사람들의 메시지는 내 하이라이트를 발동시키지 않아요 |

## 설정

대시보드의 하이라이트 페이지는 스태프용이에요. 하이라이트를 추가하지는 않고, 보고 삭제하는 용도예요.

| 탭 | 표시 내용 |
| --- | --- |
| 모든 하이라이트 | 멤버별로 묶은 서버의 모든 하이라이트예요. 단어마다 삭제 버튼이 있고, 멤버 한 명의 단어를 모두 지우는 버튼도 있어요 |
| 검색 | 모든 멤버의 하이라이트에서 단어를 찾아요. 검색은 대소문자를 구분하지 않아요 |
| 비활성 사용자 | 하이라이트를 끈 멤버와, 그 멤버가 무시하는 채널 수와 사용자 수예요 |
| 통계 | 전체 하이라이트, 활성 사용자, 가장 많은 단어, 가장 활발한 사용자, 가장 많이 하이라이트된 단어, 최근 하이라이트를 보여줘요 |

## 설정 순서

별도로 켤 필요는 없어요. 봇이 서버에 들어오면 하이라이트를 바로 사용할 수 있어요.

1. 멤버라면 아무 채널에서 `highlight add yourname`을 실행해요.
2. `highlight list`를 실행해서 저장되었는지 확인해요.
3. 다른 채널에서 누군가 내 이름을 입력하게 해요. 몇 초 기다린 뒤 DM을 확인해 보세요.
4. 알림이 너무 많으면 `highlight toggleignore #busy-channel` 또는 `highlight toggleignore @user`를 실행하세요.
5. 스태프라면 대시보드의 **하이라이트**를 열고 **모든 하이라이트** 탭을 검토한 뒤, 원하지 않는 항목을 삭제하세요.

## 명령어

이 명령어는 서버 접두사와 함께 실행하세요. 기본 접두사는 `.`이며, 바꾸지 않았다면 그대로 쓰면 돼요. 같은 동작을 하는 슬래시 명령어는 `/highlights manage` 하나예요. 이 명령어의 `action` 옵션은 `Add`, `List`, `Delete`, `Match`, `ToggleUser`, `ToggleChannel`, `ToggleGlobal`이며, 별도의 `words`, `user`, `channel` 옵션을 함께 사용해요.

| 명령어 | 별칭 | 필요 권한 | 용도 |
| --- | --- | --- | --- |
| `highlight add <word>` | `highlights`, `hl` | 없음 | 단어나 문구를 감시해요 |
| `highlight list` | `highlights`, `hl` | 없음 | 내 하이라이트를 페이지마다 10개씩 보여줘요 |
| `highlight delete <number or word>` | `highlights`, `hl` | 없음 | 목록 번호나 정확한 단어로 삭제해요. `remove`도 같은 역할을 해요 |
| `highlight match <text>` | `highlights`, `hl` | 없음 | 입력한 텍스트에서 내 단어 중 무엇이 나타나는지 보여줘요 |
| `highlight toggleignore <#channel or @user>` | `highlights`, `hl` | 없음 | 채널이나 사람을 내 무시 목록에 추가하거나 제거해요 |
| `highlight toggle <true or false>` | `highlights`, `hl` | 없음 | 이 서버의 내 하이라이트를 모두 켜거나 꺼요 |

## 팁과 주의 사항

- 봇이 채널을 읽을 수 있어야 그 채널에서 일치 검사를 할 수 있어요. 그리고 알림을 받으려면 서버 멤버에게서 DM을 받을 수 있도록 설정되어 있어야 해요.
- 이미 가지고 있는 단어를 다시 추가하면 거부돼요. 중복 확인은 대소문자를 구분하지 않지만, 실시간 일치 검사는 대소문자를 구분해요.
- 번호로 삭제할 때는 `highlight list`에 표시된 순서를 사용하는데, 삭제할 때마다 순서가 바뀌어요.
- 하이라이트 목록과 설정은 서버마다 30분 동안 캐시돼요. 명령어나 대시보드로 단어를 하나씩 추가하거나 삭제하면 캐시가 바로 갱신돼요. 하지만 대시보드에서 멤버의 단어를 모두 지우면 DM이 멈추기까지 최대 30분이 걸릴 수 있어요.
- 봇이 서버에서 나가면, 봇이 다음에 재시작될 때 그 서버의 하이라이트와 설정이 정리돼요.
