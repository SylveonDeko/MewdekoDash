## 기능 소개

도움말 모듈은 멤버가 봇으로 무엇을 할 수 있는지 알아보는 방법이에요. `help`(또는 `cmds`)를 입력하면 명령어 카테고리 목록과 각 카테고리의 모듈 및 명령어 수가 나타나고, 카테고리를 고를 수 있는 드롭다운도 함께 보여요. 카테고리를 고르면 모듈 목록이 나오고, 모듈을 고르면 명령어가 한 페이지에 10개씩 짧은 설명과 함께 표시돼요. 아주 큰 모듈은 먼저 섹션별 개요가 나와요.

`help <command>`는 명령어 하나를 보여줘요. 이름과 첫 번째 별칭, 기능, 명령어를 쓰기 위해 필요한 Discord 권한(사용자와 봇 각각), 쿨다운(있는 경우), 대응하는 슬래시 명령어, 각 매개변수, 다른 사용 형식, 사용 예시, 문서 링크를 보여줘요. **실행** 버튼을 누르면 도움말 페이지에서 바로 명령어를 실행할 수 있고, 인수가 필요하면 입력 양식이 먼저 나와요.

`searchcommand <term>`은 이름이나 설명에 검색어가 포함된 명령어를 찾아요. 봇을 멘션하고 아무 텍스트도 쓰지 않으면 현재 접두사와 `cmds` 안내를 답장해요.

모든 명령어에는 서버 접두사로 쓰는 텍스트 버전이 있고, 대부분은 슬래시 버전도 있어요. 도움말 메뉴와 명령어 페이지는 어느 쪽이든 같아요. `/help`, `/search`, `/invite`가 슬래시 명령어 진입점이에요.

## 이런 용도로 써요

- 새 멤버가 `.help`를 입력했을 때 처음 볼 곳이 필요할 때.
- 스태프가 권한을 주기 전에 명령어에 어떤 권한이 필요한지 정확히 알고 싶을 때.
- 명령어 이름의 일부만 기억나서 검색하고 싶을 때.
- 봇을 막 초대했고 모든 모듈 문서를 읽는 대신 안내에 따라 설정하고 싶을 때.

## 도움말 메뉴

인수 없이 `help`, `commands` 또는 `modules`를 입력하면 최상위 메뉴가 열려요. 임베드 설명에는 두 가지 사용 방법이 나와요. 드롭다운에서 카테고리를 고르거나, `h commandname`으로 명령어 하나를 보는 방법이에요. 문서, 지원 서버, 초대, 후원 페이지 링크도 함께 있어요.

| 카테고리 | 포함된 항목 |
| --- | --- |
| 관리 및 운영 | Administration, Moderation, Permissions, Server Management, Role States, Status Roles, Counting Moderation |
| 서버 설정 | MultiGreets, Role Greets, Starboard, Stat Channels, Suggestions, Tickets, Confessions, Channel Access, Custom Voice, Chat Triggers, Polls, Giveaways |
| 재미와 게임 | Games, Counting, NSFW, Searches, Minecraft, Switch |
| 경제와 레벨 | Currency, XP, Reputation, Vote, Patreon |
| 음악 | Music |
| 유틸리티 | Utility, Help, AFK, Todo, User Profile, Birthday, Highlights, Copr Monitoring |
| 봇 소유자 | 봇 소유자 전용 모듈 |
| 기타 | 위에 분류되지 않은 항목 |

**설명 전환** 버튼을 누르면 간결한 목록과 긴 형식 사이를 전환할 수 있어요. 긴 형식은 카테고리 아래 모든 모듈을 나열하고, 현재 채널에서 내게 켜져 있는지를 체크 표시나 X 표시로 보여줘요. 지구본과 X 표시는 봇 소유자가 모든 서버에서 해당 모듈을 끈 상태라는 뜻이에요.

### 모듈 페이지

`commands <module>`은 모듈 페이지로 바로 이동해요. 이름은 정확히 쓰거나 고유한 앞부분만 써도 돼요. 그래서 `cmds mod`는 Moderation을 열고, `cmds s`는 여러 모듈이 일치한다고 알려줘요. 모듈 이름 뒤에 단어를 더하면 목록을 거를 수 있어요. 예를 들어 `cmds utility remind`는 Utility 안에서 이름이나 설명에 "remind"가 포함된 명령어만 보여줘요.

명령어가 30개를 넘고 섹션이 세 개 이상인 모듈은 먼저 개요를 보여줘요. 모듈 설명, 섹션마다 명령어 수가 적힌 필드, 섹션을 여는 드롭다운, **모든 명령어** 버튼, 입력 양식을 여는 **검색** 버튼, **뒤로** 버튼이 나와요. 작은 모듈은 바로 페이지 목록으로 가요. 페이지에는 섹션별로 묶인 명령어 10개가 표시되고, 처음, 이전, 이동, 다음, 마지막, 뒤로, 닫기 버튼이 있어요. 페이지 넘김은 1시간 동안 작동해요.

## 명령어 페이지

`help <command>`는 정확한 이름이나 별칭과 일치해요. 임베드에는 다음 내용이 있어요.

- 접두사와 첫 번째 별칭이 붙은 명령어 이름과 설명.
- **사용자 권한**: 내가 필요한 권한. 관리 모듈의 Discord 권한 재정의가 기본 요구 사항을 대체하면, 원래 요구 사항에 취소선을 긋고 그 뒤에 재정의 내용을 보여줘요.
- **봇 권한**: 봇에 필요한 권한.
- **문서**: 문서 사이트에 있는 명령어 페이지 링크.
- **쿨다운**: 명령어에 쿨다운이 있을 때만 표시돼요.
- **슬래시 명령어**: 슬래시 버전이 있으면 클릭할 수 있는 멘션으로 보여줘요.
- 명령어 문서의 **매개변수**, **오버로드**, **사용법**. 각 인수가 선택 사항인지, 기본값이 있는지도 함께 보여줘요.
- 버그를 신고할 때 유용한 모듈, 하위 모듈, 메서드 이름 푸터.

**실행** 버튼은 입력한 것처럼 명령어를 실행해요. 인수가 필요하면 먼저 양식이 나와요. 관리자에게는 **권한** 버튼도 보여요. 이 버튼은 해당 명령어의 명령어 권한 빠른 메뉴를 열어요. 자세한 내용은 명령어 권한 문서를 참고하세요.

## 슬래시 명령어와 텍스트 명령어

텍스트 명령어는 서버 접두사(기본값 `.`)와 도움말 메뉴에 있는 정확한 이름을 사용해요. 슬래시 명령어는 그룹으로 묶여 있어요. 그래서 `setprivacy` 같은 텍스트 명령어는 `/setprivacy`로 나타나고, 권한 명령어는 `/permissions servercommand` 아래에 있어요. 명령어 페이지는 슬래시 멘션을 보여주므로 클릭해서 쓸 수 있어요. 두 형식 모두 같은 권한 규칙을 따라요.

## 봇이 들어왔을 때

봇을 서버에 추가하면 감사 로그에서 봇을 초대한 사람을 찾아 DM을 보내요. (이 기능을 쓰려면 감사 로그 보기 권한이 필요해요.) 메시지에는 해당 서버의 대시보드 마법사로 연결되는 **Mewdeko 설정하기** 버튼, `cmds`, `cmds mod`, `h purge`를 안내하는 3단계 알림, 지원 서버 링크가 있어요. 초대한 사람을 찾을 수 없거나 DM을 닫아 두었다면 아무것도 보내지 않아요. 채널에 공지하지도 않아요.

## 설정 마법사

마법사는 대시보드의 `/wizard?guild=<id>`에 있어요. 환영 DM의 링크는 빠른 설정 버전을 열고, 대시보드에서는 첫 실행용 버전을 제공할 수 있어요. 첫 실행용 버전은 시작할 때 권한 확인 단계를 추가해요.

| 단계 | 하는 일 |
| --- | --- |
| 환영 | 앞으로 진행될 내용을 설명해요 |
| 권한 | 첫 실행에만 나와요. 봇에 필요한 권한이 있는지 확인해요 |
| 서버 기본 설정 | 접두사, 봇 언어, 서버 시간대 |
| 기능 선택 | 설정할 기능을 고르고, 각 기능은 전체 설정 또는 빠른 활성화로 표시돼요 |
| 전체 설정 기능마다 한 단계 | 해당 기능의 안내 설정 |
| 빠른 설정 | 나머지 기능을 기본값으로 한꺼번에 켜요 |
| 완료 | 저장에 실패한 항목을 포함한 요약을 보여줘요 |

진행 상황은 서버별로 저장되므로, 나갔다가 돌아와도 이어서 할 수 있어요. 서버를 건너뛰기로 표시하면 마법사가 더 이상 나타나지 않아요. **내 설정** 페이지에는 안내 설정을 선호하는지 전환하는 토글과 서버 마법사 상태를 초기화하는 기능이 있어요.

## 설정

도움말 자체에는 설정할 것이 없어요. 접두사는 관리 모듈에서 설정하며, 모든 도움말 임베드에 표시돼요.

| 설정 | 기본값 | 제어 내용 |
| --- | --- | --- |
| 접두사 | `.` | 도움말 텍스트에 표시되고, 실행 버튼에서 사용하는 접두사예요 |
| 자세한 권한 안내 | 끔 | 차단된 명령어가 어떤 권한 규칙 때문에 막혔는지 설명할지 정해요 (명령어 권한 문서 참고) |

## 설정 순서

1. `help`를 입력하고 드롭다운에서 카테고리를 열어 모듈이 어떻게 묶였는지 확인해요.
2. `cmds mod`로 Moderation 모듈을 보고, `h purge`로 명령어 하나를 자세히 봐요.
3. `h ping` 같은 무해한 명령어에서 **실행** 버튼을 눌러 봐요.
4. `searchcommand role`을 입력해서 검색 결과가 어떻게 좁혀지는지 봐요.
5. 방금 봇을 초대했다면 환영 DM의 **Mewdeko 설정하기** 링크를 따라가거나, 대시보드에서 `/wizard?guild=<your server id>`를 열어요.

## 명령어

서버 접두사(변경하지 않았다면 `.`)를 붙여서 실행해요.

| 명령어 | 별칭 | 필요 권한 | 용도 |
| --- | --- | --- | --- |
| `help [command]` | `h` | 없음 | 도움말 메뉴, 또는 명령어 하나의 도움말 |
| `commands [module] [term]` | `cmds` | 없음 | 모듈 목록, 모듈 하나의 명령어, 또는 필터링된 목록 |
| `modules` | `mdls` | 없음 | `help`와 같은 최상위 메뉴 |
| `searchcommand <term>` | | 없음 | 명령어 이름과 설명을 검색해요. 최대 20개 결과 |
| `guide` | `readme` | 없음 | 시작 가이드 링크 |
| `source` | `github`, `repo`, `gitlab`, `bitbucket` | 없음 | 소스 코드 링크 |
| `donate` | | 없음 | 봇을 후원하는 방법 |
| `vote` | | 없음 | 봇에 투표하는 링크 |
| `exportcommandsjson` | `exportcommands`, `excj` | 없음 | 모든 명령어를 JSON 파일로 내보내요 (1분마다 한 번) |

슬래시 명령어 전용: 자동 완성이 있는 `/search <command>`와 `/invite`. `/help`, `/commands <module> [filter]`, `/donate`, `/guide`, `/source`, `/vote`는 텍스트 명령어와 같은 기능이에요.

## 팁과 주의 사항

- `help`에서 모듈 옆에 X 표시가 보이면, 내 권한이나 권한 규칙, 또는 봇 소유자가 이 채널에서 해당 모듈을 껐다는 뜻이에요. 스태프에게 `listperms`로 확인해 달라고 하세요.
- 도움말 페이지는 명령어의 실제 실행 조건을 반영해요. 그래서 문서 사이트가 뒤처져 있어도 도움말에 나온 권한이 정확한 기준이에요.
- 실행 버튼은 봇의 권한이 아니라 내 권한을 사용해요. 편의 기능일 뿐이며, 권한을 우회하지 않아요.
- 모듈 이름을 앞부분으로 찾으면 짧은 접두사는 여러 모듈과 겹치기 쉬우니 최소 3~4글자를 입력하세요.
- 봇은 초대한 사람에게만 가입 시 DM을 보내요. 공유 링크로 초대했는데 아무것도 받지 못했다면, 대시보드에서 마법사를 여세요.
