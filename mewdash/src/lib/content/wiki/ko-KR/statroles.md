## 기능 소개

XP 레벨 역할은 한 번 얻으면 영원히 유지돼요. 통계 역할은 일정한 주기로 다시 평가돼요. 조건을 충족하는 멤버는 역할을 받고, 조건을 더 이상 충족하지 않는 멤버는 역할을 잃어요. 그래서 "활동 멤버" 역할은 *지금* 활동하고 있다는 뜻이 돼요. 예전 방식을 원하면 영구 역할로 만들고, 반대로 비활동 멤버를 표시하고 싶다면 조건을 뒤집을 수 있어요.

## 조건

모든 통계 역할은 기간 하나에 걸쳐 한 가지 값을 측정하고, 제한 하나를 적용해요.

| 측정 대상 | 세는 내용 |
| --- | --- |
| 메시지 | 기간 안의 메시지 수예요. 원하는 채널로 제한할 수 있어요 |
| 음성 시간(분) | 기간 안의 음성 채널 체류 시간이에요. 통계 활동 페이지에서 제외한 음성 상태를 반영해요 |
| 게임 플레이 시간(분) | 기간 안에서 특정 게임이나 앱, 또는 모든 게임에서 보낸 시간이에요. 게임 추적을 켜야 해요 |
| 초대 | 멤버의 순 초대 수예요 |
| 서버 참여 일수 | 멤버가 들어온 뒤로 지난 날 수예요 |
| 계정 나이 | 계정을 만든 뒤로 지난 기간이에요 |

| 제한 | 해당되는 멤버 |
| --- | --- |
| 임계값 | 최소값과 선택 사항인 최대값 사이에 있는 멤버예요 |
| 상위 순위 | 두 순위 사이에 있는 멤버예요. 예: 상위 10명 |
| 상위 백분율 | 순위가 매겨진 멤버 중 상위 X%에 드는 멤버예요. 예: 상위 5% |
| 일일 연속 기록 | 하루 최소 기준을 채운 날이 기간 안에서 N일 이상인 멤버예요. 예: 최근 7일 중 7일 동안 하루 5개 메시지 |

기간은 1일부터 90일까지 설정하거나, 연속 기록을 제외한 모든 기준에 대해 전체 기간으로 설정할 수 있어요. 동점자는 같은 순위를 받아요.

## 필터와 옵션

| 옵션 | 기능 |
| --- | --- |
| 채널에서만 집계 | 메시지나 음성을 선택한 채널로 제한해요 |
| 필수 역할 | 고려되려면 최소 하나 이상 가지고 있어야 하는 역할이에요 |
| 제외 역할 | 이 역할 중 하나라도 가지고 있으면 절대 고려하지 않아요 |
| 무시할 멤버 | 이 멤버들에게는 역할을 주거나 제거하지 않아요 |
| 그룹 | 같은 그룹을 공유하는 통계 역할은 멤버가 충족하는 가장 높은 단계만 유지해요. 그래서 브론즈, 실버, 골드가 겹치지 않아요 |
| 영구 | 한 번 얻으면 절대 제거하지 않아요 |
| 반전 | 조건을 *충족하지 않는* 멤버가 역할을 받아요 |
| 봇 포함 | 봇 계정도 고려해요 |
| 평가 주기 | 규칙을 실행하는 빈도예요. 최소 10분마다이며, 기본값은 3시간마다예요 |
| 채널에 알림 / 멤버에게 DM | 역할을 주거나 제거할 때 메시지를 보내요. `%user%`, `%role%`, `%action%`(얻음 또는 잃음), `%value%`, `%stat%`를 쓸 수 있어요 |

## 대시보드

**통계 역할** 탭에는 모든 규칙이 조건, 주기, 마지막 실행 시간과 함께 나열돼요. 각 규칙을 켜고 끄거나, 수정하거나, 삭제하거나, **미리보기** 또는 **실행**을 할 수 있어요. 미리보기는 아무것도 바꾸지 않고, 누가 역할을 얻고 잃을지 보여줘요. 실행은 즉시 적용되며, 수동 실행은 서버당 10분에 한 번으로 제한돼요.

**만들기 / 편집** 탭은 위의 모든 항목을 입력하는 양식이에요.

## 명령어

이 명령어는 서버 접두사로 실행하세요(변경하지 않았다면 `.`이에요). 모든 명령어는 `/statrole` 아래에서도 쓸 수 있어요.

| 명령어 | 별칭 | 필요 권한 | 용도 |
| --- | --- | --- | --- |
| `statroleadd <@role> <stat> <minimum> [days] [name]` | `sradd` | 역할 관리 | 임계값 규칙이에요 |
| `statroletop <@role> <stat> <topEnd> [days] [name]` | `srtop` | 역할 관리 | 1위부터 topEnd위까지에 대한 상위 순위 규칙이에요 |
| `statrolepercent <@role> <stat> <percent> [days] [name]` | `srpercent` | 역할 관리 | 상위 백분율 규칙이에요 |
| `statrolestreak <@role> <stat> <perDay> <requiredDays> [days] [name]` | `srstreak` | 역할 관리 | 일일 연속 기록 규칙이에요 |
| `statrolelist` | `statroles` | 없음 | 모든 규칙을 보여줘요 |
| `statroleinfo <id>` | `srinfo` | 없음 | 규칙 하나를 자세히 보여줘요 |
| `statroleset <id> <setting> <value>` | `srset` | 역할 관리 | 이름, min, max, lookback, topstart, topend, days, permanent, invert, bots, group, interval, notifychannel, notifydm, message, activity 중 하나를 바꿔요 |
| `statrolefilter <id> <#channel, @role [true], or @user>` | `srfilter` | 역할 관리 | 채널 필터, 필수 역할(`true`를 붙이면 제외 역할), 또는 무시할 멤버를 켜고 꺼요 |
| `statroletoggle <id>` | `srtoggle` | 역할 관리 | 켜거나 꺼요 |
| `statrolepreview <id>` | `srpreview` | 역할 관리 | 누가 역할을 얻고 잃을지 보여줘요 |
| `statrolerun <id>` | `srrun` | 역할 관리 | 지금 바로 적용해요 |
| `statroleremove <id>` | `srremove` | 역할 관리 | 규칙을 삭제해요. 멤버는 지금 가진 역할을 유지해요 |

## 팁과 주의 사항

- 봇의 최상위 역할은 관리하려는 역할보다 위에 있어야 하며, 봇에는 **역할 관리** 권한이 필요해요.
- 디스코드 역할 하나는 통계 역할 하나만 관리할 수 있어요. 같은 역할을 새 규칙에 연결하기 전에 기존 규칙을 삭제하세요.
- 최소값이 0이고 최대값이 없는 규칙은 모든 멤버에게 맞아요. 최대값을 설정하거나, 반전을 의도적으로 사용하세요.
- 통계 활동을 끈 멤버는 메시지, 음성, 게임 시간이 기록되지 않으므로, 이 기준으로는 역할을 얻지 못해요.
- 규모가 큰 서버에서는 규칙을 켜기 전에 미리보기를 먼저 하세요. 역할 변경은 속도 제한을 지키기 위해 간격을 두고 적용되므로, 수천 명에게 영향을 주는 규칙은 적용하는 데 몇 분이 걸려요.
