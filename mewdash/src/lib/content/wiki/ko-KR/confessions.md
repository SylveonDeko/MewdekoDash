## 기능 소개

멤버가 서버에서 `/confess`를 실행하거나, 봇에게 DM으로 `.confess <server id> "text"`를 보내면, 봇은 고백 채널에 "Anonymous confession #N" 제목의 임베드로 내용을 게시해요. 채널에는 보낸 사람의 이름이 나오지 않아요. 보낸 사람에게는 개인 확인 메시지가 가고, 고백 번호는 하나씩 올라가요.

스태프는 별도의 로그 채널을 설정할 수 있어요. 모든 고백은 보낸 사람의 태그와 ID, 고백 번호, 게시된 메시지로 이동하는 링크와 함께 로그 채널에도 복사돼요. 모든 고백의 바닥글에는 고백하는 방법이 나와 있고, 확인 메시지에는 기능을 악용하는 서버를 신고할 수 있다고 안내돼요.

스태프는 개별 멤버를 블랙리스트에 추가해서 고백을 거부할 수도 있고, 대시보드에서 고백을 삭제할 수도 있어요. 삭제하면 Discord 메시지도 함께 지워져요.

## 이런 때 써요

- 멤버가 이름을 밝히지 않고 털어놓고 싶은 고민 또는 "차" 채널
- 이름 없이 칭찬이나 감사를 전할 수 있는 채널
- 익명 채널이지만 괴롭힘이 있을 때 스태프가 누가 했는지 추적해야 하는 경우

## 고백 게시물

고백은 고백 채널에 임베드로 게시돼요.

| 구성 | 내용 |
| --- | --- |
| 작성자 줄 | 서버 아이콘과 함께 `Anonymous confession #N` |
| 설명 | 고백 내용 |
| 이미지 | 첨부 파일이 있으면 표시 |
| 바닥글 | `Do /confess or dm me .confess <server id> yourconfession to send a confession!` |
| 타임스탬프 | 게시된 시간 |

번호는 1부터 시작하고, 저장된 마지막 고백 번호에서 이어져요. 고백을 삭제해도 다른 고백의 번호는 바뀌지 않아요.

첨부 파일은 두 방식 모두 지원해요. `/confess`에서 `attachment` 옵션으로 파일을 첨부하거나, 텍스트 명령어를 쓸 때는 DM에 파일을 첨부하면 돼요. 첫 번째 첨부 파일만 사용해요.

## 로그 채널

**로그 채널**을 설정하면 고백마다 로그 채널에 빨간색 임베드가 추가로 게시돼요. 임베드에는 **사용자**(태그와 ID), **Confession N**(고백 내용), **Message Link**, 그리고 악용에 대한 경고가 들어 있어요. 보낸 사람이 드러나는 곳은 이곳뿐이므로, 신뢰하는 사람에게만 접근을 허용하세요.

> [!WARNING]
> 로그 채널은 스태프가 괴롭힘을 처리할 수 있도록 만들어진 곳이에요. 고백을 보낸 사람을 공개하면 봇 소유자가 서버를 블랙리스트에 올릴 수 있어요. 멤버는 `/confessions report`로 악용을 신고할 수 있어요.

## 블랙리스트

`confessionblacklist`는 멤버를 서버의 블랙리스트에 추가하고, `confessionunblacklist`는 제거해요. 블랙리스트에 있는 멤버가 고백하면 게시되지 않고 "you are blacklisted" 메시지를 받아요. 확인은 사용자 ID로 해요.

대시보드에는 **역할 블랙리스트**가 있고, 여기서 고른 역할 ID도 같은 목록에 저장돼요. 하지만 현재 봇은 고백이 들어올 때 보낸 사람의 사용자 ID만 목록과 비교하므로, 대시보드에서 고른 역할로는 아무도 막히지 않아요. 특정 멤버를 막으려면 명령어를 사용하세요.

## 설정

**고백** 페이지에는 **설정**, **고백**, **통계** 탭이 있어요.

| 설정 | 기본값 | 역할 |
| --- | --- | --- |
| 고백 채널 | 없음 | 익명 고백이 게시되는 곳이에요. 채널을 정하기 전에는 고백 기능이 꺼져 있어요 |
| 로그 채널 (사용자 ID 표시) | 없음 | 고백 보낸 사람을 확인할 수 있는 복사본이 가는 곳이에요 |
| 역할 블랙리스트 | 없음 | 위의 블랙리스트 섹션을 참고하세요 |

**고백** 탭에는 저장된 모든 고백이 최신순으로 번호와 날짜와 함께 나와요. 내용은 펼치기 전까지 숨겨져 있고, **고백 삭제**를 누르면 데이터베이스에서 지우고 Discord 메시지가 아직 남아 있다면 그 메시지도 삭제해요.

**통계** 탭에는 **전체 고백**, **이번 달**, **오늘**, **최신 번호**가 나와요.

## 설정 순서

1. 봇이 메시지 보내기와 링크 임베드를 할 수 있고, 멤버는 읽을 수는 있지만 가능하면 글을 쓸 수 없는 채널을 만드세요.
2. 대시보드에서 **고백**을 열고 그 채널을 **고백 채널**로 고르세요.
3. 필요하면 비공개 스태프 채널을 **로그 채널**로 고르세요.
4. **설정 저장**을 누르세요.
5. 멤버 계정으로 `/confess`를 실행해서 `#1` 임베드가 보이는지 확인하세요.
6. 누군가 기능을 악용하면 로그 채널에서 그 사람을 찾아 `confessionblacklist @user`를 실행하세요.

## 명령어

서버의 접두사로 실행하세요(변경하지 않았다면 `.`). 슬래시 명령어는 `/confessions` 아래에 있고, `/confess`만 최상위에 있어요.

| 명령어 | 별칭 | 필요 권한 | 용도 |
| --- | --- | --- | --- |
| `confess <server id> <"text">` | | 없음 | DM 전용. 지정한 서버에 고백을 게시해요. 여러 단어는 따옴표로 감싸세요 |
| `confessionchannel [#channel]` | `confesschannel` | 채널 관리 | 고백 채널을 설정하거나, 채널 없이 실행하면 고백을 꺼요 |
| `confessionlogchannel [#channel]` | `confesslogchannel`, `confessionlogchnl` | 관리자 | 로그 채널 설정 |
| `confessionblacklist <@user>` | `confessblacklist`, `confessbl` | 채널 관리 | 멤버의 고백 막기 |
| `confessionunblacklist <@user>` | `confessunblacklist`, `confessunbl` | 채널 관리 | 블랙리스트에 있던 멤버가 다시 고백할 수 있게 하기 |

`/confessions report <server id> <description>`은 고백 기능을 악용하는 서버에 대한 신고를 봇 소유자에게 보내요. 텍스트 명령어는 없어요.

## 팁과 주의할 점

- 봇은 고백 채널과 로그 채널 모두에서 메시지 보내기와 링크 임베드 권한이 필요해요. 채널 명령어는 권한이 없으면 경고하지만, 설정은 그대로 저장돼요.
- 텍스트 `confess` 명령어는 DM에서만 동작하고, 고백 내용을 하나의 인수로 받아요. 그래서 `confess 123456789 "I like pineapple on pizza"`처럼 따옴표를 써야 해요. 따옴표 없이 쓰면 첫 단어만 게시돼요. 서버 안에서는 `/confess`가 멤버에게 더 간단해요.
- DM으로 하는 `confess`는 봇과 함께 있는 서버에서만 동작해요. 다른 서버 ID는 거부돼요.
- 로그 채널이 없는 상태에서 텍스트 `confessionlogchannel` 명령어를 채널 없이 실행하면, 로그 채널이 아니라 고백 채널이 지워져요. 로그 채널은 대시보드에서 지우세요.
- 고백은 로그 채널이 없어도 보낸 사람의 사용자 ID와 함께 저장되며, 대시보드에서 고백 하나의 보낸 사람을 조회할 수 있어요. 대시보드 접근은 스태프에게만 허용하세요.
- 대시보드에서 삭제하면 저장된 기록이 지워지므로, 로그 채널의 복사본만 남아요.
