## 기능 소개

프로세스 로그는 봇이 콘솔에 출력하는 내용을 pm2가 보관하는 로그 파일에서 바로 보여줘요. 서버에서 셸을 열지 않아도 돼요. 이 페이지는 봇 소유자에게만 보여요. 소유자가 아니면 사이드바에 메뉴가 나타나지 않고, URL로 직접 들어가도 대시보드 홈으로 돌아가요. 또한 로그인한 계정이 소유자가 아니면 봇도 요청을 거부해요.

선택한 봇 인스턴스에 pm2 프로세스 목록을 요청하면, 이 호스트에서 pm2가 관리하는 모든 프로세스가 표시돼요. 봇만이 아니라 전부예요. 각 프로세스의 상태, pid, 가동 시간, 재시작 횟수, CPU와 메모리 사용량, 로그 파일 두 개의 크기가 함께 보여요. 프로세스를 선택하면 표준 출력(stdout) 로그의 마지막 수백 줄을 불러와요. **따라가기**가 켜져 있으면 2초마다 새 줄을 계속 덧붙여요.

줄마다 Serilog가 출력하는 색상이 유지되고, 각 줄에는 레벨 태그가 붙어서 원하지 않는 줄을 숨길 수 있어요. 스택 트레이스 같은 이어지는 줄은 바로 위의 줄에 붙어 있으므로, 정보 줄을 숨겨도 트레이스가 떨어져 나가지 않아요.

## 이런 때 사용해요

- 봇이 재시작되었거나 충돌했을 때, 종료되기 직전 마지막으로 출력한 내용을 보고 싶을 때. 이 내용은 표준 오류(stderr) 쪽에 있어요.
- 멤버가 명령어 실패를 알려 왔을 때, 그 멤버가 다시 시도하는 동안 로그를 실시간으로 지켜보고 싶을 때
- SSH 접속 없이 최근 몇천 줄에서 서버 ID나 메시지를 찾고 싶을 때
- 버그 보고에 전체 로그 파일이 필요해서 다운로드하고 싶을 때

## 컨트롤

| 컨트롤 | 기능 |
| --- | --- |
| 프로세스 카드 | 호스트의 pm2 프로세스마다 하나씩 있어요. **이 봇**이라고 표시된 카드가 현재 요청에 응답하는 인스턴스예요. 클릭하면 해당 프로세스의 로그를 읽어요. |
| **stdout** / **stderr** | 일반 로그가 출력되는 표준 출력 로그와, 충돌과 런타임 진단 정보가 남는 표준 오류 로그 사이를 전환해요. |
| **100** ~ **2k** | 로그를 열거나 새로고침할 때 불러올 줄 수예요. 따라가기 모드에서는 페이지에 최대 5,000줄까지 유지하고, 넘치면 오래된 줄부터 지워요. |
| 필터 입력란 | 입력한 텍스트를 포함하지 않는 줄을 숨겨요. 대소문자는 구분하지 않아요. |
| **따라가기** / **팔로우** | 실시간 업데이트를 켜고 꺼요. 켜져 있으면 페이지가 2초마다 새 줄을 확인하고, 위로 스크롤하지 않은 동안에는 따라서 스크롤해요. |
| **줄바꿈** | 긴 줄을 스크롤하지 않고 감싸서 보여줘요. |
| **복사** | 보이는 줄을 색상 코드 없이 클립보드에 복사해요. |
| **새로고침** | 파일의 끝부분을 다시 읽어요. |
| **다운로드** | 디스크에 있는 로그 파일 전체를 색상 코드와 함께 저장해요. 옆의 크기는 파일의 현재 크기예요. |
| 레벨 칩 | **VRB**, **DBG**, **INF**, **WRN**, **ERR**, **FTL**이며, 각 칩에는 불러온 태그 줄 수가 표시돼요. 클릭하면 해당 레벨을 숨기거나 표시해요. |

따라가는 중에 위로 스크롤하면 새 줄은 보류되고, 오른쪽 아래의 버튼에 대기 중인 줄 수가 표시돼요. 버튼을 누르면 맨 아래로 이동하고 다시 로그를 따라가요.

> [!NOTE]
> 한 번의 읽기는 1MB까지만 가능해요. 요청한 줄이 이 크기 안에 들어가지 않으면, 페이지는 더 오래된 줄이 생략되었다고 알려 줘요. 전체 내용을 보려면 파일을 다운로드하세요.

## 봇이 로그를 찾는 방법

봇은 자신의 호스트에서 `pm2 jlist`를 실행하고, pm2가 각 프로세스에 대해 보고하는 로그 파일 경로를 읽어요. 이 작업은 같은 사용자로 pm2 데몬이 이미 실행 중일 때만 해요. 그래서 봇이 실수로 pm2를 새로 시작하는 일은 없어요. pm2가 설치되어 있지만 조회할 수 없으면, 페이지는 pm2 로그 디렉터리의 파일을 대신 보여주고 그 사실을 알려 줘요. pm2가 아예 없으면 빈 목록 대신 그 사실을 설명해요.

여러 봇 인스턴스에 연결된 대시보드에서는, 프로세스 목록이 선택된 인스턴스의 것이에요. 각 인스턴스는 자신의 호스트만 볼 수 있기 때문이에요.

## 설정 따라 하기

1. 봇을 서버에서 pm2로 실행하세요. 예를 들면 `pm2 start dotnet --name mewdeko -- Mewdeko.dll`처럼 실행해요.
2. 봇 소유자 계정으로 대시보드에 로그인하고, 사이드바에서 **프로세스 로그**를 여세요.
3. **이 봇**이라고 표시된 프로세스나, 호스트의 다른 프로세스를 고르세요.
4. 실시간으로 보려면 **따라가기**를 켜 두고, 이미 불러온 내용을 살펴보려면 끄고 필터와 레벨 칩을 사용하세요.
5. 충돌한 뒤에는 **stderr**로 전환해서 종료 과정에서 런타임이 출력한 내용을 읽으세요.

## 팁과 주의 사항

- 로그는 파일에서 읽으므로, pm2 외부에서 시작된 프로세스는 여기에 로그가 없어요. 봇의 콘솔 출력은 봇 자체가 pm2로 실행될 때만 나타나요.
- `pm2 flush`를 실행하거나 `pm2-logrotate`를 쓰면 파일이 교체되거나 비워져요. 페이지는 파일이 줄어든 것을 알아채고 끝부분을 자동으로 다시 불러와요.
- 필터와 레벨 칩은 이미 불러온 줄에만 적용돼요. 더 이전 내용을 검색하려면 줄 수를 늘려서 다시 불러오거나 파일을 다운로드하세요.
- 이 페이지에서는 봇을 바꿀 수 없어요. 프로세스를 재시작하거나 로그를 지우는 기능은 없어요. 그 작업은 소유자용 `restartinstance` 명령어나 서버에서의 `pm2 flush`로 해요.
