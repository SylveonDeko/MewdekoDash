## 기능 소개

모든 멤버는 지갑을 가지고 있고, 은행 기능을 켜 두었다면 은행 잔액도 있어요. 멤버는 일일 보상을 받거나, `work`와 `crime`을 쿨다운마다 실행하거나, 게임에서 이기거나, 다른 멤버에게 송금받아서 화폐를 얻어요. 그리고 상점에서 역할, 수집품, 텍스트 아이템을 사거나, blackjack, roulette, slots, crash, keno 같은 게임에 걸 수 있어요.

운영진은 경제가 어떻게 작동할지 정할 수 있어요. 도박 사용 여부, 베팅 한도, 하우스 엣지, 일하기와 범죄의 보상, 강도 허용 여부, 송금 수수료, 은행 이자, 연속 보상 보너스가 모두 설정 대상이에요. 이 값들은 **설정** 탭이나 `economyset` 키로 바꿀 수 있어서, 게임을 건드리지 않고도 경제를 조정할 수 있어요.

봇은 모든 입금과 출금을 거래 내역으로 기록해요. 그래서 멤버는 돈이 어디에 쓰였는지 확인할 수 있고, **분석** 탭에서는 통화량, 화폐가 어디에 머무르는지, 그리고 어떤 게임이 참여자에게 지급한 금액보다 더 많이 받는지 볼 수 있어요.

## 이런 때 사용해요

- 활동적인 멤버에게 쓸 곳을 주세요. 색이 있는 역할, 커스텀 칭호, 게임 채널의 재미 같은 것들이요.
- 베팅 한도, 일일 손실 한도, 하우스 엣지가 자동으로 적용되니 게임 채널을 공정하게 유지할 수 있어요.
- 도움을 준 멤버에게 `modifybalance`나 **잔액 조정** 도구로 보상하고, 멤버가 상점에서 고르게 해 주세요.
- **게임 성과** 표에서 게임별 실제 환급률을 확인하고, 추측이 아니라 데이터를 보고 `payoutmultiplier`를 조정하세요.

## 잔액, 은행, 송금

`cash`는 지갑을 보여 주고, 은행에 맡긴 돈이 있다면 은행 잔액과 순자산도 보여 줘요. `bank`는 다른 멤버의 같은 정보를 보여 주고, 받을 이자도 함께 받아요. `deposit`과 `withdraw`로 지갑과 은행 사이에서 돈을 옮길 수 있고, 금액 대신 `all`을 쓸 수도 있어요. 은행에 맡긴 돈은 강도 피해를 입지 않아요. **은행 한도**로 보관할 수 있는 최대 금액을 정할 수 있어요 (0이면 제한 없음).

이자는 멤버가 `bank`를 실행할 때 지급돼요. 마지막 이자 지급 이후 주기가 지났다면, 은행 잔액에 **이자 (%)**가 한 번 붙어요. 아무도 확인하지 않는 동안에는 이자가 지급되지 않아요.

`pay`는 지갑의 화폐를 다른 멤버에게 보내요. 이때 **송금 수수료 (%)**가 빠지고, **최소 송금액**과 선택 사항인 쿨다운이 적용돼요. 봇에게는 송금할 수 없어요.

`transactions`는 본인이나 다른 멤버의 최근 거래 250건을 한 페이지에 10건씩 보여 줘요. `cashleaderboard`는 지갑과 은행을 합친 금액으로 멤버 순위를 매겨요.

## 수입 얻기

| 명령어 | 기본값 | 동작 |
| --- | --- | --- |
| `dailyreward` | 운영진이 `setdaily`를 실행하기 전까지 설정되지 않음 | 쿨다운마다 일일 금액을 한 번 지급해요. 연속 보상을 켜 두면, 연속으로 받을 때마다 첫날을 넘어선 연속 일수에 **일일 보너스**를 곱한 금액이 더해지고, **최대 보너스**까지만 올라가요. 전체 쿨다운 기간을 놓치면 연속 기록이 초기화돼요. |
| `work` | 50~250, 30분마다 | 설정된 범위 안에서 무작위 금액을 지급해요. 항상 성공해요. |
| `crime` | 200~800, 성공 확률 45%, 1시간마다 | 성공하면 범죄 보상 범위의 금액을 지급해요. 실패하면 100~500의 벌금을 내는데, 지갑에 있는 금액까지만 차감돼요. |
| `rob @user` | 꺼짐 | 켜져 있을 때: 35% 확률로 대상 지갑의 최대 20%를 빼앗아요. 100 미만을 가진 대상은 보호받아요. 실패하면 본인 지갑의 15%를 잃어요. 1시간에 한 번만 시도할 수 있어요. |

## 게임

모든 베팅은 같은 조건을 통과해야 해요. 도박이 켜져 있어야 하고, 베팅 금액이 **최소 베팅**과 **최대 베팅** 사이에 있어야 하며, 멤버가 최근 24시간 동안 **일일 손실 한도**에 도달하지 않았어야 하고, 게임 쿨다운(설정되어 있다면)이 지났어야 해요. 베팅 금액은 미리 차감돼요. 당첨금은 `stake plus profit`(베팅 금액 + 수익)이고, 수익 부분은 **지급 배율**에 따라 계산돼요. 예를 들어 배율이 0.9이면 모든 당첨금이 10% 줄어들고, 무승부는 베팅 금액 전액을 돌려받아요.

| 게임 | 지급 방식 |
| --- | --- |
| `coinflip <bet> heads/tails` | 맞히면 1:1 지급 |
| `highlow higher/lower [bet]` | 1부터 10 사이의 숫자가 보여요. 다음 숫자가 더 높을지 낮을지 맞히세요. 1:1 지급이고, 같은 숫자가 나오면 베팅 금액을 돌려받아요. 기본 베팅은 100이에요. |
| `spinwheel [bet]` | 베팅 금액의 마이너스 10%에서 플러스 30%까지 여러 구간이 있는 가중 룰렛이에요. 기본 베팅은 10이에요. |
| `blackjack <bet>`, 그리고 `hit`과 `stand` | 딜러는 17까지 뽑아요. 이기면 1:1, 비기면 무승부예요. |
| `slot [bet]` | 같은 심볼 두 개가 나오면 2배, 세 개가 맞으면 3배예요. 포도는 5배, 세븐은 7배, 다이아몬드는 10배예요. 기본 베팅은 10이에요. |
| `roulette <bet> <type>` | 0부터 36 사이의 숫자를 맞히면 35:1로 지급해요. `red`, `black`, `even`, `odd`는 1:1로 지급하고, 0이 나오면 색과 홀짝 베팅은 모두 져요. |
| `rps <choice> [bet]` | 봇과 바위, 보, 가위, 도마뱀, 스팍 중 하나로 겨뤄요. 1:1 지급이고, 무승부는 베팅 금액을 돌려받아요. 베팅은 선택 사항이에요. |
| `war <bet>` | 높은 카드가 1:1로 이겨요. 무승부면 추가로 베팅 금액을 내고 카드를 한 장 더 뽑아, 두 배의 금액을 걸어요. |
| `craps <bet> [pass/dontpass/field/any]` | Pass와 Don't pass는 포인트 규칙에 따라 1:1로 지급해요. Field는 1:1이고, 2나 12가 나오면 2배예요. Any seven은 4배예요. |
| `scratchcard [bronze/silver/gold/diamond]` | 고정 비용 카드로, 10, 50, 200, 1000짜리가 있어요. 당첨 확률은 각각 30%, 25%, 20%, 15%이고, 당첨 금액은 최대 50, 200, 1000, 5000까지예요. |
| `russianroulette <bet> [bullets]` | 여섯 칸 중 1~5개의 총알이 들어가요. 살아남으면 총알 개수에 따라 1.2배, 1.5배, 2배, 3배, 5배의 수익을 얻어요. |
| `baccarat <bet> [player/banker/tie]` | Player나 Banker는 1.95배, Tie는 8배를 지급해요. |
| `minesweeper <bet> [small/medium/large]` | 생존 확률은 70%, 60%, 50%이고, 각각 1.5배, 2.5배, 4배를 지급해요. |
| `lottery [tickets]` | 티켓은 한 장에 50이고, 최대 10장까지 살 수 있어요. 티켓을 더 사면 당첨 확률(최대 40%)과 상금 배율이 올라가요. |
| `crash <bet> [target]` | 1.1배부터 10배 사이에서 자동 캐시아웃 목표를 고르세요. 크래시 지점이 목표보다 높거나 같으면 목표 배율로 이겨요. |
| `keno <bet> <numbers>` | 1부터 80 사이에서 1~10개의 숫자를 고르세요. 20개의 숫자가 뽑혀요. 1개 중 1개를 맞히면 3배, 5개 중 5개를 맞히면 800배까지 지급해요. |
| `plinko <bet> [rows]` | 5~10줄 중에서 고를 수 있어요. 가운데에 떨어지면 0.5배, 가장자리에 떨어지면 최대 10배를 지급해요. |
| `wheelfortune <bet> [classic/risky/balanced]` | 배율이 적힌 휠이에요. risky는 0.1배부터 20배까지 범위가 있어요. |
| `duckrace <bet>` | 오리 다섯 마리가 달리고, 내 오리는 무작위로 정해져요. 1등은 4배, 2등은 2배, 3등은 1.2배를 지급해요. |
| `bingo <bet> [small/large]` | 40% 확률로 2배를, 25% 확률로 3.5배를 지급해요. |
| `diceduel @user <bet>` | 상대에게 수락과 거절 버튼이 나타나요. 두 사람 모두 베팅 금액을 낼 수 있어야 해요. |
| `memory <bet> [easy/medium/hard]` | 4, 6, 8개로 이루어진 순서를 똑같이 따라 하면 1.5배, 2배, 3배를 얻어요. |
| `horserace <bet>` | 10초 안에 최대 열 명의 멤버가 참가할 수 있어요. 빈자리는 AI 경주마가 채워요. 상금 풀은 상위 3명에게 50%, 30%, 20%로 나뉘어 지급돼요. |
| `triviachain <bet> [category]` | OpenTDB 문제를 연속으로 맞혀요. 정답마다 배율이 0.5배씩 올라가요. 카테고리는 general, science, history, sports, entertainment예요. |

> [!NOTE]
> `horserace`는 양수라면 어떤 베팅이든 받아요. 베팅 금액을 바로 가져가고, 공통 베팅 한도나 지급 배율은 적용하지 않아요.

## 일일 도전 과제

멤버는 매일 무작위 도전 과제를 하나씩 받아요. 게임 다섯 번 하기, 세 번 이기기, 500 쓰기, 300 벌기, 특정 게임 세 번 하기 중 하나예요. 보상은 기본 금액에 최대 50이 추가된 금액이에요. `dailychallenge`로 확인하고, `claimchallenge`로 보상을 받고, `challengeleaderboard`로 최근 30일 동안 완료한 도전 과제 수 상위 10명을 볼 수 있어요.

> [!WARNING]
> 현재 게임은 도전 과제 추적기에 진행 상황을 보고하지 않아서, 도전 과제는 진행률이 0으로 표시되고 아직 보상을 받을 수 없어요.

## 상점

아이템은 **상점** 탭에 있거나 `shopadditem`, `shopaddrole` 명령어로 추가해요. 각 아이템에는 **이름**, **가격**, **설명**, **유형**, **재고** (비워 두거나 -1이면 무제한), **사용자당 제한**, 구매자가 가져야 하는 선택 사항인 **필수 역할**, 그리고 **정렬 순서**가 있어요.

| 유형 | 구매했을 때 |
| --- | --- |
| 역할 | 봇이 구매자에게 역할을 줘요. 기본적으로 멤버당 한 번만 살 수 있어요. |
| 수집품 | 구매자의 인벤토리에 들어가요. 소모품이라서 `use`를 하면 하나가 사라져요. |
| 텍스트 | **전달 텍스트**가 구매자에게 DM으로 전송되고, `use`를 할 때도 다시 전송돼요. |

`buy <name>`은 아이템이 활성화되어 있는지, 구매자가 필수 역할을 가졌는지, 재고가 남았는지, 돈이 충분한지, 사용자당 제한을 넘지 않았는지 확인해요. 결제 후에 하나라도 실패하면 자동으로 환불돼요. `inventory`는 멤버가 가진 아이템을 보여 줘요. `shoptoggle`은 아이템을 숨기지만 다른 사람이 가진 복사본은 그대로 두고, `shopremove`는 아이템과 모든 복사본을 삭제해요.

## 플레이스홀더

다음 화폐 플레이스홀더는 채팅 트리거 응답과 트리거 플레이스홀더를 쓰는 다른 곳에서 사용할 수 있어요.

| 플레이스홀더 | 값 |
| --- | --- |
| `%currency.balance%` | 사용자의 지갑 |
| `%currency.bank%` | 사용자의 은행 잔액 |
| `%currency.total%` | 지갑과 은행 합계 |
| `%targetuser.currency.balance%` | 대상 사용자의 지갑 |
| `%targetuser.currency.bank%` | 대상 사용자의 은행 잔액 |
| `%currency.emote%` | 서버의 화폐 이모지 |

## 설정

대시보드에는 네 개의 탭이 있어요. **분석**, **설정**, **상점**, **순위표**예요. **순위표** 탭에는 **잔액 조정**도 있는데, 이 기능으로 멤버의 잔액을 올리거나 내릴 수 있고, 사유는 원장에 기록돼요.

| 설정 | 기본값 | 조정하는 내용 |
| --- | --- | --- |
| 도박 사용 | 켜짐 | 모든 베팅 게임을 켜거나 꺼요 |
| 최소 베팅 | 1 | 가장 작은 베팅 금액 |
| 최대 베팅 | 0 (무제한) | 가장 큰 베팅 금액 |
| 지급 배율 | 1.0 | 당첨금에만 적용돼요. 0.1~5.0 |
| 일일 손실 한도 | 0 (꺼짐) | 24시간 동안 이 금액을 잃으면 멤버의 참여를 막아요 |
| 게임 쿨다운 (초) | 0 | 멤버가 베팅 사이에 기다리는 시간(초) |
| 일하기 사용 | 켜짐 | `work` 명령어 |
| 일하기 최소 / 최대 | 50 / 250 | 일하기 보상 범위 |
| 일하기 쿨다운 | 1800초 | `workcooldown`, 명령어로만 설정 가능 |
| 범죄 사용 | 켜짐 | `crime` 명령어 |
| 범죄 최소 / 최대 | 200 / 800 | 범죄 보상 범위 |
| 범죄 성공 확률 (%) | 45 | 범죄가 보상을 주는 확률 |
| 범죄 벌금 최소 / 최대 | 100 / 500 | 실패했을 때의 벌금 |
| 범죄 쿨다운 | 3600초 | `crimecooldown`, 명령어로만 설정 가능 |
| 은행 사용 | 켜짐 | `bank`, `deposit`, `withdraw` |
| 은행 한도 | 0 (무제한) | 멤버가 은행에 보관할 수 있는 최대 금액 |
| 이자 (%) | 0 | 은행 잔액에 주기마다 지급되는 이자 |
| 이자 지급 주기 (시간) | 24 | 이자를 받을 수 있는 주기 |
| 송금 사용 | 켜짐 | `pay` 명령어 |
| 송금 수수료 (%) | 0 | 송금마다 빠지는 금액 |
| 최소 송금액 | 1 | 가장 작은 송금 금액 |
| 송금 쿨다운 | 0 | `paycooldown`, 명령어로만 설정 가능 |
| 강도 사용 | 꺼짐 | `rob` 명령어 |
| 성공 확률 (%) | 35 | 강도가 성공할 확률 |
| 최대 강탈 (%) | 20 | 성공했을 때 대상 지갑에서 가져갈 수 있는 비율 |
| 실패 벌금 (%) | 15 | 실패했을 때 강도의 지갑에서 잃는 비율 |
| 보호 금액 기준 | 100 | 이 금액보다 적게 가진 대상은 강도 피해를 입지 않아요 |
| 강도 쿨다운 | 3600초 | `robcooldown`, 명령어로만 설정 가능 |
| 연속 보상 사용 | 켜짐 | 연속으로 일일 보상을 받으면 보너스를 얻어요 |
| 일일 보너스 | 0 | 첫날을 넘어선 연속 일수마다 더해지는 금액 |
| 최대 보너스 | 0 (제한 없음) | 연속 보상 보너스의 상한 |

일일 보상 금액과 쿨다운은 대시보드가 아니라 `setdaily`로 설정해요. `economyconfig`는 모든 키와 현재 값을 보여 주고, `economyreset`은 모든 설정을 기본값으로 되돌려요.

## 설정 따라 하기

1. 멤버가 받을 수 있도록 `setdaily 500 24h`를 실행하세요.
2. 대시보드에서 **화폐**를 열고 **설정**으로 이동하세요. 게임 채널을 열기 전에 **최대 베팅**과 **일일 손실 한도**를 설정하세요.
3. 멤버가 지갑의 화폐를 잃어도 괜찮을 때만 **강도 사용**을 켜세요. 멤버가 돈을 지킬 수 있도록 은행은 켜 두세요.
4. **상점**에서 역할 아이템 몇 개와 수집품 하나를 추가하세요. 멤버 전용으로 하고 싶은 아이템에는 **필수 역할**을 지정하세요.
5. **잔액 조정** 또는 `modifybalance`로 몇몇 멤버에게 초기 잔액을 주세요.
6. 일주일 뒤 **분석**을 확인하고, 게임이 참여자에게 지급하는 금액이 받는 금액보다 많다면 **지급 배율**을 낮추세요.

## 팁과 주의 사항

- 다른 무엇보다 **최대 베팅**을 먼저 설정하세요. 0으로 두면 운 좋은 멤버 한 명이 오후 한나절 만에 경제를 고갈시킬 수 있어요.
- 일일 손실 한도는 지난 24시간 동안의 순손실을 세요. 그래서 초반에 이긴 멤버는 더 오래 계속할 수 있어요.
- 역할 아이템은 봇의 가장 높은 역할이 판매되는 역할보다 위에 있고 역할 관리 권한이 있어야 해요. 그렇지 않으면 결제 후 역할 지급 오류로 구매가 실패해요.
- 텍스트 아이템과 `use`는 DM으로 전달돼요. DM을 닫아 둔 멤버는 오류를 보지만, 아이템은 그대로 가지고 있어요.
- 블랙잭은 멤버당 한 게임만 메모리에 저장해요. `hit`과 `stand`는 `blackjack` 이후에만 작동해요.
- 경주는 다른 멤버를 10초 동안 기다린 뒤, 빈자리를 AI 경주마로 채우고 시작해요.
- 트리비아 체인 게임은 10분 동안 입력이 없으면 시간 초과되고, 멤버는 한 번에 하나만 실행할 수 있어요.
- 봇이 글로벌 화폐로 호스팅되면 잔액이 모든 서버에서 공유되고, `modifybalance`는 봇 소유자만 쓸 수 있어요.
