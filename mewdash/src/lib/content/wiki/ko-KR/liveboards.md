## 기능 소개

라이브 보드는 봇이 한 번 게시하고 고정한 뒤, 일정 간격으로 수정해서 항상 최신 숫자를 보여 주는 메시지예요. 서버 보고서는 매일, 매주 또는 매월 게시되는 단발성 임베드로, 마지막 보고서 이후의 변화를 성장 차트와 함께 요약해요.

## 보드

| 보드 | 표시 내용 |
| --- | --- |
| 초대 순위표 | 일반, 떠난, 가짜 초대 수가 포함된 상위 초대자 |
| 메시지 순위표 | 가장 많이 채팅한 멤버 |
| 음성 순위표 | 음성 채널에 가장 오래 있었던 멤버 |
| 인기 게임 | 플레이어 수가 포함된 가장 많이 플레이된 게임과 앱(게임 추적 필요) |
| 입장 차트, 퇴장 차트, 성장 차트 | 하루 단위의 입장과 퇴장 |
| 멤버 차트 | 시간별 스냅샷의 멤버 수 |
| 메시지 차트 | 하루 단위의 메시지 수 |
| 서버 개요 | `serveractivity`와 같은 요약 |
| 초대 분석 | 입장, 퇴장, 유지율, 가짜 입장, 유입 경로 |

각 보드에는 **기간**(최근 하루, 주, 월 또는 전체 기간. 차트는 전체 기간에 최대 90일을 사용해요), 최소 5분 이상의 새로고침 간격, 순위표의 행 수, 메시지 고정 설정이 있어요. 서버당 최대 10개의 보드를 만들 수 있어요. 보드를 삭제하면 해당 메시지도 삭제돼요. 누군가 메시지를 직접 삭제하면, 봇은 다음 새로고침 때 새 메시지를 게시해요.

## 서버 보고서

보고서 채널과 주기를 설정하면, 봇은 일정이 처음 돌아왔을 때 보고서를 게시하고, 이후에는 매일 UTC 00:00, 매주 월요일 또는 매월 1일에 게시해요. 보고서에는 다음 내용이 들어가요.

- 기간의 입장, 퇴장, 순증가 및 유지율
- 메시지, 음성 시간, 활동 멤버
- 멤버 수와 그 변화
- 상위 초대자, 채팅 활동자, 음성 참여자, 가장 바쁜 채널
- 라벨이 붙은 상위 초대 코드와 게임 추적이 켜져 있을 때의 인기 게임
- 입장과 퇴장 차트

**지금 보고서 보내기**를 누르면 일정을 바꾸지 않고 즉시 보고서를 게시해요. 봇이 채널에 게시할 권한을 잃으면 보고서는 스스로 꺼져요.

## 명령어

이 명령어들은 서버의 접두사(변경하지 않았다면 `.`)와 함께 실행해요. 보드는 `/liveboard`, 보고서는 `/serverreport` 아래에도 있어요.

| 명령어 | 별칭 | 필요 권한 | 용도 |
| --- | --- | --- | --- |
| `liveboardadd <#channel> <board> [range] [rows] [minutes]` | `pinboard`, `pinleaderboard` | 서버 관리 | 보드를 게시하고 고정 |
| `liveboardlist` | `liveboards` | 서버 관리 | 모든 보드 보기 |
| `liveboardremove <id>` | `unpinboard` | 서버 관리 | 보드와 메시지 삭제 |
| `liveboardrefresh` | | 서버 관리 | 모든 보드를 지금 새로고침 |
| `serverreportchannel [#channel]` | `reportchannel` | 서버 관리 | 보고서 채널 설정 및 보고서 켜기, 또는 끄기 |
| `serverreportfrequency <Daily/Weekly/Monthly>` | `reportfrequency` | 서버 관리 | 보고서 게시 주기 |
| `serverreportnow [frequency]` | `reportnow` | 서버 관리 | 현재 채널에 보고서 게시 |

## 팁과 주의 사항

- 메시지 고정에는 채널의 **메시지 관리** 권한이 필요해요. 권한이 없으면 보드는 게시되지만 고정되지는 않아요.
- 보드는 같은 메시지를 수정하므로, 메시지가 많은 채널에서는 보드가 금방 위로 밀려 올라가요. 전용 통계 채널에 두거나 고정 기능을 활용하세요.
- 순위표는 초대 및 활동 제외 설정을 따르므로, 숨겨졌거나 무시된 멤버는 고정된 보드에 나타나지 않아요.
- 통계 채널은 라이브 숫자를 보여 주는 또 다른 방법이에요. 메시지 대신 채널 이름에 카운터를 표시해요.
