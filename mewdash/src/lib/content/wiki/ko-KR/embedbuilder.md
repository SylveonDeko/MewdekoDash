## 기능 소개

임베드 빌더는 Discord 메시지를 시각적으로 편집하는 도구예요. 제목, 설명, 색상, 필드, 이미지와 선택적으로 버튼이나 선택 메뉴를 채우면 실시간 미리보기를 보면서 작업할 수 있고, 마지막에 JSON 코드를 얻어요. 이 JSON은 봇의 공통 메시지 형식이에요. `say`에 붙여 넣어 메시지를 게시하거나, 이름을 붙여 템플릿으로 저장하거나, 사용자 지정 메시지를 받는 기능(멀티 인사, 채팅 트리거, AFK 응답, 피드 업데이트, giveaway 당첨자 DM 등)에 넣을 수 있어요.

템플릿은 나만 볼 수 있는 개인용으로 저장하거나, 서버와 공유해서 스태프 누구나 불러올 수 있게 할 수 있어요. 대시보드에서는 완성한 메시지를 채널로 바로 보낼 수도 있어요. 이름과 아바타를 따로 지정한 웹후크인 **페르소나**를 통해 보낼 수도 있어요.

멤버는 임베드 빌더를 직접 쓰지 않아요. 멤버는 빌더가 만든 메시지만 보게 돼요.

## 이런 때 써요

- 규칙이나 안내문을 보기 좋게 작성하고, 나중에 `edit`으로 수정할 때
- 환영 메시지를 한 번 디자인한 다음 JSON을 멀티 인사에 붙여 넣을 때
- 스태프가 일관된 모양의 공지를 올릴 수 있도록 공지 템플릿을 모아둘 때
- 채팅 트리거와 연결된 버튼이나, 트리거를 통해 역할을 나눠 주는 선택 메뉴를 추가할 때
- 웹후크 권한을 누구에게도 주지 않고 자체 아바타를 가진 "Server News"라는 이름으로 게시할 때

## JSON 형식

파서는 텍스트에서 첫 번째 `{`를 찾고, 짝이 맞는 `}`까지 읽어요. JSON 객체가 없거나 파싱되지 않으면 전체 텍스트를 일반 내용으로 취급해요. 속성 이름은 대소문자를 구분하지 않아요.

| 키 | 타입 | 의미 |
| --- | --- | --- |
| `content` | 문자열 | 임베드 위에 표시되는 일반 텍스트 |
| `embed` | 객체 | 임베드 하나. 있으면 `embeds`는 무시돼요 |
| `embeds` | 배열 | 임베드 객체 최대 10개 |
| `components` | 배열 | 버튼과 선택 메뉴 |

임베드 객체는 `title`, `description`, `url`, `color`, `author`(`name`, `url`, `icon_url`), `footer`(`text`, `icon_url`), `thumbnail`(`url`), `image`(`url`), `fields`(`name`, `value`, `inline`으로 이루어진 배열)를 받아요. `color`는 숫자나 `#5865F2` 같은 문자열일 수 있어요. 필드 이름은 256자, 값은 1024자까지 잘려요. 완전한 절대 주소가 아닌 URL은 메시지 전체가 실패하지 않도록 무시돼요. `timestamp` 키도 받지만 표시되지는 않아요.

구성 요소에는 어느 줄에 놓을지 정하는 `row`, `displayName`이 있고, 링크 버튼이면 `url`, 채팅 트리거에 연결된 버튼이면 `id`를 넣어요. `style`은 Discord 버튼 스타일 네 가지에 해당하는 1~4이고, `emoji`는 선택 사항이에요. 선택 메뉴로 만들려면 `isSelect`를 true로 설정하고, `options`(각각 `id`, `name`, `description`, `emoji`)와 0~25 사이의 `minOptions`, `maxOptions`를 넣어요. 규칙을 어긴 구성 요소는 오류 메시지가 레이블인 비활성 빨간 버튼으로 표시돼서, Discord에서 무엇이 잘못됐는지 바로 확인할 수 있어요.

> [!EXAMPLE]
> `{"content": "Welcome %user.mention%!", "embeds": [{"title": "Read the rules", "description": "See %channel.mention%", "color": "#57F287"}]}`

### 플레이스홀더

빌더의 **%** 버튼은 플레이스홀더 페이지에 있는 플레이스홀더(사용자, 서버, 채널, 봇, 시간 등)를 넣어줘요. 대시보드는 플레이스홀더를 바꾸지 않아요. **보내기** 탭에서 보낸 메시지에는 플레이스홀더가 그대로 들어가요. 봇은 `say`, `embedpreview`, 인사 메시지, 트리거처럼 JSON이 명령어나 기능을 거칠 때 플레이스홀더를 바꿔요. 각 기능은 `%afk.message%`나 `%giveawayitem%`처럼 자체 플레이스홀더를 추가로 제공해요.

## 템플릿

템플릿은 이름과 JSON으로 이루어져요. 범위는 두 가지예요.

| 범위 | 볼 수 있는 사람 | 만드는 방법 |
| --- | --- | --- |
| 개인 | 나만, 모든 서버와 DM에서 | `embedsave` 또는 대시보드에서 공유를 체크하지 않고 **저장** |
| 서버 공유 | 해당 서버에서 권한이 있는 모든 사람 | `guildembedsave`(메시지 관리 필요) 또는 **이 서버의 모든 사람과 공유**를 체크하고 **저장** |

이름은 같은 범위 안에서 유일해야 해요. `embedpreview <name>`은 먼저 내 개인 템플릿을 찾고, 없으면 서버의 공유 템플릿을 찾아요. 플레이스홀더를 바꾼 다음 현재 채널에 게시해요.

원시 JSON 대신 템플릿 참조를 받는 명령어도 있어요. 메시지 자리에 `{template:name}` 또는 `{t:name}`을 쓰면 돼요. `multigreetmessage`가 이 방식을 지원해요. 저장되는 것은 참조가 아니라 풀린 JSON이므로, 나중에 템플릿을 수정해도 이미 설정된 인사 메시지는 바뀌지 않아요.

## 대시보드 페이지

**Discord 임베드 빌더** 페이지에는 여섯 개의 탭이 있고, 옆에 **실시간 미리보기**와 **문제** 패널이 있어요. 헤더에는 **실행 취소**, **다시 실행**, **편집 취소**, **JSON 복사** 버튼이 있어요.

| 탭 | 하는 일 |
| --- | --- |
| 템플릿 | 시작용 예제 목록에서 고르거나 **처음부터 시작** |
| 편집기 | **메시지 내용**과 임베드 최대 10개. 각 임베드에는 제목, 설명, URL, 색상, 작성자, 바닥글, 필드 최대 25개, 썸네일, 이미지가 있고 글자 수 표시가 있어요 |
| 구성 요소 | 줄 최대 5개와 구성 요소 최대 25개. 버튼(텍스트, 스타일, 이모지, URL 또는 트리거)과 선택 메뉴(자리 표시 텍스트, 트리거와 연결된 옵션)를 추가해요 |
| JSON | 원시 페이로드. **빌더에서 새로 고침**은 다시 생성하고, **빌더에 적용**은 붙여 넣은 JSON을 불러와요. 전체 페이로드나 임베드 객체 하나 모두 가능해요 |
| 저장됨 | 이름과 공유 체크박스를 넣고 **현재 임베드 저장**을 누르면, **이 서버에서 공유됨** 목록과 **내 임베드** 목록에 **불러오기**와 **삭제** 버튼이 있어요 |
| 보내기 | 채널을 고르고 권한을 확인한 다음, 필요하면 페르소나로 또는 사용자 지정 이름과 아바타 URL로 웹후크를 통해 보내고, **메시지 보내기**를 눌러요 |

### 보내기와 페르소나

**보내기** 탭에는 나와 봇이 모두 메시지를 보낼 수 있는 채널만 나와요. 임베드를 보내려면 나와 봇 모두 링크 임베드 권한이 필요해요. 내가 **@everyone, @here 및 모든 역할 멘션** 권한이 없으면, everyone, here, 역할 멘션은 제거되고 탭에 경고가 표시돼요.

웹후크로 보내려면 나와 봇 모두 웹후크 관리 권한이 필요해요. **페르소나**는 저장된 이름과 아바타예요. 개인용이거나 서버와 공유할 수 있어요. **관리**를 누르면 페르소나 목록이 열려요. 이미지를 업로드한 페르소나는 채널마다 자체 웹후크를 가지므로, 한 채널에는 페르소나를 최대 15개까지만 둘 수 있어요. **사용자 지정** 옵션은 표시 이름과 아바타 링크를 직접 입력받아요. 모든 전송 기록은 대시보드 감사 로그에 남아요.

같은 빌더는 다른 대시보드 페이지(인사, 트리거 등)에서 팝업으로 열 수 있어요. 이때는 **편집기**, **구성 요소**, **JSON**, **저장됨** 탭만 나와요.

## 설정

빌더에는 서버 설정이 없어요. 모든 것은 메시지나 템플릿 단위로 적용돼요.

## 설정 순서

1. 대시보드에서 **임베드**를 열고 템플릿을 고르거나 **처음부터 시작**을 선택하세요.
2. **편집기**에서 내용을 쓰고 임베드를 채워요. Discord가 거부할 내용은 **문제** 패널에서 확인하세요.
3. 필요하면 **구성 요소**에서 버튼이나 메뉴를 추가하고, 각각 채팅 트리거나 URL에 연결하세요.
4. **저장됨**으로 가서 이름을 정하고, 스태프가 써야 한다면 **이 서버의 모든 사람과 공유**를 체크한 뒤 **저장**을 누르세요.
5. 지금 게시하려면 **보내기**를 열고 채널을 고른 다음 **메시지 보내기**를 누르세요. 다른 기능에서 쓰려면 **JSON 복사**를 누르고 다른 기능에 붙여 넣으세요.
6. Discord에서 `embedpreview <name>`을 실행하면 플레이스홀더가 채워진 저장된 템플릿이 게시돼요.

## 명령어

서버의 접두사로 실행하세요(변경하지 않았다면 `.`).

| 명령어 | 별칭 | 필요 권한 | 용도 |
| --- | --- | --- | --- |
| `say [#channel] <text or JSON>` | | 메시지 관리 | 봇 이름으로 텍스트나 임베드 JSON을 게시하고 플레이스홀더를 바꿔요. `.txt` 첨부 파일로도 메시지를 줄 수 있어요 |
| `edit #channel <message id> <text or JSON>` | | 메시지 관리 | 봇이 보낸 메시지의 내용을 바꿔요 |
| `embedsave <name> <JSON>` | `esave` | 없음 | 개인 템플릿 저장 |
| `embedlist` | `elist` | 없음 | 내 개인 템플릿 목록 |
| `embeddelete <name>` | `edel`, `edelete` | 없음 | 내 개인 템플릿 하나 삭제 |
| `guildembedsave <name> <JSON>` | `gesave`, `gembedsave` | 메시지 관리 | 이 서버와 공유하는 템플릿 저장 |
| `guildembedlist` | `gelist`, `gembedlist` | 없음 | 서버의 공유 템플릿 목록 |
| `guildembeddelete <name>` | `gedel`, `gembeddelete` | 메시지 관리 | 공유 템플릿 삭제 |
| `embedpreview <name>` | `epreview`, `eprev` | 없음 | 저장된 템플릿을 현재 채널에 게시 |

## 팁과 주의할 점

- `say`는 명령어를 실행한 사람의 멘션 권한을 그대로 따라요. @everyone 권한이 없으면 봇도 대신 모두나 역할을 멘션하지 않아요.
- 제목만 있고 나머지가 없는 임베드도 보낼 수 있어요. 하지만 대시보드에서는 제목, 설명, 필드, 내용 중 하나가 생길 때까지 복사하거나 보낼 수 없어요.
- 트리거와 연결된 버튼은 해당 트리거 ID가 있는 서버에서만 동작해요. 다른 서버에서 공유 템플릿을 불러오면 이 버튼은 작동하지 않아요.
- 잘못된 이미지, 썸네일, 작성자, 바닥글 URL은 조용히 무시돼요. 이미지가 보이지 않으면 URL이 `https://`로 시작하는지 확인하세요.
- Discord는 메시지당 임베드 10개, 임베드당 필드 25개, 구성 요소 줄 5개, 줄당 버튼 5개로 제한해요. 빌더도 같은 숫자를 강제해요.
- 페르소나를 삭제해도 페르소나가 채널에 만든 웹후크는 지워지지 않아요. 필요하면 채널의 연동 설정에서 직접 정리하세요.
