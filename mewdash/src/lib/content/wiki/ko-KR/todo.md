## 기능 소개

할 일 목록 기능은 서버에 작업 목록을 만들어 줘요. 멤버는 목록을 만들고, 항목을 추가하고, 완료 표시를 하고, 다른 사람에게 목록을 보거나 함께 작업할 권한을 줄 수 있어요. 서버 관리 권한이 있는 스태프는 모든 멤버가 볼 수 있는 서버 전체 목록을 만들 수 있어요.

각 항목에는 제목, 선택 사항인 설명, 1~4 사이의 우선순위, 선택 사항인 태그, 선택 사항인 마감일, 선택 사항인 알림 시간이 있어요. 항목은 위치를 가지므로 순서를 바꿀 수 있고, 완료된 항목에는 누가 언제 완료했는지 기록돼요.

목록에는 두 종류가 있어요. 개인 목록은 한 멤버에게 속하며, 소유자가 권한을 주지 않는 한 다른 사람에게 보이지 않아요. 서버 목록은 서버에 속하며, 기본적으로 누구나 볼 수 있어요. 하지만 항목을 추가하거나 바꾸려면 명시적인 권한이 있어야 해요.

목록은 디스코드에서 임베드로, 대시보드에서는 카드로 보여요. 대시보드는 열어 둔 목록의 진행률, 기한 초과 개수, 완료율도 보여줘요.

## 사용하면 좋은 이유

- 운영팀은 오래되어 버리는 고정 메시지 대신, 서버 목록 하나에 미처리 작업을 모아 관리할 수 있어요.
- 행사 주최자는 체크리스트를 함께 쓰면서, 진행할 때마다 항목을 완료 표시할 수 있어요.
- 멤버는 서버에서 나중에 확인할 일을 개인 목록으로 따로 관리할 수 있어요.
- 프로젝트 채널에는 태그와 우선순위가 필요해요. 그래야 "긴급"인 항목이 "낮음" 항목과 구분돼요.

## 목록과 권한

모든 목록에는 소유자가 있어요. 소유자는 목록 안에서 무엇이든 할 수 있어요. 다른 사람은 `todogrant`로 멤버별 권한을 받아요.

| 권한 | 허용하는 작업 |
| --- | --- |
| `view` | 목록과 항목을 봐요 |
| `add` | 새 항목을 추가해요 |
| `edit` | 다른 사람의 항목을 수정하고, 태그를 붙이고, 순서를 바꾸고, 날짜를 설정해요 |
| `complete` | 다른 사람의 항목을 완료 처리해요 |
| `delete` | 다른 사람의 항목을 삭제해요 |
| `manage` | 목록 설정을 바꾸고, 목록을 삭제하고, 권한을 주거나 회수해요 |
| `all` | 위의 모든 권한이에요 |

여러 권한은 쉼표로 구분한 문자열로 줄 수 있어요. 예: `todogrant 12 @user view,add,complete`. 다시 권한을 주면 그 사용자의 이전 권한이 바뀌어요. `todorevoke`는 모든 권한을 제거해요.

권한과 관계없이 적용되는 규칙이 두 가지 있어요. 항목을 만든 사람은 항상 자기 항목을 수정하고, 완료하고, 삭제할 수 있어요. 목록 소유자는 항상 무엇이든 할 수 있어요.

누가 목록을 볼 수 있는지는 다음과 같아요.

| 목록 유형 | 공개 | 볼 수 있는 사람 |
| --- | --- | --- |
| 개인 | 상관없음 | 소유자와 `view` 권한을 받은 사람 |
| 서버 | 예(기본값) | 서버의 모든 멤버 |
| 서버 | 아니요 | 소유자와 `view` 권한을 받은 사람 |

`todotoggleprivacy`는 목록을 공개와 비공개 사이에서 바꿔요. 소유자나 `manage` 권한이 있는 사람만 실행할 수 있어요.

## 항목

| 항목 | 기본값 | 참고 |
| --- | --- | --- |
| 제목 | 필수 | 목록에서 굵게 보여요 |
| 설명 | 없음 | 제목 아래에 기울임꼴로 보여요 |
| 우선순위 | 명령어에서는 1(낮음), 대시보드에서는 보통 | 1 낮음, 2 보통, 3 높음, 4 심각이에요. 1~4 밖의 값은 범위 안으로 맞춰져요 |
| 마감일 | 없음 | 제목 옆에 상대 시간 Discord 타임스탬프로 보여요 |
| 알림 시간 | 없음 | 항목에 저장되며 `todosetreminder`로 설정해요 |
| 태그 | 없음 | 대소문자를 구분하지 않아요. 이미 있는 태그를 다시 추가하면 아무 일도 일어나지 않아요 |
| 위치 | 목록 끝 | `todoreorder`로 바꿔요 |

`todoshow`는 미완료 항목을 위치, 우선순위, 생성 시간 순서로 보여줘요. 두 번째 인자로 `true`를 주면 완료된 항목도 최대 5개까지 완료 시점과 함께 보여줘요. `todosetdue`와 `todosetreminder`의 날짜는 느슨하게 해석되므로, `2026-10-01 18:00`과 `October 1 2026` 모두 쓸 수 있어요.

`todosearch`는 미완료 항목의 제목, 설명, 태그에서 검색어를 찾고 최대 10개의 결과를 보여줘요. `todofilter`는 태그 하나(`todofilter 12 tag bug`)나 우선순위 하나(`todofilter 12 priority 4`)로 목록을 좁혀요.

각 목록에는 16진수 색상을 설정할 수 있어요. `todosetcolor 12 #ff8800`으로 설정하며, 이 색상은 임베드 테두리에 쓰여요. 기본 색상은 `#7289da`예요.

## 설정

서버 전체 설정은 없어요. 모든 설정은 목록별 또는 항목별로 이루어져요.

할 일 목록 페이지에는 보기가 하나 있어요. 왼쪽에는 볼 수 있는 모든 목록이 나열되고, **할 일 목록 검색** 상자, **완료된 항목 보기** 토글, 그리고 정렬 옵션(우선순위, 마감일, 생성일, 제목)과 순서 선택기가 있어요. 목록을 선택하면 항목이 보이고, **항목 추가**와 **목록 삭제** 버튼이 있어요. 항목 편집기에는 **우선순위**와 **마감일**이 있고, 목록마다 **권한 관리** 버튼이 있어요.

| 설정 | 기본값 | 역할 |
| --- | --- | --- |
| 목록 이름과 설명 | 이름은 필수, 설명은 없음 | **목록 만들기** 버튼으로 목록을 만들 때 설정해요 |
| 우선순위(항목) | 보통 | 항목의 우선순위예요. 색깔 칩으로 보여요 |
| 마감일(항목) | 없음 | 기한 초과 개수를 계산하는 데 쓰는 기한이에요 |
| 완료된 항목 보기 | 끔 | 목록 보기에 완료된 항목을 보여줄지 정해요 |

> [!NOTE]
> 대시보드에서 만든 목록은 항상 서버 목록이에요. 개인 목록은 디스코드에서 `todocreatelist`로 만들어요.

## 설정 방법

1. 대시보드에서 **할 일 목록**을 열고 **목록 만들기**를 클릭하세요.
2. 이름과 선택 사항인 설명을 입력하세요. 목록은 공개 서버 목록으로 만들어져요.
3. 목록을 클릭한 뒤 **항목 추가**를 누르세요. **무엇을 해야 하나요?**, 선택 사항인 설명, 우선순위를 입력하세요.
4. 목록 카드의 **권한 관리**로 누가 접근할 수 있는지 확인하세요. 함께 작업할 사람에게는 디스코드에서 `todogrant <listId> @user add,complete`로 권한을 주세요.
5. 디스코드에서 `todolists`를 실행해 목록 ID를 확인하고, `todoshow <listId>`로 제대로 보이는지 확인하세요.
6. `todocomplete <itemId>`로 완료 표시를 하세요. 항목 ID는 `todoshow`에서 백틱으로 감싸져 보여요.

## 명령어

이 명령어는 서버 접두사로 실행하세요(변경하지 않았다면 `.`이에요). 목록 ID와 항목 ID는 `todolists`와 `todoshow`에서 확인할 수 있어요.

| 명령어 | 별칭 | 필요 권한 | 용도 |
| --- | --- | --- | --- |
| `todocreatelist <name> [description]` | `tcl` | 없음 | 개인 목록을 만들어요 |
| `todocreateserverlist <name> [description]` | `tcsl` | 서버 관리 | 서버 전체 목록을 만들어요 |
| `todolists [includeServer]` | | 없음 | 볼 수 있는 목록을 보여줘요. `false`를 주면 개인 목록만 보여줘요 |
| `tododeletelist <listId>` | `tdl` | 없음 | 목록과 모든 항목을 삭제해요(소유자 또는 `manage` 권한 필요) |
| `todoshow <listId> [includeCompleted]` | `ts` | 없음 | 목록의 항목을 보여줘요 |
| `todoadd <listId> <title> [description]` | `ta` | 없음 | 낮은 우선순위로 항목을 추가해요 |
| `todoaddpriority <listId> <priority> <title> [description]` | `tap` | 없음 | 우선순위 1~4로 항목을 추가해요 |
| `todoedit <itemId> <title> [description]` | `te` | 없음 | 항목의 제목과 설명을 바꿔요 |
| `todocomplete <itemId>` | `tc` | 없음 | 항목을 완료 처리해요 |
| `tododelete <itemId>` | `td` | 없음 | 항목을 삭제해요 |
| `todoreorder <itemId> <position>` | `tr` | 없음 | 항목을 1부터 시작하는 위치로 옮겨요 |
| `todosetdue <itemId> <date>` | `tsd` | 없음 | 마감일을 설정해요 |
| `todocleardue <itemId>` | `tcd` | 없음 | 마감일을 제거해요 |
| `todosetreminder <itemId> <date>` | `tsr` | 없음 | 알림 시간을 설정해요 |
| `todoclearreminder <itemId>` | `tcr` | 없음 | 알림 시간을 제거해요 |
| `todoaddtag <itemId> <tag>` | `tat` | 없음 | 태그를 추가해요 |
| `todoremovetag <itemId> <tag>` | `trt` | 없음 | 태그를 제거해요 |
| `todosearch <listId> <query>` | `tsearch` | 없음 | 미완료 항목을 제목, 설명, 태그로 검색해요 |
| `todofilter <listId> <tag or priority> <value>` | `tf` | 없음 | 미완료 항목을 태그 하나 또는 우선순위 하나로 걸러요 |
| `todosetcolor <listId> <#hex>` | `tsc` | 없음 | 임베드 색상을 설정해요 |
| `todotoggleprivacy <listId>` | `ttp` | 없음 | 목록을 공개와 비공개 사이에서 바꿔요 |
| `todogrant <listId> @user <perms>` | `tg` | 없음 | 쉼표로 구분한 권한을 줘요 |
| `todorevoke <listId> @user` | `trv` | 없음 | 사용자의 모든 권한을 제거해요 |
| `todopermissions <listId>` | `tp` | 없음 | 누가 어떤 권한을 가졌는지 보여줘요 |

"없음"은 디스코드 권한 확인이 없다는 뜻이에요. 명령어가 성공할지는 목록 자체의 권한이 결정해요. 같은 명령어는 `/todo` 아래의 슬래시 명령어로도 쓸 수 있어요.

## 팁과 주의 사항

- 알림 시간은 항목에 저장되지만, 현재 봇은 그 시간이 되어도 알림을 보내지 않아요. 지금은 메모로만 생각하세요.
- `view` 권한이 없으면, ID가 맞더라도 `todoshow`는 목록을 찾을 수 없다고 표시해요.
- 목록 이름은 소유자와 유형별로 고유해야 해요. 그래서 두 멤버가 각각 "Shopping" 개인 목록을 가질 수는 있지만, 한 멤버가 같은 이름의 개인 목록을 두 개 가질 수는 없어요.
- `todoreorder`는 목록의 모든 항목 번호를 다시 매겨서, 위치가 빈틈없이 이어지도록 해요.
- 공개 서버 목록은 누구나 읽을 수 있지만, `add` 권한을 주기 전까지는 소유자 외에는 항목을 추가할 수 없어요.
- 전체 권한 세트는 디스코드에서 `todogrant`로 주세요. 대시보드의 **권한 관리** 보기는 누가 접근할 수 있는지 확인하는 용도예요.
- 목록을 삭제하면 권한과 항목이 한꺼번에 제거되며, 되돌릴 수 없어요.
