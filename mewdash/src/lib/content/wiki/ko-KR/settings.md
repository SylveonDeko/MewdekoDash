## 기능 설명

설정 페이지에는 기능 하나에만 적용되지 않고 모든 모듈에 동시에 영향을 주는 몇 가지 옵션이 있어요. 멤버가 명령어 앞에 입력하는 접두사, 봇이 응답하는 언어, 알림과 예약 메시지에 쓰는 시간대, 명령어 사용과 경고를 기록할 채널을 여기서 바꿀 수 있어요.

뮤트 역할 이름, 뮤트된 멤버가 다른 역할을 잃을지 여부, 경고가 유지되는 기간, 그리고 두 가지 채팅 유틸리티인 메시지 스나이프와 메시지 링크 미리보기도 여기에서 설정해요.

이 설정 대부분은 대응하는 텍스트 명령어가 있어서 스태프가 Discord에서도 바꿀 수 있어요. 스태프 역할, 멤버 역할, 채널별 명령어 메시지 삭제는 명령어로만 설정할 수 있어요.

## 이런 상황에 사용해요

- 서버에서 이미 `.`을 다른 봇이 쓰고 있어서 Mewdeko를 `!`나 `m!`로 쓰고 싶을 때
- 커뮤니티가 영어가 아닌 언어를 쓰고 있어서 봇의 응답 언어를 맞추고 싶을 때
- 알림과 예약 게시물이 UTC가 아니라 현지 시간에 맞게 올라와야 할 때
- 모더레이터가 실행된 모든 명령어와 발급된 모든 경고를 기록하는 채널이 필요할 때
- 경고가 계속 쌓이지 않고 설정한 일수가 지나면 사라졌으면 할 때
- 멤버가 삭제된 메시지를 `snipe`로 확인할 수 있게 하거나, 바쁜 채팅방에서 링크 미리보기를 끄고 싶을 때

## 접두사

접두사는 멤버가 명령어 앞에 입력하는 텍스트예요. 기본값은 `.`이에요. 누구나 인수 없이 `prefix`를 실행해서 현재 접두사를 확인할 수 있어요. 관리자는 `prefix <new>`로 바꾸거나, 대시보드의 **명령어 접두사** 입력란에서 바꿀 수 있어요. 슬래시 명령어는 접두사의 영향을 받지 않아요.

## 언어

각 서버는 `languageset <code>`(예: `languageset de`)로 응답 언어를 고르거나, 대시보드의 **언어** 드롭다운에서 고를 수 있어요. `languageset default`를 실행하면 서버별 설정을 지우고 봇의 기본 언어를 따라요. `languageslist`는 지원하는 모든 로케일 코드를 출력해요. 인수 없이 `langsetdefault`를 실행하면 봇의 기본 언어가 표시돼요. 기본 언어를 바꾸는 것은 봇 소유자만 할 수 있어요.

## 시간대

서버 시간대는 알림, 예약 메시지, 모든 시간 표시에 쓰여요. `timezone`을 인수 없이 실행하면 현재 값을 보여 줘요(설정하지 않았다면 UTC). `timezone <id>`는 `Europe/London` 같은 IANA 또는 Windows 시간대 식별자로 설정하고, `timezones`는 봇이 허용하는 식별자 목록을 페이지로 보여 줘요. 대시보드에서 **서버 시간대**는 값을 고르는 순간 바로 저장되며, **변경 사항 저장**을 기다리지 않아요.

## 로그 채널

**명령어 로그 채널**은 명령어 사용을 기록해요. `commandlogchannel #channel`로 설정하고, 채널 없이 실행하면 로그를 꺼요.

**경고 로그 채널**은 모더레이션 명령어로 발급된 경고를 기록해요. 대시보드에서만 설정할 수 있어요.

## 경고

**경고 만료**는 시간 단위로 저장돼요. 0이면 경고가 만료되지 않아요. `warnexpire` 명령어는 일 단위로 동작하며 두 번째 단어를 받아요. `warnexpire 30 clear`는 30일이 지난 경고를 정리됨으로 표시하고, `warnexpire 30 delete`는 삭제해요. 허용 범위는 0에서 366일이며, `warnexpire 0`은 만료 기능을 꺼요.

## 뮤트 역할과 역할 제거

**뮤트 역할**은 뮤트 명령어와 처벌이 적용하는 역할의 이름이에요. 해당 이름의 역할이 없으면 봇이 만들어요. Discord에서 `muterole @role`을 실행하면 기존 역할을 지정할 수 있어요. 이 역할은 서버 소유자가 아닌 경우 본인의 가장 높은 역할보다 아래에 있어야 해요. 인수 없이 `muterole`을 실행하면 현재 뮤트 역할이 표시돼요.

**뮤트 중 다른 역할 모두 제거**는 뮤트 기간 동안 멤버의 다른 역할을 제거했다가 나중에 돌려줘요. 명령어 형식은 `removeonmute y` 또는 `removeonmute n`이에요.

## 채팅 유틸리티

| 설정 | 명령어 | 효과 |
| --- | --- | --- |
| 메시지 스나이프 | `snipeset enable` 또는 `snipeset disable` | 멤버가 스나이프 명령어로 최근에 삭제되거나 수정된 메시지를 복구할 수 있어요. 기본값은 꺼짐이에요. |
| 메시지 링크 미리보기 | `previewlinks y` 또는 `previewlinks n` | 누군가 Discord 메시지 링크를 올리면, 봇이 그 메시지의 내용을 보여 줘요. |

## 명령어 전용 설정

이 설정들도 같은 관리 모듈에 속하지만 대시보드에서는 설정할 수 없어요.

**스태프 역할**(`staffrole @role`)은 해당 역할의 멤버를 단어, 링크, 초대 필터와 건의 스팸 검사에서 제외해요. 인수 없이 `staffrole`을 실행하면 현재 역할을 보여 주고, `staffroledisable`로 지워요.

**멤버 역할**(`memberrole @role`)은 서버의 역할을 저장해요. 현재는 어떤 기능도 사용하지 않아요.

**명령어 메시지 삭제**(`delmsgoncmd`)는 명령어가 실행되면 해당 명령어를 호출한 메시지를 삭제해요.

| 형식 | 효과 |
| --- | --- |
| `delmsgoncmd` | 서버 전체에서 삭제 켜기 또는 끄기 |
| `delmsgoncmd list` | 서버 설정과 모든 채널별 설정 보기 |
| `delmsgoncmd channel enable [#channel]` | 해당 채널에서는 항상 삭제 (생략하면 현재 채널) |
| `delmsgoncmd channel disable [#channel]` | 해당 채널에서는 절대 삭제하지 않음 |
| `delmsgoncmd channel inherit [#channel]` | 서버 설정을 따름 |

## 설정 항목

아래 설정은 모두 하나의 **봇 설정** 페이지에 있어요. 수정한 뒤 **변경 사항 저장**을 누르세요. **서버 시간대**만 단독으로 저장돼요.

| 설정 | 기본값 | 역할 |
| --- | --- | --- |
| 명령어 접두사 | `.` | 명령어 앞에 입력하는 텍스트 |
| 명령어 로그 채널 | 없음 | 명령어 사용을 기록하는 채널 |
| 화폐 이모지 | 없음 | 서버 화폐를 나타내는 이모지 |
| 경고 로그 채널 | 없음 | 경고를 기록하는 채널 |
| 경고 만료 | 0 (만료 안 함) | 경고가 만료되기까지의 시간(시간 단위) |
| 언어 | 봇 기본값 | 이 서버의 응답 언어 |
| 서버 시간대 | UTC | 예약 메시지, 알림, 시간 표시에 쓰이는 시간대 |
| 뮤트 역할 | Muted | 뮤트와 처벌에 적용되는 역할의 이름 |
| 뮤트 중 다른 역할 모두 제거 | 꺼짐 | 뮤트 기간 동안 다른 역할 제거 |
| 메시지 스나이프 | 꺼짐 | 스나이프 명령어 허용 |
| 메시지 링크 미리보기 | 꺼짐 | Discord 메시지 링크 펼치기 |

> [!NOTE]
> 이 페이지에는 공통 기본 설정만 있어요. 로깅, 모더레이션, 스타보드 등 나머지 기능은 각자의 페이지와 설정이 있어요.

## 설정 방법

1. 대시보드에서 **설정**을 열어요.
2. `.`이 다른 봇과 겹치면 **명령어 접두사**를 바꾸세요.
3. **언어**와 **서버 시간대**를 고르세요.
4. 스태프만 볼 수 있는 **명령어 로그 채널**과 **경고 로그 채널**을 고르세요.
5. **경고 만료**를 시간 단위로 설정하세요. 예를 들어 30일이면 `720`이고, 아니면 0으로 두세요.
6. **뮤트 역할** 이름이 모더레이터가 이미 쓰는 역할과 같은지 확인하세요. 아니면 `Muted`로 두고 봇이 만들게 하세요.
7. 필요하면 **메시지 스나이프** 또는 **메시지 링크 미리보기**를 켜세요.
8. **변경 사항 저장**을 누르세요.
9. Discord에서 `staffrole @YourStaffRole`을 실행해서 필터와 건의 제한이 팀을 건너뛰게 하세요.

## 명령어

아래 명령어는 서버의 접두사로 실행하세요(변경하지 않았다면 `.`).

| 명령어 | 별칭 | 필요 권한 | 용도 |
| --- | --- | --- | --- |
| `prefix [new prefix]` | | 보기: 누구나, 변경: 관리자 | 명령어 접두사 보기 또는 설정 |
| `languageset <code>` | `langset` | 관리자 | 서버 응답 언어 설정. `default`로 초기화 |
| `langsetdefault` | `langsetd` | 보기: 누구나, 변경: 봇 소유자 | 봇 전체 기본 언어 보기 또는 설정 |
| `languageslist` | `langli` | 누구나 | 지원하는 로케일 코드 목록 |
| `timezone [id]` | | 보기: 누구나, 변경: 관리자 | 서버 시간대 보기 또는 설정 |
| `timezones` | | 누구나 | 허용되는 시간대 식별자를 페이지로 보기 |
| `commandlogchannel [#channel]` | `commandlog`, `logcommands` | 관리자 | 명령어 로그 채널 설정. 채널 없이 실행하면 끔 |
| `warnexpire <days> <clear or delete>` | `warne` | 관리자 | 일 단위로 경고 만료 설정 |
| `muterole [@role]` | `setmuterole` | 역할 관리 | 뮤트 역할 보기 또는 설정 |
| `removeonmute <y or n>` | | 관리자 | 뮤트 중 다른 역할 제거 |
| `snipeset <enable or disable>` | `setsnipe` | 관리자 | 스나이프 명령어 허용 또는 차단 |
| `previewlinks <y or n>` | `plinks` | 관리자 | Discord 메시지 링크 펼치기 |
| `staffrole [@role]` | | 관리자 | 스태프 역할 보기 또는 설정 |
| `staffroledisable` | | 관리자 | 스태프 역할 지우기 |
| `memberrole [@role]` | | 관리자 | 멤버 역할 보기 또는 설정 |
| `delmsgoncmd [list or channel <state> [#channel]]` | `dmc` | 관리자 | 서버 전체 또는 채널별 명령어 메시지 삭제 |

## 팁과 주의 사항

- `delmsgoncmd`는 봇에 **메시지 관리** 권한이 있어야 해요. 없으면 명령어가 실행되지 않아요.
- 대시보드는 경고 만료를 시간 단위로 저장하지만 `warnexpire`는 일 단위를 써요. `warnexpire 1`과 대시보드의 `24`는 같은 값이에요.
- `muterole`는 입력한 역할을 본인의 가장 높은 역할과 비교해요. 권한 부족 오류가 나오면 서버 소유자에게 요청하거나 더 낮은 역할을 고르세요.
- 슬래시 명령어는 접두사를 전혀 사용하지 않으므로, 접두사를 바꾸면 텍스트 명령어에만 영향을 줘요.
- 스태프 역할 예외는 필터와 건의 스팸 검사에만 적용돼요. 명령어 권한을 주지는 않아요. 명령어 권한은 권한 모듈에서 설정하세요.
