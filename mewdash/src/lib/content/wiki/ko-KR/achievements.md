## 기능 소개

업적은 서버를 사용하면서 달성하는 목표예요. 첫 메시지 보내기, 메시지 250개 달성, 음성 채널 참여, 여러 종류의 이모지에 반응하기, 몇 달 동안 서버에 머물기, 서버 부스트 같은 것들이 있어요. 각 업적에는 등급이 있고, 등급마다 포인트가 있어요. 쌓인 포인트는 멤버의 업적 랭크를 정해요. 멤버는 프로필 카드에 배지를 최대 4개까지 달아 획득한 업적을 자랑할 수 있어요.

업적 기능을 켜면 기존 기록도 바로 반영돼요. 멤버는 이미 저장된 메시지, 음성 시간, 반응, 초대, 레벨, 서버 체류 기간에 따라 업적을 조용히 달성해요. 별도의 알림은 나오지 않아요.

## XP와의 관계

업적과 XP는 별개의 시스템이에요. 둘 다 서로를 필요로 하지 않으며, 하나를 끈다고 다른 하나에 영향을 주지 않아요.

| | XP | 업적 |
| --- | --- | --- |
| 획득 방법 | 메시지를 보낼 때와 음성 채널에 있을 때마다 | 목표에 한 번 도달하면 |
| 올라가는 것 | XP 곡선에 따른 레벨 | 업적 랭크(뉴커머부터 챔피언까지) |
| 측정 단위 | XP | 각 달성 등급에서 나온 포인트 |
| 보상 | 레벨 역할과 화폐 | 업적별 역할, 화폐, XP |

두 시스템은 정확히 두 곳에서 연결돼요.

1. **레벨이 업적을 달성해요.** 커뮤니티 카테고리에는 XP 레벨에 도달하면 달성하는 업적이 있어요. 그래서 레벨이 오르면 업적도 달성할 수 있어요.
2. **업적이 XP를 줄 수 있어요(선택 사항).** 기본적으로는 아무것도 주지 않아요. 업적 하나에 XP 보상을 설정하거나, **설정** 탭에서 **포인트당 XP**를 정하면 달성할 때마다 포인트에 따라 XP를 받아요. 골드 업적은 50포인트이므로, 포인트당 XP가 2라면 100 XP를 줘요.

업적 랭크는 XP 레벨과 달라요. 한 멤버가 레벨 40인데 브론즈 랭크일 수 있고, 레벨 3인데 골드 랭크일 수도 있어요. 레벨은 얼마나 많이 채팅했는지, 랭크는 얼마나 다양한 일을 해 봤는지를 나타내요.

## 등급, 포인트, 랭크

| 등급 | 포인트 |
| --- | --- |
| 브론즈 | 10 |
| 실버 | 25 |
| 골드 | 50 |
| 에메랄드 | 100 |

포인트가 쌓이면 다음 랭크에 도달해요.

| 랭크 | 필요한 포인트 |
| --- | --- |
| 뉴커머 | 0 |
| 브론즈 | 100 |
| 실버 | 500 |
| 골드 | 1500 |
| 에메랄드 | 3500 |
| 아메시스트 | 7000 |
| 챔피언 | 12000 |

사용자 지정 업적은 어떤 등급이든 쓸 수 있고, 포인트를 직접 덮어쓸 수도 있어요.

## 카테고리

기본 제공 업적은 메시지, 음성, 반응, 초대, 명령어, 충성도, 부스트, 커뮤니티로 나뉘어 있어요. 카테고리 전체를 끄거나, 이름, 설명, 아이콘을 직접 정한 카테고리를 추가할 수 있어요. **카테고리** 탭에서 카테고리를 끌어다 놓으면 멤버가 보는 모든 곳에서 순서가 바뀌어요.

## 사용자 지정 업적

| 종류 | 달성 조건 |
| --- | --- |
| 목표 | 숫자가 목표에 도달할 때. 예: 메시지 1000개, 서버 체류 30일 |
| 문구 | 멤버가 특정 문구를 말할 때 |
| 반응 | 멤버가 특정 이모지에 반응할 때 |
| 수동 | 스태프가 직접 지급할 때 |

각 업적에는 이름, 설명, 등급, 아이콘(이모지, 서버 이모지, Font Awesome 아이콘, 업로드한 이미지 중 선택)과 선택 보상(역할, 화폐, XP)을 설정해요. 업적을 **비밀**로 표시하면 달성하기 전까지 이름과 목표가 가려져요.

## 공지

| 모드 | 달성 알림이 올라가는 곳 |
| --- | --- |
| 자동 | 로그 채널이 있으면 로그 채널, 없으면 달성이 일어난 채널 |
| 여기 | 달성이 일어난 채널 |
| 로그 채널 | 로그 채널에만 |
| DM만 | 멤버의 DM |
| 무음 | 어디에도 보내지 않아요 |

한 번에 여러 업적을 달성하면 메시지 하나에 함께 표시돼요. 공지에는 서버 색상이 적용된 이미지 카드가 첨부돼요. 채널에 올라간 공지는 기본적으로 5초 뒤에 자동으로 삭제되며, 더 긴 시간을 고르거나 **없음**을 선택할 수도 있어요. DM은 자동으로 삭제되지 않아요. 멤버는 자신의 업적 DM, 서버 메시지, 멘션 알림을 따로 끌 수 있어요.

업적 공지가 올라가면 안 되는 채널을 피하기 위해 두 가지 규칙이 있어요.

| 규칙 | 설명 |
| --- | --- |
| 조용한 채널 | 공지 채널처럼 직접 고른 채널이에요. 멤버는 여기서도 업적을 얻지만, 달성 알림은 여기에 올라가지 않아요 |
| 멤버가 대화할 수 있는 곳에만 전송 | 기본으로 켜져 있어요. 멤버가 메시지를 보낼 수 없는 채널(예: 읽기 전용 채널에서 반응한 경우)에는 달성 알림을 보내지 않아요 |

이 규칙 때문에 게시가 막히면, 로그 채널을 설정했다면 로그 채널로 보내고, 설정하지 않았다면 건너뛰어요. 로그 채널은 절대 건너뛰지 않아요. 채널 자체를 집계에서 빼고 싶다면 **설정** 탭의 제외 채널 기능을 쓰세요.

## 카드

**카드** 탭은 달성 이미지를 디자인하는 도구예요. 제목, 아이콘, 등급, 진행 상황, 아바타 등을 끌어다 놓고 크기를 조절할 수 있고, 도형, 텍스트, 이미지, 아이콘을 추가할 수 있어요. 서버 색상을 토큰으로 써서 새 아이콘을 넣어도 카드가 색을 따라가게 할 수 있어요. 디자인은 최대 20개까지 저장할 수 있고, 기본 디자인 하나를 고르고, 다른 디자인은 카테고리나 업적 하나에 연결할 수 있어요. 가장 구체적인 설정이 우선 적용돼요.

## 멤버 설정

멤버는 자신의 프로필 카드, 달성 목록, 배지, 리더보드 위치를 누가 볼 수 있을지 정하고, 배지를 고르고, 알림 방식을 설정할 수 있어요. 이 설정은 iOS와 Android 앱의 **Me** 탭에서도 할 수 있어요.

## 대시보드

| 탭 | 용도 |
| --- | --- |
| 개요 | 포인트 획득 시작이나 일시 정지, 달성 합계, 최근 달성 기록 |
| 업적 | 업적 찾아보기, 검색, 켜기, 편집, 생성 |
| 카테고리 | 카테고리 순서 변경, 이름 변경, 켜기/끄기, 생성 |
| 공지 | 달성 알림 위치와 방식, 메시지, 자동 삭제 |
| 카드 | 카드 디자이너와 연결 설정 |
| 멤버 | 멤버 조회, 지급, 회수, 초기화 |
| 설정 | 제외 역할과 채널, 포인트당 XP, 비밀 업적 |

## 명령어

이 명령어는 서버 접두사와 함께 실행하세요. 기본 접두사는 `.`이며, 바꾸지 않았다면 그대로 쓰면 돼요. 같은 명령어가 `/achievements` 아래에도 있어요.

## 팁과 주의 사항

- 보상은 기존 기록에도 적용돼요. 업적을 켜기 전에 포인트당 XP를 설정하거나 보상을 추가하면, 첫 점검 때 멤버가 이미 얻은 업적에 대한 보상도 지급돼요. 새로 달성한 업적에만 보상을 주고 싶다면 나중에 설정하세요.
- 업적으로 받은 XP 때문에 멤버가 레벨업할 수 있고, 새 레벨이 레벨 업적을 달성시킬 수 있으며, 그 업적이 다시 XP를 줄 수 있어요. 각 업적은 한 번만 달성되므로 결국 멈춰요.
- 제외된 역할을 가진 멤버나 제외된 채널에서 활동한 멤버는 해당 활동으로 아무것도 얻지 않아요.
