## 기능 소개

스태프는 선택지 2개에서 25개 사이의 질문을 올릴 수 있어요. 봇은 선택지마다 버튼이 있는 임베드를 보내고, 선택지가 다섯 개를 넘으면 선택 메뉴를 보내요. 멤버는 클릭해서 투표해요. 임베드에는 선택지마다 실시간 득표 수와 비율이 표시돼요. 선택지 아래에는 관리 버튼 세 개가 있어요. **"Stats"**, **"Close"**, **"Delete"**예요.

멤버는 다른 선택지를 클릭해 투표를 바꾸거나, 같은 선택지를 다시 클릭해 투표를 취소할 수 있어요. 해당 투표에서 투표 변경을 꺼 두지 않은 경우에만 가능해요. 봇이 클릭에 보내는 모든 응답은 투표한 사람에게만 보여서 채널이 깔끔하게 유지돼요.

투표는 직접 마감할 수 있고, 설정한 기간이 지나면 자동으로 만료될 수도 있으며, 나중 날짜에 게시되도록 예약할 수도 있어요. 템플릿은 질문과 선택지를 저장해서 명령어 하나로 같은 투표를 다시 게시할 수 있게 해요. 대시보드에서는 분석, CSV와 JSON 내보내기, 투표 나란히 비교 기능을 쓸 수 있어요.

## 사용하면 좋은 이유

- 다음 커뮤니티 행사의 날짜나 게임을 정할 때 써요.
- 규칙을 바꾸기 전에 빠르게 찬반을 확인할 때 써요.
- 누가 어떤 답을 골랐는지 아무도 보지 못하도록 민감한 질문을 익명으로 올릴 때 써요.
- 결정이 필요한 사안에 대해 스태프 역할이나 부스터 역할만 투표하게 할 때 써요.
- 매주 월요일마다 같은 주간 투표를 템플릿으로 게시하거나, 미리 예약해 둘 때 써요.

## 투표 유형

| 유형 | 투표 방식 |
| --- | --- |
| 찬성 / 반대 | 찬성과 반대의 고정된 선택지 두 개. `poll` 및 `/poll yesno`으로 만들어요. |
| 단일 선택 | 멤버당 선택지 하나. `pollc`, 템플릿, 대시보드의 기본값이에요. |
| 복수 선택 | 멤버가 여러 선택지를 고를 수 있어요. 선택지가 여섯 개 이상이면 선택 메뉴에서 여러 개를 고를 수 있어요. |
| 익명 | 통계와 내보내기에 투표자가 나타나지 않도록 저장돼요. |
| 역할 제한 | 허용된 역할 중 하나를 가진 멤버만 투표할 수 있어요. 나머지 멤버에게는 "not allowed"라는 비공개 응답이 가요. 대시보드에서만 설정할 수 있어요. |

모든 투표에는 기본적으로 켜져 있는 선택 설정이 세 가지 있어요. **투표 변경 허용**, **실시간 결과 표시**, **진행 막대 표시**예요.

## 투표, 마감, 만료

- 마감되었거나 만료된 투표에 대한 투표는 비공개 메시지와 함께 거부돼요.
- 투표 변경이 꺼져 있으면, 두 번째 클릭은 "already voted"로 거부돼요.
- **"Close"**와 **"Delete"** 버튼은 투표 작성자와 **메시지 관리** 권한이 있는 사람이 쓸 수 있어요. **"Delete"**를 누르면 `DELETE`를 입력하는 확인 양식이 나오고, 확인하면 투표와 메시지가 삭제돼요.
- **통계**는 총 투표 수, 고유 투표자 수, 선택지별 상세 내역을 클릭한 사람에게만 비공개로 보여 줘요.
- 만료는 5분마다 확인해요. 투표가 만료되면 버튼이 제거되고 바닥글이 만료되었음을 나타내도록 바뀌어요.
- 예약된 투표는 1분마다 확인해요. 예약 시간은 미래여야 하고 30일 이내여야 해요. 분 단위의 지속 시간을 설정할 수 있으며, 게시된 투표는 그 시간이 지나면 만료돼요.

## 템플릿

템플릿에는 이름, 질문, 선택지가 저장돼요. `polltemplate <name>`은 템플릿을 단일 선택 투표로 게시해요. `polltemplates`로 템플릿 목록을 보고, `/poll create-template`과 `/poll delete-template`으로 만들거나 삭제하거나, 대시보드의 **템플릿** 탭에서 관리할 수 있어요. 이 탭에서는 파일로 내보내거나 가져오는 것도 지원해요. 템플릿에는 최대 25개의 선택지를 저장할 수 있어요.

## 설정

설문 페이지에는 **설문**, **만들기**, **예약됨**, **템플릿**, **분석** 탭이 있어요.

| 설정 | 기본값 | 제어 대상 |
| --- | --- | --- |
| 질문 | 없음 | 투표 제목 |
| 투표 유형 | 단일 선택 | 위의 다섯 가지 유형 중 하나 |
| 채널 | 없음 | 투표를 게시할 위치 |
| 선택지 | 빈칸 두 개 | 2개에서 25개까지, 각각 최대 100자. 찬성 / 반대일 때는 숨겨져요 |
| 투표할 수 있는 역할 | 없음 | 역할 제한 투표에서 표시 |
| 지속 시간(분) | 마감할 때까지 진행 | 1분에서 20160분까지. 예약할 때 적용돼요 |
| 나중에 예약 | 없음 | 날짜와 시간. 비워 두면 즉시 게시 |
| 투표 변경 허용 | 켜짐 | 멤버가 투표를 바꾸거나 취소할 수 있는지 여부 |
| 실시간 결과 표시 | 켜짐 | 투표 진행 중에 득표 수를 보여 줄지 여부 |
| 진행 막대 표시 | 켜짐 | 득표 수 옆에 막대를 그릴지 여부 |
| 템플릿으로도 저장 | 꺼짐 | **템플릿 이름** 아래에 질문과 선택지를 저장 |

**설문** 탭에는 **마감된 투표 포함** 체크박스가 있어요. 투표를 펼치면 고유 투표자, 참여율, 가장 바쁜 시간대, 생성 시간이 나오고 **투표 마감** 버튼도 있어요. **예약됨** 탭에서는 대기 중인 투표를 **취소**할 수 있어요. **분석** 탭에는 이번 달 투표 수, 전체 투표 수, 투표당 평균 참여 수, 선호 유형, 일별 생성 투표 차트가 나와요.

## 설정 단계

1. 대시보드에서 **설문**을 열고 **만들기** 탭으로 이동해요.
2. **질문**을 입력하고, **투표 유형**과 **채널**을 골라요.
3. **선택지**를 입력해요. 필요 없는 항목은 삭제 버튼으로 지우고, 최소 두 개는 있어야 해요.
4. 역할 제한 투표라면 **투표할 수 있는 역할**을 골라요.
5. 필요하면 **템플릿으로도 저장**을 체크하고 이름을 입력해요.
6. 제출 버튼을 클릭해요. 시간을 설정했다면 **예약됨** 탭에 등록되고, 아니라면 즉시 게시돼요.
7. **설문** 탭에서 결과를 확인하고, 끝나면 **투표 마감**을 눌러요.

> [!TIP]
> 채널에서 간단히 투표할 때는 대시보드가 필요하지 않아요. `poll Should we add a movie night?`를 입력하면 몇 초 만에 찬성 / 반대 투표가 게시돼요.

## 명령어

이 명령어들은 서버의 접두사(변경하지 않았다면 `.`)와 함께 실행해요.

| 명령어 | 별칭 | 필요 권한 | 용도 |
| --- | --- | --- | --- |
| `poll <question>` | `ppoll` | 메시지 관리 | 찬성 / 반대 투표 게시 |
| `pollc <question;option1;option2;...>` | | 메시지 관리 | 선택지 2개에서 25개까지의 단일 선택 투표 게시 |
| `pollm <question;option1;option2;...>` | | 메시지 관리 | 복수 선택 투표 게시 |
| `polla <question;option1;option2;...>` | | 메시지 관리 | 익명 투표 게시 |
| `polltemplate <name>` | `ptemplate` | 메시지 관리 | 저장된 템플릿으로 투표 게시 |
| `polltemplates` | `ptemplates` | 없음 | 서버의 템플릿 목록 보기 |

`/poll` 아래의 슬래시 명령어에는 `create`(최대 10개의 선택지와 익명 및 복수 선택 설정 포함), `close`, `stats`, `list`, `create-template`, `delete-template`이 있어요. `close`, `create-template`, `delete-template`에는 **메시지 관리** 권한이 필요해요.

## 팁과 주의 사항

- 봇에는 투표 채널에서 **메시지 보내기**와 **링크 임베드** 권한이 필요해요. 텍스트 명령어는 입력한 명령어 메시지도 삭제하므로, 봇에 **메시지 관리** 권한이 필요해요.
- 선택지는 세미콜론으로 나뉘므로, 선택지 안에는 세미콜론을 넣을 수 없어요.
- 버튼 라벨에는 선택지 텍스트가 12자 이하일 때만 표시돼요. 더 긴 선택지는 번호만 표시되고, 전체 텍스트는 임베드에 나와요.
- 지속 시간은 스케줄러가 적용해요. 즉시 게시된 투표는 누군가 마감하기 전까지 열려 있으므로, 자동 만료가 필요하면 1분 뒤로 예약하세요.
- 마감된 투표는 **마감된 투표 포함**을 체크하면 대시보드에서 계속 보고 내보낼 수 있어요. 삭제된 투표는 사라져요.
- 역할 제한 투표는 투표할 때마다 역할을 확인하므로, 역할을 잃은 멤버는 더 이상 투표할 수 없지만 이전에 한 투표는 그대로 남아요.
