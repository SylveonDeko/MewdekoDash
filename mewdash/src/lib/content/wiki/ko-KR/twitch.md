## 기능 소개

Twitch 봇은 Twitch 채널 하나를 Discord 서버에 연결하고, Mewdeko가 해당 채널의 채팅 봇 역할을 하도록 해요. 시청자가 Twitch 채팅에 `!ping`, `!quote`, `!counter deaths` 또는 직접 만든 사용자 지정 명령어를 입력하면 봇이 그 채팅방에서 응답해요. 방송 중에는 타이머가 반복 메시지를 올리고, 인용문과 카운터는 서버별로 저장돼요. 채널 포인트 보상으로 채팅 답장이나 Discord 게시물을 실행할 수도 있어요.

채널에서 일어나는 이벤트는 Discord로 다시 전달돼요. 방송이 시작되면 방송 시작 게시물이 Discord 채널에 올라가고, 구독, 선물 구독, 습격도 각각 지정한 채널에 내가 정한 템플릿으로 게시할 수 있어요. 방송 종료 후에는 방송 시간, 최고 시청자 수, 채팅 메시지 수, 구독, 습격을 요약한 방송 리캡도 보낼 수 있어요.

시청자는 Twitch 계정을 Discord 계정과 연결할 수 있어요. 연결이 되면 봇은 어떤 Discord 멤버가 Twitch에서 채팅하는지 알 수 있고, 역할 동기화로 구독자, VIP, 모더레이터, 방송인에게 Discord 역할을 자동으로 줄 수 있어요.

> [!NOTE]
> 이 기능은 스트림 알림과 달라요. 스트림 알림은 여러 플랫폼의 공개 채널을 지켜보다가 방송이 시작되면 알려 주는 기능이에요. Twitch 봇은 내 Twitch 계정을 직접 인증해야 하고, 봇이 내 채팅방에 들어가 활동해요. 같은 Twitch 채널에 두 기능을 모두 설정하면 Twitch 봇의 방송 시작 게시물이 스트림 알림 게시물을 대신해서 중복 알림이 생기지 않아요.

## 이런 분께 추천해요

- Twitch 방송을 하고 있고, Discord와 Twitch 채팅에서 같은 사용자 지정 명령어와 소셜 링크를 쓰는 봇 하나로 관리하고 싶은 분
- 구독과 습격이 일어날 때마다 Discord에서 바로 축하하고 싶은 분
- 구독자나 VIP 역할을 일일이 수동으로 주지 않고 자동으로 주고 싶은 분
- 수분 보충이나 스트레칭 채널 포인트 보상이 채팅에 메시지를 남기고 Discord에 기록되도록 하고 싶은 분
- 모더레이터가 쓸 shoutout 명령어, 습격 대상 선택기, 방송 사이에도 유지되는 인용 목록이 필요한 분

## 연결하기

Twitch 인증은 두 가지가 필요하며, 모두 **설정** 탭의 **연결** 하위 탭에서 진행해요.

| 인증 | 누가 하나요 | 부여되는 권한 |
| --- | --- | --- |
| 봇 계정 | 봇 소유자만 | 봇이 채팅할 때 사용하는 Twitch 계정이에요. 모든 서버가 공유하는 하나의 계정이에요. 범위는 `user:read:chat`, `user:write:chat`, `user:bot`이에요. |
| 방송인 채널 | 스트리머인 본인 | 내 채널 이벤트 접근 권한이에요. 범위는 `channel:bot`, 구독, 비트, 교환, 투표, 예측, 방송 관리, 클립 편집, 모더레이션이에요. |

봇 계정이 있고, 내 채널이 인증되어 있고, 설정이 켜져 있으면 연동이 완료된 것으로 표시돼요. **상태** 패널에서는 전송 방식(EventSub WebSocket 또는 레거시 IRC), 마지막으로 받은 이벤트, 두 계정의 토큰 만료 시각을 확인할 수 있어요. **고급 진단**에서는 누락된 범위와 저장된 EventSub 구독을 볼 수 있어요.

채널 연결을 해제하면 내 인증 정보가 삭제되고 기능이 꺼져요. 봇 계정은 봇 소유자만 연결을 해제할 수 있어요.

## Twitch 채팅 명령어

연결된 모든 채널에는 아래 기본 명령어가 있어요. 기본 접두사는 `!`이며, 최대 5글자까지 바꿀 수 있어요. 사용자 지정 명령어는 이름이 기본 명령어와 겹치지 않을 때만 실행돼요.

| 명령어 | 사용 대상 | 기능 |
| --- | --- | --- |
| `!ping` | 모두 | "pong"으로 응답해요 |
| `!uptime` | 모두 | 봇 프로세스가 실행된 지 얼마나 되었는지 보여줘요 |
| `!commands` | 모두 | 기본 명령어와 활성화된 사용자 지정 명령어를 나열해요 |
| `!discord` | 모두 | 명령어를 입력한 사람과 연결된 Discord 계정을 보여줘요 |
| `!link` | 모두 | 계정 연결용 6자리 인증 코드를 만들어요 |
| `!rank` | 모두 | 명령어를 입력한 사람의 계산된 등급을 보여줘요 |
| `!stream` | 모두 | 라이브 상태, 제목, 카테고리, 시청자 수, 방송 시간을 보여주거나 "offline"이라고 알려줘요 |
| `!schedule` | 모두 | 스태프가 설정한 일정 메시지를 게시해요 |
| `!socials` | 모두 | 스태프가 설정한 소셜 메시지를 게시해요 |
| `!quote [id]` | 모두 | 무작위 인용문을 보여주거나 번호로 특정 인용문을 보여줘요 |
| `!quote add <text> [-- author]` | 모더레이터 | 인용문을 저장해요. `--` 뒤에 작성자를 적을 수 있어요 |
| `!quote remove <id>` | 모더레이터 | 인용문을 삭제해요 (`delete`도 사용할 수 있어요) |
| `!counter <name>` | 모두 | 카운터 값을 보여줘요 |
| `!counter <name> +` | 모더레이터 | 1 증가해요 (`++` 또는 `add`도 가능해요). `-`, `--` 또는 `sub`는 1 감소해요. `reset`은 0으로 만들어요. 숫자를 입력하면 그 값으로 설정해요 |
| `!so <user>` | 모더레이터 | 다른 Twitch 채널을 shoutout 해요 |
| `!raidtarget` | 모더레이터 | 습격 대상 목록에서 무작위 채널을 추천해요 |

### 등급

채팅하는 사람의 등급은 Twitch 배지에서 정해져요. 등급은 방송인이 가장 높고, 다음은 모더레이터, VIP, 구독자(파운더 배지도 구독자로 계산해요), 모두 순서예요. 명령어, 사용자 지정 명령어, 역할 동기화는 모두 이 순서를 기준으로 비교하므로, 모더레이터는 VIP, 구독자, 모두에게 설정된 명령어를 모두 쓸 수 있어요.

## 사용자 지정 명령어

사용자 지정 명령어는 대시보드의 **명령어** > **사용자 지정 명령어**에서 추가하거나, `/twitch commands add`로 추가할 수 있어요. 이름은 소문자로 바뀌며, 최대 32자이고, 영문, 숫자, 하이픈, 밑줄을 사용할 수 있어요. 각 명령어에는 **권한**(모두, 구독자, Vip, 모더레이터, 방송인), 0에서 86400 사이의 **쿨다운 (초)**, **활성화** 토글, **응답**이 있어요. 쿨다운은 사용자별이 아니라 채널 전체에 적용돼요. 사용 횟수는 목록에 기록되고 표시돼요.

대시보드에는 **테스트 인수** 입력란과 미리보기도 있어서, 저장하기 전에 최종 응답이 어떻게 보이는지 확인할 수 있어요.

### 응답에서 쓸 수 있는 플레이스홀더

| 플레이스홀더 | 값 |
| --- | --- |
| `%user%` | 채팅한 사람의 Twitch 로그인 이름 |
| `%display%` | 채팅한 사람의 표시 이름 |
| `%channel%` | 내 Twitch 채널 로그인 이름 |
| `%args%` | 명령어 이름 뒤에 입력한 모든 내용 |
| `%target%` | 명령어 이름 뒤 첫 번째 단어 |
| `%discord%` | 채팅한 사람과 연결된 Discord 사용자 ID이며, 없으면 비어 있어요 |
| `%random:a\|b\|c%` | 보기 중 하나를 무작위로 골라요 |
| `%count:name%` | 지정한 카운터의 현재 값이에요 |
| `%stream%` | `!stream`이 보여주는 것과 같은 요약이에요 |

> [!EXAMPLE]
> `!hug` 명령어의 응답이 `%display% hugs %target%! That is hug number %count:hugs%.`라면, 이 응답은 채팅에서 그대로 출력돼요.

## 타이머

타이머는 정해진 일정에 따라 Twitch 채팅에 메시지를 올려요. **명령어** > **타이머**에서 관리하거나, `/twitch timers`로 관리할 수 있어요.

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| 타이머 이름 | | 명령어와 같은 이름 규칙을 따라요 |
| 간격 (분) | 10 | 게시 사이의 간격이에요. 1분에서 1440분까지 설정할 수 있어요 |
| 최소 채팅 메시지 수 | 5 | 마지막 게시 이후 다시 게시하기 전까지 필요한 채팅 메시지 수예요. 0이면 이 검사를 꺼요 |
| 온라인 전용 | 켜짐 | 방송이 라이브 중일 때만 게시해요 |
| 무작위 순환 | 꺼짐 | 순서대로 돌리는 대신 무작위 줄을 골라요 |
| 활성화 | 켜짐 | 타이머 실행 여부예요 |
| 메시지 | | 한 줄에 메시지 하나를 입력해요 |

스케줄러는 30초마다 타이머를 확인해요. 타이머 줄에는 `%channel%`, `%url%`, `%stream%`, `%count:name%`, `%random:a|b|c%`를 사용할 수 있어요. `/twitch timers test`(또는 대시보드의 테스트 버튼)를 사용하면 타이머를 바로 게시해요.

## 인용문과 카운터

인용문에는 본문, 선택 작성자, 추가한 사람이 저장돼요. 대시보드의 **인용** 하위 탭에서 스태프가 인용문을 추가, 검색, 삭제할 수 있어요. 시청자는 `!quote`를 사용해요. 카운터는 모더레이터가 채팅에서 값을 올리는 간단한 이름 있는 정수예요. 스태프는 `/twitch commands counter-set`으로 값을 설정하고, `counter-list`로 목록을 확인할 수 있어요.

## Discord로 전달되는 이벤트

**이벤트** 탭의 **알림** 하위 탭에서 구독, 습격, 채널 포인트 설정을 관리해요. 방송 시작 게시물은 **설정** > **봇 설정** > **이벤트 라우팅**에 있어요.

### 방송 시작과 종료

방송이 시작되면 봇이 **방송 시작 Discord 채널**에 게시해요. **방송 시작 메시지**를 설정하지 않으면 기본 임베드가 올라가요. 기본 임베드에는 채널에 연결된 스트리머 이름, 제목을 작성자 줄로 쓴 내용, 상태, 시청자 수, 카테고리, 미리보기 이미지가 포함돼요. 사용자 지정 메시지는 임베드 빌더를 거치므로 전체 임베드와 컴포넌트도 사용할 수 있어요. 방송이 종료되면 같은 채널에 짧은 빨간색 "Offline" 임베드가 게시돼요.

| 플레이스홀더 | 값 |
| --- | --- |
| `%streamer%` | 방송인의 표시 이름이에요 |
| `%title%` | 방송 제목이에요 |
| `%game%` | 카테고리 이름이에요 |
| `%url%` | `https://twitch.tv/<channel>`이에요 |
| `%viewers%` | 현재 시청자 수예요 |

### 구독과 습격

이 메시지들은 일반 텍스트예요. 기본 구독 메시지는 `%display% subscribed to %channel%!`이고, 선물 구독은 `%display% received a gifted sub on %channel%!`이에요. 기본 습격 메시지는 `%raider% raided %channel% with %viewers% viewers!`예요.

| 이벤트 | 플레이스홀더 |
| --- | --- |
| 구독 | `%user%`, `%display%`, `%channel%`, `%tier%` |
| 습격 | `%raider%`, `%channel%`, `%viewers%` |

각 알림에는 대시보드의 **테스트 전송** 버튼이 있고, **이벤트 기록** 목록에서 최근 이벤트와 테스트 전송 내역을 볼 수 있어요.

### 채널 포인트 동작

**채널 포인트 동작**에서 **보상 제목**(대소문자 구분 없이 일치)을 **Twitch 답장**, **Discord 채널**과 **Discord 메시지**, 또는 둘 다에 연결할 수 있어요. 사용할 수 있는 플레이스홀더는 `%user%`, `%display%`, `%channel%`, `%reward%`, `%input%`(시청자가 입력한 내용), `%url%`이에요.

### 방송 리캡

`/twitch events recap-channel`은 방송이 끝날 때 임베드를 받을 채널을 설정해요. 임베드에는 방송 시간, 최고 시청자 수, 채팅 메시지 수, 구독, 습격, 마지막 제목과 카테고리가 담겨요. 리캡은 대시보드에서 설정할 수 없어요.

## 계정 연결과 역할 동기화

Discord 멤버를 Twitch 로그인과 연결하는 방법은 두 가지예요.

1. 직접 연결: 시청자가 Twitch 채팅에 `!link`를 입력해 6자리 코드를 받고, 10분 안에 Discord에서 `/twitch claim <code>`를 실행해요.
2. 스태프 연결: **계정 연결** 탭이나 `/twitch links add @user twitchlogin`을 사용해요.

서버마다 Discord 멤버 한 명은 Twitch 로그인 하나만 연결할 수 있어요. 연결되면 해당 시청자에게 `%discord%`가 채워지고 역할 동기화가 적용돼요.

역할 동기화는 `/twitch rolesync add`로 Twitch 등급을 Discord 역할에 연결해요. 연결된 시청자가 채팅할 때마다 봇은 그 사람의 등급이 연결된 등급 이상이면 역할을 주고, 미만이면 역할을 제거해요. 역할 동기화는 슬래시 명령어로만 설정할 수 있어요.

## 라이브 도구

**이벤트** 탭의 **라이브 도구** 하위 탭에서는 내 채널 인증을 사용하는 방송 운영 기능을 쓸 수 있어요. 봇 이름으로 채팅 보내기, 스트림 마커 만들기, 클립 만들기, 투표 시작(한 줄에 선택지 하나, 기본 60초), 타임아웃(기본 600초), 차단, 차단 해제, 메시지 ID로 메시지 삭제를 할 수 있어요. `/twitch stream-info`와 `/twitch clip`으로 Discord에서 제목, 카테고리, 클립 작업을 할 수 있어요.

## 설정

**설정** > **봇 설정**에서 다음을 설정해요.

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| 명령어 접두사 | `!` | Twitch 채팅 명령어 접두사예요. 최대 5글자까지 설정할 수 있어요 |
| 언어 재정의 | 서버 기본값 | 봇 채팅 응답에 사용할 BCP-47 태그예요. 예: `de-DE` |
| 이 서버에서 Twitch 채팅 봇 켜기 | 켜짐 | 전체 스위치예요. 끄더라도 설정은 남아요 |
| 채팅 이벤트에 EventSub 사용 | 켜짐 | 채팅과 이벤트를 EventSub로 받아요. 꺼져 있으면 채팅 명령어가 실행되지 않아요 |
| 방송 시작 Discord 채널 | 없음 | 방송 시작과 종료 게시물을 보낼 채널이에요 |
| 방송 시작 메시지 | 기본 임베드 | 방송 시작 플레이스홀더를 쓸 수 있는 사용자 지정 템플릿이에요 |

**설정** > **알림**에서는 **구독 Discord 채널**, **구독 메시지**, **습격 Discord 채널**, **습격 메시지**, 그리고 채널 포인트 동작 목록을 설정해요.

## 설정 순서

1. 대시보드에서 **Twitch 봇**을 열어요. 봇 소유자가 먼저 **봇 계정**을 연결해야 해요. **연결** 하위 탭에서 봇 계정이 있는지 확인할 수 있어요.
2. **채널 연결**을 누르고 내 Twitch 계정으로 인증해요.
3. **봇 설정**에서 접두사를 정하고, **이 서버에서 Twitch 채팅 봇 켜기**를 켠 다음, **방송 시작 Discord 채널**을 고르고 저장해요.
4. **명령어**에서 사용자 지정 명령어 몇 개와 소셜 타이머를 추가해요. **테스트 인수**와 미리보기로 플레이스홀더를 확인해요.
5. **이벤트** > **알림**에서 구독과 습격 채널을 고르고, 각각 **테스트 전송**을 눌러 봐요.
6. Twitch 채팅에 `!ping`을 입력해 봇이 응답하는지 확인한 다음, `!link`와 `/twitch claim`으로 내 계정을 연결해요.
7. 선택 사항으로 `/twitch rolesync add Subscriber @Subs`를 실행하면 연결된 구독자가 역할을 받아요.

## 팁과 주의 사항

- 봇 계정은 봇을 사용하는 모든 서버가 공유해요. 아무도 봇 계정을 연결하지 않았다면, 설정을 아무리 해도 채팅 응답을 보낼 수 없어요.
- 채팅 명령어는 **채팅 이벤트에 EventSub 사용**이 켜져 있을 때만 작동해요. 상태 패널에 레거시 IRC라고 표시되면 이 설정을 다시 켜 주세요.
- 방송 상태는 1분마다 한 번씩 확인하므로, 방송 시작 게시물은 실제 시작 시각보다 최대 1분 늦게 올라올 수 있어요.
- 사용자 지정 명령어의 쿨다운은 시청자별이 아니라 채널별이에요. 30초 쿨다운이면 모든 시청자가 합쳐서 30초에 한 번만 사용할 수 있어요.
- 역할 동기화는 연결된 시청자가 채팅할 때 실행되고, 정해진 일정에 따라 실행되지 않아요. 채팅을 한 번도 하지 않은 구독자는 역할을 받지 못하고, 구독이 끝난 사람은 다시 채팅할 때까지 역할을 유지해요.
- 역할을 바꾸려면 봇의 역할이 동기화할 역할보다 위에 있어야 하고, **역할 관리** 권한이 필요해요.
- `rolesync`에 알 수 없는 등급을 입력하면 구독자로 처리되고, `commands add`에 알 수 없는 권한을 입력하면 모두로 처리돼요.
- 연결 코드는 10분 뒤에 만료되며, 새 코드를 만들면 이전 코드는 무효가 돼요.
- 라이브 도구의 타임아웃과 차단은 내 채널의 모더레이션 권한을 사용하므로, Twitch에서는 인증된 계정이 한 조치로 표시돼요.
- 언어 재정의는 Twitch 채팅 응답에만 적용돼요. Discord 응답은 서버 언어를 그대로 사용해요.
