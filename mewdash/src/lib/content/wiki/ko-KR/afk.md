## What it does

멤버는 선택적으로 메시지를 붙여 `afk`를 실행해요. 그 뒤로 누군가 그 멤버를 멘션하면, 봇은 그 채널에 메시지와 자리를 비운 지 얼마나 되었는지를 답장해요. 멤버가 돌아오면 상태가 해제되고, "welcome back" 알림이 짧게 게시된 뒤 5초 후에 삭제되며, 닉네임이 복원돼요.

멤버가 자리를 비운 동안 봇은 멤버 목록에서 상태가 보이도록 닉네임을 `[AFK] name`으로 바꾸려고 시도해요. 이때 Discord의 닉네임 길이 제한에 맞게 잘라요.

메시지 없이 `afk`를 실행하면 전환돼요. 자리를 비운 상태가 아니면 빈 메시지로 AFK를 켜고, 자리를 비운 상태이면 AFK를 꺼요.

## Why you would use it

- 바쁜 서버에서 멤버들이 "brb"라고 말해도 못 본 사람들에게 계속 멘션되지 않도록 할 수 있어요.
- 스태프가 누가 자리에 있고 누가 없는지 한눈에 볼 수 있어요.
- 시간 지정 AFK는 "두 시간 뒤에 돌아올게요" 같은 상황을 다룰 수 있어요. 아무도 해제를 기억할 필요가 없어요.

## How a status ends

**AFK 유형**은 봇이 돌아온 것으로 간주할 조건을 정해요. 이 페이지에서 가장 중요한 설정이에요.

| Type | Status clears when |
| --- | --- |
| 직접 해제 | 멤버가 `afk`를 다시 실행하거나 스태프가 제거할 때만 해제돼요. 자동 해제는 없어요. |
| 메시지 입력 시 | 멤버가 서버 어디든 메시지를 보낼 때 해제돼요. |
| 타이핑 시 | 멤버가 어느 채널에서든 입력을 시작할 때 해제돼요. |
| 둘 중 하나 | 메시지나 타이핑 중 먼저 일어나는 쪽에서 해제돼요. |

**AFK 시간 제한**은 상태를 설정한 시점부터 세는 유예 기간이에요. 이 기간 안에는 입력하거나 메시지를 보내도 상태가 해제되지 않아요. 그래서 "afk, brb" 메시지 자체로 AFK가 바로 끝나는 일을 막아요. 기본값은 0이며, 유예 기간이 없다는 뜻이에요. `afktimeout` 명령어나 대시보드의 **고급 설정** 탭에서 설정할 수 있어요.

시간 지정 AFK는 다른 방식이에요. 유형과 관계없이 타이머가 끝날 때까지 유지돼요. 그 사이에 대화해도 끝나지 않아요. 타이머가 끝나면 채널 알림 없이 상태가 해제되고 닉네임이 복원돼요.

게시한 지 5분 안에 메시지를 수정하면 새 메시지를 보낸 것과 같이 취급해요.

## The reply to a mention

누군가 자리를 비운 멤버를 멘션하면, 봇은 메시지당 최대 다섯 명의 멘션된 사용자를 확인해요. 봇과 자기 자신에 대한 멘션은 무시하고, 명령어 접두사로 시작하는 메시지는 무시하며, 비활성화된 채널 목록에 있는 채널은 건너뛰어요. 자리를 비운 멤버를 찾으면 각각에 대해 답장을 게시해요.

기본 답장은 임베드예요. 작성자 줄에는 "user is currently away"와 아바타가 표시되고, 설명에는 AFK 메시지가 표시되며, 푸터에는 자리를 비운 지 얼마나 되었는지 표시돼요. 봇이 초대 버튼을 보여 주도록 설정되어 있으면 버튼도 함께 붙어요.

`customafkmessage`나 대시보드의 **사용자 지정 AFK 임베드 메시지** 편집기를 사용하면 기본 답장을 직접 만든 메시지나 임베드로 바꿀 수 있어요. 입력한 내용은 임베드 파서를 거치므로, 임베드 빌더가 만들 수 있는 것은 모두 사용할 수 있어요. `-`로 설정하면 기본 임베드로 돌아가요.

### Placeholders

다음 자리표시자는 사용자 지정 AFK 메시지 안에서 바뀌어요. 자리표시자 페이지의 일반 자리표시자는 여기서 사용할 수 없고, 이 목록만 사용할 수 있어요.

| Placeholder | Value |
| --- | --- |
| `%afk.message%` | AFK 메시지예요. 멘션은 무력화되고 최대 길이까지 잘려요 |
| `%afk.user%` | 자리를 비운 멤버의 사용자 이름이에요 |
| `%afk.user.mention%` | 자리를 비운 멤버에 대한 멘션이에요 |
| `%afk.user.avatar%` | 자리를 비운 멤버의 아바타 URL이에요 |
| `%afk.user.id%` | 자리를 비운 멤버의 사용자 ID예요 |
| `%afk.triggeruser%` | 그 멤버를 멘션한 사람의 사용자 이름이에요 |
| `%afk.triggeruser.mention%` | 그 멤버를 멘션한 사람에 대한 멘션이에요 |
| `%afk.triggeruser.avatar%` | 그 멤버를 멘션한 사람의 아바타 URL이에요 |
| `%afk.triggeruser.id%` | 그 멤버를 멘션한 사람의 사용자 ID예요 |
| `%afk.time%` | 자리를 비운 지 얼마나 되었는지를 "2 hours"처럼 단어로 나타내요 |

> [!EXAMPLE]
> 일반 텍스트 답장 예시: `%afk.user.mention% is away (%afk.time%): %afk.message%`

## Settings

모든 설정은 AFK 페이지의 **기본 설정**과 **고급 설정** 탭에 있어요.

| Setting | Default | What it controls |
| --- | --- | --- |
| 자동 삭제 시간 | 0 (없음) | 멘션에 대한 봇의 답장이 스스로 삭제되기까지의 시간(초)이에요 |
| 최대 메시지 길이 | 128 | 멤버가 설정할 수 있는 가장 긴 AFK 메시지예요. 1에서 4096까지이며, 더 길면 거부돼요 |
| AFK 해제 유형 | 직접 해제 | 위에서 설명한 네 가지 유형 중 하나예요 |
| AFK 시간 제한 | 0 (없음) | AFK를 설정한 뒤의 유예 기간이며, 최대 2시간까지 설정할 수 있어요 |
| 비활성화된 채널 | 없음 | 자리를 비운 멤버를 멘션해도 답장하지 않을 채널이에요 |
| 사용자 지정 AFK 임베드 | 기본 임베드 | 위의 자리표시자를 사용하는 나만의 답장이에요 |

> [!TIP]
> 자동 삭제 시간은 30초 정도로 설정하세요. 멘션한 사람은 답장을 볼 수 있고, 채널에 오래된 AFK 알림이 쌓이지 않아요.

**사용자 관리** 탭에는 현재 자리를 비운 모든 멤버가 나열되며, 스태프는 한 명 또는 여러 명의 상태를 한꺼번에 해제할 수 있어요.

## Setup walkthrough

1. 대시보드에서 **AFK 시스템**을 여세요.
2. **AFK 해제 유형**을 고르세요. "메시지 입력 시"가 가장 안전한 기본값이고, "둘 중 하나"가 가장 편리해요.
3. **자동 삭제 시간**을 30으로 설정하세요. **최대 메시지 길이**는 더 긴 상태 메시지가 필요하지 않다면 128로 두세요.
4. **고급 설정** 탭에서 봇 명령어 채널과 공지 채널을 **비활성화된 채널**에 추가하세요.
5. 필요하면 위의 자리표시자를 사용해 임베드 편집기에서 답장을 만드세요.
6. `afk testing`을 실행하고, 다른 계정으로 나를 멘션한 뒤 메시지를 보내서 상태가 해제되는지 확인하세요.

## Commands

이 명령어는 서버의 접두사로 실행하세요(변경하지 않았다면 `.`).

| Command | Aliases | Needs | Purpose |
| --- | --- | --- | --- |
| `afk [message]` | | 없음 | 내 AFK 메시지를 설정하거나, 메시지 없이 AFK를 켜고 끄기 |
| `timedafk <time> <message>` | `tafk` | 없음 | 스스로 끝나는 AFK. 예: `timedafk 2h dinner` |
| `getactiveafks` | `activeafks` | 없음 | 현재 AFK 상태인 모든 사람 나열 |
| `afkview [@user]` | `viewafk` | 메시지 관리 | 누군가의 현재 AFK 메시지 보기 |
| `afkremove @user...` | `afkrm` | 메시지 관리 | 한 명 이상의 멤버 상태 해제 |
| `afkdel [seconds]` | `afkdelete` | 서버 관리 | 답장의 자동 삭제 시간 보기 또는 설정 |
| `afklength <number>` | `maxafklength` | 관리자 | AFK 메시지 길이 제한 |
| `afktype <type>` | | 관리자 | `selfdisable`, `onmessage`, `ontype`, `either` 중 하나 |
| `afktimeout <time>` | | 관리자 | 유예 기간 설정. 예: `30s` |
| `afkdisable #channel...` | | 채널 관리 | 답장 없는 목록에 채널 추가 |
| `afkundisable #channel...` | | 채널 관리 | 답장 없는 목록에서 채널 제거 |
| `afkdisabledlist` | | 채널 관리 | 답장 없는 목록 보기 |
| `customafkmessage <text>` | `afkmessage` | 관리자 | 사용자 지정 답장 설정. 기본값으로 되돌리려면 `-` |

## Tips and gotchas

- 내 상태만 해제하는 명령어는 없어요. `afk`를 메시지 없이 다시 실행하거나, 유형 규칙에 따라 해제될 때까지 기다리세요.
- 닉네임 변경에는 봇의 역할이 멤버의 최상위 역할보다 위에 있고, 닉네임 관리 권한이 있어야 해요. 서버 소유자의 닉네임은 봇이 바꿀 수 없으므로 소유자는 원래 이름을 유지하지만, 상태 기능은 그대로 작동해요.
- AFK 서비스는 봇이 시작된 직후 캐시를 불러와요. 그 전까지는 명령어가 AFK가 아직 시작 중이라고 답해요.
- AFK 메시지 안의 멘션은 답장에서 무력화되므로, 멤버가 상태를 이용해 역할이나 everyone을 핑할 수 없어요.
