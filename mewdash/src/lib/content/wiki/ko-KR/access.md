## 기능 설명

기본적으로 서버 소유자와 관리자 권한이 있는 멤버만 대시보드에서 서버를 열 수 있어요. 대시보드 접근 기능으로 이 범위를 넓힐 수 있어요. 멤버나 역할을 고르고, 그 대상에게 줄 대시보드 섹션을 고르고, 섹션마다 **보기**나 **관리** 중 하나를 정해요. 그 뒤부터 해당 서버가 대상의 대시보드 서버 목록에 나타나고, 허용한 섹션이 동작해요. 그 밖의 요청은 거부돼요.

검사는 웹 페이지뿐 아니라 봇의 API에서 이루어져요. 서버를 지정하는 모든 요청에는 로그인한 사용자의 신원이 담겨 있어요. 소유자나 관리자라면 요청이 통과해요. 그렇지 않다면 봇은 요청이 속한 섹션을 찾고, 읽기는 **보기**로, 변경은 **관리**로 취급해요. 그다음 사용자가 직접 가진 권한이나 역할을 통해 가진 권한 중 가장 높은 수준과 비교해요.

서버 소유자는 접근 목록 자체를 편집할 수 있는 사람도 정해요. 기본적으로는 소유자만 편집할 수 있어요. 소유자는 특정 접근 관리자를 임명하거나, 관리자 또는 서버 관리 권한이 있는 사람 모두에게 편집을 허용하는 스위치를 켤 수 있어요.

## 사용 이유

- 커뮤니티 팀이 Discord 관리자 권한 없이 대시보드에서 기브어웨이, 제안, 티켓을 운영해요.
- 모더레이터 역할에는 모더레이션과 로깅에 **관리**를, 나머지에는 **보기**를 줘서, 자기 책임이 아닌 설정은 살펴보기만 하고 바꾸지 못하게 해요.
- 봇 도우미에게 XP와 화폐는 편집을 맡기되, 보안과 관련된 것은 맡기지 않아요.
- 소유자는 접근 목록 관리를 공동 소유자 역할에 맡기면서도, 소유자만 가능한 제어는 넘기지 않아요.

## 접근 수준

| 수준 | 허용하는 것 |
| --- | --- |
| 없음 | 해당 섹션에 대한 권한이 없어요. 섹션이 부여되지 않아요 |
| 보기 | 읽기 요청만 가능해요. 페이지를 열고 데이터를 불러오는 것 등이에요 |
| 관리 | 보기가 허용하는 모든 것에 더해 만들기, 편집, 삭제를 할 수 있어요 |

멤버가 여러 권한과 일치하면, 예를 들어 개인 권한과 역할 권한이 모두 있으면, 섹션마다 가장 높은 수준이 적용돼요. 섹션을 하나라도 부여받은 멤버는 대시보드 서버 전환기에서 해당 서버를 볼 수 있어요. 아무 권한도 없는 멤버에게는 서버가 보이지 않아요.

소유자와 관리자는 권한과 관계없이 접근 검사를 거치지 않고, 항상 모든 권한을 가져요.

## 섹션

섹션은 대시보드 사이드바와 일치해요. 선택기의 각 기능은 봇 API의 하나 이상의 영역에 대응해요. 그래서 "Administration"을 부여하면 Administration과 Protection 엔드포인트가 모두 포함되고, "Moderation"에는 Protection도 포함돼요. 선택기는 섹션을 사이드바 카테고리별로 묶어서 보여줘요. 성능처럼 서버 데이터가 아닌 봇의 공통 인프라 기능은 부여할 수 없어요.

하나의 권한이 여러 영역에 걸친 기능을 포함하면, 선택기는 그 영역들이 공유하는 가장 낮은 수준을 보여줘요. 그룹을 설정하면 해당 그룹의 모든 영역이 한꺼번에 설정돼요.

## 접근 목록을 관리할 수 있는 사람

| 대상 | 할 수 있는 일 |
| --- | --- |
| 서버 소유자 | 모든 것: 위임 스위치, 관리자 목록, 모든 권한 |
| 임명된 접근 관리자 | 권한 추가, 편집, 제거 |
| 관리자 또는 서버 관리 권한이 있는 멤버 | 위임 스위치가 켜져 있는 동안에만 권한 추가, 편집, 제거 |
| 그 밖의 모든 사람 | "여기서는 대시보드 접근 권한을 관리할 수 없어요"라는 메시지를 봐요 |

접근 관리자는 멤버일 수도 있고 역할일 수도 있어요. 관리자 목록과 위임 스위치는 소유자만 보고 바꿀 수 있어요. 다른 사람이 이 호출을 하면 API가 거부해요.

> [!WARNING]
> 대시보드 접근에 **관리** 권한을 부여할 수는 없어요. 접근 제어기는 섹션 검사에서 제외되어 있기 때문이에요. 대신 관리자 목록이나 위임 스위치를 이용해 접근 목록을 관리할 권한을 넘기세요.

## 설정

모든 설정은 대시보드 접근 페이지 하나에 있어요.

| 설정 | 기본값 | 제어하는 내용 |
| --- | --- | --- |
| 관리자 및 서버 관리 권한이 있는 멤버도 대시보드 접근 권한을 관리할 수 있게 하기 | 꺼짐 | **위임 설정** 아래에 있어요. 켜면 관리자와 서버 관리 권한이 있는 멤버가 권한을 편집할 수 있어요. 소유자만 설정할 수 있어요. |
| 접근 관리자 | 없음 | 권한을 편집하도록 임명된 멤버 또는 역할. 소유자만 설정할 수 있어요. |
| 접근 권한 | 없음 | 멤버 또는 역할마다 하나의 항목이 있고, 섹션마다 수준을 나열해요. 관리자와 소유자가 볼 수 있어요. |

**제한된 접근 권한 부여** 양식에서는 대상 유형(사용자 또는 역할), 대상, 기능 그룹마다 수준을 고를 수 있어요. 같은 대상에 두 번째 권한을 저장하면 첫 번째 권한이 대체돼요. 기존 권한을 편집하면 같은 양식이 **접근 권한 수정**이라는 제목으로 열려요.

## 설정 순서

1. 소유자로서 대시보드에서 **대시보드 접근**을 열어요.
2. 목록을 관리할 사람을 정해요. **위임 설정**에서 위임 스위치를 켜거나, **접근 관리자**에 멤버나 역할을 추가하세요.
3. **제한된 접근 권한 부여**에서 **역할**을 고르고 스태프 역할을 선택하세요.
4. 매일 운영하는 기능에는 **관리**를, 살펴보기만 해야 하는 기능에는 **보기**를 설정하세요. 나머지는 **없음**으로 두세요.
5. **접근 권한 부여**를 클릭하세요. 권한이 **접근 권한** 아래에 나타나요.
6. 그 역할을 가진 멤버에게 대시보드에 로그인하라고 하세요. 이제 서버가 그 사람의 목록에 나타나고, 부여된 페이지만 동작할 거예요.

## 명령어

대시보드 접근은 대시보드에서만 설정해요. 이를 위한 봇 명령어는 없어요.

## 팁과 주의 사항

- 권한은 봇이 캐시한 멤버 목록을 기준으로 확인하므로, 권한이 동작하려면 멤버가 서버에 있고 봇에게 보여야 해요.
- 역할 권한은 멤버의 현재 역할을 따라가요. 역할을 빼면 접근 권한도 즉시 사라져요.
- 모든 섹션을 **없음**으로 설정한 권한은 권한이 없는 것으로 간주되어 삭제되며, 멤버는 서버 전환기에서 서버를 잃어요.
- 권한 설정과 관계없이 관리자는 모든 권한을 유지해요. 누군가를 제한하려면 먼저 Discord에서 관리자 권한을 빼고, 필요한 권한을 여기서 부여하세요.
- 대시보드 프록시는 모든 요청에 공용 API 키를 붙이지만, 그 키만으로는 어떤 서버에도 접근할 수 없어요. 로그인한 사용자의 신원이 항상 필요해요.
- 글로벌 명령어 목록처럼 특정 서버에 묶이지 않은 엔드포인트는 섹션 검사를 받지 않으므로, 제한된 사용자도 계속 사용할 수 있어요.
