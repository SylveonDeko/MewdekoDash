## What it does

봇이 서버에서 추방되거나 서버를 나갈 때마다 봇은 서버 소유자에게 짧은 DM을 보내요. DM에는 흔한 사유를 고르는 드롭다운, 텍스트 입력 창을 여는 **Write something** 버튼, **No thanks** 버튼이 있어요. 응답은 선택 사항이며, DM에도 그렇게 안내되어 있어요.

각 응답은 서버 이름, 멤버 수, 소유자, 봇이 서버에 머문 기간과 함께 저장돼요. 보고 채널이 설정되어 있으면 응답마다 요약 임베드가 그곳에도 게시되며, 소유자가 나중에 댓글을 추가하면 그 임베드도 갱신돼요.

이 기능은 봇 전체에 적용돼요. 서버별 설정은 없으며, 대시보드 페이지는 봇 소유자에게만 보여요.

> [!NOTE]
> 퇴장 피드백 페이지는 봇 소유자만 볼 수 있어요. 다른 대시보드 사용자에게는 사이드바에 나타나지 않으며 페이지를 열 수도 없어요.

## Why you would use it

- 서버가 기능 부족, 설정의 어려움, 안정성 문제 중 무엇 때문에 떠나는지 알 수 있어요.
- 봇을 테스트하려고만 추가한 서버를 찾아내서, 그 이탈은 무시할 수 있어요.
- 댓글과 연락처를 남긴 소유자에게 직접 연락할 수 있어요.
- 소유자가 응답하는 비율이 얼마나 되는지 추적할 수 있어요.

## The prompt

DM의 제목은 "Sorry to see me go!"이며, 봇이 방금 어느 서버에서 제거되었는지 설명해요. 드롭다운에는 다음 사유가 이 순서대로 나와요. 사유 목록은 봇이 소유자에게 보여 주는 영어 문구이므로 그대로 둬요.

| Reason key | Shown to the owner |
| --- | --- |
| `not_needed` | We didn't need it anymore |
| `confusing` | Too confusing to set up |
| `missing_features` | Missing features we wanted |
| `unreliable` | It was broken or unreliable |
| `other_bot` | We switched to another bot |
| `temporary` | Temporary, I'm adding it back |
| `testing` | Just testing something |

사유를 고르면 바로 저장되고, 텍스트 입력 창을 다시 열어 줘요. 텍스트 입력 창은 한 단락짜리 입력란이며, 제목은 "What could we have done better?"이고 최대 1000자까지 입력할 수 있어요. **No thanks**를 누르면 기록이 무시됨으로 표시되며, 그 기록은 보고되지 않아요.

불편을 줄이기 위한 규칙은 다음과 같아요.

- 서버는 봇을 추가하고 제거하는 횟수와 관계없이 30일에 한 번만 질문을 받아요.
- 소유자의 DM이 닫혀 있으면 아무것도 저장되지 않아요.
- 기능이 꺼져 있으면 아무것도 보내지 않아요.

## Statuses

각 기록은 세 가지 상태 중 하나가 되며, 대시보드에서 이 상태로 필터링할 수 있어요.

| Status | Meaning |
| --- | --- |
| 답변함 | 소유자가 사유를 고르거나 댓글을 남겼어요 |
| 무시됨 | 소유자가 **No thanks**를 눌렀어요 |
| 응답 없음 | DM은 보냈지만 아직 응답이 없어요 |

## Settings

페이지에는 두 개의 탭이 있어요. **응답**과 **설정**이에요.

| Setting | Default | What it controls |
| --- | --- | --- |
| 봇이 제거된 이유를 소유자에게 묻기 | 켜짐 | DM을 보낼지 여부예요 |
| 신고 채널 ID | 비어 있음 | 응답마다 요약 임베드를 받을 채널이에요. 비어 있으면 봇의 입장/퇴장 로그 채널을 사용해요. |

채널 입력란 아래에는 ID가 가리키는 채널과 서버, 그리고 봇이 그 채널에 접근할 수 있는지가 표시돼요.

**응답** 탭에는 여섯 개의 카운터가 있어요. **전송된 요청**, **답변함**, **댓글 포함**, **무시됨**, **응답 없음**, **응답률**이에요. 또한 **제시된 사유** 분석과, **나감**, **서버**, **사유**, **상태** 열이 있는 표가 있어요. 사유와 상태로 필터링할 수 있고(상태 필터에는 **댓글 남김** 옵션도 있어요), 서버 이름이나 댓글 내용으로 검색할 수 있으며, 행을 펼쳐 전체 댓글을 읽거나 기록을 삭제할 수 있어요. **응답률**은 답변함과 무시됨을 함께 계산해요.

## Setup walkthrough

1. 봇 소유자 계정으로 대시보드에 로그인하고 **퇴장 피드백**을 여세요.
2. **설정** 탭에서 **봇이 제거된 이유를 소유자에게 묻기**가 켜져 있는지 확인하세요. 기본값은 켜짐이에요.
3. **신고 채널 ID**에 채널 ID를 붙여 넣고 **채널 저장**을 누르거나, 비워 두어 입장/퇴장 채널을 사용하세요.
4. 내가 소유한 테스트 서버에서 봇을 제거하고 DM에 응답해 보세요.
5. **응답** 탭과 신고 채널에서 기록을 확인하세요.

## Commands

이 기능은 대시보드 전용이에요. 봇 명령어는 없고, 소유자는 DM의 버튼과 드롭다운으로 응답해요.

## Tips and gotchas

- 봇은 Discord에 서버 소유자로 등록된 사람에게만 DM을 보내요. 봇을 추방한 사람에게 보내지 않아요.
- 30일 쿨다운은 서버마다 적용되므로, 그 기간 안에 봇을 다시 추가하고 제거한 서버에는 두 번 묻지 않아요.
- 요약 임베드는 설정된 채널, 또는 설정이 없을 때 봇 인증 정보의 입장/퇴장 로그 채널로 가요. 둘 다 없으면 응답은 그대로 저장되어 페이지에서 볼 수 있어요.
- 대시보드에서 기록을 삭제해도 신고 채널에 이미 게시된 임베드는 지워지지 않아요.
