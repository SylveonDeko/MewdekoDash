## 기능 소개

필터는 멤버가 보내거나 수정하는 모든 메시지를 다른 모듈이 확인하기 전에 검사해요. 필터가 켜진 곳에서 메시지에 필터링된 단어, Discord 초대 링크, 또는 링크가 포함되어 있으면 봇이 메시지를 삭제해요. 봇이 모더레이션 시스템을 통해 경고를 주고, 무엇이 삭제되었는지 설명하는 DM을 보내도록 설정할 수도 있어요.

두 번째 목록인 자동 차단 단어는 더 엄격해요. 자동 차단 단어에 해당하는 메시지는 삭제되고, 작성자는 즉시 차단돼요. 봇이 DM을 보낼 수 있다면 사유가 담긴 DM도 함께 보내요.

관리자와 `staffrole`로 설정한 스태프 역할을 가진 사람은 필터를 거치지 않아요. 봇의 메시지도 확인하지 않아요.

## 이런 상황에 써 보세요

- 스태프가 없을 때도 욕설이나 금지어가 채팅에 올라오지 않게 하고 싶을 때
- 초대 링크를 던져서 다른 서버를 홍보하는 것을 막고 싶을 때
- 미디어 없는 공지 채널처럼, URL이 포함된 메시지를 모두 지워서 텍스트만 올라오게 하고 싶을 때
- 알려진 사기 문구나 레이드 신호가 올라오면 즉시 차단하고 싶을 때

## 필터 종류

| 필터 | 적용 범위 | 동작 |
| --- | --- | --- |
| 단어 필터 | 단어 필터 채널 목록에 있는 채널에서만 | 메시지를 삭제해요. **필터링된 단어 사용 시 경고**가 켜져 있으면 경고와 DM을 보내요 |
| 초대 링크 필터 | 서버 스위치가 켜져 있고 채널 목록이 비어 있으면 모든 곳에서, 목록에 채널이 있으면 그 채널에서만 | 메시지를 삭제해요. **초대 링크 사용 시 경고**가 켜져 있으면 경고와 DM을 보내요 |
| 링크 필터 | 서버 스위치가 켜져 있으면 모든 곳에서, 그리고 링크 목록에 있는 채널에서 | 메시지를 삭제해요. 경고는 하지 않아요 |
| 자동 차단 단어 | 모든 곳 | 메시지를 삭제하고, 작성자에게 DM을 보낸 뒤 차단해요 |

채널 목록 3개는 대시보드의 **채널별 재정의**예요. 단어 필터는 전적으로 채널 목록에 따라 동작한다는 점에 주의하세요. 단어를 확인하려면 해당 채널이 목록에 있어야 해요.

## 단어가 매칭되는 방식

필터링된 단어와 자동 차단 단어는 정규식으로 처리되며, 소문자로 바꾼 메시지 내용과 비교해요. `example` 같은 일반 단어는 부분 문자열로 매칭되므로 `examples`도 잡혀요. 컴파일할 수 없는 패턴은 목록에서 자동으로 제거돼요. 각 패턴에는 250밀리초의 매칭 제한 시간이 있어요.

필터링된 단어는 소문자로 저장되고, 대소문자를 구분하지 않고 매칭돼요. 자동 차단 패턴은 입력한 그대로 저장되고 소문자로 바꾼 텍스트와 비교하므로, 소문자로 입력해야 해요.

> [!WARNING]
> 자동 차단 패턴은 강력해요. `ban`처럼 짧은 패턴은 "banana" 같은 단어 안에서도 매칭되어 사람들이 차단될 수 있어요. 자동 차단 패턴은 먼저 필터링된 단어로 테스트해 보세요.

## 경고

**필터링된 단어 사용 시 경고**나 **초대 링크 사용 시 경고**를 켜면, 봇은 모더레이션 모듈을 통해 "Warned for Filtered Word" 사유(또는 초대 링크 경고 사유)로 경고를 추가하고 멤버에게 DM을 보내요. 모더레이션 페이지에 설정된 경고 처벌은 평소와 같이 적용되므로, 경고 처벌이 그렇게 설정되어 있다면 필터에 3번 걸리면 음소거나 추방으로 올라갈 수 있어요.

자동 차단은 모더레이션 모듈의 "Filter" 작업 밴 메시지 삭제 설정을 따라 몇 일 치 메시지를 삭제할지 결정해요.

## 설정

메시지 필터 페이지에는 **필터**, **필터링된 단어**, **자동 차단 단어**, **채널별 재정의** 탭이 있어요.

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| 단어 필터 | 꺼짐 | **필터** 탭에 있는 서버 전체 스위치 |
| 초대 링크 필터 | 꺼짐 | Discord 초대 링크를 삭제해요. 초대 링크 채널 목록이 작동하려면 필요해요 |
| 링크 필터 | 꺼짐 | 서버 전체에서 URL이 포함된 메시지를 모두 삭제해요 |
| 필터링된 단어 사용 시 경고 | 꺼짐 | 필터링된 단어가 삭제되면 경고를 추가하고 멤버에게 DM을 보내요 |
| 초대 링크 사용 시 경고 | 꺼짐 | 초대 링크가 삭제되면 경고를 추가하고 멤버에게 DM을 보내요 |
| 필터링된 단어 | 없음 | **필터링된 단어** 탭의 목록. 단어별로 제거할 수 있고, `fwclear`와 같은 **모두 지우기** 버튼이 있으며, 단어가 10개를 넘으면 검색창이 나와요 |
| 자동 차단 단어 | 없음 | **자동 차단 단어** 탭의 목록 |
| 단어 필터 채널 | 없음 | 단어 목록이 적용되는 채널 |
| 초대 링크 필터 채널 | 없음 | 비어 있지 않을 때 초대 링크 필터를 이 채널들로 제한해요 |
| 링크 필터 채널 | 없음 | 서버 스위치가 꺼져 있어도 링크를 삭제할 추가 채널 |

페이지 상단에는 필터링된 단어, 자동 차단 단어, 채널별 재정의의 개수가 표시돼요.

## 설정 방법

1. 대시보드에서 **메시지 필터**를 열어요.
2. **필터링된 단어** 탭에서 단어나 문구를 하나씩 추가하고 추가 버튼을 눌러요.
3. **채널별 재정의**에서 **단어 필터 채널** 아래에 단어 목록을 적용할 채널을 모두 추가해요.
4. **필터** 탭으로 돌아가 모든 곳에서 초대 링크를 지우려면 **초대 링크 필터**를 켜고, 이것도 경고로 집계하려면 **초대 링크 사용 시 경고**를 켜요.
5. 원한다면 **자동 차단 단어** 탭에 확실한 패턴 몇 개를 추가하세요.
6. `staffrole @Moderators`를 실행해서 팀이 필터를 받지 않게 한 다음, 일반 계정으로 필터링된 단어를 보내서 삭제되는지 확인하세요.

## 명령어

이 명령어들은 서버의 접두사(바꾸지 않았다면 `.`)를 붙여서 실행해요.

| 명령어 | 별칭 | 필요 권한 | 용도 |
| --- | --- | --- | --- |
| `filterword <word>` | `fw` | 없음 | 단어를 필터 목록에 추가해요. 이미 있으면 제거해요 |
| `lstfilterwords` | `lfw` | 없음 | 필터링된 단어 목록을 페이지로 넘겨 봐요 |
| `fwclear` | | 관리자 | 필터링된 단어를 모두 제거하고, 단어 필터 채널 목록을 비우고, 서버 스위치를 꺼요 |
| `srvrfilterwords` | `sfw` | 없음 | 서버 전체 단어 필터 스위치를 토글해요 |
| `chnlfilterwords` | `cfw` | 없음 | 현재 채널을 단어 필터 채널 목록에 넣거나 빼요 |
| `srvrfilterinv` | `sfi` | 없음 | 서버 전체 초대 링크 필터를 토글해요 |
| `chnlfilterinv` | `cfi` | 없음 | 현재 채널을 초대 링크 필터 채널 목록에 넣거나 빼요 |
| `srvrfilterlin` | `sfl` | 없음 | 서버 전체 링크 필터를 토글해요 |
| `chnlfilterlin` | `cfl` | 없음 | 현재 채널을 링크 필터 채널 목록에 넣거나 빼요 |
| `fwarn <y or n>` | `filteredwarn` | 관리자 | 필터링된 단어 경고를 켜거나 꺼요 |
| `invwarn <y or n>` | `invitewarn` | 관리자 | 초대 링크 경고를 켜거나 꺼요 |
| `autobanword <pattern>` | `autobanw` | 관리자 | 자동 차단 목록에 패턴을 추가하고, 이미 있으면 제거해요 |
| `autobanwordlist` | `autobwlist` | 관리자 | 자동 차단 목록을 페이지로 넘겨 봐요 |

> [!PERMISSION]
> 필터 토글과 `filterword`에는 자체 권한 검사가 없어요. 권한 모듈로 사용을 제한하거나, 대시보드 접근 규칙이 적용되는 대시보드에서 필터를 관리하세요.

## 팁과 주의 사항

- 봇은 필터링된 모든 채널에서 **메시지 관리** 권한이, 자동 차단 단어에는 **멤버 차단** 권한이 필요해요.
- 수정된 메시지도 다시 검사해요. 그래서 기존 메시지를 링크로 수정해도 삭제돼요.
- 필터는 관리자, 스태프 역할, 봇에는 적용되지 않아요. 관리자 계정으로 테스트하지 마세요.
- `fwclear`는 목록만 비우는 것이 아니에요. 단어 필터 채널 재정의도 모두 제거해요.
- 잘못된 정규식은 조용히 목록에서 제거돼요. 단어가 사라졌다면 `(`, `[`, `*` 같은 이스케이프되지 않은 문자가 들어 있지 않은지 확인하세요.
- 필터가 삭제한 내용을 기록하고 싶다면 로깅 기능으로 메시지 삭제를 기록하세요.
