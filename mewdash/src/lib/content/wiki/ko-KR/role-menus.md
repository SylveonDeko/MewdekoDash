## 기능 소개

역할 메뉴는 채널에 올라가는 메시지 하나로, 아래에 **드롭다운** 또는 **버튼** 줄이 붙어 있어요. 메뉴의 각 옵션은 역할 하나를 줘요. 멤버가 옵션을 고르면 역할을 받고, 같은 옵션을 다시 고르면 역할을 내려놓아요. 그래서 서버는 스태프에게 요청하지 않고도 멤버가 대명사, 색상, 알림, 지역 등을 직접 고르게 할 수 있어요.

각 메뉴에는 이름(스태프만 보고, 기본 메시지의 제목으로도 쓰여요), 채널, 메시지, 최대 25개의 옵션이 있어요. 옵션에는 역할, 메뉴에 표시되는 이름, 선택 사항인 이모지와 설명이 있어요. 설명은 드롭다운의 각 옵션 아래와 기본 메시지에 표시돼요. 버튼에는 색상도 있어요. 파란색(blurple), 회색(grey), 초록색(green), 빨간색(red) 중에서 고를 수 있어요.

메시지는 임베드 빌더로 만들 수 있는 모든 것이 될 수 있어요. 일반 텍스트, 임베드 하나 이상, 또는 둘 다 가능해요. 비워 두면 봇이 메뉴 이름과 각 옵션의 줄을 게시해요.

## 여러 개 선택 또는 하나만 선택

- **여러 개 선택**은 멤버가 각 역할을 켜거나 끌 수 있게 해요. 보유 개수는 두 가지 제한으로 조절해요. **최소 유지 개수**는 멤버가 한 번 고른 뒤 이 수보다 적게 남기지 못하게 해요. **최대 개수**는 메뉴에서 가질 수 있는 최대 개수를 제한해요(기본값은 제한이 없어요).
- **하나만 선택**은 역할을 교체해요. 새로운 옵션을 고르면 기존에 가지고 있던 역할이 제거돼요. **한 번 선택하면 유지**를 켜면 멤버는 역할을 바꿀 수는 있지만 선택을 해제할 수는 없어요.

## 제한

| 제한 | 값 |
| --- | --- |
| 서버당 메뉴 수 | 50개 |
| 메뉴당 옵션 수 | 25개 |
| 줄당 버튼 수 | 5개 |
| 메뉴 이름 | 100자 |
| 메뉴에 표시되는 이름 | 80자 |
| 설명 | 100자 |
| 드롭다운 힌트 텍스트 | 150자 |
| 일반 텍스트 메시지 | 2000자 |

같은 역할은 한 메뉴에 한 번만 넣을 수 있어요. 봇은 자신의 가장 높은 역할보다 아래에 있으면서 연동 기능이 관리하지 않는 역할만 지급할 수 있어요. 스태프도 자신의 가장 높은 역할보다 아래에 있는 역할만 메뉴에 올릴 수 있어요.

## 필요 역할

메뉴에 필요한 역할을 지정할 수 있어요. 그 역할이 없는 멤버는 필요한 역할이 있어야 한다는 개인 알림을 받고, 아무것도 바뀌지 않아요.

## 변경 알림

**멤버에게 변경 사항 알리기**를 켜면, 멤버는 추가되거나 제거된 역할이 나열된 개인 알림을 받아요. 본인에게만 보여요. 끄면 메뉴는 조용히 작동해요. 다만 제한에 걸리거나 봇이 지급할 수 없는 역할처럼 문제가 생기면 멤버는 여전히 개인 알림을 받아요.

## 수정, 일시정지, 다시 게시

수정 내용을 저장하면 같은 메시지를 그 자리에서 다시 만들어요. 채널이 바뀌었거나 기존 메시지가 사라졌을 때만 새 메시지를 게시해요.

**일시정지**를 누르면 메뉴를 다시 시작할 때까지 Discord에서 드롭다운이나 버튼이 회색으로 비활성화돼요. **다시 게시**는 새 복사본을 게시하고 기존 메시지를 삭제해요. 메뉴가 화면 밖으로 밀려났거나 사람이 직접 메시지를 지웠을 때 유용해요. 메뉴의 채널이 삭제되었다면, 메뉴를 수정해서 새 채널을 고르고 저장하면 다시 게시돼요.

메뉴를 삭제하면 메시지도 함께 삭제돼요. 멤버는 이미 고른 역할을 그대로 유지해요.

## 이전 설정 옮기기

예전 이모지 역할 설정은 멤버가 메시지 아래에 이모지를 추가해서 역할을 받는 방식이었어요. **예전 설정 옮기기** 탭에 이런 설정이 나열돼요. 항목을 옮기면 같은 역할과 이모지를 가진 역할 메뉴가 만들어져요. 드롭다운이나 버튼 중 선택할 수 있고, 같은 채널이나 다른 채널에 게시할 수 있어요. 기존 메시지의 텍스트와 임베드를 복사할 수 있고, 기존 설정을 폐기할 수도 있어요. 폐기하면 설정이 중단되고 이모지가 지워져요. 봇이 원래 메시지를 게시했다면 그 메시지도 삭제돼요. 멤버가 역할을 하나만 가질 수 있었던 설정은 **하나만 선택** 메뉴가 돼요.

## 명령어

| 명령어 | 설명 |
| --- | --- |
| `rolemenus` | 모든 메뉴를 채널, 유형, 옵션 수, 상태와 함께 나열해요. |
| `rolemenuinfo 3` | 메뉴 하나의 모든 정보를 보여 줘요. |
| `rolemenucreate #roles dropdown @Role @Role` | 역할마다 옵션을 하나씩 넣은 새 메뉴를 게시해요. |
| `rolemenuadd 3 @Role [emoji] [name]` | 메뉴에 역할을 추가해요. |
| `rolemenuremove 3 @Role` | 메뉴에서 역할을 제거해요. |
| `rolemenuname 3 Pronouns` | 메뉴 이름을 바꿔요. |
| `rolemenumessage 3 [message\|clear]` | 메뉴 위에 표시되는 메시지를 보거나, 설정하거나, 지워요. |
| `rolemenustyle 3 dropdown\|buttons` | 드롭다운과 버튼 형식을 바꿔요. |
| `rolemenumode 3 multi\|exclusive` | 여러 개 선택과 하나만 선택을 바꿔요. |
| `rolemenulimits 3 0 2` | 멤버가 유지해야 하는 개수와 가질 수 있는 개수를 설정해요. |
| `rolemenurequire 3 [@Role]` | 필요한 역할을 설정하거나 지워요. |
| `rolemenureply 3 private\|silent` | 개인 알림을 켜거나 꺼요. |
| `rolemenupause 3` | 메뉴를 일시정지하거나, 일시정지된 상태면 다시 시작해요. |
| `rolemenurepost 3 [#channel]` | 새 복사본을 게시하고 기존 메시지를 삭제해요. |
| `rolemenudelete 3` | 메뉴와 메시지를 삭제해요. |
| `rolemenuimport messageId [dropdown\|buttons]` | 예전 이모지 역할 설정을 새 메뉴로 옮겨요. |
