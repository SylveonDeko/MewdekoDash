## 기능 소개

봇은 이미 메시지를 세고 있었어요. 활동 통계는 여기에 음성 채팅 시간, 게임과 앱, 시간별 멤버 및 상태 스냅샷을 더해서, 어떤 기간이든 질문할 수 있게 해 줘요. 기간은 최근 하루, 일주일, 한 달, 최대 90일, 또는 전체 기간을 고를 수 있어요. 모든 내용은 대시보드, 명령어, 차트, CSV로 볼 수 있고, 통계 역할, 실시간 보드, 리포트, 통계 채널에서도 쓸 수 있어요.

## 추적하는 항목

| 데이터 | 방식 |
| --- | --- |
| 메시지 | 집계된 모든 메시지를 시간과 함께 90일 동안 보관하고, 멤버별 및 채널별 누적 합계도 보관해요 |
| 음성 채팅 시간 | 멤버별, 채널별 구간을 기록해요. 채널을 옮기거나, 음소거하거나, 스피커를 끄거나, 방송하거나, 카메라를 켜면 구간이 나뉘어요. 90일 동안 보관하고, 누적 합계도 보관해요 |
| 게임과 앱 | 멤버별, 활동별(플레이, 방송, 듣기, 시청, 경쟁) 구간을 90일 동안 보관하고, 누적 합계도 보관해요. 기본적으로 꺼져 있어요 |
| 스냅샷 | 멤버, 사람, 봇, 온라인, 자리 비움, 방해 금지, 오프라인, 음성 채팅 중인 인원 수를 매시간 90일 동안 보관해요 |
| 참여와 퇴장 | 모든 참여와 퇴장을 시간과 함께 기록해요 |

90일 이내의 기간은 시간이 기록된 데이터를 읽어요. **전체 기간**은 누적 합계를 읽으므로, 90일 데이터가 지워진 뒤에도 계속 작동해요.

## 게임과 앱

게임 추적은 직접 켜기 전까지 꺼져 있어요. 가장 무거운 추적기이기 때문이에요. 켜면 봇은 모든 멤버의 상태를 살펴보고, 게임, 방송, Spotify 세션, 시청 중인 앱이 얼마나 오래 지속되는지 기록해요.

- **활동 검증**(기본값 켜짐)은 Discord가 직접 확인한 활동만 세요. 등록된 애플리케이션 ID가 있는 활동, Spotify, 방송이 해당해요. 수정된 클라이언트는 무엇이든 플레이 중이라고 주장할 수 있으므로, 이 옵션이 켜져 있으면 이름만 있는 활동은 무시해요.
- **활동 필터**는 게임 이름 목록이에요. **블랙리스트**(목록에 있는 게임 무시) 또는 **화이트리스트**(목록에 있는 게임만 집계) 중 하나로 동작해요.
- 사용자 지정 상태는 절대 집계하지 않아요.

| 탭 | 보여주는 내용 |
| --- | --- |
| 개요 | 메시지, 음성 채팅 시간, 채팅한 사람 수, 참여, 퇴장, 순증가, 현재 멤버, 채팅 1위, 음성 채팅 1위, 가장 활발한 채널, 가장 많이 한 게임, 그리고 메시지, 음성 시간, 멤버, 멤버 상태, 참여와 퇴장 차트 |
| 순위 | 메시지, 음성, 게임 시간 기준으로 멤버와 채널의 순위, 플레이어 수가 포함된 상위 게임 목록을 보여주며 CSV로 내보낼 수 있어요. 멤버, 채널, 게임을 클릭하면 상세 내용이 열려요 |
| 멤버 및 채널 | 한 멤버의 메시지, 음성 시간, 순위, 누적 합계, 자주 가는 채널과 게임, 한 채널의 활동과 상위 멤버, 그리고 모든 게임의 **플레이하는 사람**을 보여줘요 |
| 설정 | 모든 추적기, 기본 기간, 메시지 쿨다운, 봇, 집계하지 않을 음성 상태, 무시된 채널, 역할, 멤버, 활동 필터를 설정해요 |

## 설정

| 설정 | 기본값 | 역할 |
| --- | --- | --- |
| 기본 기간 | 14일 | 기간을 지정하지 않았을 때 명령어와 페이지가 사용하는 기간이에요 |
| 메시지 쿨다운 | 0 | 한 멤버가 메시지를 집계되게 보낸 뒤 다음 집계까지 기다릴 시간(초)이에요. 스팸으로 수치가 부풀려지는 것을 막아요 |
| 음성 채팅 시간 추적 | 켜짐 | 음성 구간을 기록할지 정해요 |
| 시간별 스냅샷 | 켜짐 | 멤버와 상태 수를 매시간 기록할지 정해요 |
| 봇 집계 | 꺼짐 | 봇 계정을 포함할지 정해요 |
| 게임 및 앱 추적 | 꺼짐 | 상태 활동을 기록할지 정해요 |
| 활동 검증 | 켜짐 | Discord가 확인한 활동만 집계해요 |
| 집계하지 않을 음성 상태 | 없음 | 자체 음소거, 자체 스피커 끄기, 서버 음소거, 서버 스피커 끄기, 잠수 채널, 혼자 있음, 방송 중, 카메라 켜짐 중 하나 이상을 선택할 수 있어요 |
| 무시된 채널, 역할, 멤버 | 없음 | 이 대상에서 발생한 활동은 집계하지 않아요 |

## 개인정보

모든 멤버는 `statsprivacy`(또는 `/serverstats privacy`)를 실행해서 수집을 거부할 수 있어요. 그러면 봇이 그 멤버와 함께 있는 모든 서버에서 기록된 메시지, 음성 시간, 게임 시간이 삭제돼요. 다시 실행해서 수집을 허용하기 전까지는 아무것도 새로 기록하지 않아요. 서버 관리자도 이 설정을 무시할 수 없어요.

## 명령어

이 명령어들은 서버의 접두사(바꾸지 않았다면 `.`)를 붙여서 실행하세요. 모든 명령어는 `/serverstats` 아래에도 있어요. `days`는 기간이에요. 0이면 전체 기간이고, 생략하면 서버의 기본 기간을 써요.

| 명령어 | 별칭 | 필요 권한 | 용도 |
| --- | --- | --- | --- |
| `serveractivity [days]` | `sstats` | 필요 없음 | 서버 개요 |
| `useractivity [@user] [days]` | `ustats`, `mystats` | 필요 없음 | 멤버의 메시지, 음성 시간, 순위, 누적 합계, 상위 채널과 게임 |
| `channelactivity [#channel] [days]` | `cstats` | 필요 없음 | 채널의 활동과 상위 멤버 |
| `activitytop [Messages/Voice/Activity] [days] [@role]` | `topchatters`, `topvoice` | 필요 없음 | 멤버 순위 |
| `activitytopchannels [Messages/Voice] [days]` | `topchannels` | 필요 없음 | 채널 순위 |
| `topgames [days]` | `games` | 필요 없음 | 가장 많이 플레이한 게임과 앱 |
| `whoplays <game>` | | 필요 없음 | 지금 게임을 하고 있는 사람과 가장 많이 플레이한 사람 |
| `activitychart [Messages/Voice/Members/Status/Joins/Leaves/Growth/InVoice/Activities] [days]` | `graph` | 필요 없음 | 차트 이미지 |
| `activityexport [Messages/Voice/Activity] [days]` | | 서버 관리 | CSV 순위 내보내기 |
| `statssettings` | | 서버 관리 | 설정 보기 |
| `statslookback <days>`, `statscooldown <seconds>` | `lookback` | 서버 관리 | 기본 기간과 메시지 쿨다운 |
| `statstrackvoice`, `statstracksnapshots`, `statscountbots`, `statstrackactivities`, `statsverifyactivities` | `trackvoice`, `trackgames` | 서버 관리 | 각 추적기 켜기 또는 끄기 |
| `statsignorevoicestate <state>` | | 서버 관리 | 음성 상태 집계 여부 전환 |
| `statsignore <#channel, @role or @user>`, `statsignored` | | 서버 관리 | 제외 대상 설정 |

| `statsprivacy` | `optoutstats` | 필요 없음 | 모든 곳에서 추적 거부 또는 다시 허용 |

## 팁과 주의사항

- 스냅샷을 켠 뒤 한 시간이 지나야 멤버 및 상태 차트가 채워지기 시작해요. 그 전의 기록은 없어요.
- 음성 채팅 시간은 봇이 실행 중일 때만 집계돼요. 재시작하면 모든 세션이 닫혔다가 다시 열리므로 데이터는 잃지 않지만, 구간의 경계는 달라져요.
- 채널을 제외하면 새 집계를 멈출 뿐 아니라 그 채널의 기록도 모든 조회에서 사라져요. 그래서 예전 수치도 바뀌어요.
- 메시지 수치가 보이려면 메시지 통계 페이지의 메시지 집계 설정이 켜져 있어야 해요.
- 필터와 `whoplays`에서 게임 이름은 대소문자를 구분하지 않고 맞춰요.
