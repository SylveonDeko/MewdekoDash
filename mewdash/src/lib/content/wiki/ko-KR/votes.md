## 기능 소개

투표 기능은 설문 기능이 아니에요. 서버가 top.gg에서 받은 투표를 추적하고, 투표한 사람에게 보상을 줘요. top.gg가 누군가 투표했다고 Mewdeko에 알리면, 봇은 투표를 기록하고, 투표 채널에 그 멤버의 누적 투표 수가 담긴 감사 메시지를 올리며, 설정해 둔 투표 보상 역할을 지급해요.

멤버 입장에서는 top.gg에서 서버에 투표하면, 투표 채널에 멘션과 함께 투표 횟수가 표시된 메시지가 나타나는 것이 전부예요. 투표 역할을 설정했다면, 같은 시점에 그 역할도 받아요. 역할은 영구적으로 지급되거나 정해진 기간 동안만 지급될 수 있어요.

운영진 입장에서는 투표 채널, 웹후크 비밀번호, 선택 사항인 사용자 지정 메시지, 최대 10개의 보상 역할을 설정하면 돼요. 그 뒤로는 봇이 모든 투표를 자동으로 처리해요. `votes`와 `votesleaderboard`로 누구나 투표 수를 확인할 수 있어요.

top.gg와 서버를 연결하는 것은 투표 비밀번호예요. top.gg는 웹후크 호출의 Authorization 헤더에 이 비밀번호를 담아 보내고, Mewdeko는 그 헤더를 각 서버에 저장된 비밀번호와 대조해서 투표가 어느 서버의 것인지 찾아요.

## 이런 때 사용해요

- top.gg에 서버를 등록했고, 투표가 들어올 때마다 눈에 보이는 감사 메시지를 받고 싶을 때
- "투표자" 역할을 주거나, 12시간 뒤 만료되는 임시 혜택 역할을 주고 싶을 때
- 매달 투표 순위표를 만들어 "최다 투표자" 보상을 운영하고 싶을 때
- 멤버가 운영진에게 묻지 않고 자신의 투표 수를 직접 확인할 수 있게 하고 싶을 때

## 투표 처리 과정

1. top.gg가 봇의 `/votes/` 웹후크 엔드포인트로 투표자의 디스코드 ID와 서버 비밀번호를 Authorization 헤더에 담아 보내요.
2. 봇은 저장된 투표 비밀번호가 일치하는 서버를 찾아요. 일치하는 서버가 없으면 투표를 버려요.
3. 투표자의 ID와 시간과 함께 투표를 저장해요.
4. 투표 채널이 설정되어 있으면 봇이 그곳에 감사 메시지를 올려요. 투표 채널이 없으면 아무 메시지도 올리지 않고, 역할도 지급하지 않아요.
5. 모든 투표 역할을 멤버에게 부여해요. 기간이 있는 역할은 타이머가 끝나면 제거되는데, 이때 사용하는 방식은 타이머가 있는 음소거와 같은 기간제 역할 시스템이에요.

> [!WARNING]
> 비밀번호는 투표를 서버와 연결하는 유일한 수단이에요. 이 비밀번호를 아는 사람은 가짜 투표를 보낼 수 있어요. 공개 채널에 절대 붙여 넣지 마세요. 봇은 이 때문에 비밀번호를 비공개 입력창에서만 설정해요.

## 감사 메시지

기본적으로 봇은 투표자를 멘션하고, "<server>에 투표해 주셔서 감사해요"라는 제목의 임베드를 보내요. 임베드에는 투표자의 총 투표 수가 한 줄로 표시되고, 아바타가 썸네일로 들어가요.

`votemessage`나 대시보드의 **사용자 지정 투표 공지** 칸으로 직접 쓴 텍스트나 임베드로 바꿀 수 있어요. 입력한 텍스트는 임베드 파서를 거치므로 임베드 빌더로 만들 수 있는 것은 무엇이든 쓸 수 있어요. 명령어에서 `-`로 설정하거나, 대시보드에서 칸을 비우면 기본 메시지로 돌아가요.

### 플레이스홀더

사용자 지정 메시지는 일반 플레이스홀더 세트(플레이스홀더 페이지의 사용자, 서버, 채널, 봇, 시간 플레이스홀더)를 지원하고, 투표 전용 플레이스홀더 두 개를 추가로 지원해요.

| 플레이스홀더 | 값 |
| --- | --- |
| `%votestotalcount%` | 이 멤버가 전체 기간에 투표한 횟수 |
| `%votesmonthcount%` | 이 멤버가 이번 달 달력 기준으로 투표한 횟수 |
| `%user.mention%`, `%user.name%`, `%user.id%`, `%user.avatar%` | 투표자 |
| `%server.name%`, `%server.id%`, `%server.icon%`, `%server.members%` | 서버 |

> [!EXAMPLE]
> `Thanks %user.mention% for voting! That is vote number %votestotalcount% (%votesmonthcount% this month).`

`votemessage`를 내용 없이 실행하면, 현재 메시지가 본인의 투표 수로 어떻게 보이는지 미리 볼 수 있어요.

## 투표 역할

투표 역할은 모든 투표자에게 지급돼요. 역할마다 선택 사항인 기간을 초 단위로 정할 수 있어요. `0`이면 영구 역할이에요.

- 서버당 투표 역할은 최대 10개예요.
- `@everyone` 역할은 추가할 수 없어요.
- 같은 역할은 두 번 추가할 수 없어요. 기간을 바꾸려면 `voteroleedit`를 쓰세요.
- 기간이 있는 역할은 기간이 지나면 자동으로 제거돼요.
- 봇이 역할을 부여할 수 없으면(예를 들어 봇의 가장 높은 역할보다 위에 있는 역할이면) 그 역할은 조용히 건너뛰어요.

## 투표 수와 순위표

`votes`는 멤버의 이번 달 투표 수와 전체 투표 수를 아바타와 함께 보여줘요. `votesleaderboard`는 서버 전체 멤버를 전체 투표 수 기준으로 순위 매기며, 한 페이지에 12명씩 보여줘요. `true`를 붙이면 이번 달 투표 수 기준으로 순위를 매겨요. 두 "월간" 수치는 최근 30일이 아니라 달력상의 월을 기준으로 해요.

## 설정

투표 페이지에는 **설정**, **투표 역할**, **통계** 세 개의 탭이 있어요.

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| 투표 공지 채널 | 없음 | 감사 메시지를 올릴 채널. 이 설정이 없으면 아무 일도 일어나지 않아요 |
| API 비밀번호 (웹후크용) | 없음 | top.gg가 Authorization 헤더에 보내야 하는 비밀 값 |
| 사용자 지정 투표 공지 | 기본 임베드 | 위의 플레이스홀더를 쓸 수 있는 사용자 지정 메시지. 비워 두면 기본 메시지예요 |
| 지급할 역할 | 없음 | 모든 투표자에게 추가되는 역할(투표 역할 탭) |
| 기간 (초, 0이면 영구) | 0 | 투표 역할이 제거되기까지의 시간 |

**통계** 탭에는 전체 투표 수, 투표 역할 수, 최다 투표자의 투표 수, 상위 10명의 순위표가 표시돼요.

## 설정 따라 하기

1. 대시보드에서 **투표**를 열고 **설정** 탭에 머무르세요.
2. **투표 공지 채널**을 고르세요. 채널이 없으면 투표는 기록되지만 아무것도 올라가지 않고 역할도 지급되지 않아요.
3. **API 비밀번호**를 입력하세요. 길고 무작위한 값으로 만들고, API 키처럼 다루세요.
4. 필요하다면 위의 플레이스홀더로 **사용자 지정 투표 공지**를 작성한 뒤 **설정 저장**을 누르세요.
5. top.gg에서 서버 페이지의 웹후크 섹션을 여세요. 웹후크 URL은 봇의 `/votes/` 엔드포인트로, Authorization 값은 같은 비밀번호로 설정하세요.
6. **투표 역할** 탭에서 **지급할 역할**과 **기간**을 고르고 **투표 역할 추가**를 누르세요. 최대 10개까지 반복하세요.
7. 봇의 역할이 역할 목록에서 모든 투표 역할보다 위에 있는지 확인하세요.
8. top.gg의 테스트 웹후크 버튼을 누르거나 실제 투표를 기다린 뒤 투표 채널을 확인하세요.

## 명령어

이 명령어는 서버의 접두사(바꾸지 않았다면 `.`)와 함께 실행해요.

| 명령어 | 별칭 | 필요 권한 | 용도 |
| --- | --- | --- | --- |
| `votechannel <#channel>` | | 서버 관리 | 감사 메시지를 올릴 채널 설정 |
| `votemessage [text]` | `votemsg` | 서버 관리 | 사용자 지정 메시지 미리보기, 설정, 또는 `-`로 초기화 |
| `votepassword` | `votepass` | 서버 관리 | 비공개 입력창에서 웹후크 비밀번호 설정 |
| `voteroleadd <@role> [time]` | `vra` | 서버 관리 | 투표 역할 추가. 기간 지정 가능. 예: `voteroleadd @Voter 12h` |
| `voteroleedit <@role> <time>` | `vre` | 서버 관리 | 역할의 지속 기간 변경 |
| `voteroleremove <@role>` | `vrr` | 서버 관리 | 투표 역할 하나 제거 |
| `voteroleslist` | `vrl` | 서버 관리 | 투표 역할과 기간 목록 표시 |
| `voterolesclear` | `vrc` | 서버 관리 | 확인 후 모든 투표 역할 제거 |
| `votes [@user]` | | 없음 | 멤버의 이번 달 투표 수와 전체 투표 수 표시 |
| `votesleaderboard [true]` | `voteslb` | 없음 | 전체 투표 수 기준 순위. `true`를 입력하면 이번 달 기준 |

같은 명령어가 `/votes` 아래에 슬래시 명령어로도 있어요.

## 팁과 주의 사항

- top.gg의 서버 투표만 지원해요. 다른 봇 목록과는 연동되지 않으며, 이 기능으로는 설문을 만들 수 없어요.
- 투표 채널이 없으면 투표는 집계되더라도 메시지도, 역할도 없어요.
- 봇에는 역할 관리 권한이 필요하고, 봇의 역할이 모든 투표 역할보다 위에 있어야 해요. 그렇지 않으면 역할 보상이 아무 알림 없이 실패해요.
- 기간이 있는 투표 역할은 기간제 음소거와 같은 역할 시스템을 쓰며, 감사 로그에 사유 "Vote Role"과 함께 기록돼요.
- `voteroleedit`는 역할을 ID로만 찾으므로, 이 서버에서 실제로 추가한 역할에만 사용하세요.
- 비밀번호를 바꾼다고 기존 투표가 무효화되지는 않지만, top.gg 쪽 헤더도 함께 바꾸기 전까지 top.gg 투표가 일치하지 않게 돼요.
