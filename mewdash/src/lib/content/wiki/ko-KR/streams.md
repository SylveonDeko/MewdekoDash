## What it does

스태프가 스트림 URL을 붙여 넣고 디스코드 채널을 고르면, 봇이 해당 스트리머의 플랫폼을 확인하다가 스트림이 오프라인에서 온라인으로 바뀌면 선택한 채널에 방송 시작 메시지를 게시해요. 기본값은 스트리머 이름이 스트림으로 연결되는 임베드예요. 여기에는 스트림 제목, 게임 또는 카테고리, 시청자 수, 스트리머 아바타, 미리보기 이미지가 포함돼요.

기본 임베드는 직접 만든 메시지로 바꿀 수 있어요. 팔로우한 모든 스트림에 적용되는 서버 전체 템플릿이 있고, 각 스트림은 자체 온라인 메시지와 오프라인 메시지를 가질 수도 있어요. 모든 메시지는 아래 `%stream.*%` 자리 표시자를 사용할 수 있으며, 일반 텍스트이거나 대시보드의 임베드 편집기로 만든 전체 임베드일 수 있어요.

오프라인 알림은 기본적으로 꺼져 있어요. 켜면 팔로우한 스트림이 끝날 때도 봇이 게시해요. 이때는 해당 스트림의 오프라인 메시지가 있으면 그것을 쓰고, 없으면 서버 템플릿을 쓰고, 그것도 없으면 "Offline"이 표시된 기본 임베드를 써요.

> [!NOTE]
> 스트림 알림은 다른 사람의 스트림을 디스코드에 알리는 기능이에요. 별도의 Twitch Bot 기능은 봇을 여러분의 Twitch 채팅에 연결해 명령어, 타이머, 이벤트를 처리해요. 자세한 내용은 Twitch Bot 문서를 참고하세요.

## Why you would use it

- 크리에이터 중 누가 방송을 시작하면 자동으로 불이 들어오는 "지금 방송 중" 채널이 필요한 커뮤니티 서버
- 방송을 시작할 때 제목과 카테고리가 자동으로 올라가서 누구도 직접 공지할 필요가 없는 스트리머 전용 디스코드
- 여러 토너먼트 채널을 Twitch와 Kick에서 한곳에 모아 팔로우하는 e스포츠나 이벤트 서버
- 방송 시작 게시물이 오래된 것처럼 보이지 않도록 깔끔한 "방송 종료" 알림이 필요한 서버

## Supported platforms

봇은 입력한 URL을 보고 플랫폼을 결정해요. 아래 패턴 중 하나와 맞는 URL만 팔로우할 수 있어요.

| 플랫폼 | URL 형식 | 참고 |
| --- | --- | --- |
| Twitch | `twitch.tv/username` | Twitch Helix API를 사용해요. 제목, 게임, 시청자 수, 아바타, 미리보기를 모두 채워요. |
| YouTube | `youtube.com/@handle` 또는 `youtube.com/channel/ID` | 채널의 라이브 페이지를 스크래핑해서 읽어요. 그래서 Twitch보다 데이터가 덜 완전할 수 있어요. 채널 ID URL은 핸들로 변환돼요. |
| Kick | `kick.com/slug` | Kick 공개 API를 사용해요. 아바타 자리 표시자는 채널 배너 이미지로 채워져요. |
| Picarto | `picarto.tv/name` | Picarto API를 사용해요. |

Trovo와 Facebook은 대시보드의 플랫폼 목록과 저장된 데이터에 나타나지만, 현재 코드에는 Trovo URL 매처가 없고 Facebook 제공자도 없어요. 그래서 이 URL들은 팔로우를 시도하면 거부돼요.

## How checking works

봇은 플랫폼마다 추적기 하나를 두고, 팔로우한 모든 채널의 상태를 라운드마다 3초씩 쉬면서 반복해서 확인해요. 스트림은 오프라인이었다가 라이브로 처음 확인되면 온라인으로 알려요.

오프라인 전환은 더 신중하게 처리돼요. Twitch는 방송 중에 잠깐 오프라인으로 보고할 때가 있기 때문이에요. 오프라인 알림을 보내기 전에 스트림이 연속된 두 번의 확인에서 오프라인으로 보여야 해요. 그 사이에 다시 온라인이 되면 아무것도 게시되지 않아요.

30분마다 봇은 플랫폼 조회가 12시간 넘게 실패하는 스트림을 찾아요. 예를 들어 삭제되었거나 이름이 바뀐 채널이에요. 그런 스트림은 이를 팔로우한 모든 서버에서 제거돼요.

팔로우한 스트림의 알림 채널이 삭제되었다면, 누군가 `streamlist`를 실행할 때 그 스트림은 목록에서 제거돼요.

## The message it sends

스트림 상태가 바뀌면 봇은 다음 순서로 메시지를 골라요.

1. 새 상태에 맞는 스트림 자체의 **온라인 메시지** 또는 **오프라인 메시지**
2. 서버 전체 **전체 스트림 메시지** 템플릿
3. 기본 임베드

스트림별 메시지가 유효한 임베드 JSON이 아니면, 기본 임베드 위에 일반 텍스트로 게시돼요. 전체 템플릿이 임베드 JSON이 아니면, 그 자체로 일반 텍스트로 게시돼요. 대시보드의 임베드 빌더가 만드는 유효한 임베드 JSON은 설계한 그대로 전송되며, 버튼도 포함돼요.

기본 임베드에는 스트리머 이름이 링크된 제목으로 표시되고, 스트림 제목은 작성자 줄에 표시되고, **상태** 필드에는 Online 또는 Offline이, **Viewers** 필드에는 시청자 수가, **방송 중** 필드에는 게임 또는 카테고리가 표시돼요. 아바타는 썸네일로, 미리보기는 큰 이미지로 표시돼요. 방송 중에는 초록색이고, 오프라인이면 빨간색이에요.

### Placeholders

스트림 메시지에서는 아래 세트만 바뀌어요. 자리 표시자 문서의 일반 서버 및 사용자 자리 표시자는 여기에서 사용할 수 없어요.

| 자리 표시자 | 값 |
| --- | --- |
| `%stream.name%` | 스트리머의 표시 이름이에요. 없으면 `Unknown` |
| `%stream.username%` | 스트리머의 로그인 이름 또는 핸들이에요 |
| `%stream.url%` | 스트림으로 바로 가는 링크예요. 항상 `https://`가 붙어요 |
| `%stream.title%` | 현재 스트림 제목이에요. 없으면 `No title` |
| `%stream.game%` | 게임 또는 카테고리예요. 없으면 `No category` |
| `%stream.viewers%` | 천 단위 구분 기호가 있는 시청자 수예요. 오프라인이면 `-` |
| `%stream.platform%` | `Twitch` 또는 `Youtube`처럼 플랫폼 이름이에요 |
| `%stream.avatar%` | 스트리머 아바타 URL이에요 |
| `%stream.preview%` | 스트림 미리보기 또는 썸네일 URL이에요 |
| `%stream.status%` | `Online` 또는 `Offline`이며, 각각 색깔 원이 앞에 붙어요 |
| `%stream.channelid%` | 플랫폼이 제공하는 경우 해당 플랫폼의 채널 ID예요 |

> [!EXAMPLE]
> 간단한 전체 템플릿 예시: `%stream.name% is live on %stream.platform% playing %stream.game%: %stream.title% %stream.url%`

## Settings

스트림 알림 페이지에는 **방송**, **스트림 팔로우**, **설정**, **통계** 탭이 있어요.

| 설정 항목 | 기본값 | 역할 |
| --- | --- | --- |
| 알림 채널 | 없음 | 새 스트림의 알림을 보낼 채널이에요. **스트림 팔로우**에서 고릅니다 |
| 스트림 URL | 없음 | 팔로우할 링크예요. **스트림 팔로우**에서 입력합니다 |
| 온라인 메시지 | 없음 | 방송을 시작할 때 보내는 스트림별 메시지예요. **방송**의 스트림 카드에서 편집합니다 |
| 오프라인 메시지 | 없음 | 방송이 끝날 때 보내는 스트림별 메시지예요. 같은 카드에서 편집합니다 |
| 전체 스트림 메시지 | 없음 | 스트림에 자체 메시지가 없을 때 사용하는 서버 전체 템플릿이에요. **설정**에서 설정합니다 |
| 오프라인 알림 | 꺼짐 | 팔로우한 스트림이 오프라인이 되었을 때 봇이 게시할지 여부예요. **설정**에서 설정합니다 |

**방송**에는 팔로우한 모든 스트림이 플랫폼, 채널, 추가한 날짜와 함께 나열되며, 각 카드에는 삭제 버튼이 있고 **모두 지우기** 버튼도 있어요. **통계**에는 전체 스트림 수, 고유 스트리머 수, 알림이 설정된 채널 수, 사용 중인 플랫폼, 플랫폼별 분류가 표시돼요.

서버는 최대 10개의 스트림을 팔로우할 수 있어요. 11번째를 추가하면 실패해요.

## Setup walkthrough

1. 대시보드에서 **방송 알림**를 열고 **스트림 팔로우** 탭으로 이동하세요.
2. **알림 채널**을 고르고, **스트림 URL**을 붙여 넣은 뒤 **스트림 팔로우**을 누르세요.
3. **설정**에서 임베드 편집기로 위의 자리 표시자를 사용해 **전체 스트림 메시지**를 만든 뒤 **메시지 저장**을 누르세요. 기본 임베드를 유지하려면 이 단계는 건너뛰세요.
4. 방송 종료 알림도 원하면 **오프라인 알림**을 켜세요.
5. **방송**로 돌아가 스트림 카드를 열고, 전체 템플릿과 다른 내용이 필요하면 해당 스트림에 **온라인 메시지** 또는 **오프라인 메시지**를 설정하세요.
6. `streamcheck <url>`로 봇이 스트림을 읽을 수 있는지 확인한 뒤, 다음 방송 시작을 기다리세요.

## Commands

서버의 접두사로 명령어를 실행하세요(변경하지 않았다면 `.`).

| 명령어 | 별칭 | 필요 권한 | 용도 |
| --- | --- | --- | --- |
| `streamadd <url>` | `sta`, `stadd` | 메시지 관리 | 스트림을 팔로우하고 현재 채널로 알림을 보내요 |
| `streamremove <index>` | `strm` | 메시지 관리 | `streamlist`에서 해당 순서의 스트림을 팔로우 취소해요 |
| `streamsclear` | `stclear` | 관리자 | 서버의 모든 스트림 팔로우를 취소해요 |
| `streamlist` | `stl`, `streamslist` | 없음 | 팔로우한 스트림을 번호, 플랫폼, 채널과 함께 페이지 단위로 나열해요 |
| `streamoffline` | `sto`, `stoff` | 메시지 관리 | 오프라인 알림을 켜거나 꺼요 |
| `streammessage <index> <message>` | `stm`, `stmsg` | 메시지 관리 | 스트림의 온라인 메시지를 설정해요. 빈 메시지면 초기화돼요 |
| `streamofflinemessage <index> <message>` | `stofmsg`, `stoffline` | 메시지 관리 | 스트림의 오프라인 메시지를 설정해요. 빈 메시지면 초기화돼요 |
| `streamtemplate [template]` | `stt`, `sttemplate` | 메시지 관리 | 전체 템플릿과 자리 표시자를 보여 주고, 새 템플릿을 설정하거나 `reset`으로 지워요 |
| `streamcheck <url>` | `stc` | 없음 | 스트림이 지금 방송 중인지와 시청자 수를 알려 줘요 |

## Tips and gotchas

- `streamadd`는 명령어를 실행한 채널을 사용해요. 다른 채널을 고르려면 대시보드를 사용하세요.
- 스트림 번호는 `streamlist`에서 확인하며 1부터 시작해요. 스트림을 제거하면 번호가 바뀌므로, 번호로 제거하기 전에 목록을 다시 확인하세요.
- 봇에는 알림 채널의 메시지 보내기와 링크 첨부 권한이 필요해요. 봇이 볼 수 없는 채널로의 알림은 로그 항목과 함께 건너뛰어요.
- 서버에 Twitch Bot이 연결되어 있고 같은 Twitch 채널에 방송 시작 채널이 설정되어 있다면, 그 기능이 우선 처리하고 스트림 알림은 해당 채널에 대해 조용해져요. 그래서 게시물이 두 번 올라가지 않아요.
- YouTube 데이터는 API가 아니라 스크래핑으로 가져와요. 제목, 카테고리, 시청자 수가 없거나 `Live Stream`으로 읽힐 수 있어요.
- 12시간 동안 조회가 계속 실패하는 스트림은 자동으로 제거돼요. 스트리머가 채널 이름을 바꿨다면 새 URL을 팔로우하세요.
