## 概要

設定ページには、機能ごとではなく、すべての機能に同時に影響する基本的なオプションがあります。メンバーがコマンドの前に入力するプレフィックス、ボットが返信に使う言語、リマインダーや予約投稿に使うタイムゾーン、コマンドの使用状況や警告を記録するチャンネルを変更できます。

また、ミュートロールの名前、ミュートされたメンバーの他のロールを外すかどうか、警告の有効期間、2つのチャットユーティリティ（メッセージのスナイプとメッセージリンクのプレビュー）も設定できます。

これらの設定の多くには、対応するテキストコマンドがあるため、スタッフはDiscordからも変更できます。一部の設定はコマンドでのみ利用でき、スタッフロール、メンバーロール、チャンネルごとのコマンドメッセージの削除があります。

## 利用するメリット

- サーバーで別のボットが `.` を使用している場合、Mewdekoを `!` または `m!` で動作させたい。
- コミュニティが英語以外の言語を使用しており、ボットの返信を合わせたい。
- リマインダーや予約投稿が、UTCではなく現地時間で届くようにしたい。
- モデレーターが、実行されたすべてのコマンドと、発行されたすべての警告を記録するチャンネルを用意したい。
- 警告が際限なく積み重なるのではなく、一定の日数が経過すると消えるようにしたい。
- メンバーが削除されたメッセージを `snipe` で確認できるようにしたい。または、混み合ったチャットでリンクのプレビューを無効にしたい。

## プレフィックス

プレフィックスは、メンバーがコマンドの前に入力するテキストです。デフォルトは `.` です。誰でも、引数なしで `prefix` を実行すると、現在のプレフィックスを確認できます。管理者は `prefix <new>` で変更するか、ダッシュボードの**コマンドのプレフィックス**ボックスで変更できます。スラッシュコマンドはプレフィックスの影響を受けません。

## 言語

各サーバーは、`languageset <code>` で返信の言語を選択できます（例：`languageset de`）。ダッシュボードの**言語**ドロップダウンからも選択できます。`languageset default` を実行すると上書きがクリアされ、サーバーはボットのデフォルト言語に従います。`languageslist` は、サポートされているすべてのロケールコードを表示します。引数なしの `langsetdefault` は、ボットのデフォルトを表示します。デフォルトを変更できるのは、ボットの所有者だけです。

## タイムゾーン

サーバーのタイムゾーンは、リマインダー、予約投稿、すべての時刻表示に使われます。`timezone` を単独で実行すると、現在の値が表示されます（設定されていない場合はUTC）。`timezone <id>` は、`Europe/London` のようなIANAまたはWindowsのタイムゾーン識別子を使って設定します。`timezones` は、ボットが受け付ける識別子をページ送りで表示します。ダッシュボードでは、**サーバーのタイムゾーン**は値を選択した時点で保存されます。**変更を保存**を待つことはありません。

## ログのチャンネル

**コマンドログのチャンネル**は、コマンドの使用状況を記録します。`commandlogchannel #channel` で設定します。チャンネルを指定せずにコマンドを実行すると、ログ記録が無効になります。

**警告ログのチャンネル**は、モデレーションコマンドで発行された警告を記録します。これはダッシュボードで設定します。

## 警告

**警告の有効期限**は時間単位で保存されます。0の場合、警告は期限切れになりません。`warnexpire` コマンドは日単位で動作し、2つ目の単語を取ります。`warnexpire 30 clear` は、30日より古い警告を解除済みとしてマークし、`warnexpire 30 delete` は削除します。指定できる範囲は0〜366日で、`warnexpire 0` を実行すると有効期限が無効になります。

## ミュートロールとロールの削除

**ミュートロール**は、ミュートコマンドや処罰が適用されるロールの名前です。その名前のロールが存在しない場合、ボットがそのロールを作成します。Discordからは、`muterole @role` で既存のロールを指定できます。サーバーのオーナーでない限り、そのロールは自分の最上位ロールより下にある必要があります。引数なしの `muterole` は、現在のミュートロールを表示します。

**ミュート中は他のロールをすべて削除**をオンにすると、ミュートの期間中、メンバーの他のロールが外され、ミュートが終わると戻されます。コマンドでは、`removeonmute y` または `removeonmute n` と入力します。

## チャットユーティリティ

| 設定 | コマンド | 効果 |
| --- | --- | --- |
| メッセージのスナイプ | `snipeset enable` または `snipeset disable` | メンバーがスナイプコマンドを使って、最近削除または編集されたメッセージを確認できるようになります。デフォルトはオフです。 |
| メッセージリンクのプレビュー | `previewlinks y` または `previewlinks n` | 誰かがDiscordのメッセージのリンクを投稿すると、ボットがそのメッセージの内容を表示します。 |

## コマンドでのみ設定できる項目

これらは同じ管理モジュールに含まれますが、ダッシュボードでは設定できません。

**スタッフロール**（`staffrole @role`）は、そのロールのメンバーを、単語、リンク、招待のフィルターと、提案のスパムチェックから除外するロールです。ロールを指定せずに `staffrole` を実行すると現在のロールが表示され、`staffroledisable` を実行するとクリアされます。

**メンバーロール**（`memberrole @role`）は、サーバーのロールを保存します。現時点では記録されるだけで、どの機能でも使われていません。

**コマンド実行時にメッセージを削除**（`delmsgoncmd`）は、コマンドが実行されると、そのコマンドを発動させたメッセージを削除します。

| 形式 | 効果 |
| --- | --- |
| `delmsgoncmd` | サーバー全体で削除をオン/オフ |
| `delmsgoncmd list` | サーバーの設定と、各チャンネルの上書き設定を表示 |
| `delmsgoncmd channel enable [#channel]` | そのチャンネルでは常に削除（省略時は現在のチャンネル） |
| `delmsgoncmd channel disable [#channel]` | そのチャンネルでは削除しない |
| `delmsgoncmd channel inherit [#channel]` | サーバーの設定に従う |

## 設定

以下のすべては、1つの**ボットの設定**ページにあります。編集後は**変更を保存**を押してください。保存ボタンを使わずに保存されるのは、**サーバーのタイムゾーン**だけです。

| 設定 | デフォルト | 制御する内容 |
| --- | --- | --- |
| コマンドのプレフィックス | `.` | コマンドの前に入力するテキスト |
| コマンドログのチャンネル | なし | コマンドの使用状況を記録するチャンネル |
| 通貨の絵文字 | なし | サーバー通貨に表示される絵文字 |
| 警告ログのチャンネル | なし | 警告を記録するチャンネル |
| 警告の有効期限 | 0（無期限） | 警告が期限切れになるまでの時間 |
| 言語 | ボットのデフォルト | このサーバーの返信の言語 |
| サーバーのタイムゾーン | UTC | 予約投稿、リマインダー、時刻表示に使うタイムゾーン |
| ミュートロール | Muted | ミュートや処罰で適用されるロールの名前 |
| ミュート中は他のロールをすべて削除 | オフ | ミュートの期間中、他のロールを外す |
| メッセージのスナイプ | オフ | スナイプコマンドを許可 |
| メッセージリンクのプレビュー | オフ | Discordのメッセージリンクを展開する |

> [!NOTE]
> このページでは、共通の基本設定のみを扱います。ログ、モデレーション、スターボード、その他の機能には、それぞれ独自の設定ページがあります。

## 初期設定の手順

1. ダッシュボードで**設定**を開きます。
2. `.` が別のボットと競合する場合は、**コマンドのプレフィックス**を設定します。
3. **言語**と**サーバーのタイムゾーン**を選択します。
4. スタッフだけが閲覧できる**コマンドログのチャンネル**と**警告ログのチャンネル**を選択します。
5. **警告の有効期限**を時間単位で設定します。たとえば、30日の場合は `720` を指定します。0のままにすることもできます。
6. **ミュートロール**の名前が、モデレーターが使用しているロールと一致することを確認します。または、`Muted` のままにして、ボットに作成させます。
7. 必要に応じて、**メッセージのスナイプ**または**メッセージリンクのプレビュー**をオンにします。
8. **変更を保存**を押します。
9. Discordで `staffrole @YourStaffRole` を実行して、フィルターと提案の制限をチームがスキップするようにします。

## コマンド

以下のコマンドは、サーバーのプレフィックス（変更していない場合は `.`）を付けて実行します。

| コマンド | エイリアス | 必要な権限 | 用途 |
| --- | --- | --- | --- |
| `prefix [new prefix]` | | 表示は誰でも、変更は管理者 | コマンドのプレフィックスを表示または設定 |
| `languageset <code>` | `langset` | 管理者 | サーバーの返信言語を設定。`default` でクリア |
| `langsetdefault` | `langsetd` | 表示は誰でも、変更はボットの所有者 | ボット全体のデフォルト言語を表示または設定 |
| `languageslist` | `langli` | なし | サポートされているロケールコードを一覧表示 |
| `timezone [id]` | | 表示は誰でも、変更は管理者 | サーバーのタイムゾーンを表示または設定 |
| `timezones` | | なし | 受け付けるタイムゾーン識別子をページ送りで表示 |
| `commandlogchannel [#channel]` | `commandlog`, `logcommands` | 管理者 | コマンドログのチャンネルを設定。チャンネルを指定しないと無効化 |
| `warnexpire <days> <clear or delete>` | `warne` | 管理者 | 指定した日数で警告を期限切れにする |
| `muterole [@role]` | `setmuterole` | ロールの管理 | ミュートロールを表示または設定 |
| `removeonmute <y or n>` | | 管理者 | ミュート中に他のロールを外す |
| `snipeset <enable or disable>` | `setsnipe` | 管理者 | スナイプコマンドを許可またはブロック |
| `previewlinks <y or n>` | `plinks` | 管理者 | Discordのメッセージリンクを展開する |
| `staffrole [@role]` | | 管理者 | スタッフロールを表示または設定 |
| `staffroledisable` | | 管理者 | スタッフロールをクリア |
| `memberrole [@role]` | | 管理者 | メンバーロールを表示または設定 |
| `delmsgoncmd [list or channel <state> [#channel]]` | `dmc` | 管理者 | サーバー全体またはチャンネルごとにコマンドメッセージを削除 |

## ヒントと注意点

- `delmsgoncmd` には、ボットのメッセージの管理権限が必要です。権限がない場合、コマンドは実行を拒否します。
- ダッシュボードは警告の有効期限を時間単位で保存しますが、`warnexpire` は日単位で指定します。`warnexpire 1` と、ダッシュボードで `24` を設定することは同じ意味です。
- `muterole` は、指定したロールを自分の最上位ロールと比較します。権限が不足していることを示すエラーが表示された場合は、オーナーに依頼するか、より下位のロールを選択してください。
- スラッシュコマンドはプレフィックスを一切無視するため、プレフィックスの変更はテキストコマンドにのみ影響します。
- スタッフロールの除外は、フィルターと提案のスパムチェックだけに適用されます。コマンドの権限は付与されません。その設定には、権限モジュールを使用してください。
