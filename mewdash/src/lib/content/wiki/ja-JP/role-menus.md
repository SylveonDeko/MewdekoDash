## What it does

ロールメニューは、チャンネルにある1つのメッセージで、その下に**ドロップダウン**または**ボタン**の行が付いたものです。メニューの各オプションは、1つのロールを付与します。メンバーはオプションを選ぶとロールを受け取り、もう一度選ぶとロールを外せます。そのため、サーバーはスタッフに頼らずに、代名詞、色、通知、地域などを選べるようにできます。

各メニューには、名前（スタッフだけが見え、既定のメッセージのタイトルになります）、チャンネル、メッセージ、最大25個のオプションがあります。オプションには、ロール、メニューに表示される名前、任意の絵文字、任意の説明があります。説明は、ドロップダウンの各オプションの下と既定のメッセージに表示されます。ボタンには色もあり、blurple、grey、green、red から選べます。

メッセージには、埋め込みビルダーで作れるもの、つまりプレーンテキスト、1つ以上の埋め込み、またはその両方を使えます。空欄のままにすると、ボットはメニューの名前と、各オプションの行を投稿します。

## Pick any or pick one

- **複数選択** では、メンバーが各ロールを個別にオン・オフできます。保持できる数は2つの制限で管理されます。**最低限保持する数** は、一度選んだ後に、その数より少なくなることを防ぎます。**最大設定数** は、メニューから持てるロールの上限を設定します（既定では上限なし）。
- **1つだけ選択** ではロールを入れ替えます。新しいオプションを選ぶと、以前持っていたロールは外されます。**一度選んだら1つは保持** をオンにすると、メンバーは切り替えはできますが、選択を解除することはできません。

## Limits

| Limit | Value |
| --- | --- |
| サーバーごとのメニュー数 | 50 |
| メニューごとのオプション数 | 25 |
| 1行あたりのボタン数 | 5 |
| メニューの名前 | 100文字 |
| メニューに表示される名前 | 80文字 |
| 説明 | 100文字 |
| ドロップダウンのヒントテキスト | 150文字 |
| プレーンテキストのメッセージ | 2000文字 |

同じロールは、1つのメニューに1回しか登録できません。ボットは、統合機能が管理していないロールのうち、自分の最上位のロールより下のロールしか付与できません。スタッフは、自分の最上位のロールより下のロールしか提供できません。

## Required role

メニューには必要なロールを設定できます。そのロールを持たないメンバーには、そのロールが必要であることを伝える非公開のメッセージが届き、何も変わりません。

## Confirmation

**変更内容をメンバーに通知** をオンにすると、メンバーには、付与されたロールと外されたロールを一覧にした非公開のメッセージが届きます。オフにすると、メニューは静かに動作します。ただし、上限に達した場合や、ボットが付与できないロールの場合など、問題が起きたときは、メンバーに非公開のメッセージが届きます。

## Editing, pausing, and posting again

編集を保存すると、同じメッセージがその場で作り直されます。新しいメッセージが投稿されるのは、チャンネルが変わったとき、または古いメッセージがなくなったときだけです。

**一時停止** を押すと、メニューが再開されるまで、Discord 上でドロップダウンまたはボタンがグレーアウトします。**再投稿** は新しいコピーを投稿し、古いメッセージを削除します。メニューが画面から流れてしまった場合や、手動で削除された場合に役立ちます。メニューのチャンネルが削除された場合は、編集して新しいチャンネルを選び、保存すると再投稿されます。

メニューを削除すると、そのメッセージも削除されます。メンバーがすでに選んだロールは保持されます。

## Moving older setups

以前の絵文字ロールの設定では、メンバーはメッセージの下に絵文字を付けてロールを受け取っていました。**古い設定を移行** タブには、そうした設定が一覧表示されます。1つを移行すると、同じロールと絵文字を使ったロールメニューが、ドロップダウンまたはボタンとして作成されます。同じチャンネルでも別のチャンネルでもかまいません。古いメッセージのテキストと埋め込みをコピーすることもでき、古い設定を廃止することもできます。廃止すると、その設定は停止し、絵文字がクリアされます。ボットが元のメッセージを投稿していた場合、廃止するとそのメッセージは削除されます。メンバーが1つのロールしか持てなかった設定は、Pick one のメニューになります。

## Commands

| Command | What it does |
| --- | --- |
| `rolemenus` | すべてのメニューを、チャンネル、種類、オプション数、状態とともに一覧表示します。 |
| `rolemenuinfo 3` | 1つのメニューのすべての情報を表示します。 |
| `rolemenucreate #roles dropdown @Role @Role` | ロールごとに1つのオプションを持つ新しいメニューを投稿します。 |
| `rolemenuadd 3 @Role [emoji] [name]` | メニューにロールを追加します。 |
| `rolemenuremove 3 @Role` | メニューからロールを削除します。 |
| `rolemenuname 3 Pronouns` | メニューの名前を変更します。 |
| `rolemenumessage 3 [message\|clear]` | メニューの上に表示されるメッセージを表示、設定、またはクリアします。 |
| `rolemenustyle 3 dropdown\|buttons` | ドロップダウンとボタンを切り替えます。 |
| `rolemenumode 3 multi\|exclusive` | Pick any と Pick one を切り替えます。 |
| `rolemenulimits 3 0 2` | メンバーが保持しなければならないロールの数と、持てるロールの数を設定します。 |
| `rolemenurequire 3 [@Role]` | 必要なロールを設定またはクリアします。 |
| `rolemenureply 3 private\|silent` | 非公開のメッセージのオンとオフを切り替えます。 |
| `rolemenupause 3` | メニューを一時停止します。一時停止中の場合は再開します。 |
| `rolemenurepost 3 [#channel]` | 新しいコピーを投稿し、古いメッセージを削除します。 |
| `rolemenudelete 3` | メニューとそのメッセージを削除します。 |
| `rolemenuimport messageId [dropdown\|buttons]` | 以前の絵文字ロールの設定を、新しいメニューに移行します。 |
