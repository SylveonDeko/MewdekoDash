## 概要

ボットがサーバーからキックされるか、サーバーを退出するたびに、ボットはそのサーバーのオーナーに短いDMを送ります。DMには、よくある理由のドロップダウン、**Write something** ボタン（テキストボックスを開きます）、**No thanks** ボタンがあります。回答は任意で、DMにもそう書かれています。

回答は、サーバー名、メンバー数、オーナー、ボットがそのサーバーにいた期間とともに保存されます。報告チャンネルが設定されている場合は、回答ごとに概要の埋め込みもそこに投稿されます。オーナーが後からコメントを追加すると、その埋め込みも更新されます。

これはボット全体の機能です。サーバーごとの設定はありません。ダッシュボードのページは、ボット所有者にのみ表示されます。

> [!NOTE]
> 退出フィードバックのページを見られるのはボット所有者だけです。他のダッシュボードユーザーには、サイドバーに表示されず、開くこともできません。

## 利用する理由

- 機能の不足、セットアップの混乱、信頼性の問題のどれが原因でサーバーが離れていくのかを知るため。
- ボットをテストするためだけに追加されたサーバーを見つけ、その退出を無視できるようにするため。
- コメントと連絡先を残してくれたオーナーに連絡するため。
- そもそもオーナーが回答する頻度を把握するため。

## 質問文

DMのタイトルは「Sorry to see me go!」で、ボットが削除されたサーバー名を示して、削除されたことを説明します。ドロップダウンには、次の順番で理由が表示されます。

| 理由のキー | オーナーに表示される内容 |
| --- | --- |
| `not_needed` | We didn't need it anymore |
| `confusing` | Too confusing to set up |
| `missing_features` | Missing features we wanted |
| `unreliable` | It was broken or unreliable |
| `other_bot` | We switched to another bot |
| `temporary` | Temporary, I'm adding it back |
| `testing` | Just testing something |

理由を選ぶと、すぐに保存され、テキストボックスが再び表示されます。テキストボックスは1段落のフィールドで、「What could we have done better?」というラベルが付き、1000文字までです。**No thanks** を押すと、記録は非表示としてマークされ、報告されることはありません。

迷惑にならないためのルール：

- サーバーに対するお願いは、30日に最大1回です。ボットを何度追加・削除しても同じです。
- オーナーのDMが閉じられている場合、何も保存されません。
- この機能がオフの場合、何も送信されません。

## ステータス

各記録は、次の3つの状態のいずれかになります。ダッシュボードはこれで絞り込めます。

| ステータス | 意味 |
| --- | --- |
| Answered | オーナーが理由を選ぶか、コメントを書きました |
| Dismissed | オーナーが **No thanks** を押しました |
| No response | DMは送信されましたが、まだ何も返ってきていません |

## 設定

ページには **回答** と **設定** の2つのタブがあります。

| 設定 | デフォルト | 制御する内容 |
| --- | --- | --- |
| Ask owners why the bot was removed | オン | DMを送るかどうかです |
| Report channel ID | 空 | 回答ごとに概要の埋め込みを受け取るチャンネルです。空の場合は、ボットの参加・退出ログチャンネルを使います |

チャンネルのフィールドの下には、そのIDがどのチャンネルとサーバーに対応しているか、またボットがそのチャンネルにアクセスできるかが表示されます。

**回答** タブには6つのカウンターがあります。**送信された問い合わせ**、**回答済み**、**コメントあり**、**却下**、**応答なし**、**回答率** です。また、**回答された理由** の内訳と、**退出**、**サーバー**、**理由**、**ステータス** の列を持つ表があります。理由とステータスで絞り込むことができます（ステータスのフィルターには **コメントあり** もあります）。サーバー名やコメントの内容で検索でき、行を開くとコメントの全文を読めます。記録を削除することもできます。**回答率** は、回答とスキップ（Dismissed）の両方を合わせて数えます。

## セットアップの手順

1. ボット所有者のアカウントでダッシュボードにログインし、**退出フィードバック** を開きます。
2. **設定** タブで、**Botが削除された理由をオーナーに尋ねる** がオンになっていることを確認します。デフォルトでオンです。
3. **報告チャンネルID** にチャンネルIDを貼り付け、**チャンネルを保存** をクリックします。空のままにすると、参加・退出ログチャンネルを使います。
4. 自分が所有するテスト用のサーバーからボットを削除し、届いたDMに回答します。
5. **回答** タブと報告チャンネルで、記録を確認します。

## コマンド

この機能はダッシュボードからのみ使えます。ボットのコマンドはありません。オーナーはDM内のボタンとドロップダウンで回答します。

## ヒントと注意点

- ボットがDMを送るのは、Discordでサーバーのオーナーとして登録されている人だけです。ボットをキックした人には送られません。
- 30日間のクールダウンはサーバーごとです。そのため、期間内にボットを再追加してから再度削除したサーバーには、2回目の質問は送られません。
- 概要の埋め込みは、設定されたチャンネルに送られます。設定がない場合は、ボットの認証情報にある参加・退出ログチャンネルに送られます。どちらも存在しない場合でも、回答は保存され、ページで確認できます。
- ダッシュボードから記録を削除しても、報告チャンネルに投稿済みの埋め込みは削除されません。
