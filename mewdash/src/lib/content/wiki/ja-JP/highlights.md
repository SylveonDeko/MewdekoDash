## 概要

メンバーが `highlight add` で単語またはフレーズを追加すると、そのサーバーでその単語を含むメッセージが投稿されるたびに、Botがそのメンバーにだけ DMを送信します。DMには、サーバー名とチャンネル名、一致したメッセージの直前の5件のメッセージと一致したメッセージ、そして **メッセージに移動** ボタンが含まれます。

ハイライトは個人のものです。各メンバーは自分のリストを管理し、無視するチャンネルと人を選ぶことができ、ハイライトを削除せずにオフにすることもできます。スタッフは他の人のためにハイライトを追加することはできませんが、ダッシュボードで監視されている内容を確認し、エントリーを削除できます。

メンバーがDMを受け取るのは、実際に閲覧できるチャンネルの場合だけです。メンバーがサーバーで入力中の場合は、その人が在席しているとみなされ、2分間ハイライトが一時停止します。

## 使う理由

- メンションをせずに、自分の名前、ニックネーム、プロジェクト名が言及されたときに通知を受け取りたい。
- 大きなサーバーで「giveaway」や「patch notes」のような話題を追いかけたい。
- スタッフが、すべてのチャンネルを読まなくても、「help」や「report」のような単語を見張りたい。
- モデレーターが、メンバーが何を追跡しているかを確認し、攻撃的なエントリーやスパムのようなエントリーを整理したい。

## 一致の仕組み

Botは、空でないすべてのメッセージを、そのサーバーのすべてのハイライトと照合します。

- ハイライトは単語またはフレーズ単位で一致します。`cat` は "category" には一致しませんが、"the cat sat" には一致します。
- 大文字と小文字は区別されます。`Cat` と `cat` の両方を見張りたい場合は、それぞれ別に追加してください。
- 一致する単語がいくつあっても、各メンバーは同じサーバーで2分ごとに最大1件のDMを受け取ります。
- サーバーのどこかで入力すると、同じ2分間の一時停止が始まるため、すでに参加している会話についてDMを受け取ることはありません。
- 無視しているユーザーのメッセージや、無視しているチャンネルのメッセージは、そのメンバーについてスキップされます。
- メンバーがそのチャンネルを閲覧できない場合、またはDMを閉じている場合は、DMは送信されません。
- メッセージは、1つ2秒ずつ処理するキューを通して確認されます。非常に混雑したシャードでは、キューからメッセージが落ちることがあります。

`highlight match some text` は、あなたのリストを見本の文に照らし合わせ、どの単語が一致したかを示します。この確認では大文字と小文字は区別されないため、実際のルールを正確に再現したものではなく、大まかな目安になります。

## メンバーごとの設定

各メンバーには設定の行があり、最初に何かを切り替えたときに作成されます。

| 設定 | デフォルト | 制御する内容 |
| --- | --- | --- |
| Highlights on | オン | `highlight toggle false` を実行すると、このサーバーのすべてのハイライトを一時停止します |
| Ignored channels | なし | あなたの単語が決してDMを発生させないチャンネル |
| Ignored users | なし | そのメッセージがあなたのハイライトを発動させない人 |

## 設定

ダッシュボードのHighlightsページはスタッフ用です。ハイライトを追加するのではなく、表示と削除を行います。

| タブ | 表示内容 |
| --- | --- |
| All Highlights | サーバーのすべてのハイライトをメンバーごとにまとめたもの。単語ごとの削除ボタンと、1人のメンバーのすべての単語を削除するボタンがあります |
| Search | すべてのメンバーの中から単語を含むハイライトを検索します。検索では大文字と小文字は区別されません |
| Disabled Users | ハイライトをオフにしているメンバー。無視しているチャンネルと人の数を表示します |
| Statistics | ハイライトの総数、アクティブなユーザー、最も多い単語、最も活発なメンバー。さらに、よくハイライトされる単語と最近のハイライト |

## セットアップの手順

設定する必要はありません。Botがサーバーに参加すると、すぐにハイライトが動作します。

1. メンバーとして、任意のチャンネルで `highlight add yourname` を実行します。
2. `highlight list` を実行して、保存されたことを確認します。
3. 別のチャンネルで誰かがあなたの名前を入力するのを待ちます。数秒待ってからDMを確認してください。
4. 多すぎる場合は、`highlight toggleignore #busy-channel` または `highlight toggleignore @user` を実行します。
5. スタッフの方は、ダッシュボードで **ハイライト** を開き、**すべてのハイライト** タブを確認して、不要なものを削除します。

## コマンド

サーバーのプレフィックス（変更していない場合は `.`）を付けて実行します。同じ操作は、単一のスラッシュコマンド `/highlights manage` としても利用できます。その `action` オプションは `Add`、`List`、`Delete`、`Match`、`ToggleUser`、`ToggleChannel`、`ToggleGlobal` で、`words`、`user`、`channel` のオプションが別々にあります。

| コマンド | エイリアス | 必要な権限 | 用途 |
| --- | --- | --- | --- |
| `highlight add <word>` | `highlights`, `hl` | なし | 単語またはフレーズを見張ります |
| `highlight list` | `highlights`, `hl` | なし | あなたのハイライトをページごとに表示します。1ページ10件です |
| `highlight delete <number or word>` | `highlights`, `hl` | なし | 一覧の番号、または完全一致の単語で削除します。`remove` も同じように動作します |
| `highlight match <text>` | `highlights`, `hl` | なし | テキストの中にあなたの単語のどれが含まれるかを表示します |
| `highlight toggleignore <#channel or @user>` | `highlights`, `hl` | なし | チャンネルまたは人を、あなたの無視リストに追加または削除します |
| `highlight toggle <true or false>` | `highlights`, `hl` | なし | このサーバーのすべてのハイライトをオンまたはオフにします |

## ヒントと注意点

- Botは、一致させたいチャンネルを読み取れる必要があります。また、通知を受け取るには、サーバーのメンバーからのDMが許可されている必要があります。
- すでに登録している単語を追加しようとすると拒否されます。重複のチェックでは大文字と小文字は区別されませんが、リアルタイムの一致では区別されます。
- 番号で削除する場合は、`highlight list` に表示されている位置を使います。その位置は削除のたびに変わります。
- ハイライトの一覧と設定は、サーバーごとに30分間キャッシュされます。コマンドやダッシュボードで単語を1つずつ追加または削除した場合は、すぐに反映されます。ただし、ダッシュボードからメンバーの単語をすべて削除した場合、DMが止まるまでに最大30分かかることがあります。
- Botがサーバーから退出すると、そのサーバーのハイライトと設定は、次回Botが再起動したときに削除されます。
