## 概要

メンバーがボイスチャンネルに参加し、リンクまたは検索語を指定して `play` を実行します。ボットが参加し、曲をキューに追加して再生を開始します。YouTube、YouTube Music、SoundCloud、Spotifyのリンクは直接読み込まれます。Spotifyのトラック、アルバム、プレイリストは、YouTubeの対応する曲と照合されます。通常の検索では、最大25件の結果が選択メニューに表示されるので、メンバーは目的の曲を選べます。

チャンネル内のすべての人が、1つのキューを共有します。メンバーは、キューの表示、特定の項目へのジャンプ、曲の移動や削除、シャッフル、曲またはキュー全体のループを行えます。キューは名前を付けてプレイリストとして保存でき、後で読み込めます。スキップは、DJロールを持つメンバーであれば即時に行われます。それ以外のメンバーは投票によってスキップします。

スタッフは、再生中の曲やキューが空になったときのお知らせを投稿する音楽チャンネルを選べます。また、DJロール、既定の音量、リピートモードを設定できます。低音ブーストやナイトコアなどのオーディオフィルターも有効にできます。ダッシュボードには、キュー、リピートボタン、フィルターの切り替えを備えたライブのプレーヤーが表示されます。同じライブ情報は、モバイルアプリにも反映されます。

同じモジュールには、2つの追加機能もあります。読み上げ（TTS）は、ボイスチャンネル内でチャットのメッセージを読み上げます。ユーザーごとに声を選べ、ブロックリストも設定できます。Last.fmを使うと、メンバーはボットが再生した曲をスクロブルし、`fm` 形式のコマンドで自分の再生履歴を確認できます。

## 使いどころ

- 雑談用のボイスチャンネルで、一人がずっとDJをしなくても、誰でも曲を追加できるBGMを流したい。
- 信頼できるメンバーだけが即時にスキップできるようにしたいが、ほかのメンバーは投票でスキップできるようにしたい。
- コミュニティで、イベントの開始時に毎回読み込むお気に入りのプレイリストを用意したい。
- 発言できないメンバーがいるボイスチャンネルで、そのメッセージを読み上げてほしい。
- 音楽好きのメンバーが、Last.fmの統計や「このアーティストを聴いているのは誰か」のランキングを共有したい。

## 再生とキュー

ほとんどの音楽コマンドは、ボイスチャンネルに参加している必要があります。ボットがすでに別のチャンネルで再生中の場合は、ほかのチャンネルからのコマンドは拒否されます。

`play <link or search>` は次の入力を受け付けます。

| 入力 | 動作 |
| --- | --- |
| YouTubeまたはYouTube Musicのリンク | 直接読み込みます（プレイリストも含みます） |
| SoundCloudのリンク | 直接読み込みます |
| Spotifyのトラックリンク | YouTubeの曲と照合します |
| Spotifyのアルバムまたはプレイリストのリンク | 各項目をYouTubeと照合し、解決した順にキューへ追加します。進行状況のメッセージも表示されます |
| それ以外 | YouTubeで検索し、最大25件の結果を選択メニューに表示します |

`play <number>` は、そのキュー位置の曲に移動します。`search <query>` は、キューに追加せずに10件の結果を一覧表示します。`queue` は、1ページ5件の表示を出し、曲ごとの操作を行う選択メニューを付けます。`nowplaying` は、現在の曲、リクエストしたユーザー、提供元を表示します。

`songremove <number>` は項目を削除し、`movesong <from> <to>` は並び替えを行います。`shuffle` は、現在の曲より後のすべての曲をシャッフルします。`clearqueue` はキューを空にして再生を停止します。`seek mm:ss` は、現在の曲内の指定位置に移動します。`volume 0..100` は音量を設定し、サーバーの既定値として保存します。

`loop <type>` でリピートを設定します。`none`（`off` も可）、`track`（`song` も可）、`queue`（`all` も可）から選べます。リピートがオフのままキューが終わると、ボットは音楽チャンネルにキューが空になったことを通知します。

### スキップとDJロール

`skip` は、実行したユーザーに対して現在の曲を即座に終了します。`voteskip` は投票を集計します。DJロールまたは管理者権限を持つメンバーは即座にスキップされます。それ以外のメンバーは1票を投じます。ボイスチャンネル内のボット以外のメンバーのうち70%が投票すると、曲がスキップされます。

DJロールは `setdjrole @role` で設定するか、ダッシュボードの **DJロール** で選択します。ロールを指定せずに `setdjrole` を実行すると、DJロールを削除します。

### 自動再生

`autoplay <0..5>` を設定すると、キューが空になったときに、Spotifyのおすすめを使って関連する曲を指定した数だけ追加します。0を指定するとオフになります。この機能は、ボットにSpotifyの認証情報が設定されていることが前提です。認証情報がない場合、自動再生は動作しません。

## プレイリスト

`saveplaylist <name>` は、現在のキューを、サーバーごとに名前を付けて保存します。作成者はあなたとして記録されます。`loadplaylist <name> [true]` はキューの末尾に追加します。`true` を指定するとキューを置き換えます。キューが空の場合は、再生も開始されます。曲は読み込み時にYouTubeで再度解決されるため、存在しなくなった項目は黙ってスキップされます。`playlists` は、曲数と作成者を添えて一覧を表示します。`deleteplaylist <name>` は、プレイリストを削除します。

## オーディオフィルター

フィルターは再生中のプレーヤーに適用され、ボットが切断すると初期化されます。

| コマンド | 効果 |
| --- | --- |
| `bass <0..1>` | 低音域を強調します。0にするとオフになります |
| `nightcore [on/off]` | 速く、高い音程になります |
| `vaporwave [on/off]` | 遅く、低い音程になります |
| `karaoke [on/off]` | 中央に定位するボーカルを抑えます |
| `tremolo [on/off]` | 音量を揺らします |
| `vibrato [on/off]` | 音程を揺らします |
| `eightd [on/off]` | 音を聴取者の周りで回転させます |
| `distortion [on/off]` | ディストーションをかけます |
| `stereowiden [on/off]` | ステレオの広がりを強くします |

`activefilters` は、有効なフィルターを一覧表示します。`resetfilters` はすべてのフィルターを解除します。ダッシュボードの **再生中** カードには、低音ブースト、ナイトコア、ヴェイパーウェーブ、カラオケ、トレモロ、ビブラート、8D回転、ディストーションの切り替えボタンがあります。

## 音楽リンクの変換

有効にしたチャンネルで、Apple Music、Spotify、YouTube Music、YouTube、Amazon Music、Deezer、Tidal、Pandora、SoundCloudのリンクを投稿すると、その曲のタイトル、アーティスト、ジャケット画像と、ほかのサービスでの同じ曲へのリンクを含む埋め込みで返信されます。`musiclinkchannel [#channel]`（サーバーの管理）でチャンネルごとに切り替えられ、`musiclinkchannels` で一覧を確認できます。ダッシュボードでは、**音楽** 設定タブの **音楽リンクの変換** セクションで設定します。

## 読み上げ（TTS）

TTSは、ボットがいるボイスチャンネル内で、メッセージを読み上げます。スタッフがボイスチャンネルごとに有効にします。そのボイスチャンネルにいるメンバーのメッセージは、ボイスチャンネルのテキストチャットまたはリンクされたテキストチャンネルに投稿されると、キューに追加されて読み上げられます。読み上げ中は音楽の音量が15%まで下がり、読み上げ後に元に戻ります。既定でキューには10件のメッセージを保持します。

メンバーは `ttsvoice <name>` で自分の声を選べ、`ttsvoices [search]` で一覧を確認できます。スタッフは、既定の声、速度（ダッシュボードでは0.5から3.0、コマンドでは0.5から2.0）、音量、必要なロール、入室と退室のお知らせとその書式を設定できます。また、特定のユーザーをブロックすることもできます。ダッシュボードの **TTS設定** タブには、同じ設定があり、**TTSの一般設定**、**TTSの動作**、**ボイスチャンネルのTTS**、**ブロックされたTTSユーザー** に分かれています。

## Last.fm

メンバーは、ダッシュボードの `/me` ページ（`lastfmlink` を実行するとボタンが表示されます）からLast.fmアカウントを連携できます。連携後は、ボットが30秒以上再生した曲がアカウントにスクロブルされます。`lastfmtoggle` でスクロブルを一時停止でき、`lastfmstatus` で状態を確認できます。連携済みのメンバーは、`fm` で始まるコマンドを利用できます。最近の再生履歴、期間別のトップアーティスト・アルバム・トラック、アーティストやアルバムの検索、サーバー内の「誰が聴いているか」のランキング、王冠、好みの比較、コラージュのチャートなどが利用できます。

## 設定

ダッシュボードのページには、**音楽設定** と **TTS設定** の2つのタブがあります。音楽タブでは、ボットが再生中の場合、キューの件数、シャッフルとクリアのボタン、リピートモードのボタン、フィルターの切り替えを備えた **再生中** カードも表示されます。

| 設定 | 既定値 | 制御する内容 |
| --- | --- | --- |
| 既定の音量 | 100 | 開始時の音量（0から100）。`volume` の値もここに保存されます |
| 音楽チャンネル | すべてのチャンネル | 再生中とキューのお知らせを投稿する場所 |
| DJロール | DJロールなし | 即座にスキップでき、投票スキップを回避できるロール |
| リピートモード | なし | なし、1曲のみ、キュー |
| 自動切断 | しない | しない、ボイスチャンネルが空のとき、キューが空のとき、いずれかの条件を満たしたとき |
| 類似曲の自動再生 | 無効 | キューが空になったときに関連する曲を追加します。コマンドでは最大5曲まで指定できます |
| 投票スキップを有効化 | オフ | プレーヤーのフッターに投票スキップのしきい値を表示します |
| 投票スキップのしきい値 | パーセント、1から100 | 表示のみの値です。`voteskip` コマンドは常に70%を必要とします |
| 音楽リンクのチャンネル | なし | 音楽リンクが、ほかのサービスの埋め込みに変換されるチャンネル |
| TTS音量 | 100 | 読み上げの音量 |
| TTS速度 | 1.0 | 0.5から3.0 |
| キューの最大数 | 10 | 保留中のTTSメッセージ数。1から50 |
| 既定の声 | プロバイダーの既定 | メンバーが声を選んでいないときに使われる声 |
| 必要なロール | ロール不要 | このロールを持つメンバーだけがTTSを使えます。管理者は常に使えます |
| 返信の文脈 | オフ | 返信の前に「〇〇への返信」と読み上げます |
| 添付ファイルの読み上げ | オフ | 送信された画像、動画、ファイルを知らせます |
| 連続メッセージのまとめ | オフ | 同じメンバーが続けて送信したとき、名前の読み上げを省略します |
| ボイスチャンネルのTTS | なし | ボイスチャンネルごとの有効化、リンクされたテキストチャンネル、入室と退室のお知らせとその書式 |
| ブロックされたTTSユーザー | なし | メッセージを決して読み上げないメンバー |

> [!NOTE]
> ダッシュボードで設定したリピートモードは、次の再生から適用されます。`loop` を実行すると、再生中のプレーヤーにすぐ反映されます。

## セットアップの手順

1. ボットが使用したいボイスチャンネルで、接続と発言の権限を持っていることを確認します。
2. ダッシュボードで **音楽** を開きます。再生中の埋め込みが一般チャットに投稿されないよう、**音楽チャンネル** を設定します。
3. 自由にスキップしてよいメンバー向けに **DJロール** を選びます。
4. **既定の音量** を50前後に設定します。100は大音量です。
5. ボイスチャンネルに参加し、`play never gonna give you up` を実行して結果を1つ選び、`queue` と `nowplaying` を実行します。
6. 曲をキューに追加し、`saveplaylist chill` を実行して、お気に入りのプレイリストを作成します。
7. TTSを使う場合は、**TTS設定** に切り替え、**ボイスチャンネルのTTS** にボイスチャンネルを追加してから、メンバーに `ttsvoice` で声を選んでもらいます。

## ヒントと注意点

- ボットには、ボイスチャンネルでの接続と発言の権限が必要です。お知らせのために、音楽チャンネルでのメッセージの送信の権限も必要です。
- ほとんどのコマンドは、まずあなたがボイスチャンネルに参加しているか、またそれがボットの参加しているチャンネルかを確認します。
- `volume` で設定した音量はサーバーの既定値として保存されるため、夜遅くに設定した10は、翌日の開始時の音量になります。
- Spotifyのプレイリストは、曲ごとにYouTubeで検索して変換されるため、長いプレイリストには時間がかかり、一部の曲が誤って一致することがあります。
- 保存されたプレイリストに保存されるのは音声ではなくリンクです。YouTubeから動画が削除されている場合、読み込み時にその項目はスキップされます。
- 投票スキップの対象になるのは、チャンネル内の人間だけです。ボイスチャンネルに一人しかいない場合は、あなたの1票だけで十分です。
- TTSが読み上げるのは、ボイスチャンネルにいるメンバーのメッセージだけです。テキストのみで参加しているメンバーは、TTSを起動できません。
