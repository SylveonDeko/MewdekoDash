## 概要

スタッフが、1つのボイスチャンネルをハブとして設定します。メンバーがそのチャンネルに参加すると、ボットがテンプレートから名前を付けた新しいボイスチャンネルを、設定されたカテゴリー内に作成し、そのメンバーを移動させます。そのメンバーがチャンネルのオーナーになり、名前の変更、人数上限とビットレートの設定、許可されたメンバーのみが参加できるロック、特定のユーザーの許可または拒否、チャンネルの維持、別の人への譲渡などを行えます。

最後の人間が退出すると、オーナーが「チャンネルを維持」をオンにしていない限り、短い待機時間の後にチャンネルは削除されます。オーナーが退出し、ほかの人がまだ中にいる場合は、その人がチャンネルを引き継げます。

メンバーはチャンネルの設定を保存しておけるため、作成するすべてのチャンネルは、希望する名前、人数上限、ビットレート、ロックの状態、チャンネル維持の設定から始まります。スタッフは、メンバーが使える設定を決め、人数上限とビットレートの上限を設定できます。また、どのカスタムチャンネルでも管理できる管理者ロールを指定できます。

## 使いどころ

- 「ゲーム 1」から「ゲーム 8」のようなチャンネルを大量に管理する必要がなくなります。必要なときにメンバーが作成し、用が済めば消えます。
- 非公開で通話したいメンバーは、チャンネルをロックし、友達だけを許可できます。
- 配信者やイベントの主催者は、席を外しても残るようにチャンネルを維持できます。
- 管理者ロールを持つモデレーターは、サーバー全体のチャンネルの管理権限がなくても、どのチャンネルの名前変更、ロック、譲渡も行えます。

## ハブ

`setupvoicehub` を実行すると、新しく作られる「Custom Voice Channels」カテゴリーの中に「Create Voice Channel」というボイスチャンネルが作成され、全員が接続できるが発言はできない設定になり、ハブとして登録されます。`setvoicehub #channel [category]` を使うと、既存のチャンネルをハブとして登録できます。ダッシュボードの **基本設定** セクションでも、チャンネルとカテゴリーを選択して同じことができます。

**ユーザーごとに複数のチャンネルを許可** がオフ（既定）の場合、すでにチャンネルを所有している状態でハブに参加すると、新しいチャンネルを作る前に古いチャンネルが削除されます。

## チャンネル名

**既定の名前形式** はテンプレートです。ボットは `{0}` をメンバーのユーザー名に、`{1}` を識別子（ディスクリミネーター）に、`{2}` をサーバー名に置き換えます。既定値は `{0}'s Channel` です。名前は、Discordの制限内に収まるように切り詰められます。

> [!NOTE]
> ダッシュボードのプレースホルダーには `{username}'s Channel` と表示されますが、ボットが置き換えるのは `{0}`、`{1}`、`{2}` だけです。番号付きの形式を使用してください。

## オーナーの操作

`voicecontrols` を実行すると、あなたがいるチャンネル用のパネルが投稿されます。現在の名前、人数上限、ビットレート、ロックとチャンネル維持の状態、中にいるメンバーが表示され、**名前変更**、**人数上限**、**ビットレート**、**ロック** / **ロック解除**、チャンネル維持、**譲渡** のボタンと、中にいるメンバーを管理するためのメンバー選択メニューがあります。サーバーで無効化されている設定のボタンは、使用できなくなります。

同じ操作はコマンドでも実行できます。各コマンドは、あなたがカスタムチャンネルにいること、そのチャンネルを所有しているか管理者ロールを持っていること、サーバーがその設定を許可していることを確認します。

| 操作 | コマンド | 内容 |
| --- | --- | --- |
| 名前変更 | `voicerename <name>` | **名前のカスタマイズを許可** がオンの場合、チャンネル名を変更します |
| 人数上限 | `voicelimit <n>` | 人数上限を設定します。サーバーの最大人数上限が上限になります |
| ビットレート | `voicebitrate <kbps>` | ビットレートを設定します。サーバーの最大ビットレートが上限になります |
| ロック | `voicelock [true/false]`、`voiceunlock` | ロックすると、許可されたメンバー、オーナー、管理者ロール以外は接続できなくなります |
| 許可 | `voiceallow @user` | ロック中でも、メンバーの接続を許可します |
| 拒否 | `voicedeny @user` | メンバーの接続権限を削除し、中にいる場合は切断します |
| チャンネル維持 | `voicekeepalive [true/false]` | このチャンネルを、空の場合の自動削除の対象外にします |
| 譲渡 | `voicetransfer @user` | 別のメンバーをオーナーにし、管理権限の上書き設定も移します |
| 引き継ぎ | `voiceclaim` | オーナーがチャンネルにいない場合、中にいるどのメンバーでもオーナーを引き継げます |

**チャンネル権限を自動管理** がオンの場合、オーナーは自分のチャンネルで、接続、発言、チャンネルの管理、メンバーの移動、メンバーのミュート、メンバーのスピーカーミュートの権限を得ます。許可・拒否されたメンバーには、それに対応する上書き設定が適用されます。管理者ロールには管理権限が与えられます。

## 片付け

**チャンネルが空になったら削除** がオン（既定）の場合、人間が誰もいなくなったチャンネルは、空チャンネルのタイムアウト後に削除されるように予約されます。タイマーが切れる前に再入室すると、削除はキャンセルされます。チャンネル維持が設定されたチャンネルは、自動的に削除されることはありません。5分ごとのバックグラウンドの確認でも、タイムアウトより長く空だったチャンネルが削除されます。ダッシュボードの **非アクティブなチャンネルを整理** ボタンを押すと、指定した時間以上使われていないチャンネルを削除できます。

## メンバーの設定

`voicepreferences` を実行すると、保存されている名前形式、人数上限、ビットレート、ロック、チャンネル維持の設定が表示されます。`voiceprefs...` の各コマンドでそれぞれの設定を変更でき、値を指定せずに実行すると設定を解除します。`voiceprefsreset` ではすべての設定を解除します。設定が適用されるのは **ユーザーの設定を記憶** がオンの場合のみです。人数上限とビットレートは、引き続きサーバーの上限で制限されます。スタッフは、**ユーザーの設定** タブでユーザーIDを指定して、任意のメンバーの設定を確認・編集できます。

## 設定

ダッシュボードには、**設定**、**アクティブなチャンネル**、**ユーザーの設定** の3つのタブがあります。**設定** タブは、**基本設定**、**チャンネルの既定値**、**チャンネルの管理** に分かれています。引数なしで `voiceconfig` を実行するとすべての値が表示され、`voiceconfig <setting> <value>` で1つの値を変更できます。

| 設定 | 既定値 | 制御する内容 |
| --- | --- | --- |
| ハブチャンネル | なし | 参加して作成するチャンネル |
| カテゴリー | なし | 新しいチャンネルを作成する場所 |
| 既定の名前形式 | `{0}'s Channel` | 新しいチャンネル名のテンプレート（`nameformat`） |
| 既定の人数上限 | 0（無制限） | 開始時の人数上限（`userlimit`） |
| 既定のビットレート | 64 kbps | 開始時のビットレート（`bitrate`） |
| 空になったらチャンネルを削除 | オン | 誰もいないチャンネルを削除します（`deleteempty`） |
| 空のタイムアウト | 1 | 空のチャンネルが削除されるまでの待機時間（`emptytimeout`）。ダッシュボードでは秒として表示され、5から300まで指定できます |
| ユーザーごとに複数のチャンネルを許可 | オフ | 1人のメンバーが複数のチャンネルを所有できるようにします（`multiplechannels`） |
| ユーザーの設定を記憶 | オン | 保存されたメンバーの設定を適用します（`persistpreferences`） |
| チャンネル権限を自動管理 | オン | オーナー、許可、拒否、管理者の上書き設定を行います（`autopermission`） |
| 名前のカスタマイズを許可 | オン | `namechange` |
| 人数上限のカスタマイズを許可 | オン | `limitchange` |
| ビットレートのカスタマイズを許可 | オン | `bitratechange` |
| チャンネルのロックを許可 | オン | `locking` |
| ユーザー管理を許可 | オン | 許可・拒否のコマンド（`usermanagement`） |
| 最大人数上限 | 99 | メンバーが設定できる人数上限の上限（`maxuserlimit`） |
| 最大ビットレート | 96 kbps | メンバーが設定できるビットレートの上限。サーバーのブーストレベルによっても制限されます（`maxbitrate`） |
| 管理者ロール | なし | どのカスタムチャンネルでも管理できるロール（`adminrole`） |

**最大人数上限**、**最大ビットレート**、**管理者ロール** にはダッシュボードの設定項目がありません。`voiceconfig` で設定してください。

**アクティブなチャンネル** タブには、稼働中のすべてのカスタムチャンネルが、オーナー、ロックとチャンネル維持の状態とともに一覧表示されます。各チャンネルのロック、ロック解除、削除ができます。また、作成されたチャンネル数、過去1時間にアクティブだったチャンネル数、ロックされているチャンネル数、チャンネル維持が設定されているチャンネル数の合計が表示されます。このタブには、**非アクティブなチャンネルを整理** ボタンと、サーバーでこのモジュールを無効にする **カスタムボイスを無効化** ボタンもあります。

## セットアップの手順

1. 使用するカテゴリーで、ボットに、チャンネルの管理、メンバーの移動、ロールの管理（権限の上書き設定のため）の権限を与えます。
2. `setupvoicehub` を実行するか、ダッシュボードの **カスタムボイス** を開き、**基本設定** で既存のハブチャンネルとカテゴリーを選択します。
3. **チャンネルの既定値** で、**既定の名前形式**、**既定の人数上限**、**既定のビットレート** を設定します。
4. **チャンネルの管理** で、メンバーに使わせたくないカスタマイズをオフにします。
5. `voiceconfig adminrole @Moderators` を実行して、**管理者ロール** を設定します。これにより、スタッフは自分が所有していないチャンネルも管理できます。
6. 自分でハブに参加し、`voicecontrols` を実行して、チャンネルの名前変更とロックを試してください。

| `voiceprefsreset` | `vcprefsreset`, `vprefsreset`, `resetprefs`, `clearprefs` | なし | すべての設定を解除します |

## ヒントと注意点

- ボットには、カテゴリー内でのチャンネルの管理、作成者を新しいチャンネルに移動させるためのメンバーの移動、権限の上書き設定を書き込むためのロールの管理の権限が必要です。
- 最大ビットレートは、サーバーのブーストレベルで許可される値に制限されます。そのため、ブーストされていないサーバーで384を設定すると、自動的に下げられます。
- ロックすると、@everyoneロールの接続が拒否されます。管理者権限を持つメンバーや、すでに接続が明示的に許可されているロールを持つメンバーは、引き続き参加できます。
- 最後のメンバーが退出したときに動作する空チャンネルのタイマーは、タイムアウトの値を秒として扱います。一方、設定の表示と5分ごとの確認では分として扱われます。既定の値である1の場合、チャンネルが空になるとほぼすぐに消えます。
- チャンネル維持が設定されたチャンネルは、自動的に片付けられることはありません。忘れられたチャンネルを探すには、**アクティブなチャンネル** タブか `voicechannels` を使ってください。
- 引き継ぎは、元のオーナーがチャンネルに接続していない場合にのみ可能です。
