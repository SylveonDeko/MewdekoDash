## 概要

TODOリストは、サーバー内でタスクリストを管理するための機能です。リストはボットの中に保存されます。メンバーはリストを作成し、項目を追加し、完了にマークできます。また、ほかの人に同じリストを閲覧させたり、編集させたりするためのアクセス権を付与できます。サーバー管理権限を持つスタッフは、すべてのメンバーが閲覧できるサーバー全体のリストを作成できます。

各項目には、タイトル、任意の説明、1から4の優先度、任意のタグ、任意の期限、任意のリマインダーの時刻を設定できます。項目には位置があるため、並べ替えができます。完了した項目には、完了したメンバーと完了日時が記録されます。

リストには2種類あります。個人用リストは1人のメンバーに属し、所有者がアクセスを許可しない限り、ほかの人からは見えません。サーバーリストはサーバーに属し、既定では公開されているため、誰でも閲覧できます。ただし、項目を追加または変更できるのは、明示的に権限を与えられた人だけです。

リストは、Discordでは埋め込みとして、ダッシュボードではカードとして表示されます。ダッシュボードでは、開いているリストの進捗、期限切れの件数、完了率も確認できます。

## 利用するメリット

- モデレーションチームが、古くなりがちな固定メッセージの代わりに、サーバーの1つのリストで未完了のタスクを管理できます。
- イベントの運営者が、チェックリストを共有し、作業が終わった項目にチェックを付けられます。
- メンバーが、サーバー内でフォローアップが必要な項目を、非公開のリストで管理できます。
- プロジェクトのチャンネルでは、タグと優先度を使って、「critical」の項目を「low」の項目と区別できます。

## リストと権限

すべてのリストには所有者がいます。所有者は、そのリストに対するすべての操作を行えます。ほかの人には、`todogrant` を使ってユーザーごとに権限を付与することでアクセスを許可します。

| 権限 | 許可される操作 |
| --- | --- |
| `view` | リストと項目を閲覧 |
| `add` | 新しい項目を追加 |
| `edit` | ほかの人の項目を編集、タグ付け、並べ替え、日付の設定 |
| `complete` | ほかの人の項目を完了 |
| `delete` | ほかの人の項目を削除 |
| `manage` | リストの設定の変更、リストの削除、アクセス権の付与と取り消し |
| `all` | 上記のすべての権限 |

複数の権限は、カンマ区切りの文字列で指定します（例：`todogrant 12 @user view,add,complete`）。再度付与すると、そのユーザーの以前の権限は置き換えられます。`todorevoke` を実行すると、すべての権限が削除されます。

権限に関係なく、次の2つのルールが適用されます。項目を作成した人は、自分の項目を常に編集、完了、削除できます。リストの所有者は、常にすべての操作を行えます。

リストを閲覧できる人は次のとおりです。

| リストの種類 | 公開 | 閲覧できる人 |
| --- | --- | --- |
| 個人用 | いずれも | 所有者と、`view` を付与された人 |
| サーバー | はい（デフォルト） | サーバーの全員 |
| サーバー | いいえ | 所有者と、`view` を付与された人 |

`todotoggleprivacy` は、リストを公開と非公開の間で切り替えます。所有者、または `manage` 権限を持つ人だけが実行できます。

## 項目

| 項目 | デフォルト | 補足 |
| --- | --- | --- |
| タイトル | 必須 | リストで太字で表示 |
| 説明 | なし | タイトルの下に斜体で表示 |
| 優先度 | コマンドでは1（低）、ダッシュボードでは中 | 1 低、2 中、3 高、4 緊急。1〜4の範囲外の値は、範囲内に丸められます |
| 期限 | なし | タイトルの横に、相対的なDiscordのタイムスタンプとして表示 |
| リマインダーの時刻 | なし | 項目に保存され、`todosetreminder` で設定 |
| タグ | なし | 大文字と小文字を区別しません。既存のタグを追加しても変化はありません |
| 位置 | リストの末尾 | `todoreorder` で変更 |

`todoshow` は、未完了の項目を、位置、優先度、作成日時の順で並べて表示します。2つ目の引数に `true` を指定すると、完了した項目を最大5件まで、完了日時とともに表示します。`todosetdue` と `todosetreminder` の日付は、柔軟に解析されるため、`2026-10-01 18:00` と `October 1 2026` のどちらでも指定できます。

`todosearch` は、未完了の項目のタイトル、説明、タグに対して検索を行い、最大10件の結果を表示します。`todofilter` は、1つのタグ（`todofilter 12 tag bug`）または優先度（`todofilter 12 priority 4`）でリストを絞り込みます。

各リストには16進数の色を設定でき、`todosetcolor 12 #ff8800` で指定します。この色は埋め込みの枠線に使われます。デフォルトは `#7289da` です。

## 設定

サーバー全体の設定はありません。すべての設定は、リストごと、または項目ごとに行います。

TODOリストのページには1つのビューがあります。左側には、閲覧できるすべてのリストが表示され、**TODOリストを検索**のボックス、**完了した項目を表示**のトグル、**並べ替え**（優先度、期限、作成日、タイトル）と順序の選択があります。リストを選択すると、その項目が表示され、**項目を追加**と**リストを削除**のボタンがあります。また、**優先度**と**期限**を編集できる項目エディターと、リストごとの**権限を管理**ボタンがあります。

| 設定 | デフォルト | 制御する内容 |
| --- | --- | --- |
| リストの名前と説明 | 必須、なし | **リストを作成**ボタンからリストを作成するときに設定 |
| 優先度（項目） | 中 | 項目の優先度。色付きのチップで表示 |
| 期限（項目） | なし | 期限切れの件数に使われる締め切り |
| 完了した項目を表示 | オフ | 完了した項目をリストの表示に含めるかどうか |

> [!NOTE]
> ダッシュボードから作成したリストは、常にサーバーリストになります。個人用リストは、Discordで `todocreatelist` を使って作成してください。

## 初期設定の手順

1. ダッシュボードで**TODOリスト**を開き、**リストを作成**をクリックします。
2. 名前と、任意で説明を入力します。リストは公開されたサーバーリストとして作成されます。
3. リストをクリックしてから、**項目を追加**をクリックします。**何をする必要がありますか？**、任意の説明、優先度を入力します。
4. リストのカードにある**権限を管理**で、誰がアクセスできるかを確認します。Discordで `todogrant <listId> @user add,complete` を実行して、その人が作業できるようにアクセスを付与します。
5. Discordで `todolists` を実行してリストのIDを確認し、`todoshow <listId>` を実行して表示されることを確認します。
6. `todocomplete <itemId>` で項目を完了にします。項目のIDは、`todoshow` でバッククォートに囲まれて表示されます。

## コマンド

以下のコマンドは、サーバーのプレフィックス（変更していない場合は `.`）を付けて実行します。リストと項目のIDは、`todolists` と `todoshow` で確認できます。

| コマンド | エイリアス | 必要な権限 | 用途 |
| --- | --- | --- | --- |
| `todocreatelist <name> [description]` | `tcl` | なし | 個人用リストを作成 |
| `todocreateserverlist <name> [description]` | `tcsl` | サーバー管理 | サーバー全体のリストを作成 |
| `todolists [includeServer]` | | なし | 閲覧できるリストを一覧表示。個人用リストのみの場合は `false` を指定 |
| `tododeletelist <listId>` | `tdl` | なし | リストとすべての項目を削除（所有者または `manage`） |
| `todoshow <listId> [includeCompleted]` | `ts` | なし | リストの項目を表示 |
| `todoadd <listId> <title> [description]` | `ta` | なし | 低い優先度で項目を追加 |
| `todoaddpriority <listId> <priority> <title> [description]` | `tap` | なし | 優先度1〜4で項目を追加 |
| `todoedit <itemId> <title> [description]` | `te` | なし | 項目のタイトルと説明を変更 |
| `todocomplete <itemId>` | `tc` | なし | 項目を完了にする |
| `tododelete <itemId>` | `td` | なし | 項目を削除 |
| `todoreorder <itemId> <position>` | `tr` | なし | 項目を1から始まる位置に移動 |
| `todosetdue <itemId> <date>` | `tsd` | なし | 期限を設定 |
| `todocleardue <itemId>` | `tcd` | なし | 期限を削除 |
| `todosetreminder <itemId> <date>` | `tsr` | なし | リマインダーの時刻を設定 |
| `todoclearreminder <itemId>` | `tcr` | なし | リマインダーの時刻を削除 |
| `todoaddtag <itemId> <tag>` | `tat` | なし | タグを追加 |
| `todoremovetag <itemId> <tag>` | `trt` | なし | タグを削除 |
| `todosearch <listId> <query>` | `tsearch` | なし | 未完了の項目をタイトル、説明、タグで検索 |
| `todofilter <listId> <tag or priority> <value>` | `tf` | なし | 未完了の項目を1つのタグまたは1つの優先度で絞り込み |
| `todosetcolor <listId> <#hex>` | `tsc` | なし | 埋め込みの色を設定 |
| `todotoggleprivacy <listId>` | `ttp` | なし | リストを公開と非公開の間で切り替え |
| `todogrant <listId> @user <perms>` | `tg` | なし | カンマ区切りの権限を付与 |
| `todorevoke <listId> @user` | `trv` | なし | ユーザーのすべての権限を削除 |
| `todopermissions <listId>` | `tp` | なし | 誰がどの権限を持っているかを表示 |

「なし」は、Discordの権限チェックがないことを意味します。コマンドが成功するかどうかは、リストの権限によって決まります。同じコマンドは、`/todo` の下にスラッシュコマンドとしても存在します。

## ヒントと注意点

- リマインダーの時刻は項目に保存されますが、現時点では、その時刻になってもボットがリマインダーを送信することはありません。現時点では、メモとして扱ってください。
- `view` 権限がない場合、IDが正しくても `todoshow` はリストが見つからないと表示します。
- リスト名は、所有者と種類ごとに一意である必要があります。そのため、2人のメンバーがそれぞれ「Shopping」という個人用リストを持つことはできますが、1人のメンバーが同じ名前のリストを2つ持つことはできません。
- `todoreorder` は、リスト内のすべての項目に番号を振り直すため、位置は常に連続したままになります。
- 公開されたサーバーリストは誰でも閲覧できますが、所有者以外は、`add` 権限を付与されるまで項目を追加できません。
- 権限を完全に設定するには、Discordで `todogrant` を使用してください。ダッシュボードの**権限を管理**ビューは、誰がアクセスできるかを確認するためのものです。
- リストを削除すると、その権限と項目がまとめて削除され、元に戻すことはできません。
