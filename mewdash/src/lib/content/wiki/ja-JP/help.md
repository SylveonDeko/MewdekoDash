## What it does

ヘルプモジュールは、メンバーがボットでできることを見つけるための機能です。`help`（または `cmds`）を実行すると、コマンドカテゴリの一覧が表示されるメニューが開きます。各カテゴリにはモジュール数とコマンド数が表示され、ドロップダウンからカテゴリを開けます。カテゴリを選ぶとモジュールが表示され、モジュールを選ぶと、コマンドが1ページに10件ずつ短い説明とともに表示されます。非常に大きなモジュールの場合は、先にセクションに分かれた概要が表示されます。

`help <command>` は、1つのコマンドを表示します。コマンド名と最初のエイリアス、その機能、あなたとボットに必要なDiscordの権限、クールダウンがある場合はそのクールダウン、対応するスラッシュコマンド、各パラメーター、別の書き方、使用例、ドキュメントへのリンクが含まれます。**実行** ボタンを使うと、ヘルプページからそのコマンドを直接実行できます。引数がある場合は、引数を入力するフォームが開きます。

`searchcommand <term>` は、名前または説明に検索語を含むコマンドを探します。テキストなしでボットにメンションすると、現在のプレフィックスと、`cmds` を案内する返信が表示されます。

すべてのコマンドには、サーバーのプレフィックスで使うテキスト版があり、ほとんどの場合はスラッシュ版もあります。ヘルプメニューとコマンドページはどちらの場合も同じです。`/help`、`/search`、`/invite` がスラッシュコマンドの入口です。

## Why you would use it

- 新しいメンバーが `.help` と入力したとき、わかりやすい入口が必要です。
- スタッフは、コマンドを許可する前に、そのコマンドにどの権限が必要かを正確に知りたいと考えています。
- 誰かがコマンド名の一部しか覚えておらず、検索したいと考えています。
- ボットを招待したばかりで、すべてのモジュールのドキュメントを読む代わりに、案内に従ってセットアップしたいと考えています。

## The help menu

引数なしで `help`、`commands`、`modules` を実行すると、最上位のメニューが開きます。埋め込みの説明には、2つの使い方が書かれています。ドロップダウンからカテゴリを選ぶか、`h commandname` で1つのコマンドを調べるかです。ドキュメント、サポートサーバー、招待、寄付のページへのリンクも含まれています。

| Category | Contains |
| --- | --- |
| Moderation & Admin | Administration、Moderation、Permissions、Server Management、Role States、Status Roles、Counting Moderation |
| Server Setup | MultiGreets、Role Greets、Starboard、Stat Channels、Suggestions、Tickets、Confessions、Channel Access、Custom Voice、Chat Triggers、Polls、Giveaways |
| Fun & Games | Games、Counting、NSFW、Searches、Minecraft、Switch |
| Economy & Levels | Currency、XP、Reputation、Vote、Patreon |
| Music | Music |
| Utility | Utility、Help、AFK、Todo、User Profile、Birthday、Highlights、Copr Monitoring |
| Bot Owner | ボットオーナーのみのモジュール |
| Other | 上記に分類されていないもの |

**Toggle descriptions** ボタンを押すと、簡潔な一覧と、各カテゴリの下にすべてのモジュールを表示する詳しいレイアウトを切り替えられます。詳しいレイアウトでは、現在のチャンネルであなたに対して有効かどうかが、チェックマークまたはバツ印で示されます。地球儀とバツ印は、ボットオーナーがそのモジュールをすべてのサーバーで無効にしていることを意味します。

### Module pages

`commands <module>` を使うと、モジュールに直接移動します。名前は完全一致でも、一意の接頭辞でもかまいません。そのため `cmds mod` は Moderation を開きますが、`cmds s` は複数のモジュールが一致するため、その旨を通知します。モジュール名の後に語を付けると絞り込めます。`cmds utility remind` は、Utility のコマンドのうち、名前または説明に "remind" を含むものだけを表示します。

30個を超えるコマンドがあり、3つ以上のセクションがあるモジュールでは、先に概要が表示されます。モジュールの説明、セクションごとの項目（コマンド数付き）、セクションを開くドロップダウン、**All commands** ボタン、フォームを開く **検索** ボタン、**戻る** が表示されます。小さいモジュールでは、ページ分けされた一覧に直接移動します。ページには、セクションごとにまとめられた10件のコマンドが表示され、最初、前、ジャンプ、次、最後、戻る、閉じるのボタンがあります。ページ送りは1時間有効です。

## Command pages

`help <command>` は、完全なコマンド名またはいずれかのエイリアスに一致します。埋め込みには次の内容が含まれます。

- プレフィックスと最初のエイリアスを付けたコマンド、およびその説明。
- **User Permissions**: あなたに必要な権限。Administration モジュールの Discord 権限のオーバーライドが組み込みの要件を置き換えている場合は、元の要件に取り消し線が付けられ、その後にオーバーライドが表示されます。
- **Bot Permissions**: ボットに必要な権限。
- **Documentation**: ドキュメントサイトのコマンドページへのリンク。
- **クールダウン**: コマンドにクールダウンがある場合のみ表示されます。
- **Slash Command**: スラッシュ版がある場合、そのクリック可能なメンション。
- **Parameters**、**Overloads**、**使用量**: コマンドのドキュメントから。各引数、任意かどうか、既定値を示します。
- フッター: モジュール、サブモジュール、メソッド名。バグを報告する際に役立ちます。

**実行** ボタンは、入力したかのようにコマンドを実行します。引数が必要な場合は、先にフォームで入力を求められます。管理者には **権限** ボタンも表示されます。このボタンを押すと、そのコマンドの Command Permissions のクイックメニューが開きます。詳細は Command Permissions の記事を参照してください。

## Slash versus text commands

テキストコマンドは、サーバーのプレフィックス（既定では `.`）と、ヘルプメニューに記載されている正確な名前を使います。スラッシュコマンドはグループ化されているため、`setprivacy` のようなテキストコマンドは `/setprivacy` として表示され、権限関連のコマンドは `/permissions servercommand` の下にあります。コマンドページにはスラッシュコマンドのメンションが表示されるため、クリックできます。どちらの形式も同じ権限ルールに従います。

## When the bot joins

ボットがサーバーに追加されると、監査ログからボットを招待した人を特定し（そのためには監査ログの表示の権限が必要です）、その人にDMを送ります。メッセージには、そのサーバーのダッシュボードウィザードへの **Set Up Mewdeko** ボタン、`cmds`、`cmds mod`、`h purge` の3段階の案内、サポートサーバーへのリンクが含まれます。招待者を特定できない場合、またはDMが閉じられている場合は、何も送信されません。チャンネルへのお知らせもありません。

## The setup wizard

ウィザードは、ダッシュボードの `/wizard?guild=<id>` にあります。ようこそのDMのリンクは、クイックセットアップの形式で開きます。ダッシュボード自体は初回用の形式を提供することもあり、その場合は最初に権限の確認が追加されます。

| Step | What it does |
| --- | --- |
| Welcome | これから行うことを説明します |
| Permissions | 初回のみ: ボットに必要な権限があるか確認します |
| Server Basics | プレフィックス、ボットの言語、サーバーのタイムゾーン |
| Select Features | 設定する機能を選びます。機能には、フルセットアップまたはクイック有効化の印が付いています |
| One step per full-setup feature | その機能のガイド付きの設定 |
| Quick Setup | 残りの機能を、既定値で一括して有効にします |
| Complete | 保存に失敗したものを含む概要 |

進行状況はサーバーごとに保存されるため、離れて戻ってきても続きから再開できます。サーバーをスキップ済みとしてマークすると、ウィザードが再度表示されなくなります。**マイ設定** ページには、ガイド付きセットアップを使うかどうかの切り替えと、サーバーのウィザードの状態のリセットがあります。

## Settings

ヘルプ自体に設定するものはありません。プレフィックスは Administration モジュールで設定し、すべてのヘルプの埋め込みに表示されます。

| Setting | Default | What it controls |
| --- | --- | --- |
| Prefix | `.` | ヘルプのテキストに表示され、Run ボタンで使われるプレフィックス |
| Verbose permissions | off | 拒否されたコマンドが、どの権限ルールによって拒否されたかを説明するかどうか（Command Permissions を参照） |

## Setup walkthrough

1. `help` を実行し、ドロップダウンからカテゴリを開いて、モジュールがどのようにグループ化されているかを確認します。
2. `cmds mod` を実行して Moderation モジュールを確認し、次に `h purge` を実行して1つのコマンドの詳細を確認します。
3. `h ping` のような無害なコマンドで **実行** ボタンを試します。
4. `searchcommand role` を実行して、検索で結果がどのように絞られるかを確認します。
5. ボットを招待したばかりの場合は、ようこそのDMにある **Set Up Mewdeko** のリンクに従うか、ダッシュボードで `/wizard?guild=<your server id>` を開きます。

## Commands

これらのコマンドは、サーバーのプレフィックスを付けて実行します（変更していなければ `.`）。

| Command | Aliases | Needs | Purpose |
| --- | --- | --- | --- |
| `help [command]` | `h` | Nobody | ヘルプメニュー、または1つのコマンドのヘルプを表示します |
| `commands [module] [term]` | `cmds` | Nobody | モジュールの一覧、1つのモジュールのコマンド、または絞り込んだ一覧を表示します |
| `modules` | `mdls` | Nobody | `help` と同じ最上位のメニューを表示します |
| `searchcommand <term>` | | Nobody | コマンド名と説明を検索します。最大20件まで |
| `guide` | `readme` | Nobody | はじめてのガイドへのリンク |
| `source` | `github`, `repo`, `gitlab`, `bitbucket` | Nobody | ソースコードへのリンク |
| `donate` | | Nobody | ボットを支援する方法 |
| `vote` | | Nobody | ボットに投票するためのリンク |
| `exportcommandsjson` | `exportcommands`, `excj` | Nobody | すべてのコマンドを JSON ファイルとしてエクスポートします（1分に1回） |

スラッシュコマンドのみ: オートコンプリート付きの `/search <command>` と `/invite`。`/help`、`/commands <module> [filter]`、`/donate`、`/guide`、`/source`、`/vote` は、テキストコマンドと同じ動作をします。

## Tips and gotchas

- `help` で、あるモジュールの横にバツ印が表示される場合は、権限のルールがあるか、そのチャンネルでボットオーナーが無効にしています。スタッフに `listperms` で確認してもらってください。
- ヘルプのページには、コマンドの実際の前提条件が反映されています。そのため、ドキュメントサイトが古くても、そこに記載された権限が正式なものです。
- Run ボタンは、ボットの権限ではなく、あなた自身の権限を使います。便利な機能であり、権限を回避するものではありません。
- 接頭辞でモジュールを一致させるため、短い接頭辞は曖昧になることがよくあります。3〜4文字以上を使ってください。
- ボットは参加時に招待者にだけDMを送ります。共有リンクから招待してDMが届かなかった場合は、ダッシュボードからウィザードを開いてください。
