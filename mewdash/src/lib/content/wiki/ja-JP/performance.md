## 概要

パフォーマンスは、ボットを運用している人のための監視ページです。ボットのオーナーにのみ表示されます。オーナー以外には、サイドバーに表示されず、URLを直接開いても、ダッシュボードのホームに戻されます。サーバーのスタッフが設定する項目はありません。

このページには、実行中のボットプロセスのリアルタイムの数値が表示されます。あるタブではシステムリソースを表示し、別のタブでは最もCPU時間を使うメソッドを一覧にします。さらに2つのタブでは、Discordイベントの処理を、イベントの種類ごと、およびボットのモジュールごとに分類して表示します。それぞれ件数、平均実行時間、エラー率が含まれます。ページが開いている間は、すべて自動的に更新されます。

イベントとモジュールの数値は、ボットの内部イベントハンドラーから取得されます。このハンドラーは、ディスパッチされたすべてのゲートウェイイベントを記録します。メソッドの計測は、追跡対象のメソッドをラップするパフォーマンスモニターから取得されます。どちらもメモリ内にのみ保存されるため、ボットを再起動するとリセットされます。イベントの指標は1時間ごとに自動でリセットされます。同じ数値の保存された履歴が必要な場合は、[Analytics](/wiki/analytics) を使ってください。

## 利用するメリット

- ボットの動作が重いとき、CPU、メモリ、または特定の遅いメソッドのどれが原因かを確認できます。
- あるモジュールがエラーを出している場合、ログを読まずにモジュールごとのエラー率を確認できます。
- デプロイ後にメモリが安定しているかを、数分間観察して確認できます。
- サポートの問い合わせに対応するため、稼働時間とスレッド数を確認できます。

## タブ

| タブ | セクション | 表示内容 | 更新頻度 |
| --- | --- | --- | --- |
| Overview | System Resources | **CPU使用率**、**メモリ使用量**（使用量と合計）、**稼働時間**、**スレッド数**、および平均時間付きの **CPUを多く使うメソッド（上位）** | 5秒ごと |
| Methods | Method Performance | 追跡されているすべてのメソッドの **呼び出し**、**平均時間**、**合計時間**、**最後の実行**。どの列でも並べ替えでき、収集されたデータを消去するボタンがあります。 | 30秒ごと |
| Events | Event Metrics | **イベントの合計**、**エラー合計**、**イベントの種類**、**平均エラー率**、そして処理件数、エラー、実行時間、エラー率付きの各Discordイベントの種類 | 10秒ごと |
| Modules | Module Metrics | **有効なモジュール**、**イベントの合計**、**エラー合計**、**平均エラー率**、そして処理したイベント数、エラー、実行時間、エラー率付きの各モジュール | 10秒ごと |

CPU使用率は、Overviewが更新されるたびに0.5秒間サンプリングされます。マシン全体ではなく、ボットのプロセスのみが対象です。メモリはプロセスのワーキングセットです。合計メモリは、WindowsとLinuxではホストから読み取られ、それ以外では0と表示されます。

> [!NOTE]
> Methods タブは、追跡されているメソッドが実行されるまで空です。ボットをしばらく使ってから戻ってきてください。

## 設定

設定項目はありません。唯一の操作は、Methods タブのクリアボタンで、メソッドの計測結果を消去します。イベントとモジュールの指標は、手動でクリアできず、1時間ごとにリセットされます。

## セットアップの流れ

1. ボットのオーナーのアカウントでダッシュボードにサインインします。
2. サイドバーから **パフォーマンス** を開きます。オーナーにのみ表示されます。
3. **概要** を1分ほど開いたままにして、CPUとメモリが落ち着く様子を確認します。
4. **モジュール** に移動し、エラーで並べ替えて問題のあるモジュールを見つけます。その後 **イベント** で、最も頻繁に発生しているイベントの種類を確認します。
5. **メソッド** で遅いメソッドを見つけます。修正後は、それをクリアして再計測します。

## コマンド

パフォーマンスのページはダッシュボードのみです。対応するボットのモジュールはありません。チャットで関連する操作を行うオーナー向けのコマンドがいくつかあります。これらは、サーバーのプレフィックス（変更していない場合は `.`）で実行します。

| コマンド | エイリアス | 必要な権限 | 目的 |
| --- | --- | --- | --- |
| `stats` | | なし | ボットのバージョン、5秒ごとに実行されたコマンド数、メモリ、キャッシュの数、シャード、稼働時間 |
| `commandstats` | `cstats` | ボットのオーナー | 最も使われたコマンド、モジュール、サーバー、ユーザー |
| `shardstats` | | ボットのオーナー | すべてのシャードの状態 |

## ヒントと注意点

- このページはボットを通じてオーナーであることを確認するため、あるボットインスタンスではオーナーでも、別のインスタンスではオーナーでないアカウントは、2つ目のインスタンスでリダイレクトされます。
- 数値はプロセスごとです。複数のプロセスにまたがるシャード構成のボットでは、ダッシュボードが接続しているプロセスの数値が表示されます。
- このページの内容は保存されません。履歴が必要な場合は、数値を書き留めるか、スクリーンショットを撮ってください。
- あるイベントの種類でエラー率が高い場合、通常はそのイベントを待ち受けているモジュールに原因があります。次に Modules タブを確認してください。
