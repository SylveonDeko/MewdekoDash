## 概要

フィードのURLとチャンネルをBotに指定します。それ以降、Botは定期的にフィードを確認し、前回の確認以降に公開されたものを投稿します。サイトが何かを公開するたびに、メンバーはチャンネルに新しいメッセージを見られます。メッセージには、項目のタイトル、リンク、そしてフィードが提供している場合は説明文と画像が含まれます。

スタッフは、サーバーごとに最大10件のフィードを登録でき、それぞれに独自のメッセージを設定できます。メッセージは埋め込みパーサーを通るため、フィードの更新はプレーンテキスト、埋め込み、またはボタン付きの埋め込みにでき、項目のタイトル、リンク、作成者などを取り込むプレースホルダーも使えます。

メンバーに必要な操作はありません。チャンネルを読むだけです。

## 使う理由

- コミュニティのブログ、パッチノート、更新履歴を、お知らせチャンネルに自動で投稿する。
- ニュースサイトやサブレディットのフィードを、ディスカッションチャンネルに転送する。
- YouTubeチャンネルやポッドキャストを、そのRSSフィードでフォローする。
- 誰も手作業でリンクをコピーしなくても、ステータスやリリースのフィードを表示し続ける。

## 更新の投稿方法

Botは登録されているすべてのフィードのURLを順番に処理し、取得して、次の処理まで約10秒待ちます。起動後の最初の取得では、最も新しい項目の日付を記録するだけで、何も投稿しません。その後は、前回確認した日付より新しい公開日を持つすべての項目が、古いものから順に投稿され、記録された日付が進みます。Atomフィードの場合、公開日がないときは更新日が使われます。どちらもない項目は無視されます。

1回の処理で投稿される項目の数に上限はありません。そのため、過去の日付の項目を20件一度に出すフィードでは、20件のメッセージが投稿されます。

読み込みに失敗したフィードは、次の処理まで黙ってスキップされます。削除はされず、Botが失敗を報告することもありません。

### 初期のメッセージ

フィードにカスタムメッセージがない場合、Botは次の内容の埋め込みを送信します。

| 項目 | 値 |
| --- | --- |
| タイトル | 項目のタイトル。256文字に切り詰め |
| 説明 | HTMLを取り除いた項目の説明。2048文字に切り詰め |
| URL | 項目のリンク。タイトルをクリック可能にします |
| 画像 | フィードの画像のエンクロージャー、または存在する場合は Atom の `preview` か `thumbnail` 要素 |
| フッター | フィードのURL |

### カスタムメッセージとプレースホルダー

`feedmessage` を使うか、ダッシュボードの **メッセージを編集** ボタンでカスタムメッセージを設定します。テキストは埋め込みパーサーを通るため、[埋め込みビルダー](/wiki/embedbuilder)で作れるものはすべて使えます。プレーンテキスト、埋め込みのJSON、またはその両方です。プレーンテキストの部分にあるロールやユーザーのメンションは通知されます。

カスタムメッセージでは、プレースホルダーのページにある一般的なサーバー、チャンネル、Botのプレースホルダーに加えて、次のプレースホルダーが置き換えられます。

| プレースホルダー | 値 |
| --- | --- |
| `%title%` | 項目のタイトル |
| `%author%` | 項目の作成者。不明な場合は「Unknown」 |
| `%content%` | HTMLを取り除いた項目の説明 |
| `%url%` | 項目へのリンク |
| `%feedurl%` | フィード自身のURL |
| `%image_url%` | フィードが画像を提供している場合はその項目の画像。それ以外はフィードの画像 |
| `%categories%` | 項目のカテゴリ。カンマ区切り |
| `%timestamp%` | 公開日のDiscordタイムスタンプ |

> [!EXAMPLE]
> `feedmessage 1 New post: **%title%** by %author%
> %url%`

メッセージを `-` に設定すると、デフォルトの埋め込みに戻ります。

## 設定

フィードには、サーバー全体の設定はありません。各購読には、追加時に選んだチャンネルとURLがあり、任意でメッセージも設定できます。ダッシュボードのページは **RSSフィード** と呼ばれ、3つのタブがあります。

| タブ | 表示内容 |
| --- | --- |
| RSS Feeds | すべての購読。チャンネル、URL、追加日を表示します。**メッセージを編集** または **カスタムメッセージを追加** でテキストボックスを開き、その下にメッセージのプレビューが表示されます。**削除** は、確認後にフィードを削除します。 |
| Add Feed | **チャンネル** の選択と **RSSフィードのURL** の入力欄があり、**RSSフィードを追加** ボタンがあります |
| Statistics | **フィードの合計**、**ユニークなフィード**、**チャンネル**、**チャンネルごとのフィード** の内訳 |

既存のフィードのチャンネルとURLは変更できません。フィードを削除して、もう一度追加してください。

## セットアップの手順

1. ダッシュボードで **フィード** を開き、**フィードを追加** に切り替えます。
2. 更新を投稿したい **チャンネル** を選びます。
3. フィードのアドレスを **RSSフィードのURL** に貼り付け、**RSSフィードを追加** を押します。サイトのトップページではなく、RSSまたはAtomのドキュメントへの完全な `http` または `https` のアドレスである必要があります。
4. **RSSフィード** に戻り、独自の文言にしたい場合は **カスタムメッセージを追加** を押してから、**保存** を押します。
5. Discordで `feedtest 1` を実行して、最も新しい項目を投稿し、結果を確認します。この番号は、`feedlist` でのフィードの位置です。

## コマンド

これらのコマンドは、サーバーのプレフィックス(変更していなければ `.`)を付けて実行します。フィードのすべてのコマンドにはメッセージの管理の権限が必要です。

| コマンド | エイリアス | 必要な権限 | 目的 |
| --- | --- | --- | --- |
| `feedadd <url> [#channel]` | `rss` | メッセージの管理 | チャンネルをフィードに登録。省略すると現在のチャンネル。Botは先にフィードを取得し、読み込めない場合は拒否します。 |
| `feedlist` | `feeds` | メッセージの管理 | 購読を番号付きで一覧表示。1ページに10件 |
| `feedremove <number>` | `feedrm`, `feeddel` | メッセージの管理 | 一覧の番号を指定して購読を削除 |
| `feedmessage <number> <message>` | `rssmessage` | メッセージの管理 | 購読のカスタムメッセージを設定 |
| `rsstest <number>` | `feedtest` | メッセージの管理 | フィードの最新の項目を現在のチャンネルに投稿 |

## ヒントと注意点

- フィードの上限は、サーバーごとに10件です。同じURLを2回追加することはできません。`feedadd` は、読み込めないリンク、重複、上限のエラーをまとめて1つのエラーで報告します。どれが原因か不明な場合は、`feedlist` を確認してください。
- ダッシュボードからフィードを追加しても、URLは事前にテストされません。その後で `feedtest` を使い、Botが読み取れることを確認してください。
- `feedremove`、`feedmessage`、`feedtest` の番号は `feedlist` から取得します。一覧は、フィードを追加された順に並びます。
- Botには、送信先チャンネルで メッセージの送信 と 埋め込みリンク の権限が必要です。埋め込みリンクがないと、デフォルトの埋め込みは表示されません。
- 公開日(Atomの場合は更新日)がある項目だけが投稿されます。項目に日付がないフィードでは、更新が投稿されることはありません。
- Botは再起動後の最初の処理では何も投稿しません。その時点で最も新しい項目から開始するため、Botがオフラインだった間に公開された項目は取り込まれません。
- カスタムメッセージは埋め込みパーサーを使うため、埋め込みビルダーと同じルールに従ってください。有効なJSON、またはプレーンテキストです。
