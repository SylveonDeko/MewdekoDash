## 概要

リピーターとは、ボットが1つのチャンネルに繰り返し投稿するメッセージです。典型的な使い方は、6時間ごとに「ルールを読んでください」と投稿するような、時間指定のリマインダーです。投稿のたびに、ボットは前回の投稿を先に削除するため、チャンネルに同じメッセージが溜まることはなく、そのメッセージは常にチャンネルの下のほうに表示されます。

リピーターには5つのトリガーモードがあります。固定の間隔に加えて、ほかの人が投稿した瞬間に投稿する（本当の意味での固定メッセージ）、一定数のメッセージの後、チャンネルが活発なとき、チャンネルが静かなときに投稿することもできます。任意の時間枠を設定すると、サーバーのタイムゾーンで、営業時間、夜間、週末に限定できます。フォーラムのリピーターは、新しいすべてのスレッドに自動で投稿できます。

メッセージには、埋め込みビルダーの全機能、プレーンテキスト、コンポーネント、一般的なプレースホルダーを使用できます。そのため、リピーターを一行のテキストだけでなく、リッチなお知らせにできます。メンションは、作成者が「@everyoneと@hereにメンション」の権限を持っている場合にのみ残ります。持っていない場合は無効化されます。

## 使いどころ

- 混雑したチャンネルの最下部に、ルールや「助けを求めるには」というお知らせを表示し続けます。
- サーバー時間の18:00に、毎日のイベントのリマインダーを投稿します。
- 新しいフォーラムのスレッドすべてに、タグで絞り込んで投稿のガイドラインを表示します。
- 1時間静かだったチャンネルに、会話のきっかけとなる話題を投稿して活気づけます。
- 営業時間内だけ、かつ今後7日間だけ、キャンペーンを告知します。

## トリガーモード

| モード | 投稿するタイミング |
| --- | --- |
| 時間間隔 | 指定した間隔ごとに投稿します。必要に応じて、開始時刻に合わせることもできます。既定のモードです。 |
| 即時 | 一度投稿し、そのメッセージがチャンネルの最新のメッセージではなくなるたびに再投稿します。 |
| メッセージ数後 | 前回の投稿以降に、指定したメッセージ数が送信されると投稿します。 |
| 活動時 | チャンネルが活発なときに投稿します。しきい値は、時間枠内の最近のメッセージ数と比較されます。 |
| 非活動時 | 時間枠全体にわたって、チャンネルにメッセージが送信されなかったときに投稿します。 |

活動に基づくモードは1分ごとに確認され、サーバーでメッセージ集計が有効になっている必要があります。間隔は5秒から25000分のあいだで指定します。既定値は5分です。時刻を指定して間隔を指定しなかった場合は、1日になります。**活動のしきい値** の既定値は5件で、**時間枠** の既定値は5分です。時間枠は30秒から6時間の範囲で指定できます。

## 条件と制限

- **チャンネルの最後のメッセージである場合は再投稿しない**（重複チェック）：ボットは、前回の投稿がまだ最新のメッセージである場合、その実行をスキップします。
- **会話の検出**：直前の1分間に3件以上のメッセージが届いている場合、投稿を遅らせ、30秒後に再確認します。
- **時間のスケジュール**：`business` は月曜から金曜の9:00から17:00、`evening` は毎日18:00から23:00、`weekend` は土曜と日曜の終日です。時刻はサーバーのタイムゾーンを使用します。先にタイムゾーンを設定してください。設定していない場合、ボットはUTCとみなし、その旨を通知します。
- **自動削除までの期間**と**最大表示回数**：リピーターは、指定した最大期間または投稿数に達すると、自動的に削除されます。
- **通知を抑制**：メッセージは通知なしで送信されるため、誰のデバイスにも通知は届きません。
- **優先度**はリピーターごとに0から100で保存されます。既定値は50で、一覧に表示されます。

## スレッドとフォーラム

- **新しいスレッドに自動作成**：リピーターのチャンネルの下に新しいスレッドが作成されると、ボットはそのスレッドにメッセージを投稿し、メンバーが返信しても最下部に表示され続けるようにします。
- **スレッドのみモード**：リピーターは親チャンネルには投稿せず、スレッドにのみ投稿します。投稿先がフォーラムチャンネルの場合は必須です。
- **フォーラムのタグフィルター**：必須タグと除外タグによって、どのフォーラム投稿に固定メッセージを付けるかが決まります。

## プレースホルダー

メッセージは、一般的なプレースホルダーのセットを通して処理されます。リピーターはだれかがトリガーするものではないため、ユーザーのプレースホルダーはボット自身を指します。よく使われるものは次のとおりです。

| プレースホルダー | 値 |
| --- | --- |
| `%server%`、`%server.name%` | サーバー名 |
| `%server.members%` | キャッシュされたメンバー数 |
| `%server.id%`、`%server.icon%` | サーバーIDとアイコンのURL |
| `%channel%`、`%channel.name%` | リピーターのチャンネルのメンションと名前 |
| `%bot.name%`、`%bot.avatar%` | ボットの名前とアバター |
| `%server.time%`、`%time.day%` | サーバーの時刻と現在の曜日 |

`%huggif%` などのリアクションGIFのプレースホルダーも置き換えられます。`%user%` などのトリガー用のプレースホルダーは、ボットに置き換えられます。

## 設定

リピーターのページには、**概要**、**リピーターの管理**、**新規作成** の3つのタブがあります。

| 設定 | 既定値 | 制御する内容 |
| --- | --- | --- |
| 投稿先チャンネル | なし | 投稿するテキストチャンネルまたはフォーラムチャンネル |
| フォーラムのタグフィルター | なし | 必須タグと除外タグ（フォーラムチャンネルのみ） |
| メッセージの内容 | なし | 埋め込みビルダーを開きます |
| トリガーモード | 時間間隔 | 5つのモードのいずれか |
| 繰り返し間隔 | 5分 | 1分から毎日までのプリセット、または `HH:MM:SS` 形式のカスタム値 |
| チャンネルの最後のメッセージである場合は再投稿しない | オフ | 重複チェック |
| @everyoneと@hereのメンションを許可 | オフ | 一括メンションを無効化せず、メッセージに残します |
| 優先度（0〜100） | 50 | 一覧に表示される優先度の値 |
| キュー内の位置 | 0 | 保存された並び順の値 |
| 開始時刻（HH:MM） | なし | 時間間隔のリピーターを合わせる時刻 |
| 会話の検出 | オフ | 会話中は投稿を遅らせます |
| 通知を抑制 | オフ | 通知なしで送信します |
| 新しいスレッドに自動作成 | オフ | スレッドへの固定。フォーラムチャンネルのみ |
| スレッドのみモード | オフ | 親チャンネルをスキップします。フォーラムチャンネルのみ |
| 自動削除までの期間（日） | なし | `d.hh:mm:ss` 形式（例：`7.00:00:00`）での最大期間 |
| 最大表示回数 | 無制限 | 削除されるまでの投稿数 |
| 時間のスケジュール | なし | プリセットボタンまたはカスタムのスケジュール |
| 活動のしきい値 / 必要なメッセージ数 | 5 | 活動モードのメッセージ数 |
| 時間枠 | 00:05:00 | 活動モードの時間枠 |

**概要** には、合計、稼働中の数、合計表示回数、トリガーモードごとの内訳、最も活発なリピーターが表示されます。**リピーターの管理** には、各リピーターとともに **編集**、**今すぐトリガー**、**削除** があります。また、間隔、しきい値、最大期間、最大トリガー数を素早く編集できます。

## セットアップの手順

1. ダッシュボードで **リピーター** を開き、**新規作成** を選びます。
2. **投稿先チャンネル** を選択します。フォーラムの場合は、**スレッドのみモード** をオンにし、必要に応じて **フォーラムのタグフィルター** を設定します。
3. **メッセージの内容** のボックスをクリックし、埋め込みビルダーでメッセージを作成します。
4. **トリガーモード** を選びます。固定メッセージの場合は即時、リマインダーの場合は **繰り返し間隔** のプリセットを指定した時間間隔を選びます。
5. 重複チェック、通知なしの送信、時間のスケジュール、有効期限が必要な場合は、**詳細オプション** を開きます。
6. **リピーターを作成** をクリックし、**リピーターの管理** タブの **今すぐトリガー** で動作を確認します。

> [!NOTE]
> 時間のスケジュールには、サーバーのタイムゾーンが必要です。営業時間、夜間、週末の時間枠を有効にする前に、タイムゾーンのコマンドで設定してください。

## コマンド

サーバーのプレフィックスを付けて実行します（変更していなければ `.`）。いずれのコマンドもメッセージの管理の権限が必要です。リピーターは、`repeatlist` で表示される番号で指定します。

| コマンド | エイリアス | 必要な権限 | 用途 |
| --- | --- | --- | --- |
| `repeat [time] [interval] <message>` | | メッセージの管理 | 現在のチャンネルにリピーターを作成します。例：`repeat 6h Read the rules` や `repeat 18:00 Event tonight` |
| `repeatlist` | `replst`, `replist`, `repli` | メッセージの管理 | チャンネル、モード、間隔、次回の実行時刻とともにリピーターを一覧表示します |
| `repeatinvoke <index>` | `repinv` | メッセージの管理 | リピーターを今すぐ実行し、タイマーを再開します |
| `repeatremove <index>` | `reprm` | メッセージの管理 | リピーターを削除します |
| `repeattoggle <index>` | `reptoggle`, `reptog` | メッセージの管理 | 削除せずに有効または無効にします |
| `repeatmessage <index> <message>` | `repmsg` | メッセージの管理 | メッセージを置き換えます |
| `repeatchannel <index> [#channel]` | `repchan` | メッセージの管理 | テキストチャンネルまたはフォーラムチャンネルに移動します |
| `repeatredundant <index>` | `repeatredun`, `repred` | メッセージの管理 | 重複チェックを切り替えます |
| `repeattriggermode <index> <mode>` | `reptriggermode`, `repmode` | メッセージの管理 | `timeinterval`、`immediate`、`aftermessages`、`onactivity`、`onnoactivity` のいずれか |
| `repeatactivity <index> <threshold> <window>` | `repactivity`, `repact` | メッセージの管理 | 活動のしきい値と時間枠を設定します。例：`10 5m` |
| `repeatpriority <index> <0-100>` | `reppriority`, `repprio` | メッセージの管理 | 優先度の値を設定します |
| `repeatschedule <index> <preset>` | `repschedule`, `repsched` | メッセージの管理 | `business`、`evening`、`weekend`、または解除する場合は `none` |
| `repeatconversation <index>` | `repconversation`, `repconv` | メッセージの管理 | 会話の検出を切り替えます |
| `repeatsuppressnotifications <index>` | `repsuppressnotif`, `repsilent`, `repsuppress` | メッセージの管理 | 通知なしの送信を切り替えます |
| `repeatthreadautosticky <index>` | `repthreadauto`, `repthreads` | メッセージの管理 | 新しいスレッドへの投稿を切り替えます |
| `repeatthreadonly <index>` | `repthreadonly`, `reptonly` | メッセージの管理 | スレッドのみモードを切り替えます |
| `repeatforumtags <index> <add/remove/clear/list> [required/excluded] [tags]` | `repforumtags`, `repftags` | メッセージの管理 | タグIDを指定して、フォーラムのタグフィルターを管理します |

## ヒントと注意点

- ボットには、チャンネルでのメッセージの送信、リンクの埋め込み、メッセージの管理の権限が必要です。再投稿する前に前回の投稿を削除するためです。
- チャンネルが削除された場合、またはボットのアクセス権を失った場合、リピーターは自動的に削除されます。
- リピーターは、ボットの起動後すぐに読み込まれます。読み込みが終わるまで、コマンドは何もせず、エラーも表示されません。
- 即時モードは、ほかの人のメッセージが投稿されるたびに再投稿します。そのため、非常に活発なチャンネルでは避けるか、会話の検出と組み合わせてください。
- 全員またはロールにメンションするリピーターを作成できるのは、「@everyoneと@hereにメンション」の権限を持つメンバーだけです。それ以外の場合、メンションは無効化されます。
- 活動に基づくモードは、メッセージ集計に依存します。モードを切り替える前に集計を有効にしてください。有効にしていない場合、コマンドは実行されません。
- 最大表示回数による期限は、手動でトリガーした投稿も含め、すべての投稿を数えます。
