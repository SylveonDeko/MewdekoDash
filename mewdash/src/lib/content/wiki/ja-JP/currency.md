## 概要

すべてのメンバーにはウォレットがあり、銀行を有効にしている場合は銀行残高もあります。メンバーはデイリー報酬を受け取ったり、クールダウンのある `work` と `crime` を実行したり、ゲームで勝ったり、他のメンバーから送金されたりして通貨を得ます。通貨はサーバーのショップでロール、コレクションアイテム、テキストアイテムと交換したり、ブラックジャック、ルーレット、スロット、クラッシュ、ケノなどのゲームでベットしたりして使えます。

スタッフは経済の動きを決めます。ギャンブルを有効にするかどうか、ベットの上限と下限、ハウスエッジ、仕事と犯罪の報酬額、強盗の可否、送金税、銀行の利息、デイリーのストリークボーナスなどです。これらはすべて **設定** タブの設定か `economyset` のキーとして用意されており、ゲームに手を加えることなく経済を調整できます。

Botはすべての入金と出金を取引として記録するため、メンバーは自分のお金の流れを確認できます。また **アナリティクス** タブでは、通貨供給量、その所在、どのゲームが収益を上回る払い戻しをしているかを確認できます。

## 使う理由

- 活発なメンバーに、色付きのロール、カスタムの肩書き、ゲームチャンネルでの楽しみなど、使い道を提供したい。
- ベットの上限、1日の損失上限、ハウスエッジが自動で適用されるため、公平なゲームチャンネルを運営したい。
- 手伝ってくれたメンバーに `modifybalance` または **残高を調整** ツールでボーナスを与え、ショップから選んでもらいたい。
- **ゲームのパフォーマンス** の表を見て、各ゲームの実際の還元率を確認し、感覚ではなくデータに基づいて `payoutmultiplier` を調整したい。

## 残高、銀行、送金

`cash` はあなたのウォレットを表示し、銀行に預金がある場合は銀行残高と純資産も表示します。`bank` は任意のメンバーについて同じ情報を表示し、受け取れる利息も回収します。`deposit` と `withdraw` はウォレットと銀行の間で資金を移動します。金額の代わりに `all` を指定できます。銀行に預けた資金は強盗に奪われることはありません。**銀行の上限** で預けられる上限を設定でき、0は無制限を意味します。

利息は、メンバーが `bank` を実行したときに支払われます。前回の利息支払いから指定の間隔が経過していれば、銀行残高に **Interest (%)** が一度だけ付与されます。誰も確認しない間は利息は支払われません。

`pay` は、**Transfer tax (%)** を差し引いたウォレットの通貨を別のメンバーに送ります。送金には **最小送金額** があり、任意でクールダウンを設定できます。Botには送金できません。

`transactions` は、あなたまたは指定したメンバーの直近250件の記録を、1ページ10件で表示します。`cashleaderboard` はウォレットと銀行を合わせた額でメンバーをランキングします。

## 稼ぐ

| コマンド | デフォルト | 動作 |
| --- | --- | --- |
| `dailyreward` | スタッフが `setdaily` を実行するまで未設定 | クールダウンごとに1回、デイリーの金額を付与します。ストリークを有効にすると、連続して受け取るたびに、最初の日を超えた日数に **1 日あたりのボーナス** を掛けた額が加算され、**ボーナスの上限** で上限が決まります。クールダウンの期間を丸ごと逃すと、ストリークはリセットされます。 |
| `work` | 50から250、30分ごと | 設定された範囲内でランダムな額を獲得します。必ず成功します。 |
| `crime` | 200から800、成功率45%、1時間ごと | 成功すると犯罪の報酬範囲の額を獲得します。失敗すると100から500の罰金が科され、ウォレットの残高が上限になります。 |
| `rob @user` | オフ | 有効にすると、35%の確率で相手のウォレットの最大20%を奪います。残高が100未満の相手は保護されます。失敗すると自分のウォレットの15%を失います。1時間に1回まで実行できます。 |

## ゲーム

すべてのベットは、同じチェックを通過する必要があります。ギャンブルが有効であること、ベットが **最小ベット額** と **最大ベット額** の間にあること、過去24時間に **1 日の損失上限** に達していないこと、そしてゲームのクールダウン（設定されている場合）が経過していることです。賭け金は先に差し引かれます。勝利時の払い戻しは `stake plus profit`（賭け金と利益の合計）で、利益の部分には **配当倍率** が掛けられます。たとえば倍率が0.9なら、すべての勝ちが10%減額されます。引き分けの場合は賭け金の全額が返却されます。

| ゲーム | 払い戻し |
| --- | --- |
| `coinflip <bet> heads/tails` | 正しく予想すると等倍 |
| `highlow higher/lower [bet]` | 1から10までの数字が表示され、次の数字を予想します。等倍で、同じ数字の場合は賭け金が返却されます。デフォルトのベットは100 |
| `spinwheel [bet]` | ベットの-10%から+30%までのセグメントを持つ重み付きホイールです。デフォルトのベットは10 |
| `blackjack <bet>`、その後 `hit` と `stand` | ディーラーは17まで引きます。勝利で等倍、引き分けで返却です |
| `slot [bet]` | 同じシンボルが2つ揃うと2倍。3つ揃うと3倍、ブドウは5倍、セブンは7倍、ダイヤは10倍です。デフォルトのベットは10 |
| `roulette <bet> <type>` | 0から36までの数字が当たると35対1の払い戻しです。`red`、`black`、`even`、`odd` は等倍です。0の場合は色と偶奇のベットが負けになります |
| `rps <choice> [bet]` | ボットに対してグー、チョキ、パー、トカゲ、スポックで勝負します。等倍で、引き分けは返却です。ベットは任意です |
| `war <bet>` | ハイカードが勝つと等倍です。引き分けの場合は追加の賭け金を取られ、カードを1枚追加で引いて2倍になります |
| `craps <bet> [pass/dontpass/field/any]` | passとdon't passはポイントのルールに従い、等倍です。Fieldは等倍、2または12が出ると2倍です。Anyセブンは4倍です |
| `scratchcard [bronze/silver/gold/diamond]` | 固定料金のカードで、10、50、200、1000のいずれかです。勝率は30%、25%、20%、15%で、賞金の範囲は最大50、200、1000、5000です |
| `russianroulette <bet> [bullets]` | 6発の弾倉に1発から5発の弾を入れます。生き残ると、弾の数に応じて利益の1.2倍、1.5倍、2倍、3倍、5倍になります |
| `baccarat <bet> [player/banker/tie]` | プレイヤーまたはバンカーは1.95倍、引き分けは8倍です |
| `minesweeper <bet> [small/medium/large]` | 生存率は70%、60%、50%で、それぞれ1.5倍、2.5倍、4倍になります |
| `lottery [tickets]` | チケットは1枚50で、最大10枚まで購入できます。枚数が増えるほど当選確率（最大40%）と賞金の倍率が上がります |
| `crash <bet> [target]` | 1.1倍から10倍までの精算ポイントを選びます。クラッシュポイントがそれ以上であれば、その倍率で勝ちになります |
| `keno <bet> <numbers>` | 1から80までの数字を1から10個選びます。20個の数字が抽選されます。払い戻しは、1個中1個の3倍から、5個中5個の800倍までです |
| `plinko <bet> [rows]` | 5から10行です。中央に落ちると0.5倍、端に落ちると最大10倍です |
| `wheelfortune <bet> [classic/risky/balanced]` | 倍率のホイールです。risky は0.1倍から20倍までの範囲です |
| `duckrace <bet>` | アヒルが5羽います。あなたのアヒルはランダムに決まります。1位は4倍、2位は2倍、3位は1.2倍です |
| `bingo <bet> [small/large]` | 40%の確率で2倍、または25%の確率で3.5倍です |
| `diceduel @user <bet>` | 相手には承諾と辞退のボタンが表示されます。両者ともベットを支払える必要があります |
| `memory <bet> [easy/medium/hard]` | 4、6、8個の数列を正確に再現すると、1.5倍、2倍、3倍になります |
| `horserace <bet>` | 10秒以内に最大10人のメンバーが参加できます。空いている枠はAIのレーサーで埋められます。プールは上位3位に50%、30%、20%を支払います |
| `triviachain <bet> [category]` | OpenTDBのクイズに連続して答えます。正解するたびに倍率が0.5倍ずつ上がります。カテゴリは general、science、history、sports、entertainment です |

> [!NOTE]
> `horserace` は、正の値であればどんなベットでも受け付けます。賭け金をそのまま使用し、共通のベット上限や払い戻し倍率は適用しません。

## デイリーチャレンジ

メンバーは毎日ランダムなチャレンジを1つ受け取ります。ゲームを5回プレイする、3回勝つ、500を使う、300を稼ぐ、または指定したゲームを3回プレイする、といった内容です。報酬は基本額に最大50が加算されたものです。`dailychallenge` で内容を表示し、`claimchallenge` で報酬を受け取り、`challengeleaderboard` で過去30日間に完了したチャレンジ数の上位10人をランキングします。

> [!WARNING]
> 現在、ゲームはチャレンジのトラッカーに進捗を報告しないため、チャレンジの進捗は常に0と表示され、まだ受け取ることはできません。

## ショップ

アイテムは **ショップ** タブで管理するか、`shopadditem` と `shopaddrole` で追加します。各アイテムには **名前**、**価格**、**説明**、**種類**、**在庫**（空欄または-1で無制限）、**1 ユーザーあたりの上限**、購入者が持っている必要がある任意の **必要なロール**、そして **並び順** があります。

| タイプ | 購入時の動作 |
| --- | --- |
| Role | Botが購入者にロールを付与します。デフォルトではメンバーごとに1つです。 |
| Collectible | 購入者のインベントリに入ります。消費型のため、`use` を実行すると1つ減ります。 |
| Text | **送信するテキスト** が購入者にDMで送信されます。`use` を実行するたびにも再度送信されます。 |

`buy <name>` は、アイテムが有効であること、購入者が必要なロールを持っていること、在庫が残っていること、支払い能力があること、ユーザーごとの上限に達していないことを確認します。支払い後に失敗した場合は、自動的に返金されます。`inventory` は、メンバーが所有しているアイテムを一覧表示します。`shoptoggle` はアイテムを削除せずに非表示にし、誰が持っているコピーもそのまま残ります。`shopremove` はアイテムとそのすべてのコピーを削除します。

## 設定

ダッシュボードには **アナリティクス**、**設定**、**ショップ**、**ランキング** の4つのタブがあります。**ランキング** タブには **残高を調整** もあり、これでメンバーに対して通貨を加算または減算でき、理由は台帳に記録されます。

| 設定 | デフォルト | 制御する内容 |
| --- | --- | --- |
| Enable gambling | オン | すべてのベットゲームのオン・オフ |
| Minimum bet | 1 | 最小の賭け金 |
| Maximum bet | 0（無制限） | 最大の賭け金 |
| Payout multiplier | 1.0 | 勝ちの利益のみを倍率で調整します。0.1から5.0 |
| Daily loss limit | 0（オフ） | 24時間で指定額を負けると、そのメンバーの参加を制限します |
| Game cooldown (seconds) | 0 | メンバーがベットできる間隔（秒） |
| Enable work | オン | `work` コマンド |
| Work minimum / maximum | 50 / 250 | 仕事の報酬の範囲 |
| Work cooldown | 1800 seconds | `workcooldown`。コマンドのみ |
| Enable crime | オン | `crime` コマンド |
| Crime minimum / maximum | 200 / 800 | 犯罪の報酬の範囲 |
| Crime success chance (%) | 45 | 犯罪が成功して報酬を得られる確率 |
| Crime fine minimum / maximum | 100 / 500 | 失敗時の罰金 |
| Crime cooldown | 3600 seconds | `crimecooldown`。コマンドのみ |
| Enable bank | オン | `bank`、`deposit`、`withdraw` |
| Bank capacity | 0（無制限） | メンバーが銀行に預けられる上限 |
| Interest (%) | 0 | 間隔ごとに銀行残高へ付与される利息 |
| Interest interval (hours) | 24 | 利息を回収できる間隔（時間） |
| Enable transfers | オン | `pay` コマンド |
| Transfer tax (%) | 0 | 送金ごとに差し引かれる税 |
| Minimum transfer | 1 | 最小の送金額 |
| Pay cooldown | 0 | `paycooldown`。コマンドのみ |
| Enable robbery | オフ | `rob` コマンド |
| Success chance (%) | 35 | 強盗が成功する確率 |
| Maximum steal (%) | 20 | 成功時に奪える相手のウォレットの割合 |
| Failure fine (%) | 15 | 失敗時に失う強盗自身のウォレットの割合 |
| Protected below | 100 | この額未満の相手は強盗できません |
| Rob cooldown | 3600 seconds | `robcooldown`。コマンドのみ |
| Enable streaks | オン | 連続したデイリー受け取りでボーナスを得られます |
| Bonus per day | 0 | 最初の日を超えて連続した日ごとに加算される額 |
| Maximum bonus | 0（無制限） | ストリークボーナスの上限 |

デイリー報酬の金額とそのクールダウンは、ダッシュボードではなく `setdaily` で設定します。`economyconfig` はすべてのキーと現在の値を表示し、`economyreset` はすべてのデフォルト値に戻します。

## セットアップの手順

1. `setdaily 500 24h` を実行して、メンバーが受け取れる報酬を用意します。
2. ダッシュボードで **通貨** を開き、**設定** に移動します。ゲームチャンネルを開く前に、**最大ベット額** と **1 日の損失上限** を設定します。
3. メンバーがウォレットの通貨を失うことに同意している場合に限り **強盗を有効にする** をオンにします。メンバーが自分の資金を守れるように、銀行は有効にしておきます。
4. **ショップ** で、ロールのアイテムをいくつかとコレクションアイテムを1つ追加します。メンバー限定にしたいものには **必要なロール** を設定します。
5. **残高を調整** または `modifybalance` で、数人のメンバーに初期残高を与えます。
6. 1週間後に **アナリティクス** を確認し、ゲームが払い戻し過多になっている場合は **配当倍率** を下げます。

## ヒントと注意点

- 何より先に **最大ベット額** を設定してください。0のままだと、運の良い1人のメンバーが午後のうちに経済を枯渇させることがあります。
- 1日の損失上限は、過去24時間の純損失を数えます。そのため、序盤に勝ったメンバーはより長くプレイを続けられます。
- ロールのアイテムには、Botの最上位ロールが販売するロールより上にあり、かつ「ロールの管理」権限が必要です。そうでない場合、支払い後にロール付与のエラーで購入が失敗します。
- テキストアイテムと `use` の結果はDMで届けられます。DMを閉じているメンバーにはエラーが表示されますが、アイテムは所有したままです。
- ブラックジャックは、メンバーごとに1ゲームだけをメモリ上で保持します。`hit` と `stand` は `blackjack` を実行した後にのみ動作します。
- 競馬は、他のメンバーを10秒間待ち、その後AIのレーサーで枠を埋めてレースを開始します。
- トリビアチェーンのゲームは、10分間操作がないとタイムアウトします。1人のメンバーが同時に実行できるのは1つだけです。
- Botがグローバル通貨でホストされている場合、残高はすべてのサーバーで共有され、`modifybalance` はオーナーのみが使えます。
