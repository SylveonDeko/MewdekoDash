## 概要

メンバーは一度 `setbirthday` で誕生日を設定し、機能が有効になっているサーバーで `birthdayannouncements` を実行します。Botは毎日、誕生日の人を確認し、発表用のチャンネルにメッセージを投稿します。また、24時間のあいだ誕生日ロールを付与できます。通知ロールを設定している場合は、メッセージの前にそのロールにメンションします。

誕生日は、サーバーごとではなく、メンバーのBotのプロフィールに保存されます。そのため、一度 `setbirthday` を実行すれば、Botと共有しているすべてのサーバーで有効になります。特定のサーバーで誕生日が発表されるかは、3つの条件で決まります。メンバーが参加していること、プロフィールが非公開ではないこと、誕生日の表示モードが無効ではないことです。

誰がお祝いされているかは `birthdaytoday` で、もうすぐ誕生日の人は `birthdaylist` で、誰でも確認できます。年齢は名前の横に表示されますが、メンバーが年を隠す表示モードを選んでいる場合は表示されません。

スタッフは、ダッシュボードの **誕生日** ページか、`birthday*` コマンドを使って、チャンネル、ロール、メッセージを設定します。

## 使う理由

- 誰も手作業で日付を管理しなくても、毎日「お誕生日おめでとう」の投稿をしたいコミュニティサーバー。
- その日だけ色付きの誕生日ロールを付け、チャットで目立たせたい場合。
- 「誕生日チーム」のロールに通知して、発表が確実に目に入るようにしたい場合。
- メンバーが、誕生日をどの程度公開するかを、完全に非表示にするまで選べるようにしたい場合。

## 発表される人

メンバーが発表やリストに含まれるのは、次のすべてを満たす場合だけです。

| 条件 | メンバーがどう管理するか |
| --- | --- |
| 誕生日が設定されている | `setbirthday <date>` |
| 発表に参加している | `birthdayannouncements` で切り替え。初期値はオフ |
| プロフィールが非公開ではない | プロフィールで `setprivacy public` |
| 表示モードが Disabled ではない | `setbirthdayprivacy <mode>` |

この確認は、現在サーバーにいるメンバーを対象に行われるため、退出した人は発表されません。

### 誕生日の表示モード

`setbirthdayprivacy` は次のいずれかの値を受け付けます。リスト、プロフィール、`birthdaytoday` での表示に影響します。

| モード | 効果 |
| --- | --- |
| `Default` | 日付全体を表示し、リストでは年齢も表示 |
| `MonthOnly` | 月のみを表示し、年齢は非表示 |
| `YearOnly` | 年のみを表示し、年齢は表示 |
| `MonthAndDate` | 月と日を表示し、年齢は非表示 |
| `Disabled` | 誕生日を非表示にし、発表もしない |

## 毎日のチェックの仕組み

このサービスは1時間に1回実行され、各メンバーの誕生日の月と日を、UTCの今日の日付と比較します。UTCの新しい1日の最初の1時間に誕生日の人が見つかると、それを投稿し、そのサーバーはその日の処理が完了したとマークされるため、同じ投稿が2回行われることはありません。

発表は、**お知らせ** の機能がオンで、チャンネルが設定されている場合にのみ行われます。`birthdaychannel` またはダッシュボードでチャンネルを設定すると、この機能が自動的にオンになります。

タイムゾーンは保存されますが、毎日のチェックではまだ使われていません。`birthdaytimezone` と **サーバーのタイムゾーン** の設定は受け付けられ、設定の埋め込みにも表示されますが、発表はUTCの日付で行われます。

## 誕生日ロール

**誕生日のロール** が有効で、ロールが設定されている場合、発表された各メンバーは発表の時点でロールを付与され、24時間後に削除されます。削除のタイマーはメモリ上にあるため、日中にBotが再起動すると、誰かがロールを外すまでロールは残ります。

Botにはロールの管理の権限が必要で、Botの最上位ロールは誕生日ロールより上にある必要があります。

## 発表メッセージ

初期のメッセージは、周りに祝いの絵文字を付けた `Happy Birthday %user.mention%!` です。`birthdaymessage` またはダッシュボードの **誕生日メッセージ** エディターで置き換えられます。テキストは埋め込みパーサーを通るため、埋め込みビルダーで作成できるものはすべて使えます。通知ロールが有効な場合は、そのメンションがメッセージの前に付きます。

### プレースホルダー

メッセージは、プレースホルダーのページにある標準のユーザー、サーバー、チャンネル、Botのプレースホルダーに加えて、誕生日専用の値を1つ使えます。

| プレースホルダー | 値 |
| --- | --- |
| `%user.mention%` | 誕生日のメンバーをメンション |
| `%user.name%` | ユーザー名 |
| `%user.avatar%` | アバターのURL |
| `%server.name%` | サーバー名 |
| `%birthday.age%` | 迎える年齢。不明な場合は `Unknown` |

> [!WARNING]
> `{user}` ではなく `%user.mention%` を使ってください。テキストコマンドのヘルプには `{user}` と書かれていますが、投稿される発表では `%...%` 形式のみが置き換えられます。

## 設定

すべての設定は、**誕生日** ページの3つのタブ **設定**、**ユーザー**、**統計** にあります。

**設定** には、基本設定、メッセージエディター、機能ごとのトグルがある **誕生日の機能** パネルがあります。

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| Channel | なし | 発表を投稿する場所 |
| Birthday Role | なし | 誕生日に24時間付与されるロール |
| Ping Role | なし | 各発表の前にメンションするロール |
| Server Timezone | UTC | サーバー用に保存され、設定の埋め込みに表示 |
| Reminder Days Before Birthday | 0 | 0から30。保存されるだけで、リマインダーはまだ送信されません |
| Birthday Message | 初期の埋め込み | 上記のプレースホルダーを含む発表 |

| 機能のトグル | 初期値 | 内容 |
| --- | --- | --- |
| Announcements | オフ | チャンネルに毎日のメッセージを投稿 |
| Birthday Role | オフ | 一時的なロールを付与 |
| Reminders | オフ | プレースホルダーのトグル。まだ何も送信されません |
| Ping Role | オフ | 発表時に通知ロールにメンション |
| Timezone Support | オフ | プレースホルダーのトグル。チェックは引き続きUTCで実行 |

**ユーザー** には、次の7日、14日、30日の **近日中の誕生日** と、誕生日が設定されているすべてのメンバーの **All Users** の一覧があります。今日の誕生日の人は、ページの上部に強調表示されます。**統計** には、**ユーザーの合計**、**設定された誕生日**、**公開されている誕生日**、**今日の誕生日** が表示されます。

> [!NOTE]
> ダッシュボードのフォームを保存すると、入力された値だけが書き込まれます。ロールやチャンネルを消去するには、ロールを指定せずに `birthdayrole` または `birthdaypingrole` を実行するか、`/birthday config reset` ですべてを初期化してください。

## セットアップの手順

1. ダッシュボードで **誕生日** を開きます。
2. **設定** で、発表用の **チャンネル** を選び、**設定を保存** をクリックします。
3. **誕生日の機能** パネルで **お知らせ** をオンにします。
4. 任意で **誕生日のロール** を選び、**誕生日のロール** を有効にします。また、**Ping Role** を選び、**Ping Role** を有効にします。
5. 任意で、`%user.mention%` と `%birthday.age%` を使って独自の **誕生日メッセージ** を書きます。
6. メンバーに、`setbirthday` を実行してから `birthdayannouncements` を実行して参加するように伝えます。
7. **ユーザー** タブで、**近日中の誕生日** に表示されているかを確認します。

## コマンド

これらのコマンドは、サーバーのプレフィックス(変更していなければ `.`)を付けて実行します。スラッシュ版は `/birthday` と `/birthday config` の下にあります。

| コマンド | エイリアス | 必要な権限 | 目的 |
| --- | --- | --- | --- |
| `setbirthday <date>` | | なし | プロフィールに誕生日を設定。例: `setbirthday 1998-04-12` |
| `setbirthdayprivacy <mode>` | | なし | 上記の表示モードから1つを選択 |
| `birthdayannouncements` | `bdayann` | なし | 発表に参加するか、参加をやめるかを切り替え |
| `birthdaytimezone <zone>` | `bdaytz` | なし | タイムゾーンを保存。例: `Europe/London` |
| `birthdaytoday` | `todaysbirthdays` | なし | 今日お祝いされる人を一覧表示 |
| `birthdaylist [days]` | `bdaylist`, `upcomingbirthdays` | なし | もうすぐの誕生日。1から30日、初期値は7 |
| `birthdaychannel [#channel]` | `bdaychannel`, `bdaychan` | 管理者 | 発表用のチャンネルを設定し、発表を有効化 |
| `birthdayrole [@role]` | `bdayrole` | 管理者 | 24時間の誕生日ロールを設定。ロールを省略すると消去 |
| `birthdaypingrole [@role]` | `bdayping` | 管理者 | メンションするロールを設定。ロールを省略すると消去 |
| `birthdaymessage [text]` | `bdaymsg` | 管理者 | 発表のテキストを設定。または現在のものを表示 |
| `birthdayconfig` | `bdaycfg` | 管理者 | 現在の設定を表示 |

`/birthday config reset` は、すべての設定を消去し、すべての機能を無効にします。テキストコマンドに相当するものはありません。

## ヒントと注意点

- メンバーは `birthdayannouncements` を実行するまで発表されません。そのことを伝えておかないと、誰も表示されません。
- `setbirthday` は、Botが日付として解釈できるものをすべて受け付けます。`1998-04-12` のように、あいまいでない形式を使ってください。
- `birthdaytimezone` が受け付けるのは、`UTC`、`GMT`、`America/New_York`、`Europe/London`、`Asia/Tokyo`、`Asia/Kolkata`、`Australia/Sydney`、`Pacific/Auckland` などの、16の固定されたタイムゾーンのみです。ダッシュボードの **サーバーのタイムゾーン** のドロップダウンにも、同様の13のタイムゾーンの一覧があります。
- 毎日のチェックはUTCを使います。UTCから遠いメンバーは、数時間早くまたは遅く発表されることがあります。
- Botには、誕生日ロールのためにロールの管理の権限が、発表用のチャンネルで送信・埋め込みリンクの権限が必要です。
- `birthdayconfig` には「Reminder Days」の項目と、Reminders の機能が表示されます。これらは保存されるだけで、現時点では何も送信しません。
- 保存された誕生日を削除するコマンドはありません。メンバーは `setbirthdayprivacy Disabled` を実行するか、`birthdayannouncements` で参加をやめることで、非表示にできます。
