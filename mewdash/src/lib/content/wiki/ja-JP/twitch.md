## 概要

Twitchボットは、1つのTwitchチャンネルをDiscordサーバーに接続し、そのチャンネル内でMewdekoをチャットボットとして動作させます。視聴者はTwitchチャットで `!ping`、`!quote`、`!counter deaths`、またはあなたが作成したカスタムコマンドを入力すると、ボットがそのチャットに返信します。タイマーは配信中に定期的にメッセージを投稿します。引用とカウンターはサーバーごとに保存されます。チャンネルポイントの報酬は、チャットへの返信やDiscordへの投稿をトリガーできます。

チャンネルでのイベントはDiscordに送られます。チャンネルが配信を開始すると、配信開始の投稿がDiscordの指定したチャンネルに送信されます。サブスクライブ、ギフトサブ、レイドは、それぞれ独自のテンプレートを使って専用のチャンネルに投稿できます。配信終了時には、配信時間、最大同時視聴者数、チャットメッセージ数、サブスク数、レイド数をまとめた振り返りを送信することもできます。

視聴者は、Twitchアカウントを自分のDiscordアカウントにリンクできます。リンクすると、ボットはどのDiscordメンバーがTwitchでチャットしているかを把握できます。ロールの同期を使うと、サブスクライバー、VIP、モデレーター、配信者にDiscordのロールを自動で付与できます。

> [!NOTE]
> これは配信アラートとは異なります。配信アラートは、複数のプラットフォームの公開チャンネルを監視し、配信が開始されたときにお知らせします。Twitchボットでは、自分のTwitchアカウントの認証が必要で、ボットが自分のチャットに参加します。同じTwitchチャンネルで両方を設定している場合、Twitchボットの配信開始の投稿が配信アラートの投稿に置き換わるため、重複は発生しません。

## 利用するメリット

- Twitchで配信していて、DiscordとTwitchチャットの両方で同じカスタムコマンドやSNSの案内を使える1つのボットを使いたい場合。
- サブスクやレイドが発生したときに、その場でDiscordでお祝いしたい場合。
- 手作業をせずに、サブスクライバーやVIPにDiscordのロールを付与したい場合。
- 水分補給やストレッチのチャンネルポイント報酬が、実際にチャットでメッセージを表示し、Discordにも記録されるようにしたい場合。
- モデレーターに、シャウトアウトのコマンド、レイド先の選択機能、配信をまたいで残る引用のリストを提供したい場合。

## 接続

2つのTwitch認証が必要です。どちらも**セットアップ**タブの**接続**サブタブから行います。

| 認証 | 実行者 | 付与される権限 |
| --- | --- | --- |
| ボットアカウント | ボットの所有者のみ | ボットがチャットに使うTwitchアカウント。スコープは `user:read:chat`、`user:write:chat`、`user:bot`。すべてのサーバーで共通の1つのアイデンティティ |
| 配信者のチャンネル | 配信者本人 | チャンネルのイベントへのアクセス。スコープは `channel:bot`、サブスク、ビッツ、引き換え、投票、予測、配信管理、クリップ編集、モデレーション |

ボットアカウントが存在し、チャンネルが認証され、設定が有効になっている場合に、連携は設定済みとみなされます。**ヘルス**パネルには、トランスポート（EventSub WebSocketまたは従来のIRC）、最後に受信したイベント、両方のアカウントのトークンの有効期限が表示されます。**詳細診断**では、不足しているスコープと、保存されているEventSubのサブスクリプションを確認できます。

チャンネルの接続を解除すると、認証情報が削除され、連携が無効になります。ボットアカウントの接続を解除できるのは、ボットの所有者だけです。

## Twitchでのチャットコマンド

接続済みのすべてのチャンネルでは、以下の組み込みコマンドが使えます。プレフィックスのデフォルトは `!` で、変更することもできます（最大5文字）。カスタムコマンドは、組み込みコマンドに一致しない場合にのみ検索されます。

| コマンド | 使用できる人 | 機能 |
| --- | --- | --- |
| `!ping` | 全員 | pongと返信 |
| `!uptime` | 全員 | ボットプロセスが動作している時間 |
| `!commands` | 全員 | 組み込みコマンドと有効なカスタムコマンドを一覧表示 |
| `!discord` | 全員 | 実行者にリンクされているDiscordアカウントを表示 |
| `!link` | 全員 | アカウント連携用の6桁の認証コードを生成 |
| `!rank` | 全員 | 実行者の解決済みのランクを表示 |
| `!stream` | 全員 | 配信状況、タイトル、カテゴリ、視聴者数、配信時間。または「offline」 |
| `!schedule` | 全員 | スタッフが設定したスケジュールのメッセージを投稿 |
| `!socials` | 全員 | スタッフが設定したSNSのメッセージを投稿 |
| `!quote [id]` | 全員 | ランダムな引用、または番号を指定した引用 |
| `!quote add <text> [-- author]` | モデレーター | 引用を保存。`--` の後に作者を指定することも可能 |
| `!quote remove <id>` | モデレーター | 引用を削除（`delete` でも可） |
| `!counter <name>` | 全員 | カウンターの値を表示 |
| `!counter <name> +` | モデレーター | 1つ増やす（`++` や `add` も可）。`-`、`--`、`sub` は1つ減らす。`reset` は0に設定。数値を指定するとその値に設定 |
| `!so <user>` | モデレーター | 別のTwitchチャンネルをシャウトアウト |
| `!raidtarget` | モデレーター | レイド先リストからランダムにチャンネルを提案 |

### ランク

チャッターのランクは、Twitchのバッジから決まります。高い順に、配信者、モデレーター、VIP、サブスクライバー（創設者バッジもサブスクライバーとして扱われます）、そして全員です。コマンド、カスタムコマンド、ロール同期はすべてこの順序で比較されるため、モデレーターは、VIP、サブスクライバー、全員に設定されたものをすべて実行できます。

## カスタムコマンド

カスタムコマンドは、ダッシュボードの**コマンド**、**カスタムコマンド**から、または `/twitch commands add` で追加します。名前は小文字に変換され、最大32文字で、英字、数字、ハイフン、アンダースコアを使用できます。各コマンドには、**権限**（全員、サブスクライバー、VIP、モデレーター、配信者）、0から86400までの**クールダウン（秒）**、**有効**のトグル、**応答**があります。クールダウンは視聴者ごとではなく、チャンネル全体で共有されます。使用回数は追跡され、一覧に表示されます。

ダッシュボードには**テスト引数**の入力欄とプレビューもあり、保存する前に、展開された応答を確認できます。

### 応答内のプレースホルダー

| プレースホルダー | 値 |
| --- | --- |
| `%user%` | チャッターのTwitchログイン名 |
| `%display%` | チャッターの表示名 |
| `%channel%` | あなたのTwitchチャンネルのログイン名 |
| `%args%` | コマンド名の後に入力されたすべての内容 |
| `%target%` | コマンド名の後の最初の単語 |
| `%discord%` | チャッターにリンクされたDiscordユーザーID。ない場合は空 |
| `%random:a\|b\|c%` | ランダムに選ばれた1つの選択肢 |
| `%count:name%` | 指定した名前のカウンターの現在の値 |
| `%stream%` | `!stream` が返すものと同じ概要 |

> [!EXAMPLE]
> `!hug` の応答を `%display% hugs %target%! That is hug number %count:hugs%.` とする。

## タイマー

タイマーは、スケジュールに従ってTwitchチャットにメッセージを投稿します。**コマンド**、**タイマー**、または `/twitch timers` から管理します。

| 設定 | デフォルト | 制御する内容 |
| --- | --- | --- |
| タイマー名 | | コマンドと同じ命名規則 |
| 間隔（分） | 10 | 投稿の間隔。1〜1440分 |
| 最小チャットメッセージ数 | 5 | 前回の投稿以降に必要なチャットメッセージ数。0で確認を無効化 |
| 配信中のみ | オン | 配信中の場合にのみ投稿 |
| ランダムローテーション | オフ | 順番に切り替える代わりに、ランダムな行を選択 |
| 有効 | オン | タイマーを実行するかどうか |
| メッセージ | | 1行に1メッセージ |

スケジューラーは30秒ごとにタイマーを確認します。タイマーの行では、`%channel%`、`%url%`、`%stream%`、`%count:name%`、`%random:a|b|c%` を使用できます。`/twitch timers test`（またはダッシュボードのテストボタン）を実行すると、タイマーをすぐに投稿します。

## 引用とカウンター

引用は、テキスト、任意の作者、追加した人の情報とともに保存されます。ダッシュボードの**引用**サブタブでは、スタッフが引用の追加、検索、削除を行えます。視聴者は `!quote` を使います。カウンターは、モデレーターがチャットから増やす単純な名前付きの整数です。スタッフは `/twitch commands counter-set` で値を設定し、`counter-list` で一覧を確認できます。

## イベントをDiscordに送信

**イベント**タブの**アラート**サブタブには、サブスク、レイド、チャンネルポイントの設定があります。配信開始の投稿は、**セットアップ**、**ボット設定**、**イベントの送信先**にあります。

### 配信開始と配信終了

チャンネルが配信を開始すると、ボットは**配信開始の通知先のDiscordチャンネル**に投稿します。**配信開始のメッセージ**が設定されていない場合、デフォルトの埋め込みを送信します。埋め込みには、チャンネルにリンクされた配信者名、作成者行としてのタイトル、ステータス、視聴者数、カテゴリ、プレビュー画像が含まれます。カスタムメッセージは埋め込みビルダーを通るため、完全な埋め込みやコンポーネントも使えます。チャンネルが配信を終了すると、同じチャンネルに「Offline」という短い赤い埋め込みが投稿されます。

| プレースホルダー | 値 |
| --- | --- |
| `%streamer%` | 配信者の表示名 |
| `%title%` | 配信のタイトル |
| `%game%` | カテゴリ名 |
| `%url%` | `https://twitch.tv/<channel>` |
| `%viewers%` | 現在の視聴者数 |

### サブスクとレイド

これらは、プレーンテキストのメッセージです。デフォルトのサブスクメッセージは `%display% subscribed to %channel%!` です。ギフトサブの場合は `%display% received a gifted sub on %channel%!` になります。デフォルトのレイドメッセージは `%raider% raided %channel% with %viewers% viewers!` です。

| イベント | プレースホルダー |
| --- | --- |
| サブスク | `%user%`、`%display%`、`%channel%`、`%tier%` |
| レイド | `%raider%`、`%channel%`、`%viewers%` |

各アラートにはダッシュボードの**テスト送信**ボタンがあり、**イベント履歴**の一覧では、最近のイベントとテスト送信を確認できます。

### チャンネルポイントのアクション

**チャンネルポイントのアクション**では、**報酬のタイトル**（大文字と小文字を区別せずに照合）を、**Twitchの返信**、**Discordチャンネル**と**Discordのメッセージ**、またはその両方に対応付けます。使用できるプレースホルダーは `%user%`、`%display%`、`%channel%`、`%reward%`、`%input%`（視聴者が入力した内容）、`%url%` です。

### 配信の振り返り

`/twitch events recap-channel` を使うと、配信終了時に埋め込みを受け取るチャンネルを設定できます。埋め込みには、配信時間、最大同時視聴者数、チャットメッセージ数、サブスク数、レイド数、最後のタイトルとカテゴリが含まれます。振り返りはダッシュボードでは設定できません。

## アカウント連携とロール同期

Discordメンバーを Twitch のログインに連携する方法は2つあります。

1. 自己登録：視聴者がTwitchチャットで `!link` と入力し、6桁のコードを受け取ります。その後、10分以内にDiscordで `/twitch claim <code>` を実行します。
2. スタッフによる設定：**アカウント連携**タブ、または `/twitch links add @user twitchlogin` を使います。

1つのサーバーにおいて、Discordメンバー1人につきTwitchログインは1つだけです。連携が完了すると、その視聴者の `%discord%` が入力され、ロール同期が適用されます。

ロール同期は、`/twitch rolesync add` を使って、Twitchのランクを Discord のロールに対応付けます。連携済みの視聴者がチャットでメッセージを送信するたびに、ボットは、その人のランクが対応付けのランク以上であればロールを付与し、下回っていれば削除します。ロール同期はスラッシュコマンドからのみ利用できます。

## ライブツール

**イベント**タブの**ライブツール**サブタブには、チャンネルの認証を使う配信操作があります。ボットとしてチャットにメッセージを送信する、配信マーカーを作成する、クリップを作成する、投票を開始する（選択肢は1行に1つ、デフォルトは60秒）、タイムアウト（デフォルトは600秒）、BAN、BAN解除、メッセージIDを指定した削除を行えます。`/twitch stream-info` と `/twitch clip` を使うと、Discordからタイトル、カテゴリ、クリップの操作ができます。

## 設定

**セットアップ**、**ボット設定**にある項目です。

| 設定 | デフォルト | 制御する内容 |
| --- | --- | --- |
| コマンドのプレフィックス | `!` | Twitchチャットのコマンドのプレフィックス。最大5文字 |
| 言語の上書き | サーバーのデフォルト | ボットのチャット返信に使うBCP-47タグ（例：`de-DE`） |
| このサーバーでTwitchチャットボットを有効化 | オン | メインスイッチ。オフにしても設定は保持されます |
| チャットイベントにEventSubを使用 | オン | EventSubでチャットとイベントを受信。オフの場合、チャットコマンドは実行されません |
| 配信開始の通知先のDiscordチャンネル | なし | 配信開始と配信終了の投稿先 |
| 配信開始のメッセージ | デフォルトの埋め込み | 配信開始のプレースホルダーを使ったカスタムテンプレート |

**イベント**、**アラート**では、**サブスクの通知先Discordチャンネル**、**サブスクのメッセージ**、**レイドの通知先Discordチャンネル**、**レイドのメッセージ**、チャンネルポイントのアクション一覧を設定します。

## セットアップの手順

1. ダッシュボードで**Twitchボット**を開きます。最初に、ボットの所有者が**ボットアカウント**を接続している必要があります。**接続**サブタブに、アカウントが存在するかどうかが表示されます。
2. **チャンネルを接続**をクリックし、自分のTwitchアカウントで認証します。
3. **ボット設定**で、プレフィックスを設定し、**このサーバーでTwitchチャットボットを有効化**をオンにします。**配信開始の通知先Discordチャンネル**を選び、保存します。
4. **コマンド**で、いくつかのカスタムコマンドとSNSのタイマーを追加します。**テスト引数**とプレビューを使って、プレースホルダーを確認します。
5. **イベント**、**アラート**で、サブスクとレイドのチャンネルを選択し、それぞれで**テスト送信**を押します。
6. Twitchチャットで `!ping` と入力して、ボットが反応することを確認します。次に、`!link` と `/twitch claim` を使って、自分自身を連携します。
7. 必要に応じて `/twitch rolesync add Subscriber @Subs` を実行すると、連携済みのサブスクライバーにロールが付与されます。

## ヒントと注意点

- ボットアカウントは、ボット上のすべてのサーバーで共有されます。誰も接続していない場合、どのように設定してもチャットの返信は送信できません。
- チャットコマンドは、**チャットイベントにEventSubを使用**がオンの場合にのみ動作します。ヘルスパネルに従来のIRCと表示される場合は、オンに戻してください。
- 配信状態も1分ごとにポーリングされるため、配信開始の投稿が実際の開始より最大1分遅れることがあります。
- カスタムコマンドのクールダウンは、視聴者ごとではなくチャンネルごとです。30秒のクールダウンは、全員が30秒に1回だけ使えることを意味します。
- ロール同期は、連携済みの視聴者がチャットで発言したときに実行され、スケジュールでは実行されません。チャットで一度も発言しないサブスクライバーはロールを受け取れず、サブスクが切れた人は、再度発言するまでロールを保持します。
- ロールの変更には、ボットのロールが同期するロールより上にあり、かつロールの管理権限が必要です。
- `rolesync` に不明なランクを指定すると、サブスクライバーとして扱われます。`commands add` に不明な権限を指定すると、全員として扱われます。
- 連携コードは10分で期限切れになります。新しいコードを生成すると、古いコードは無効になります。
- ライブツールによるタイムアウトとBANは、チャンネルのモデレーションのスコープを使うため、Twitchでは認証されたアカウントによる操作として表示されます。
- 言語の上書きは、Twitchチャットの返信にのみ影響します。Discordの返信は、サーバーのロケールのままです。
