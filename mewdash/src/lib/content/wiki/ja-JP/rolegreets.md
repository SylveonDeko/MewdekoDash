## 概要

ロールの挨拶は、メンバーがロールを受け取ったときにBotが投稿するメッセージです。スタッフはロールとチャンネルを選び、メッセージを書きます。それ以降、そのロールがメンバーに追加されるたびに、Botはそのチャンネルにメッセージを投稿します。デフォルトのメッセージは `Welcome %user.mention%!` です。

メッセージは埋め込みパーサーを通るため、プレーンテキスト、完全な埋め込み、またはダッシュボードのエディターで作成したボタン付きの埋め込みのいずれにもできます。プレースホルダーは、メンバーの名前、アバター、参加日、サーバーの詳細を埋め込みます。各挨拶はWebhookを通じて、独自の名前とアバターで投稿でき、設定した秒数の後に自分自身を削除することもできます。

挨拶はロールごと、チャンネルごとに設定されます。1つのロールには最大10件の挨拶を設定でき、それぞれ別のチャンネルや別のメッセージにできます。挨拶は削除せずに無効にすることもできます。

## 使う理由

- 認証を通過して認証済みロールを受け取ったメンバーにだけ、メインチャットへのウェルカムメッセージを送りたい。
- ブーストのロールが付与されたら、感謝のチャンネルでブースターを発表したい。
- ゲームのロールを選んだ人に、そのゲームのチャンネルの場所を伝えたい。
- モデレーターのロールが付与されたら、スタッフ用チャンネルにスタッフのオンボーディングのチェックリストを投稿したい。
- ギブアウェイやイベントのロールを得たメンバーに、そのイベントのルールを案内したい。

## 挨拶が発動する仕組み

Botはメンバーの更新を監視し、ロールの変化を前後で比較します。追加されたロールごとに、そのロールの挨拶を探し、それぞれを投稿します。削除されたロールでは何も発動しません。**Botにも挨拶** がその挨拶でオンになっていない限り、Botはスキップされます。無効な挨拶は無視されます。

チャンネルが存在しなくなった場合、挨拶は自分自身を削除します。Webhookの挨拶が、Webhookの削除やBotの権限の喪失によって失敗した場合は、挨拶を削除するのではなく無効にするため、修正してから再度有効にできます。

Webhookを設定している場合、メッセージはWebhookの名前とアバターで送信されます。自動削除は引き続き動作します。Botは送信したメッセージを取得し、指定の遅延の後に削除します。

## プレースホルダー

ロールの挨拶では、ユーザー、サーバー、Botのプレースホルダーのグループを使用できます。チャンネルのプレースホルダーは使用できません。

| プレースホルダー | 値 |
| --- | --- |
| `%user.mention%`、`%user%` | ロールを得たメンバーへのメンション |
| `%user.name%`、`%username%` | そのユーザー名 |
| `%user.fullname%` | タグ付きのユーザー名 |
| `%user.avatar%` | アバターのURL |
| `%user.banner%` | バナーのURL |
| `%user.id%` | ユーザーID |
| `%user.created_date%`、`%user.created_time%` | アカウントの作成日と時刻 |
| `%user.joined_date%`、`%user.joined_time%` | サーバーへの参加日と時刻 |
| `%server.name%`、`%server%` | サーバー名 |
| `%server.members%` | キャッシュされたメンバー数 |
| `%server.icon%`、`%server.banner%` | サーバーのアイコンとバナーのURL |
| `%server.boostlevel%`、`%server.boostcount%` | ブーストのティアと数 |
| `%server.time%`、`%time.day%` | サーバーの時刻と曜日 |
| `%bot.name%`、`%bot.avatar%`、`%bot.id%` | Botの名前、アバター、ID |

サーバーで招待の追跡が有効な場合、マルチ挨拶の招待者と招待のプレースホルダー（`%inviter.username%`、`%inviter.mention%`、`%inviter.count%`、`%invite.code%`、`%invite.label%` など）も、メンバーの招待者から入力されます。招待者が分からない場合、これらは `Unknown` と表示されます。

> [!EXAMPLE]
> `Welcome to the team, %user.mention%! You are member number %server.members%. Check the pins in this channel first.`

## 設定

ロールの挨拶ページの上部には **新しいロールの挨拶を追加** のフォームがあり、その下に各挨拶のカードが並びます。

| 設定 | デフォルト | 制御する内容 |
| --- | --- | --- |
| Role | なし | 挨拶を発動させるロール |
| Channel | なし | メッセージを投稿する場所 |
| Message | `Welcome %user.mention%!` | 埋め込みエディターを開きます |
| Delete Time (seconds, 0 for never) | 0 | 自動削除までの遅延 |
| Webhook URL (optional) | なし | Botではなく、Webhookを通じて投稿します |
| Greet Bots | オフ | そのロールを得たBotアカウントにも挨拶します |
| Enabled | オン | カード上のスイッチ。無効な挨拶は何もしません |

## セットアップの手順

1. ダッシュボードで **ロールあいさつ** を開きます。
2. **新しいロールの挨拶を追加** で **ロール** と **チャンネル** を選び、**ロールの挨拶を追加** をクリックします。
3. 新しいカードで、メッセージのボックスをクリックしてエディターを開き、上記のプレースホルダーを使って挨拶を書きます。
4. チャンネルを整理しておきたい場合は **Delete Time** を設定します。カスタムの名前とアバターを使いたい場合は **Webhook URL** を貼り付けます。
5. カードを保存し、テスト用のアカウントにロールを付与して、チャンネルを確認します。
6. カードのスイッチで挨拶を一時停止したり、削除ボタンで削除したりできます。

> [!TIP]
> Discordでは、`rolegreetmessage 1` をテキストなしで実行すると、現在のメッセージが表示され、自分の情報で描画する **プレビュー** ボタンが表示されます。

## コマンド

サーバーのプレフィックス（変更していない場合は `.`）を付けて実行します。挨拶には `rolegreetlist` での位置に応じて番号が付けられます。

| コマンド | エイリアス | 必要な権限 | 用途 |
| --- | --- | --- | --- |
| `rolegreetadd <@role> [#channel]` | `rgadd`, `rga` | 管理者 | ロールの挨拶を追加します。チャンネルを指定しない場合は現在のチャンネルに追加されます |
| `rolegreetlist` | `rglist`, `rgl` | 管理者 | すべての挨拶と設定をページごとに表示します |
| `rolegreetmessage <id> [message]` | `rgmsg`, `rgm` | 管理者 | メッセージを設定します。テキストを指定しない場合は表示してプレビューします |
| `rolegreetremove <id or @role>` | `rgrem`, `rgrm`, `rgr` | 管理者 | 番号で1件の挨拶を削除します。または、確認の後にそのロールのすべての挨拶を削除します |
| `rolegreetdelete <id> <time or seconds>` | `rgdel`, `rgd` | 管理者 | 自動削除の遅延。例：`30s` または `30`。`0` で無効になります |
| `rolegreetdisable <id> <true/false>` | `rgdisable`, `rgdis` | 管理者 | 挨拶を無効にするか、再び有効にします |
| `rolegreetgreetbots <id> <true/false>` | `rolegreetbots`, `rggb` | 管理者 | Botが挨拶を発動させるかどうか |
| `rolegreetwebhook <id> [name] [avatar url]` | `rgwebhook`, `rghook`, `rgh` | 管理者 | 挨拶のチャンネルに、指定した名前とアバターでWebhookを作成します。名前を指定しなければ解除します |

スラッシュコマンドは `/rolegreets` の下にあり、同じ操作を提供します。`add`、`remove`、`removerole`、`message`、`delete`、`disable`、`greetbots`、`webhook`、`list` です。

## ヒントと注意点

- Botには、挨拶のチャンネルでの「メッセージを送信」と「リンクの埋め込み」の権限が必要です。自動削除には「メッセージの管理」が必要です。`rolegreetwebhook` でWebhookを作成するには「ウェブフックの管理」が必要です。
- 上限は、サーバー全体ではなく、ロールごとに10件です。追加コマンドは11件目を拒否します。
- 挨拶は、リアクションロール、レベル報酬、他のBotによるものも含め、ロールが追加されるたびに発動します。そのため、頻繁に付与・削除されるロールはチャンネルを荒らすことがあります。
- 埋め込みパーサーが何も生成しない場合（例：空白のみのメッセージ）、何も送信されません。
- `rolegreetremove` にロールを指定すると、はい・いいえの確認の後に、そのロールのすべての挨拶が削除されます。番号を指定すると、その1件だけがすぐに削除されます。
- 挨拶を削除すると番号がずれます。番号を指定して編集する前に、`rolegreetlist` をもう一度実行してください。
- ロールの挨拶は、MultiGreetsページのサーバー参加時の挨拶とは別のものです。サーバーへの参加にはMultiGreetsを使い、その後に得たロールにはロールの挨拶を使ってください。
