## 概要

埋め込みビルダーは、Discordのメッセージを視覚的に編集できるエディターです。タイトル、説明、色、フィールド、画像、任意のボタンやセレクトメニューを入力し、ライブプレビューを確認すると、最後にJSONのブロックが得られます。そのJSONは、Botの汎用的なメッセージ形式です。このJSONを `say` に貼り付けて投稿したり、名前付きのテンプレートとして保存したり、カスタムメッセージを受け付ける機能（挨拶、チャットトリガー、AFKの返信、フィードの更新、giveawayの当選DMなど）に入れたりできます。

テンプレートは個人用にできます。その場合は、すべてのサーバーであなただけが見られます。また、サーバーと共有することもできます。その場合は、どのスタッフでも読み込めます。ダッシュボードでは、完成したメッセージをチャンネルに直接送信することもできます。カスタムの名前とアバターを付けたWebhookを通して送ることもでき、その設定はペルソナと呼ばれます。

メンバーがビルダーを操作することはありません。メンバーが目にするのは、そこで作られたメッセージだけです。

## 使う理由

- 書式の整ったルールや案内の投稿を作成し、後から `edit` で更新したい。
- ウェルカムメッセージを一度デザインし、そのJSONを挨拶に貼り付けたい。
- スタッフが統一感のあるお知らせを投稿できるように、アナウンス用のテンプレートを保管したい。
- チャットトリガーを実行するボタンや、トリガーを通じてロールを付与するセレクトメニューを追加したい。
- メンバーにWebhookへのアクセス権を与えることなく、独自の名前とアバターで「サーバーニュース」として投稿したい。

## JSONの形式

パーサーは、テキスト内で最初に現れる `{` を探し、対応する `}` までを読み取ります。JSONのオブジェクトがない場合、または解析できない場合は、テキスト全体がプレーンテキストとして扱われます。プロパティ名は大文字と小文字を区別しません。

| キー | 型 | 意味 |
| --- | --- | --- |
| `content` | 文字列 | 埋め込みの上に表示されるプレーンテキスト |
| `embed` | オブジェクト | 単一の埋め込み。存在する場合、`embeds` は無視されます |
| `embeds` | 配列 | 最大10個の埋め込みオブジェクト |
| `components` | 配列 | ボタンとセレクトメニュー |

埋め込みのオブジェクトには、`title`、`description`、`url`、`color`、`author`（`name`、`url`、`icon_url`）、`footer`（`text`、`icon_url`）、`thumbnail`（`url`）、`image`（`url`）、`fields`（`name`、`value`、`inline` を持つ配列）を指定できます。`color` は数値、または `#5865F2` のような文字列で指定できます。フィールド名は256文字、値は1024文字で切り詰められます。完全な絶対アドレスではないURLは、メッセージ全体の失敗を避けるために破棄されます。`timestamp` キーは受け付けられますが、表示はされません。

コンポーネントには、どの行に配置するかを示す `row`、`displayName`、そしてリンクボタンの場合は `url`、チャットトリガーに紐づくボタンの場合は `id` のいずれかを指定します。`style` は、Discordの4種類のボタンのスタイルに対応する1から4までの値です。`emoji` は任意です。セレクトメニューにする場合は `isSelect` を true に設定し、`options`（それぞれ `id`、`name`、`description`、`emoji` を持つ）と、0から25までの値の `minOptions` と `maxOptions` を指定します。ルールに違反するコンポーネントは、無効化された赤いボタンとして表示され、そのラベルにエラーが表示されるため、Discord上で問題を確認できます。

> [!EXAMPLE]
> `{"content": "Welcome %user.mention%!", "embeds": [{"title": "Read the rules", "description": "See %channel.mention%", "color": "#57F287"}]}`

### プレースホルダー

埋め込みビルダーの **%** ボタンを押すと、プレースホルダーページのプレースホルダー（ユーザー、サーバー、チャンネル、Bot、時刻など）が挿入されます。ダッシュボードは、プレースホルダーを置き換えません。**送信** タブから送信されるメッセージは、そのままの文字列として送られます。Botは、JSONがコマンドや機能を通過するときにプレースホルダーを置き換えます。たとえば、`say`、`embedpreview`、挨拶、トリガーなどです。各機能は、一般的なプレースホルダーに加えて独自のセットを追加します。たとえば `%afk.message%` や `%giveawayitem%` などです。

## テンプレート

テンプレートは、名前とJSONの組み合わせです。スコープは2種類あります。

| スコープ | 閲覧できる人 | 作成方法 |
| --- | --- | --- |
| 個人 | あなただけ。どのサーバーでもDMでも閲覧できます | `embedsave`、またはダッシュボードで共有をオフにして **保存** |
| サーバー共有 | そのサーバーでアクセス権を持つ全員 | `guildembedsave`（メッセージの管理）、またはダッシュボードで **Share with everyone in (server)** をオンにして **保存** |

名前は、同じスコープ内で一意である必要があります。`embedpreview <name>` は、まずあなたの個人テンプレートを探し、次にサーバーの共有テンプレートを探します。プレースホルダーを置き換えたうえで、現在のチャンネルに投稿します。

一部のコマンドは、生のJSONの代わりにテンプレートの参照を受け付けます。メッセージとして `{template:name}` または `{t:name}` と書きます。`multigreetmessage` がこれに対応しています。解決されたJSONが保存され、参照は保存されません。そのため、後からテンプレートを編集しても、設定済みの挨拶は更新されません。

## ダッシュボードのページ

ページのタイトルは **Discord 埋め込みビルダー** で、6つのタブがあります。また、右側には **ライブプレビュー** と **問題** パネルがあります。ヘッダーには **元に戻す**、**やり直し**、**編集を取り消す**、**JSON をコピー** があります。

| タブ | 操作内容 |
| --- | --- |
| Templates | テンプレートのギャラリーから出発点を選ぶか、**ゼロから作成** を選択します |
| Editor | **メッセージの内容** と最大10個の埋め込み。各埋め込みには、タイトル、説明、URL、色、作成者、フッター、最大25個のフィールド、サムネイル、画像があり、文字数のカウンターが付いています。 |
| Components | 最大5行、25個のコンポーネント。ボタン（テキスト、スタイル、絵文字、URLまたはトリガー）とセレクトメニュー（プレースホルダー、トリガーと紐づけたオプション）を追加します。 |
| JSON | 生のペイロードです。**ビルダーから更新** でビルダーから再生成し、**ビルダーに適用** で貼り付けたJSONを読み込みます。完全なペイロードでも、単一の埋め込みオブジェクトでも構いません。 |
| Saved | 名前と共有のチェックボックスを指定して **現在の埋め込みを保存** を実行します。その後、**Shared in (server)** と **My Embeds** の一覧が表示され、**読み込み** と **削除** を使えます。 |
| Send | チャンネルを選択し、そのチャンネルでの権限を確認します。任意で、ペルソナまたはカスタムの名前とアバターURLを使ってWebhook経由で送信できます。その後 **メッセージを送信** を押します。 |

### 送信とペルソナ

**送信** タブには、あなたとBotの両方が投稿できるチャンネルだけが表示されます。埋め込みの送信には、両者に「リンクの埋め込み」権限が必要です。あなたに「@everyone、@here、全ロールにメンション」権限がない場合、everyone、here、ロールへのメンションは削除され、タブに警告が表示されます。

Webhookでの送信には、あなたとBotの両方に「ウェブフックの管理」権限が必要です。**ペルソナ** とは、保存された名前とアバターのことで、個人用またはサーバーと共有されたものがあります。**管理** を押すと、ペルソナの一覧が開きます。アップロードした画像を持つペルソナには、チャンネルごとに専用のWebhookが作られるため、1つのチャンネルに置けるのは最大15個までです。**カスタム** オプションでは、表示名とアバターのリンクを直接入力します。すべての送信は、ダッシュボードの監査ログに記録されます。

他のダッシュボードのページ（挨拶、トリガーなど）の中からも、同じビルダーをポップアップで開けます。その場合は **エディター**、**コンポーネント**、**JSON**、**保存しました** のタブのみが表示されます。

## 設定

ビルダーにサーバーの設定はありません。すべての設定はメッセージごと、またはテンプレートごとです。

## セットアップの手順

1. ダッシュボードで **埋め込み** を開き、テンプレートを選ぶか **ゼロから作成** を選択します。
2. **エディター** で、本文を書き、埋め込みを入力します。Discordが拒否しそうな内容は **問題** パネルで確認します。
3. 必要であれば **コンポーネント** でボタンやメニューを追加します。それぞれをチャットトリガーまたはURLに紐づけます。
4. **保存しました** に移動して名前を付け、スタッフに使ってほしい場合は **Share with everyone in (server)** をオンにして、**保存** を押します。
5. 今すぐ投稿するには **送信** を開き、チャンネルを選んで **メッセージを送信** を押します。別の場所で使うには、**JSON をコピー** を押して、もう一方の機能に貼り付けます。
6. Discordでは、`embedpreview <name>` を実行すると、プレースホルダーを埋めた保存済みのテンプレートを投稿できます。

## コマンド

サーバーのプレフィックス（変更していない場合は `.`）を付けて実行します。

| コマンド | エイリアス | 必要な権限 | 用途 |
| --- | --- | --- | --- |
| `say [#channel] <text or JSON>` | | メッセージの管理 | テキストまたは埋め込みのJSONをBotとして投稿します。プレースホルダーは置き換えられます。`.txt` の添付ファイルからメッセージを読み込むこともできます。 |
| `edit #channel <message id> <text or JSON>` | | メッセージの管理 | Botが送信したメッセージの内容を置き換えます |
| `embedsave <name> <JSON>` | `esave` | なし | 個人用のテンプレートを保存します |
| `embedlist` | `elist` | なし | あなたの個人用テンプレートを一覧表示します |
| `embeddelete <name>` | `edel`, `edelete` | なし | あなたの個人用テンプレートを1つ削除します |
| `guildembedsave <name> <JSON>` | `gesave`, `gembedsave` | メッセージの管理 | このサーバーと共有するテンプレートを保存します |
| `guildembedlist` | `gelist`, `gembedlist` | なし | サーバーの共有テンプレートを一覧表示します |
| `guildembeddelete <name>` | `gedel`, `gembeddelete` | メッセージの管理 | 共有テンプレートを削除します |
| `embedpreview <name>` | `epreview`, `eprev` | なし | 保存されたテンプレートを現在のチャンネルに投稿します |

## ヒントと注意点

- `say` は、あなた自身のメンションの権限を反映します。「@everyone、@here、全ロールにメンション」権限がない場合、Botはあなたのために全員やロールにメンションしません。
- タイトルだけで他に何もない埋め込みも送信されますが、ダッシュボードでは、タイトル、説明、フィールド、またはコンテンツのいずれかが入力されるまで、コピーも送信もできません。
- トリガーに紐づくボタンは、そのトリガーIDを参照するサーバーでのみ動作します。共有テンプレートを別のサーバーで読み込むと、それらのボタンは動かなくなります。
- 不正な画像、サムネイル、作成者、フッターのURLは、警告なしに破棄されます。画像が表示されない場合は、URLが `https://` で始まっているか確認してください。
- Discordの制限では、1つのメッセージに埋め込みは10個まで、埋め込みごとのフィールドは25個まで、コンポーネントの行は5行まで、1行のボタンは5個までです。ビルダーも同じ数値を適用します。
- ペルソナを削除しても、そのペルソナが各チャンネルに作成したWebhookは削除されません。必要であれば、チャンネルの連携設定から手動で削除してください。
