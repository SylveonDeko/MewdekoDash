## 概要

メンバーは、任意のメッセージを添えて `afk` を実行します。それ以降、誰かがそのメンバーにメンションすると、ボットはそのチャンネルで、AFKメッセージと離席している時間を返信します。メンバーが戻ると、ステータスは解除され、「おかえりなさい」という短い通知が投稿されます。この通知は5秒後に削除され、ニックネームも元に戻ります。

離席中は、ボットがメンバーの名前を `[AFK] name` に変更しようとします。Discordのニックネームの上限に収まるように切り詰められるため、メンバーリストでステータスが見えるようになります。

メッセージを付けずに `afk` を実行すると、切り替えになります。離席中でなければ、空のメッセージでAFKをオンにし、離席中であればオフにします。

## 利用するメリット

- 活発なサーバーでは、「brb」と言った後も、それに気づかなかった人から何度もメンションされることがなくなります。
- スタッフは、誰が近くにいて、誰がいないかをひと目で確認できます。
- 時間指定のAFKは、「2時間後に戻ります」というような場合に、誰かがステータスを解除し忘れることを防ぎます。

## ステータスの終わり方

**AFKの種類** によって、ボットが「戻った」と判断する条件が決まります。このページで最も重要な設定です。

| 種類 | ステータスが解除される条件 |
| --- | --- |
| Self disable | メンバーが再度 `afk` を実行したとき、またはスタッフがステータスを削除したときのみ。自動的には解除されません。 |
| On message | メンバーがサーバー内のどこかでメッセージを送信したとき。 |
| On type | メンバーがどのチャンネルでも入力中になったとき。 |
| Either | メッセージまたは入力中のどちらか早い方。 |

**AFKタイムアウト** は、ステータスを設定した時点から数える猶予期間です。その期間内は、入力やメッセージの送信ではステータスは解除されません。そのため、「afk、brb」というメッセージ自体によってAFKがすぐに終わってしまうことを防げます。デフォルトは0で、猶予期間はありません。`afktimeout` で設定するか、ダッシュボードの **詳細設定** タブで設定します。

時間指定のAFKは異なります。種類に関係なく、タイマーが切れるまで続きます。その間に発言しても終わりません。タイマーが切れると、チャンネルへの通知なしでステータスが解除され、ニックネームが元に戻ります。

投稿から5分以内にメッセージを編集した場合も、新しいメッセージを送信したのと同じ扱いになります。

## メンションへの返信

離席中のメンバーがメンションされると、ボットはメッセージ内のメンションされたユーザーを最大5人まで確認します。ボットとメンバー自身へのメンションは無視され、コマンドのプレフィックスで始まるメッセージも無視されます。無効化されたチャンネルもスキップされます。離席中のメンバーごとに、ボットは返信を投稿します。

デフォルトでは、返信は埋め込みです。作者の行には「user is currently away」と表示され、アバターが付きます。説明にはそのメンバーのAFKメッセージが表示され、フッターには離席していた時間が表示されます。ボットが招待ボタンを表示するように設定されている場合は、ボタンも付きます。

独自のメッセージまたは埋め込みに置き換えるには、`customafkmessage`、またはダッシュボードの **カスタム AFK 埋め込みメッセージ** エディターを使います。テキストは埋め込みパーサーで処理されるため、埋め込みビルダーで作成できるものはすべて使えます。デフォルトに戻すには `-` を設定します。

### プレースホルダー

これらは、カスタムのAFKメッセージ内で置き換えられます。プレースホルダーのページにある一般的なプレースホルダーは使用できません。このセットのみが使えます。

| プレースホルダー | 値 |
| --- | --- |
| `%afk.message%` | AFKメッセージ。メンションは無効化され、最大長に切り詰められます。 |
| `%afk.user%` | 離席中のメンバーのユーザー名 |
| `%afk.user.mention%` | 離席中のメンバーへのメンション |
| `%afk.user.avatar%` | 離席中のメンバーのアバターのURL |
| `%afk.user.id%` | 離席中のメンバーのユーザーID |
| `%afk.triggeruser%` | メンションした人のユーザー名 |
| `%afk.triggeruser.mention%` | メンションした人へのメンション |
| `%afk.triggeruser.avatar%` | メンションした人のアバターのURL |
| `%afk.triggeruser.id%` | メンションした人のユーザーID |
| `%afk.time%` | 離席していた時間を「2 hours」のような言葉で表したもの |

> [!EXAMPLE]
> プレーンテキストの返信の例：`%afk.user.mention% is away (%afk.time%): %afk.message%`

## 設定

これらはすべてAFKのページにあり、**基本設定** タブと **詳細設定** タブに分かれています。

| 設定 | デフォルト | 内容 |
| --- | --- | --- |
| Auto-deletion time | 0（削除しない） | メンションへのボットの返信が自動で削除されるまでの秒数 |
| Max message length | 128 | メンバーが設定できるAFKメッセージの最大長（1〜4096）。超えるものは拒否されます。 |
| AFK removal type | Self disable | 上の4つの種類のいずれか |
| AFK timeout | 0（なし） | AFKを設定してから猶予期間。最大2時間。 |
| Disabled channels | なし | 離席中のメンバーをメンションしても返信しないチャンネル |
| Custom AFK embed | デフォルトの埋め込み | 上のプレースホルダーを使った独自の返信 |

> [!TIP]
> 自動削除は30秒程度に設定することをおすすめします。メンションした人は返信を見られ、チャンネルに古いAFKの通知が溜まりません。

**ユーザー管理** タブには、現在離席中のすべてのメンバーが一覧表示され、スタッフは1人または複数人のステータスをまとめて解除できます。

## セットアップの流れ

1. ダッシュボードで **AFKシステム** を開きます。
2. **AFK removal type** を選びます。「On message」が最も安全なデフォルトで、「Either」が最も便利です。
3. **Auto-deletion time** を30に設定します。長いステータスを使いたい場合を除き、**Max message length** は128のままにします。
4. **詳細設定** で、ボットのコマンド用チャンネルとお知らせ用チャンネルを **Disabled channels** に追加します。
5. 必要に応じて、埋め込みエディターで上のプレースホルダーを使い、独自の返信を作成します。
6. テストします。`afk testing` を実行し、別のアカウントから自分をメンションし、その後メッセージを送信してステータスが解除されることを確認します。

## コマンド

これらのコマンドは、サーバーのプレフィックス（変更していない場合は `.`）で実行します。

| コマンド | エイリアス | 必要な権限 | 目的 |
| --- | --- | --- | --- |
| `afk [message]` | | なし | AFKメッセージを設定、またはメッセージなしでAFKをオン・オフ |
| `timedafk <time> <message>` | `tafk` | なし | 自動的に終わるAFK（例：`timedafk 2h dinner`） |
| `getactiveafks` | `activeafks` | なし | 現在AFKのすべてのメンバーを一覧表示 |
| `afkview [@user]` | `viewafk` | メッセージの管理 | 誰かの現在のAFKメッセージを表示 |
| `afkremove @user...` | `afkrm` | メッセージの管理 | 1人以上のメンバーのステータスを解除 |
| `afkdel [seconds]` | `afkdelete` | サーバー管理 | 返信の自動削除を表示または設定 |
| `afklength <number>` | `maxafklength` | 管理者 | AFKメッセージの最大長を制限 |
| `afktype <type>` | | 管理者 | `selfdisable`、`onmessage`、`ontype`、または `either` |
| `afktimeout <time>` | | 管理者 | 猶予期間を設定（例：`30s`） |
| `afkdisable #channel...` | | チャンネルの管理 | 返信しないリストにチャンネルを追加 |
| `afkundisable #channel...` | | チャンネルの管理 | 返信しないリストからチャンネルを削除 |
| `afkdisabledlist` | | チャンネルの管理 | 返信しないリストを表示 |
| `customafkmessage <text>` | `afkmessage` | 管理者 | カスタムの返信を設定、または `-` でリセット |

## ヒントと注意点

- 自分だけのステータスを解除するコマンドはありません。引数なしで `afk` を再度実行するか、種類の条件によって解除されるのを待ってください。
- ニックネームの変更には、ボットのロールがメンバーの最上位ロールより上にあり、「ニックネームの管理」権限が必要です。サーバーオーナーのニックネームは、ボットが変更することはできません。そのため、オーナーは名前を保持しますが、ステータス機能は動作します。
- AFKサービスは、ボットの起動後しばらくしてからキャッシュを読み込みます。それまでは、コマンドが「AFK is still starting」と返答します。
- 返信内でAFKメッセージのメンションは無効化されるため、メンバーはステータスを使って、ロールや全員にpingを送ることはできません。
