## 概要

ボットはすでにメッセージを集計していました。アクティビティ統計では、ボイス時間、ゲームやアプリ、1時間ごとのメンバーとステータスのスナップショットを追加し、任意の期間について確認できるようにします。期間は、直近1日、1週間、1か月、最大90日、または全期間から選択できます。すべてのデータは、ダッシュボード、コマンド、グラフ、CSV、ステータスロール、ライブボード、レポート、統計チャンネルで利用できます。

## 追跡されるデータ

| データ | 方法 |
| --- | --- |
| メッセージ | カウントされたすべてのメッセージを、タイムスタンプ付きで90日間保存。メンバーとチャンネルごとの累計も保存 |
| ボイス時間 | メンバーとチャンネルごとのセグメント。移動、ミュート、スピーカーオフ、配信の開始、カメラのオンのたびに分割され、90日間保存。累計も保存 |
| ゲームとアプリ | メンバーとアクティビティ（プレイ中、配信中、視聴中、鑑賞中、競技中）ごとのセグメントを90日間保存。累計も保存。デフォルトではオフ |
| スナップショット | メンバー数、人間、ボット、オンライン、退席中、取り込み中、オフライン、ボイス参加中の人数を1時間ごとに記録し、90日間保存 |
| 参加と退出 | 参加と退出のすべてをタイムスタンプとともに記録 |

90日までの期間では、タイムスタンプ付きのデータを参照します。**全期間**では累計を参照するため、90日分のデータが古くなって消えた後も機能し続けます。

## ゲームとアプリ

ゲームの追跡は、最も負荷が高い機能であるため、オンにするまではオフのままです。オンにすると、ボットはすべてのメンバーの在席状況を監視し、各ゲーム、配信、Spotifyのセッション、視聴中のアプリが続いた時間を記録します。

- **アクティビティを検証**（デフォルトでオン）は、Discord自身が証明したアクティビティのみをカウントします。対象は、登録されたアプリケーションIDを持つもの、Spotify、および配信です。改変されたクライアントは何でもプレイしていると主張できるため、これがオンの間は、名前を付けただけの通常のアクティビティは無視されます。
- **アクティビティフィルター**は、ゲーム名の一覧で、**ブラックリスト**（一覧のゲームを無視）または**ホワイトリスト**（一覧のゲームのみをカウント）のいずれかとして動作します。
- カスタムステータスは、一切カウントされません。

## 設定

| 設定 | デフォルト | 制御する内容 |
| --- | --- | --- |
| デフォルトの期間 | 14日 | 期間を指定しない場合に、コマンドとページで使われる期間 |
| メッセージのクールダウン | 0 | 1人のメンバーのカウントされるメッセージの間隔（秒）。スパムで数値が膨らむのを防ぎます |
| ボイス時間を追跡 | オン | ボイスのセグメントを記録するかどうか |
| 1時間ごとのスナップショット | オン | メンバー数とステータスを1時間ごとに記録するかどうか |
| ボットをカウント | オフ | ボットのアカウントを含めるかどうか |
| ゲームとアプリを追跡 | オフ | 在席状況のアクティビティを記録するかどうか |
| アクティビティを検証 | オン | Discordが証明したアクティビティのみをカウント |
| カウントしないボイス状態 | なし | 自分のミュート、自分のスピーカーオフ、サーバーのミュート、サーバーのスピーカーオフ、AFKチャンネル、一人でいる、配信中、カメラオンのいずれか |
| 無視するチャンネル、ロール、メンバー | なし | これらからのものは一切カウントされません |

## プライバシー

どのメンバーも `statsprivacy`（または `/serverstats privacy`）を実行すると、オプトアウトできます。そのメンバーが、ボットと共有しているすべてのサーバーで、記録されたメッセージ、ボイス時間、ゲーム時間は削除されます。再度オプトインするまで、新しいデータは一切記録されません。サーバーの管理者もこれを上書きすることはできません。

## コマンド

以下のコマンドは、サーバーのプレフィックス（変更していない場合は `.`）を付けて実行します。すべてのコマンドは `/serverstats` の下にもあります。`days` は期間です。0は全期間を意味し、省略するとサーバーのデフォルトを使います。

| コマンド | エイリアス | 必要な権限 | 用途 |
| --- | --- | --- | --- |
| `serveractivity [days]` | `sstats` | なし | サーバーの概要 |
| `useractivity [@user] [days]` | `ustats`, `mystats` | なし | メンバーのメッセージ、ボイス時間、順位、累計、上位のチャンネルとゲーム |
| `channelactivity [#channel] [days]` | `cstats` | なし | チャンネルのアクティビティと上位メンバー |
| `activitytop [Messages/Voice/Activity] [days] [@role]` | `topchatters`, `topvoice` | なし | メンバーをランク付け |
| `activitytopchannels [Messages/Voice] [days]` | `topchannels` | なし | チャンネルをランク付け |
| `topgames [days]` | `games` | なし | 最もプレイされたゲームとアプリ |
| `whoplays <game>` | | なし | 現在そのゲームをプレイしている人と、最もプレイした人 |
| `activitychart [Messages/Voice/Members/Status/Joins/Leaves/Growth/InVoice/Activities] [days]` | `graph` | なし | グラフの画像 |
| `activityexport [Messages/Voice/Activity] [days]` | | サーバー管理 | CSVのランキング |
| `statssettings` | | サーバー管理 | 設定を表示 |
| `statslookback <days>`、`statscooldown <seconds>` | `lookback` | サーバー管理 | デフォルトの期間とメッセージのクールダウン |
| `statstrackvoice`、`statstracksnapshots`、`statscountbots`、`statstrackactivities`、`statsverifyactivities` | `trackvoice`, `trackgames` | サーバー管理 | 各トラッカーを切り替え |
| `statsignorevoicestate <state>` | | サーバー管理 | ボイス状態をカウントするかどうかを切り替え |
| `statsignore <#channel, @role or @user>`、`statsignored` | | サーバー管理 | 除外 |
| `statsactivityfiltermode <Whitelist/Blacklist>`、`statsactivityfilter <game>`、`statsactivityfilters` | `gamefilter` | サーバー管理 | アクティビティフィルター |
| `statsprivacy` | `optoutstats` | なし | すべての追跡からオプトアウト、または再度オプトイン |

## ヒントと注意点

- メンバーとステータスのグラフは、スナップショットを有効にしてから1時間後に記録が始まります。それより前の履歴はありません。
- ボイス時間は、ボットが動作している間だけカウントされます。再起動すると、すべてのセッションが閉じられて再度開かれます。データは失われませんが、セグメントの境界は移動します。
- チャンネルを除外すると、新しいカウントが停止するだけでなく、そのチャンネルの履歴がすべてのクエリから非表示になります。そのため、過去の数値も変わります。
- メッセージの数値をここに表示するには、メッセージの集計自体がオンになっている必要があります（メッセージ統計ページのトグル）。
- フィルターと `whoplays` では、ゲーム名は大文字と小文字を区別せずに照合されます。
