## 概要

ライブボードとは、ボットが一度投稿して固定し、その後は一定の間隔で編集して、常に最新の数値を表示するメッセージです。サーバーレポートは、前回のレポート以降に起きたことをまとめた、成長グラフ付きの埋め込みです。毎日、毎週、または毎月投稿されます。

## ボード

| ボード | 表示内容 |
| --- | --- |
| 招待ランキング | 通常、退出、不正の数を含む、招待数の上位者 |
| メッセージランキング | 発言数の上位者 |
| ボイスランキング | ボイスチャンネルにいた時間が最も長いメンバー |
| 人気のゲーム | 最もプレイされたゲームとアプリ、およびプレイヤー数（ゲーム追跡が必要です） |
| 参加グラフ、退出グラフ、成長グラフ | 1日あたりの参加と退出 |
| メンバーグラフ | 1時間ごとのスナップショットからのメンバー数 |
| メッセージグラフ | 1日あたりのメッセージ数 |
| サーバーの概要 | `serveractivity` と同じ要約 |
| 招待の分析 | 参加、退出、継続率、不正な参加、招待元 |

各ボードには、**期間**（直近1日、1週間、1か月、または全期間。グラフは全期間の場合、最大90日を使用します）、最低5分の更新間隔、ランキングの行数、固定の切り替えがあります。1つのサーバーには、最大10個のボードを設定できます。ボードを削除すると、そのメッセージも削除されます。誰かがメッセージを手動で削除した場合、ボットは次の更新時に新しいメッセージを投稿します。

## サーバーレポート

チャンネルと頻度を設定すると、ボットは最初にスケジュールが回ってきたときにレポートを投稿します。その後は、毎日UTC 0:00、毎週月曜日、または毎月1日に投稿します。レポートには次の内容が含まれます。

- 期間中の参加、退出、純増、継続率
- メッセージ、ボイス時間、アクティブなメンバー
- メンバー数と、その変化
- 招待数の上位者、発言数の上位者、ボイスチャンネルのメンバー、最も活発なチャンネル
- 上位の招待コードとそのラベル。ゲーム追跡がオンの場合は、人気のゲームも含みます
- 参加と退出のグラフ

**今すぐレポートを送信** を押すと、スケジュールを変更せずに、すぐにレポートを投稿します。ボットがそのチャンネルへの投稿権限を失うと、レポートは自動的にオフになります。

## コマンド

サーバーのプレフィックスを付けて実行します（変更していなければ `.`）。ボードは `/liveboard`、レポートは `/serverreport` からも利用できます。

| コマンド | エイリアス | 必要な権限 | 用途 |
| --- | --- | --- | --- |
| `liveboardadd <#channel> <board> [range] [rows] [minutes]` | `pinboard`, `pinleaderboard` | サーバーの管理 | ボードを投稿して固定します |
| `liveboardlist` | `liveboards` | サーバーの管理 | すべてのボードを一覧表示します |
| `liveboardremove <id>` | `unpinboard` | サーバーの管理 | ボードとそのメッセージを削除します |
| `liveboardrefresh` | | サーバーの管理 | すべてのボードを今すぐ更新します |
| `serverreportchannel [#channel]` | `reportchannel` | サーバーの管理 | レポートのチャンネルを設定してレポートを有効にします。または、レポートを無効にします |
| `serverreportfrequency <Daily/Weekly/Monthly>` | `reportfrequency` | サーバーの管理 | レポートを投稿する頻度を設定します |
| `serverreportnow [frequency]` | `reportnow` | サーバーの管理 | 現在のチャンネルにレポートを投稿します |

## ヒントと注意点

- メッセージを固定するには、チャンネルでのメッセージの管理の権限が必要です。権限がない場合でも、ボードは投稿されますが、固定はされません。
- ボードは同じメッセージを編集するため、混雑したチャンネルのボードはすぐに流れてしまいます。専用の統計チャンネルに置くか、固定に頼ってください。
- ランキングは招待と活動の除外設定に従います。そのため、非表示または無視されているメンバーが、固定されたボードに表示されることはありません。
- 統計チャンネルは、ライブの数値を表示するもう1つの方法です。メッセージではなく、チャンネル名にカウンターを表示します。
