## 概要

実績は、サーバーを利用することで達成できる目標です。例えば、最初のメッセージを送る、250件のメッセージに到達する、ボイスチャンネルに参加する、多くの種類の絵文字にリアクションする、数か月在籍する、ブーストするなどがあります。各実績にはグレードがあり、各グレードにはポイントが割り当てられます。ポイントによってメンバーの実績ランクが決まります。メンバーは、プロフィールカードに最大4つのバッジを表示して、獲得した実績を示せます。

実績を有効にすると、過去の履歴がすぐに反映されます。メンバーは、保存されているメッセージ、ボイス時間、リアクション、招待、レベル、在籍期間によってすでに獲得している実績を、お知らせなしで静かに解除します。

## XPとの関係

実績とXPは、並行して動作する2つの別々の仕組みです。どちらか一方が他方に依存することはなく、片方をオフにしても、もう片方には影響しません。

| | XP | 実績 |
| --- | --- | --- |
| 獲得の条件 | すべてのメッセージと、ボイスチャンネルでの毎分 | 目標に到達すること（1回限り） |
| 進む指標 | レベル（XPの曲線に従う） | 実績ランク（Newcomer から Champion まで） |
| 測定単位 | XP | 解除したそれぞれのグレードから得られるポイント |
| 報酬 | レベルロールと通貨 | 実績ごとのロール、通貨、XP |

2つの仕組みが連携するのは、次の2か所だけです。

1. **レベルが実績を解除します。** コミュニティのカテゴリには、XPレベルに到達することで解除される実績があります。そのため、レベルアップが実績の解除につながることがあります。
2. **実績がXPを与えることができます。** 初期設定では、XPは与えられません。個々の実績にXP報酬を設定するか、設定タブの **ポイントあたりのXP** を設定すると、解除のたびにポイントに応じたXPが与えられます。例えば、Goldの解除は50ポイントなので、1ポイントあたり2XPに設定すると100XPになります。

実績ランクは、XPのレベルとは異なります。メンバーはレベル40でBronzeランクにもなれば、レベル3でGoldランクにもなれます。一方はどれだけチャットしたかを、もう一方は異なる行動をどれだけ行ったかを測るためです。

## グレード、ポイント、ランク

| グレード | ポイント |
| --- | --- |
| Bronze | 10 |
| Silver | 25 |
| Gold | 50 |
| Emerald | 100 |
| Amethyst | 250 |

ポイントは合計されてランクになります。

| ランク | 必要なポイント |

| Newcomer | 0 |
| Bronze | 100 |
| Silver | 500 |

カスタムの実績では、任意のグレードを使えるほか、ポイントを個別に上書きできます。

## カテゴリ

組み込みの実績は、Messages、Voice、Reactions、Invites、Commands、Loyalty、Boosts、Community のカテゴリに分類されます。カテゴリ全体をオフにすることも、独自の名前、説明、アイコンを持つカテゴリを追加することもできます。**カテゴリー** タブでカテゴリをドラッグすると、メンバーに表示される順序をすべての場所で変更できます。

## カスタムの実績

| 種類 | 解除される条件 |
| --- | --- |
| Goal | 数値が目標に達したとき（例：1000件のメッセージ、サーバーに30日在籍） |
| Phrase | メンバーが特定のフレーズを言ったとき |
| Reaction | メンバーが絵文字にリアクションしたとき |
| Manual | スタッフが手動で付与したとき |

それぞれに、名前、説明、グレード、アイコン（絵文字、サーバーの絵文字、Font Awesomeのアイコン、またはアップロードした画像）と、任意の報酬（ロール、通貨、XP）を設定します。秘密の実績に設定すると、解除されるまでその名前と目標が非表示になります。

## お知らせ

| モード | 解除の投稿先 |
| --- | --- |
| Auto | ログチャンネルが設定されていればそこ、なければ発生したチャンネル |
| Here | 発生したチャンネル |
| Log channel | ログチャンネルのみ |
| DM only | メンバーのDM |
| Silent | 投稿しない |

同時に複数の解除が発生した場合は、1つのメッセージにまとめられます。お知らせには、サーバーの色を使った画像カードが付きます。チャンネルに投稿されたお知らせは、別の時間やNeverを選んでいない限り、5秒後に自動的に削除されます。DMは削除されません。メンバーは、自分のために解除のDM、サーバー内のメッセージ、メンションをオフにできます。

2つのルールにより、解除が不適切なチャンネルに投稿されることを防ぎます。

| ルール | 内容 |
| --- | --- |
| 静かなチャンネル | お知らせチャンネルなど、選択したチャンネル。メンバーはそこでも実績を獲得できますが、解除の投稿は決してそこに行われません。 |
| メンバーが発言できる場所にのみ投稿 | デフォルトでオンです。メンバーがメッセージを送信できないチャンネル（リアクションを付けた読み取り専用のチャンネルなど）には、解除を投稿しません。 |

いずれかのルールによって投稿が止められた場合、ログチャンネルを設定していればその解除はログチャンネルに送られ、設定していなければスキップされます。ログチャンネル自体は決してスキップされません。チャンネルでのカウントを完全に止めたい場合は、設定タブの除外チャンネルを使ってください。

## カード

**カード** タブは、解除の画像をデザインするためのツールです。タイトル、アイコン、グレード、進捗、アバターなどをドラッグしてサイズを変更できます。図形、テキスト、画像、アイコンを追加でき、サーバーの色をトークンとして使えば、新しいアイコンにもカードが追従します。デザインは最大20件まで保存でき、1つをデフォルトに設定し、ほかのデザインはカテゴリまたは単一の実績に割り当てられます。最も具体的な指定のものが優先されます。

## メンバーの設定

メンバーは、プロフィールカード、解除した実績の一覧、バッジ、リーダーボードの表示範囲を誰に見せるか、どのバッジを表示するか、そしてどのように通知を受け取るかを選べます。これらはすべて、iOSおよびAndroidアプリの **Me** タブでも設定できます。

## ヒントと注意点

- 過去の履歴に対しても報酬が与えられます。実績を有効にする前に、XP per point を設定したり報酬を追加したりすると、最初の走査で、メンバーがすでに獲得しているすべてについて報酬が支払われます。新しい解除にだけ報酬を与えたい場合は、有効にした後で設定してください。
- 実績によるXPでメンバーがレベルアップすることがあり、新しいレベルがレベルの実績を解除し、さらにXPを与えることがあります。実績は1回しか解除されないため、この連鎖は必ず止まります。
- 除外されたロールを持つメンバー、または除外されたチャンネルでの活動からは、その実績による報酬は得られません。
