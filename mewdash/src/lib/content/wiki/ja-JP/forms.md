## 概要

スタッフは、ダッシュボードでフォームを作成します。フォームには、名前、質問のセット、誰が回答できるか、回答後の処理に関するルールを設定します。公開すると、永続的な共有リンクが作成されます。メンバーはリンクを開き、Discordでログインし、ページごとに質問に答え、回答を確認してから送信します。入力中の内容は下書きとして保存されるため、後で続きから回答できます。

各回答は、選択したチャンネルに埋め込みとして投稿されます。フォームで判断が必要な場合は、**承認**と**却下**のボタンが付きます。審査担当者は、Discord内のボタンを押すか、ダッシュボードの**回答**タブを使って判断できます。回答者には、判断の結果とメモがDMで届きます。また、いつでも状況ページで結果を確認できます。

フォームには3つの種類があります。通常のフォームはメンバー向けです。BAN異議申し立てフォームは、現在BANされている人向けで、承認するとBANが解除されます。参加申請は、サーバー外の人向けです。承認すると1回限りの招待リンクが送られ、参加時に付与されるロールが準備されます。

フォームには、コマンドはありません。2つの審査ボタン以外のすべての操作は、ダッシュボードで行います。

## 利用するメリット

- スタッフ、パートナー、イベントの申請を、DMが大量に届く状態ではなく、適切な審査キューで管理できます。
- 待機期間、試行回数の上限、承認時の自動BAN解除を備えた、BANの異議申し立てのプロセスを作れます。
- 申請者を審査してから招待するクローズドコミュニティを運営できます。
- 回答数の上限とCSVエクスポートを備えたフィードバック用のアンケートを作れます。

## フォームの種類

| 種類 | 回答できる人 | 承認時 |
| --- | --- | --- |
| 通常フォーム | メンバー。**サーバー外の人の回答を許可**がオンの場合は誰でも | 設定されている場合にのみロールを変更 |
| BAN異議申し立て | 現在サーバーからBANされている人 | BANを解除 |
| 参加申請 | サーバーに参加していない人 | 招待リンクを作成し、**参加時に付与されるロール**がある場合は、ロールの状態として保存されるため、本人が参加したときに適用される |

フォームの種類は、作成後に変更できません。BAN異議申し立てと参加申請は、必ず審査を経由します。通常フォームは、**回答の承認が必要**がオンの場合にのみ審査を経由します。

## 質問

質問は、ビルダーの**質問**から追加します。質問の種類は次のとおりです。

| 種類 | 回答 | 選択肢 |
| --- | --- | --- |
| 短文テキスト | 1行 | 最小および最大の文字数。最大5000文字 |
| 長文テキスト | 複数行 | 文字数の制限は同じ |
| 複数選択 | 提示された選択肢から1つ | 最大25個の選択肢 |
| チェックボックス | 複数の選択肢 | 最大25個の選択肢。**最小値**と**最大値**で、チェックできる数を制限可能 |
| ドロップダウン | 一覧から1つの選択肢 | 最大25個の選択肢 |
| 数値 | 数字 | 最小値と最大値 |
| メールアドレス | 有効なメールアドレス | |
| URL | `http` または `https` のアドレス | |
| セクション区切り | なし。新しいページを開始し、タイトルと説明文を付けられます | |

質問文は500文字、プレースホルダーは200文字、回答は4000文字までです。各質問には画像のURLを設定でき、必須にすることもできます。また、以前の回答が条件に一致した場合にのみ必須となるように設定することもできます。

### 回答の引用

質問で回答の引用をオンにし、質問文またはプレースホルダーに `{{Q12}}` と書きます。12の部分は、前の質問のIDです。前の質問の回答が、100文字に切り詰められて挿入されます。前の質問が未回答の場合は、代わりに質問文が括弧付きで表示されます。質問は、それより上にある質問からしか引用できません。

### 条件

各質問は、条件が満たされた場合にのみ表示できます。表示されない質問はページ上でスキップされ、その質問への回答は、サーバー側で破棄されます。

| 条件の種類 | 表示される条件 |
| --- | --- |
| 回答に基づく | 前の回答が一致する場合：**等しい**、**等しくない**、**含む**、**より大きい**、**より小さい** |
| ロールに基づく | メンバーが、選択したロールのいずれか（**いずれか**）、すべて（**すべて**）、または一つも持たない（**いずれも持たない**）場合 |
| サーバー在籍期間 | メンバーが、サーバーに N 日以上在籍している、またはアカウントが N 日以上前に作成された場合 |
| ブースト/Nitro | メンバーがサーバーをブーストしている場合。Nitroの判定は、アバターとブーストのデータに基づく推測です |
| 権限に基づく | メンバーが、選択した権限をすべて持っている場合 |
| 複数の条件 | 複数の行を組み合わせます。同じグループ内の行はすべて満たされる必要があります（AND）。いずれかのグループが満たされれば質問が表示されます（OR） |

テキストの比較では、大文字と小文字は区別されません。「より大きい」と「より小さい」は、数値を比較します。

## 回答できる人

フォームは、次の順序で確認を行い、理由とともに回答を拒否します。下書きの状態であるか、回答を受け付けていないか、**受付開始日時**に達していないか、**受付終了日時**を過ぎていないか、アカウントが**Discordアカウントの最低作成日数**より新しいか、**回答の上限数**に達していないか、本人がすでに回答済みで複数回答が許可されていないか、**回答に必要なロール**を持っていないか、最後に上記の種類のルールに違反していないかです。

**却下された人の再回答を許可**をオンにすると、却下された回答は「回答済み」として扱われなくなります。**キャプチャを必須にする**がオンの場合、審査の段階でCloudflare Turnstileのチェックが表示されます。

BAN異議申し立てには、**異議申し立ての制限**で独自の制限を追加できます。制限には、BAN後の待機時間（BANの監査ログの記録から計算）、異議申し立ての最大回数、異議申し立て同士の間隔（クールダウン）、**却下は最終決定とする**があります。審査中の異議申し立てがあると、新しい異議申し立てはできません。

## フォームへの回答

公開ページを表示するには、Discordへのログインが必要です。回答は、最後のキー入力から約1.5秒後、および次のページに移動したときに下書きとして保存されます。30日以内に戻ると、下書きが復元され、「We brought back what you had already written」というバナーと**最初からやり直す**ボタンが表示されます。

進捗バーには、回答済みの質問が表示されます。最後のページには**確認して送信へ**があり、すべての回答と**編集**リンクが表示されます。その後、**確認して送信**を押します。送信後のページには、**送信後のメッセージ**（またはタイプごとのデフォルトのメッセージ）と、**状況を確認**リンクが表示されます。状況ページからは、**マイ投稿**（`/forms/submissions`）にもアクセスできます。ここには、ログインしているユーザーがサーバーを問わず行ったすべての匿名以外の回答が一覧表示されます。

回答者は、回答が審査待ちで、フォームが匿名ではなく、まだ締め切られていない場合、状況ページから回答を編集できます。以前の回答は、修正履歴として保持されます。回答者が回答を取り下げる方法はありません。

## 送信時の処理

1. **送信時に付与するロール**と**審査中のロール**が付与されます。
2. **回答の投稿先**が設定されている場合、ユーザー（または「Anonymous (login required)」）、時刻、最大20件の回答を含む埋め込みが投稿されます。**回答時に通知するロール**にメンションが付きます。承認ボタンと却下ボタンは、フォームの審査時に追加されます。
3. **Webhookに送信**が設定されている場合、同じ埋め込みがそのWebhookに、ボタンなしで投稿されます。後で回答が承認または却下されると、結果、審査者、理由を含む2つ目のメッセージもWebhookに送信されます。URLはDiscordのWebhookである必要があります。それ以外は無視され、ボットのログに警告が記録されます。また、Webhookが失敗しても、送信がブロックされることはありません。
4. 回答は、**回答**タブに「審査待ち」の状態で表示されます。

匿名のフォームはユーザーIDを保存しないため、ロールを変更できず、回答を編集することもできません。

## 審査の流れ

回答は、「審査待ち」から「承認」または「却下」に移ります。**承認または却下できる人**では、ロールを指定します。サーバー管理権限または管理者権限を持つ人は、常に判断できます。審査ロールが設定されていない場合は、承認ロールの保持者も判断できます。

Discordでは、**承認**を押すとすぐに判断されます。**却下**を押すと、理由を入力するモーダルが開きます。理由は回答者に送信されるため、必須です。どちらの場合も、埋め込みの色が変わり、**承認**または**却下**のフィールドが追加されます。このフィールドには、審査者、時刻、理由（あれば）が表示されます。ボタンは削除されます。ダッシュボードでは、同じ判断を、キューから**回答者へのメモ**ボックスと共に行えます。

判断が行われると、ボットは次の処理を行います。

- **承認時に追加**、**承認時に削除**、**却下時に追加**、**却下時に削除**に設定されたロールを追加または削除します。また、**審査中のロール**は必ず削除されます。両方に指定されたロールは削除されます。
- 承認されたBAN異議申し立ての場合は、ユーザーのBANを解除します。承認された参加申請の場合は、招待リンクを作成します。
- 回答者に、「Your response was approved」または「Your response was not accepted」というDMを送信します。DMには、メモ、承認時の**送信後のメッセージ**、招待リンクが含まれます。DMの送信に失敗した場合、埋め込みとキューにその旨が表示されます。

審査ボタンの絵文字は、フォームに設定されたものを使います。設定されていない場合は**設定**タブの**サーバーのデフォルト**を使い、それもない場合はチェックマークとバツ印を使います。

## バージョン

フォームを保存するたびに、最大20件まで、バージョンが保存されます。**バージョン履歴**には、各バージョンが、設定と質問の差分とともに表示され、**復元**ボタンがあります。復元すると、質問は新しいIDで再作成され、条件と引用は新しいIDに合わせて書き換えられます。

## 設定

**フォーム**ページには、**フォーム**、**作成**、**設定**のタブがあります。フォームを選択すると、**編集**と**回答**のタブも表示されます。**作成**タブと**編集**タブは、同じ設定パネルを共有しています。

| 設定 | デフォルト | 制御する内容 |
| --- | --- | --- |
| 名前 | 空（必須） | フォームのタイトル。最大255文字 |
| 説明 | 空 | タイトルの下と、Discordのリンクプレビューに表示 |
| 回答の投稿先 | なし | 送信の埋め込みを投稿するチャンネル。空の場合、回答はダッシュボードにのみ保存されます |
| 送信後のメッセージ | なし | 確認ページと承認時のDMに表示されるテキスト |
| 下書き | 新規フォームではオン | 下書きには送信できません |
| 回答を受け付ける | オン | 削除せずに締め切るには、オフにします |
| 回答に必要なロール | サーバーの全員 | ロールで制限 |
| Discordアカウントの最低作成日数 | 制限なし | 日数 |
| サーバー外の人の回答を許可 | オフ | 通常フォームのみ |
| 匿名で送信 | オフ | 送信者を記録しない |
| 受付開始日時、受付終了日時 | なし | 受付期間。開始の告知には、開始日時が必要です |
| 回答の上限数 | 制限なし | 全体での上限 |
| 1人が複数回答することを許可 | オフ | |
| 却下された人の再回答を許可 | オフ | |
| キャプチャを必須にする | オフ | 審査の段階でTurnstileを使用 |
| 受付開始を告知、告知でメンション、告知文 | なし | 締め切りのカウントダウン付きの告知の埋め込み。**受付開始日時**の約1分以内、または公開時に送信 |
| 回答時に通知するロール | なし | 各送信とともにメンションされるロール |
| 送信時に付与するロール | なし | すぐに付与される |
| 審査中のロール | なし | 判断時に削除される |
| Webhookに送信 | なし | 各送信の埋め込みと、各承認または却下の判断も受け取るDiscordのWebhook URL |
| 回答の承認が必要 | オフ | 通常フォームに審査を追加 |
| 承認または却下できる人 | サーバー管理のみ | 審査ロール |
| 承認ボタンの絵文字、却下ボタンの絵文字 | サーバーのデフォルト | |
| 承認時に追加/削除、却下時に追加/削除 | なし | 判断時のロールの変更 |
| 却下は最終決定とする、BAN後の待機時間、異議申し立ての許可数、異議申し立て間の待機時間 | オフ、待機なし、無制限、待機なし | BAN異議申し立てのみ |
| 招待の使用回数、招待の有効期限（秒）、参加時に付与されるロール | 1、86400、なし | 参加申請のみ |

フォームの種類に適用されない設定は、保存時に削除されます。

## 初期設定の手順

1. ダッシュボードで**フォーム**を開き、**作成**を押します。
2. **フォームの種類**を選択します。これは後から変更できません。
3. **名前**と**説明**を入力し、**回答の投稿先**を選択します。
4. **質問**で質問を追加し、必須のものにマークします。長いフォームは、**ページを追加**で分割します。
5. 誰が回答できるかを設定します。審査の段階を設けたい場合は、**回答の承認が必要**をオンにし、**承認または却下できる人**を選択します。
6. **フォームを保存**を押します。フォームカードの**プレビュー**を使うと、管理者として回答の流れを確認できます。
7. カードの**公開**を押し、**リンクをコピー**をクリックして、申請者が見つけられる場所にリンクを投稿します。
8. **回答**タブ、または送信用のチャンネルを確認し、各回答を判断します。

## コマンド

フォームには、テキストコマンドもスラッシュコマンドもありません。Discordでの操作は、各送信の埋め込みにある**承認**と**却下**のボタンだけです。

## ヒントと注意点

- ボットには、ロールの管理権限が必要です。また、ボットのロールは、フォームが付与または削除するすべてのロールより上にある必要があります。ボットより上にあるロール、管理されたロール、および全員は、警告なしにスキップされます。
- BAN後の待機時間を確認するには、BANの異議申し立てに監査ログの表示権限が必要です。BANの解除にはBANメンバーの権限が、参加申請の招待リンクには、全員が見られるチャンネルでのリンクの作成権限が必要です。
- 送信の埋め込みには、最大20件の回答が表示されます。回答の全体は、ダッシュボードで確認してください。
- **回答**タブの**CSVを書き出す**には、質問ごとに1列が含まれます。複数選択の回答は、セミコロンで区切られます。
- 回答のフィルターとページは、URLに含まれます。そのため、「審査待ちのみ」をブックマークして、審査担当者と共有できます。
- 下書きは検証されないため、復元した下書きは、送信時に検証に失敗することがあります。
- 期限切れのフォームは、1分ごとに実行されるチェックで締め切られます。また、送信時にも資格が確認されるため、その間に不正な回答が通ることはありません。
