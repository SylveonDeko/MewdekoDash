## 概要

フィルターは、メンバーが送信または編集したすべてのメッセージを、ほかのモジュールが処理する前に確認します。メッセージに、そのフィルターが有効な場所でフィルター対象のワード、Discordの招待、またはリンクが含まれていると、Botはそのメッセージを削除します。Botに、モデレーションの仕組みを通じて警告を出させ、何が削除されたかを説明するDMを送ることもできます。

2つ目のリストである自動BANワードは、より厳格です。自動BANワードに一致したメッセージは削除され、投稿者はすぐにBANされます。Botがメッセージを送信できる場合は、理由を含むDMも送られます。

管理者と、サーバーのスタッフロール(`staffrole` で設定)を持つ人は、フィルターの対象外です。Botのメッセージも確認されません。

## 使う理由

- モデレーターがオンラインでなくても、差別用語やその他の禁止用語をチャットから排除する。
- 招待リンクを貼って、ほかのサーバーを宣伝するメンバーを止める。
- URLを含むメッセージをすべて削除して、チャンネルをテキストのみにする。たとえば、メディアを投稿しないお知らせチャンネルなどに使えます。
- 既知の詐欺フレーズや荒らしのパターンを投稿したアカウントを、即座にBANする。

## フィルターの種類

| フィルター | 適用される場所 | 動作 |
| --- | --- | --- |
| ワードフィルター | ワードフィルターのチャンネル一覧にあるチャンネルのみ | メッセージを削除。**フィルター対象の単語で警告** がオンの場合は警告とDM |
| 招待フィルター | サーバーのスイッチがオンで、チャンネル一覧が空の場合はすべての場所。一覧に項目がある場合は一覧のチャンネルのみ | メッセージを削除。**招待リンクで警告** がオンの場合は警告とDM |
| リンクフィルター | サーバーのスイッチがオンの場合はすべての場所に加えて、その一覧にあるチャンネル | メッセージを削除。警告はなし |
| 自動BANワード | すべての場所 | メッセージを削除し、投稿者にDMを送ってBAN |

3つのチャンネル一覧は、ダッシュボードの **チャンネルごとの上書き** です。ワードフィルターは、チャンネル一覧によって完全に制御される点に注意してください。ワードを確認してもらうには、そのチャンネルが一覧に含まれている必要があります。

## ワードの照合方法

フィルター対象のワードと自動BANワードは正規表現として扱われ、小文字に変換されたメッセージ本文に対して照合されます。`example` のような普通の単語は部分一致として機能するため、`examples` も検知されます。コンパイルできないパターンはリストから自動的に削除されます。各パターンには250ミリ秒の照合タイムアウトがあります。

フィルター対象のワードは小文字で保存され、大文字と小文字を区別せずに照合されます。自動BANのパターンは入力したとおりに保存され、小文字に変換されたテキストに対して照合されるため、小文字で入力してください。

> [!WARNING]
> 自動BANのパターンは強力です。`ban` のような短いパターンが、より長い単語の中に含まれると、「banana」と入力した人もBANされてしまいます。まずはフィルター対象のワードとしてパターンをテストしてください。

## 警告

**フィルター対象の単語で警告** または **招待リンクで警告** をオンにすると、Botはモデレーションモジュールを通じて、「Warned for Filtered Word」または招待の警告の理由で警告を追加し、メンバーにDMを送ります。モデレーションのページで設定された警告による処分は、通常どおり適用されます。そのため、警告の設定が上記のとおりであれば、フィルターに3回ヒットすると、ミュートやキックにエスカレートすることもあります。

自動BANは、モデレーションモジュールのBANのプルーン設定を、「Filter」の処分に対して使い、削除するメッセージの日数を決めます。

## 設定

メッセージフィルターのページには、**フィルター**、**Filtered Words**、**Auto-ban Words**、**チャンネルごとの上書き** の4つのタブがあります。

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| Word filter | オフ | Filters タブにあるサーバー全体のスイッチ |
| Invite filter | オフ | Discordの招待リンクを削除。招待のチャンネル一覧が機能するには必要 |
| Link filter | オフ | URLを含むすべてのメッセージを、サーバー全体で削除 |
| Warn on filtered word | オフ | フィルター対象のワードが削除されたときに、警告を追加してメンバーにDMを送る |
| Warn on invite link | オフ | 招待が削除されたときに、警告を追加してメンバーにDMを送る |
| Filtered words | なし | Filtered Words タブの一覧。ワードごとに削除ができ、`fwclear` と同じ動作の **すべてクリア** ボタンと、10語を超えると表示される検索ボックスがあります |
| Auto-ban words | なし | Auto-ban Words タブの一覧 |
| Word filter channels | なし | ワード一覧が適用されるチャンネル |
| Invite filter channels | なし | 空でない場合、招待フィルターをこれらのチャンネルに限定 |
| Link filter channels | なし | サーバーのスイッチがオフでも、リンクが削除される追加のチャンネル |

ページの上部には、フィルター対象のワード、自動BANワード、チャンネルの上書きの数が表示されます。

## セットアップの手順

1. ダッシュボードで **メッセージフィルター** を開きます。
2. **Filtered Words** タブで、ワードまたはフレーズを1つずつ追加し、追加を押します。
3. **チャンネルごとの上書き** で、**単語フィルターのチャンネル** に、ワード一覧を適用したいすべてのチャンネルを追加します。
4. **フィルター** に戻り、招待をすべての場所で削除したい場合は **招待リンクフィルター** をオンにします。招待を警告として扱いたい場合は **招待リンクで警告** をオンにします。
5. 任意で、**Auto-ban Words** タブに、確実性の高いパターンをいくつか追加します。
6. `staffrole @Moderators` を実行して、チームが対象外になるようにします。その後、通常のアカウントからフィルター対象のワードを投稿し、削除されることを確認します。

## コマンド

これらのコマンドは、サーバーのプレフィックス(変更していなければ `.`)を付けて実行します。

| コマンド | エイリアス | 必要な権限 | 目的 |
| --- | --- | --- | --- |
| `filterword <word>` | `fw` | なし | ワードをフィルター一覧に追加。すでにある場合は削除 |
| `lstfilterwords` | `lfw` | なし | フィルター対象のワード一覧をページ送りで表示 |
| `fwclear` | | 管理者 | フィルター対象のワードをすべて削除し、ワードのチャンネル一覧を消去して、サーバーのスイッチをオフにする |
| `srvrfilterwords` | `sfw` | なし | サーバー全体のワードフィルターのスイッチを切り替え |
| `chnlfilterwords` | `cfw` | なし | 現在のチャンネルを、ワードフィルターのチャンネル一覧に追加または削除 |
| `srvrfilterinv` | `sfi` | なし | サーバー全体の招待フィルターを切り替え |
| `chnlfilterinv` | `cfi` | なし | 現在のチャンネルを、招待フィルターのチャンネル一覧に追加または削除 |
| `srvrfilterlin` | `sfl` | なし | サーバー全体のリンクフィルターを切り替え |
| `chnlfilterlin` | `cfl` | なし | 現在のチャンネルを、リンクフィルターのチャンネル一覧に追加または削除 |
| `fwarn <y or n>` | `filteredwarn` | 管理者 | フィルター対象のワードに対する警告をオンまたはオフ |
| `invwarn <y or n>` | `invitewarn` | 管理者 | 招待リンクに対する警告をオンまたはオフ |
| `autobanword <pattern>` | `autobanw` | 管理者 | パターンを自動BANの一覧に追加。すでにある場合は削除 |
| `autobanwordlist` | `autobwlist` | 管理者 | 自動BANの一覧をページ送りで表示 |

> [!PERMISSION]
> フィルターのスイッチと `filterword` には、独自の権限チェックがありません。権限モジュールで制限するか、ダッシュボードのアクセスルールが適用されるダッシュボードからフィルターを管理してください。

## ヒントと注意点

- Botには、フィルター対象のすべてのチャンネルでメッセージの管理の権限が、自動BANワードのためにメンバーのBANの権限が必要です。
- 編集されたメッセージは再確認されるため、古いメッセージにリンクを追加しても削除されます。
- フィルターは、管理者、スタッフロール、Botには適用されません。管理者アカウントでテストしないでください。
- `fwclear` は一覧を空にするだけでなく、ワードフィルターのすべてのチャンネルの上書きも削除します。
- 無効な正規表現は、一覧から黙って削除されます。ワードが消えた場合は、`(`、`[`、`*` などのエスケープされていない文字が含まれていないか確認してください。
- フィルターが削除した内容の記録が必要な場合は、ログ機能でメッセージの削除を記録してください。
