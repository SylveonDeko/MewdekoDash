## 概要

XPのレベルロールは一方通行です。一度獲得すると、ずっと保持されます。統計ロールは、スケジュールに従って再評価されます。条件を満たしているメンバーにはロールが付与され、条件を満たさなくなったメンバーはロールを失います。そのため、「アクティブメンバー」のロールは、*今* アクティブであることを意味します。従来の動作にしたい場合は永続に設定し、逆に非アクティブなメンバーを示すためにすることもできます。

## 条件

すべての統計ロールは、一定期間で1つのものを測定し、1つの制限を適用します。

| 測定対象 | 数えられるもの |
| --- | --- |
| メッセージ | 期間内のメッセージ。選んだチャンネルだけに限定することも可能 |
| ボイスの分数 | 期間内のボイスチャンネルにいた時間。活動統計で除外したボイスの状態を考慮 |
| ゲームの分数 | 期間内に、特定のゲームまたはアプリで過ごした時間、またはすべてのゲームでの時間。ゲームの追跡をオンにする必要があります |
| 招待 | メンバーの招待の正味の合計 |
| サーバーの日数 | メンバーが参加してからの日数 |
| アカウントの年数 | アカウントが作成されてからの日数 |

| 制限 | 対象となる人 |
| --- | --- |
| 閾値 | 最小値と、任意の最大値の間 |
| 上位順位 | 2つの順位の間(例: 上位10位) |
| 上位パーセント | ランク付けされたメンバーの上位X%(例: 上位5%) |
| 毎日の連続記録 | 期間内の少なくともN日で、1日の最低数に達している(例: 直近7日のうち7日で、1日5メッセージ) |

期間は1から90日、または連続記録以外はすべての期間から選べます。同点の場合は同じ順位になります。

## フィルターとオプション

| オプション | 内容 |
| --- | --- |
| Only count in channels | メッセージやボイスを、選んだチャンネルだけに限定 |
| Required roles | メンバーが対象として考慮されるために、少なくとも1つ必要なロール |
| Excluded roles | このロールを持つメンバーは、一切考慮されない |
| Ignored members | これらのメンバーには、付与も削除もされない |
| Group | 同じグループの統計ロールは、メンバーが満たす最も高い段階のみを残すため、ブロンズ、シルバー、ゴールドが重複しない |
| Permanent | 一度獲得すると、削除されない |
| Invert | 条件を満たさない*メンバー*にロールを付与 |
| Include bots | Botアカウントも考慮 |
| Evaluate every | ルールを実行する頻度。最低10分ごとで、初期値は3時間ごと |
| Announce in / DM the member | ロールの付与または削除時にメッセージを投稿。`%user%`、`%role%`、`%action%`(獲得または喪失)、`%value%`、`%stat%` を使用 |

## ダッシュボード

**統計ロール** タブには、各ルールの条件、スケジュール、最後の実行が一覧表示され、各ルールを有効化、無効化、編集、削除、**preview**(プレビュー)、**run**(実行)できます。プレビューでは、何も変更せずに、ロールを獲得する人と失う人が表示されます。Run は直ちに適用します。手動の実行は、サーバーごとに10分に1回までに制限されます。

**作成/編集** タブには、上記のすべてを設定するフォームがあります。

## コマンド

これらのコマンドは、サーバーのプレフィックス(変更していなければ `.`)を付けて実行します。すべてのコマンドは `/statrole` の下にもあります。

| コマンド | エイリアス | 必要な権限 | 目的 |
| --- | --- | --- | --- |
| `statroleadd <@role> <stat> <minimum> [days] [name]` | `sradd` | ロールの管理 | 閾値のルール |
| `statroletop <@role> <stat> <topEnd> [days] [name]` | `srtop` | ロールの管理 | 1位からtopEndまでの上位順位のルール |
| `statrolepercent <@role> <stat> <percent> [days] [name]` | `srpercent` | ロールの管理 | 上位パーセントのルール |
| `statrolestreak <@role> <stat> <perDay> <requiredDays> [days] [name]` | `srstreak` | ロールの管理 | 毎日の連続記録のルール |
| `statrolelist` | `statroles` | なし | すべてのルール |
| `statroleinfo <id>` | `srinfo` | なし | 1つのルールの詳細 |
| `statroleset <id> <setting> <value>` | `srset` | ロールの管理 | name、min、max、lookback、topstart、topend、days、permanent、invert、bots、group、interval、notifychannel、notifydm、message、activity を変更 |
| `statrolefilter <id> <#channel, @role [true], or @user>` | `srfilter` | ロールの管理 | チャンネルのフィルター、必要なロール(`true` を付けると除外するロール)、または対象外のメンバーを切り替え |
| `statroletoggle <id>` | `srtoggle` | ロールの管理 | 有効化または無効化 |
| `statrolepreview <id>` | `srpreview` | ロールの管理 | 獲得する人と失う人 |
| `statrolerun <id>` | `srrun` | ロールの管理 | 今すぐ適用 |
| `statroleremove <id>` | `srremove` | ロールの管理 | ルールを削除。メンバーは保持しているロールを保持したまま |

## ヒントと注意点

- Botの最上位ロールは、管理対象のロールより上にある必要があり、Botにはロールの管理の権限が必要です。
- 各Discordロールは、1つの統計ロールでのみ管理できます。同じロールに新しいルールを設定する前に、古いルールを削除してください。
- 最小値が0で最大値がないルールは、全員に一致します。最大値を設定するか、意図的に invert を使ってください。
- 活動統計をオプトアウトしたメンバーには、メッセージ、ボイス、ゲームの時間がないため、それらの測定対象には一切該当しません。
- 大規模なサーバーでルールを有効にする前には、必ずプレビューしてください。ロールの編集はレート制限を守るように間隔を空けて行われるため、数千人に影響するルールは適用に数分かかります。
