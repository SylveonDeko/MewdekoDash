## 概要

これはアンケート機能ではありません。投票は、top.ggでサーバーが受け取った投票を追跡し、投票したメンバーに報酬を与える機能です。top.ggがMewdekoに誰かが投票したことを伝えると、ボットはその投票を記録し、投票チャンネルに、そのメンバーの累計数とともにお礼のメッセージを投稿します。さらに、設定した投票報酬のロールを付与します。

メンバーから見ると、top.ggでサーバーに投票すると、投票チャンネルにメンションとともに投票回数が表示されたメッセージが現れます。投票ロールを設定している場合は、同時にそのロールも付与されます。永続的な場合も、一定期間の場合もあります。

スタッフから見ると、投票チャンネル、Webhookのパスワード、任意のカスタムメッセージ、最大10個の報酬ロールを設定します。そのあとは、ボットがすべての投票を自動で処理します。`votes` と `votesleaderboard` では、誰でも投票数を確認できます。

top.ggとサーバーをつなぐのは投票パスワードです。top.ggはこのパスワードをWebhookの呼び出しのAuthorizationヘッダーに入れて送信します。Mewdekoはそのヘッダーを、各サーバーに保存されているパスワードと照合して、投票がどのサーバーのものかを判断します。

## 利用する理由

- サーバーをtop.ggに掲載しており、投票のたびに目に見えるお礼を表示したい場合。
- 投票者に「Voter」ロールや、12時間で期限切れになる一時的な特典ロールを与えたい場合。
- 「今月のトップ投票者」の報酬のために、月間の投票者リーダーボードを用意したい場合。
- メンバーがスタッフに聞かなくても、自分の投票数を確認できるようにしたい場合。

## 投票の処理の流れ

1. top.ggが、ボットの `/votes/` Webhookエンドポイントに、投票者のDiscord IDとあなたのパスワードをAuthorizationヘッダーに入れて送信します。
2. ボットは、保存されている投票パスワードが一致するサーバーを探します。一致するものがない場合、投票は破棄されます。
3. 投票者のIDと時刻とともに、投票が保存されます。
4. 投票チャンネルが設定されている場合、ボットはそのチャンネルにお礼のメッセージを投稿します。投票チャンネルがなければ、何も投稿されず、ロールも付与されません。
5. すべての投票ロールがメンバーに追加されます。期限のあるロールは、タイマーが切れたときに削除されます。ミュートと同じ期限付きロールの仕組みを使います。

> [!WARNING]
> 投票をサーバーに結びつけるのはパスワードだけです。それを知っている人は、偽の投票を送ることができます。公開チャンネルに貼り付けないでください。ボットは、この理由から、プライベートなモーダルでパスワードを設定します。

## お礼のメッセージ

デフォルトでは、ボットは投票者へのメンションと、「Thanks for voting for <server>」というタイトルの埋め込み、累計投票数の行、そして投票者のアバターをサムネイルとして送信します。

`votemessage` またはダッシュボードの **カスタムの投票告知** ボックスを使うと、独自のテキストや埋め込みに置き換えられます。テキストは埋め込みパーサーを通るため、埋め込みビルダーが生成できるものは何でも使えます。コマンドで `-` を指定するか、ダッシュボードのボックスを空にすると、デフォルトに戻ります。

### プレースホルダー

カスタムメッセージでは、一般的なプレースホルダーのセット（プレースホルダーのページにあるユーザー、サーバー、チャンネル、ボット、時間のプレースホルダー）に加えて、投票専用の2つのプレースホルダーを使えます。

| プレースホルダー | 値 |
| --- | --- |
| `%votestotalcount%` | このメンバーが合計で投票した回数 |
| `%votesmonthcount%` | このメンバーが今月の暦の中で投票した回数 |
| `%user.mention%`、`%user.name%`、`%user.id%`、`%user.avatar%` | 投票者 |
| `%server.name%`、`%server.id%`、`%server.icon%`、`%server.members%` | あなたのサーバー |

> [!EXAMPLE]
> `Thanks %user.mention% for voting! That is vote number %votestotalcount% (%votesmonthcount% this month).`

`votemessage` をテキストなしで実行すると、現在のメッセージが、あなた自身の投票数を使ったプレビューとして表示されます。

## 投票ロール

投票ロールは、すべての投票者に付与されます。各ロールには任意の期間（秒）を設定でき、`0` は永続を意味します。

- サーバーごとに最大10個の投票ロールを設定できます。
- `@everyone` ロールは追加できません。
- 同じロールを2回追加することはできません。期間を変更するには `voteroleedit` を使います。
- 期限付きのロールは、期間が過ぎると自動的に削除されます。
- ボットがロールを付与できない場合（たとえば、そのロールがボットの最上位のロールより上にある場合）、そのロールは静かにスキップされます。

## 投票数とリーダーボード

`votes` は、メンバーの今月の投票数と累計投票数を、アバターとともに表示します。`votesleaderboard` は、サーバー内のすべての人を累計投票数で順位付けし、1ページに12人ずつ表示します。`true` を指定すると、今月の投票数だけで順位付けします。どちらの「今月」も、直近30日ではなく暦の上の月を比較します。

## 設定

投票のページには、**設定**、**投票ロール**、**統計** の3つのタブがあります。

| 設定 | デフォルト | 制御する内容 |
| --- | --- | --- |
| Vote Announcement Channel | なし | お礼のメッセージを投稿する場所です。これがないと何も起こりません |
| API Password (for webhooks) | なし | top.ggがAuthorizationヘッダーで送らなければならない秘密の値です |
| Custom Vote Announcement | デフォルトの埋め込み | 上記のプレースホルダーを使った独自のメッセージです。空の場合はデフォルトになります |
| Role to Grant | なし | すべての投票者に追加されるロールです（**投票ロール** タブ） |
| Duration (seconds, 0 for permanent) | 0 | 投票ロールが削除されるまでの期間です |

**統計** タブには、合計投票数、投票ロールの数、トップ投票者の投票数、そして上位10人のリーダーボードが表示されます。

## セットアップの手順

1. ダッシュボードで **投票** を開き、**設定** のままにします。
2. **投票結果のお知らせチャンネル** を選びます。これがないと、投票は記録されますが、何も投稿されず、ロールも付与されません。
3. **API Password** を入力します。長くランダムなものにし、APIキーと同じように扱ってください。
4. 必要に応じて、上記のプレースホルダーを使って **カスタムの投票告知** を書き、**設定を保存** を押します。
5. top.ggのサーバーのページで、Webhookのセクションを開きます。Webhook URLにボットの `/votes/` エンドポイントを設定し、Authorizationの値を同じパスワードにします。
6. **投票ロール** で、**付与するロール** と **期間** を選び、**投票ロールを追加** をクリックします。最大10個まで繰り返せます。
7. ボットのロールが、ロール一覧のすべての投票ロールより上にあることを確認します。
8. top.ggのテストWebhookボタンを使うか、実際の投票を待って、投票チャンネルを確認します。

## コマンド

コマンドは、サーバーのプレフィックスで実行します（変更していなければ `.`）。

| コマンド | エイリアス | 必要な権限 | 目的 |
| --- | --- | --- | --- |
| `votechannel <#channel>` | | Manage Server | お礼のメッセージのチャンネルを設定します |
| `votemessage [text]` | `votemsg` | Manage Server | カスタムメッセージをプレビュー、設定、または `-` でリセットします |
| `votepassword` | `votepass` | Manage Server | プライベートなモーダルでWebhookのパスワードを設定します |
| `voteroleadd <@role> [time]` | `vra` | Manage Server | 投票ロールを追加します。期間を指定することもできます（例：`voteroleadd @Voter 12h`） |
| `voteroleedit <@role> <time>` | `vre` | Manage Server | 投票ロールの期間を変更します |
| `voteroleremove <@role>` | `vrr` | Manage Server | 1つの投票ロールを削除します |
| `voteroleslist` | `vrl` | Manage Server | 投票ロールと期間を一覧表示します |
| `voterolesclear` | `vrc` | Manage Server | 確認の後に、すべての投票ロールを削除します |
| `votes [@user]` | | Nobody | メンバーの今月の投票数と累計投票数を表示します |
| `votesleaderboard [true]` | `voteslb` | Nobody | 累計で、または `true` を指定して今月の投票数で、投票者を順位付けします |

同じコマンドは、`/votes` の下のスラッシュコマンドとしても使えます。

## ヒントと注意点

- 対応しているのはtop.ggのサーバー投票だけです。他のボットリストとの連携はなく、この機能でアンケートは作成されません。
- 投票チャンネルがなければ、投票はカウントされても、メッセージもロールも出ません。
- ボットには Manage Roles が必要で、ボットのロールはすべての投票ロールより上にある必要があります。そうでないと、ロールの報酬は静かに失敗します。
- 期限付きの投票ロールは、期限付きのミュートと同じ仕組みを使い、監査ログに「Vote Role」という理由とともに表示されます。
- `voteroleedit` はロールをIDだけで検索するため、そのサーバーで実際に追加したロールに対してのみ使ってください。
- パスワードを変更しても古い投票は無効になりませんが、top.gg側のAuthorizationヘッダーも更新するまで、top.ggは一致しなくなります。
