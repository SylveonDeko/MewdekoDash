## 概要

スタッフは、2から25個の選択肢を持つ質問を投稿します。ボットは、選択肢ごとにボタンを付けた埋め込みを送信します。選択肢が5つを超える場合は、選択メニューを使います。メンバーはクリックして投票します。埋め込みには、各選択肢の現在の票数と割合がリアルタイムに表示されます。選択肢の下には、**統計**、**終了**、**削除** の3つの管理ボタンがあります。

メンバーは、別の選択肢をクリックすると投票を変更でき、同じ選択肢をもう一度クリックすると投票を取り消せます。ただし、その投票で投票の変更がオフになっている場合は除きます。ボットがクリックに対して返すすべての応答は、投票したメンバーだけに表示されるため、チャンネルは整理された状態を保てます。

投票は手動で終了することも、設定した期間が過ぎると自動的に期限切れにすることもできます。また、後日投稿されるように予約することもできます。テンプレートは、質問と選択肢を保存するもので、1つのコマンドで同じ投票を再び投稿できます。ダッシュボードでは、分析、CSVとJSONへのエクスポート、投票の並べての比較ができます。

## 使いどころ

- 次のコミュニティイベントの日程やゲームを選びます。
- ルールを変更する前に、簡単な「はい / いいえ」の確認を行います。
- 誰がどの回答に投票したかを誰にも見られないよう、センシティブな質問を匿名で行います。
- 決定に関係するスタッフのロールやブーストのロールを持つメンバーだけが投票できるようにします。
- テンプレートを使って毎週月曜日に同じ投票を投稿するか、事前に予約します。

## 投票の種類

| 種類 | 投票の方法 |
| --- | --- |
| はい / いいえ | 「はい」と「いいえ」の2つの固定の選択肢です。`poll` と `/poll yesno` で作成されます。 |
| 単一選択 | メンバーは1つの選択肢を選べます。`pollc`、テンプレート、ダッシュボードの既定です。 |
| 複数選択 | メンバーは複数の選択肢を選べます。選択肢が6つ以上の場合、選択メニューで複数選択が可能になります。 |
| 匿名 | 投票は保存されますが、統計やエクスポートには投票者が表示されません。 |
| ロールによる制限 | 許可されたロールのいずれかを持つメンバーだけが投票できます。それ以外のメンバーには、非公開の「許可されていません」という返信が届きます。ダッシュボードのみで利用できます。 |

すべての投票には、次の投票ごとの切り替え設定があります。いずれも既定ではオンです。**投票の変更を許可**、**リアルタイムの結果を表示**、**進捗バーを表示** です。

## 投票、終了、期限切れ

- 終了済みまたは期限切れの投票への投票は、非公開のメッセージで拒否されます。
- 投票の変更がオフの場合、2回目のクリックは「すでに投票済み」として拒否されます。
- **終了** ボタンと **削除** ボタンは、投票の作成者と、メッセージの管理の権限を持つ人が使用できます。**削除** を押すと確認フォームに `DELETE` と入力するよう求められ、その後、投票とそのメッセージが削除されます。
- **統計** を押すと、総投票数、ユニークな投票者数、選択肢ごとの内訳が、クリックした人だけに非公開で表示されます。
- 期限切れは5分ごとに確認されます。投票が期限切れになると、ボタンが削除され、フッターが期限切れであることを示す表示に変わります。
- 予約された投票は1分ごとに確認されます。予約された投票の日時は未来であり、30日以内である必要があります。期間を分単位で指定でき、その場合は投稿された投票がその時間の経過後に期限切れになります。

## テンプレート

テンプレートには、名前、質問、選択肢が保存されます。`polltemplate <name>` を実行すると、単一選択の投票として投稿されます。テンプレートは `polltemplates` で一覧表示できます。`/poll create-template` と `/poll delete-template` で作成と削除を行うか、ダッシュボードの **テンプレート** タブで管理できます。このタブでは、ファイルとしてのエクスポートとインポートもできます。テンプレートに設定できる選択肢は最大25個です。

## 設定

投票のページには、**投票**、**作成**、**予約済み**、**テンプレート**、**分析** の5つのタブがあります。

| 設定 | 既定値 | 制御する内容 |
| --- | --- | --- |
| 質問 | なし | 投票のタイトル |
| 投票の種類 | 単一選択 | 上記の5つの種類のいずれか |
| チャンネル | なし | 投票を投稿する場所 |
| 選択肢 | 空欄2つ | 2から25個の選択肢。それぞれ100文字まで。はい / いいえの場合は非表示 |
| 投票を許可するロール | なし | ロールによる制限の投票の場合に表示されます |
| 期間（分） | 終了するまで開いたまま | 1から20160分。予約時に適用されます |
| 後で予約 | なし | 日付と時刻。空欄のままにすると、すぐに投稿されます |
| 投票の変更を許可 | オン | メンバーが投票を変更または取り消せるかどうか |
| リアルタイムの結果を表示 | オン | 投票の実行中に票数を表示するかどうか |
| 進捗バーを表示 | オン | 票数の横にバーを描画するかどうか |
| テンプレートとしても保存 | オフ | **テンプレート名** の下に、質問と選択肢を保存します |

**投票** タブには、**非アクティブを含む** のチェックボックス付きで投票が一覧表示されます。投票を展開すると、ユニークな投票者、参加率、ピーク時間、作成日時が表示され、**投票を終了** のボタンがあります。**予約済み** では、保留中の投票を **キャンセル** できます。**分析** には、今月の投票数、投じられた票数、投票あたりの平均票数、よく使われる種類、1日あたりの投票数のグラフが表示されます。

## セットアップの手順

1. ダッシュボードで **投票** を開き、**作成** タブに移動します。
2. **質問** を入力し、**投票の種類** と **チャンネル** を選びます。
3. **選択肢** に入力します。余分な選択肢は削除ボタンで取り除きます。少なくとも2つ必要です。
4. ロールによる制限の投票の場合は、**投票を許可するロール** を選びます。
5. 必要であれば **テンプレートとしても保存** をオンにし、名前を付けます。
6. 送信ボタンをクリックします。投票はすぐに投稿されます。時刻を設定した場合は、**予約済み** タブに追加されます。
7. **投票** タブで結果を確認し、終わったら **投票を終了** を押します。

> [!TIP]
> チャンネルで簡単な投票をするだけなら、ダッシュボードは必要ありません。`poll Should we add a movie night?` を実行すると、数秒で「はい / いいえ」の投票が投稿されます。

## コマンド

サーバーのプレフィックスを付けて実行します（変更していなければ `.`）。

| コマンド | エイリアス | 必要な権限 | 用途 |
| --- | --- | --- | --- |
| `poll <question>` | `ppoll` | メッセージの管理 | 「はい / いいえ」の投票を投稿します |
| `pollc <question;option1;option2;...>` | | メッセージの管理 | 2から25個の選択肢を持つ単一選択の投票を投稿します |
| `pollm <question;option1;option2;...>` | | メッセージの管理 | 複数選択の投票を投稿します |
| `polla <question;option1;option2;...>` | | メッセージの管理 | 匿名の投票を投稿します |
| `polltemplate <name>` | `ptemplate` | メッセージの管理 | 保存されたテンプレートから投票を投稿します |
| `polltemplates` | `ptemplates` | なし | サーバーのテンプレートを一覧表示します |

`/poll` のスラッシュコマンドには、`create`（匿名と複数選択の切り替え付きで、最大10個の選択肢）、`close`、`stats`、`list`、`create-template`、`delete-template` があります。`close`、`create-template`、`delete-template` にはメッセージの管理の権限が必要です。

## ヒントと注意点

- ボットには、投票チャンネルでのメッセージの送信とリンクの埋め込みの権限が必要です。テキストコマンドでは、コマンドのメッセージも削除されるため、ボットにはメッセージの管理の権限も必要です。
- 選択肢はセミコロンで区切られるため、選択肢の中にセミコロンを含めることはできません。
- ボタンのラベルに選択肢の文字が表示されるのは、12文字以下の場合のみです。それより長い選択肢は番号だけが表示され、全文は埋め込みに表示されます。
- 期間は、スケジューラーによって適用されます。すぐに投稿された投票は、誰かが終了するまで開いたままです。自動で期限切れにしたい場合は、1分後の予約として設定してください。
- 終了した投票は、**非アクティブを含む** をオンにすると、ダッシュボードで引き続き表示およびエクスポートできます。削除された投票は、残りません。
- ロールによる制限の投票は、投票時にロールを確認します。そのため、ロールを失ったメンバーは投票できなくなりますが、以前の投票は残ります。
