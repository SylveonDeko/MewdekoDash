## 概要

メンバーは、メッセージを送信したり、ボイスチャンネルで話したりすることでXPを獲得します。XPは、選択したカーブに従って積み上がり、レベルになります。どのメンバーも `rank` を実行すると、レベル、進捗バー、サーバー内の順位、アバターを表示したランクカードを確認できます。`leaderboard` を実行すると、ランキング上位のメンバーを確認できます。

メンバーがレベルアップすると、ボットはチャンネル、専用のレベルアップチャンネル、またはDMでお知らせを投稿できます。プレースホルダーを使って独自のレベルアップメッセージを作成することも、デフォルトの埋め込みに任せることもできます。特定のレベルに到達すると、ロールやサーバー通貨を自動的に付与することもできます。

スタッフは、XPの獲得速度を管理できます。管理できる項目は、メッセージごとのXP、クールダウン、ボイスXP（1分あたり）、グローバル倍率、チャンネルごとおよびロールごとの倍率です。期間限定のブーストイベントを使うと、一定期間すべての獲得量を倍増できます。コンペティションでは、上位入賞者に報酬を与えるタイムレースを開催できます。ユーザー、ロール、チャンネルを除外できるため、botのスパム用チャンネルやミュートされたロールではXPを獲得できません。

## 利用するメリット

- アクティブなメンバーに進捗が見えるようにして、チャットを続けるきっかけを作れます。
- 設定したレベルでロールを解放できるため、スタッフが手作業で行わなくても、長く在籍しているメンバーに特典を提供できます。
- 週末のダブルXPイベントや「レベル20に最初に到達した人が勝ち」というレースを開催できます。
- コマンド用チャンネル、AFKチャンネル、botのロールを除外して、XPの公平性を保てます。
- 通貨モジュールと連携させ、レベルアップ時に報酬を支払えます。

## XPの獲得方法

### テキストXP

ボット以外のメンバーが送信したメッセージごとに、**メッセージごとのXP**（デフォルトは3、上限は50）が付与されます。ただし、付与されるのはクールダウン期間ごとに1回です。**メッセージXPのクールダウン**のデフォルトは60秒なので、その期間内に10件のメッセージを送信しても、XPが付与されるのは1回だけです。除外されたチャンネル、または除外されたユーザーやロールからのメッセージでは、XPは獲得できません。サーバー全体が除外されている場合は、一切カウントされません。

その後、獲得量に倍率が適用されます。以下の倍率はすべて重ねて適用されます。

| 倍率 | 設定方法 | 備考 |
| --- | --- | --- |
| グローバル倍率 | `setxpmultiplier` または **グローバルXP倍率** | すべての獲得量に適用されます |
| チャンネル倍率 | `setchannelxp` | そのチャンネルでの獲得量に適用されます |
| ロール倍率 | `setrolexp` | 倍率が設定されたロールを複数持っている場合は、最も高い倍率だけが使われます |
| ブーストイベント | `xpboost` | 有効なイベントはすべて適用されます |

計算結果は、小数点以下を切り捨てて整数になります。

**初回メッセージボーナス**は、メンバーが UTC の1日で最初に送信したメッセージに対して付与される1回限りの報酬です。XP設定には保存されていますが、ダッシュボードには表示されません。

### ボイスXP

ボイスXPは、セッションごとに記録されます。メンバーは、少なくとも2人の参加者（botは含みません）がいるボイスチャンネルに参加しており、本人またはサーバーによってミュートやスピーカーオフにされていない場合にのみ獲得できます。ミュート、スピーカーオフ、または一人でいた時間はカウントされません。

セッションが終了すると、有効な分数に**ボイスXP（1分あたり）**（デフォルトは2、上限は10）が掛けられます。15秒未満のセッションでは、XPは付与されません。**ボイスXPのタイムアウト**（デフォルトは60分）は、1回のセッションで報酬の対象となる最大分数です。倍率は、基本量が5以上の場合にのみボイスXPに適用されます。ボイスXP（1分あたり）またはタイムアウトを0に設定すると、ボイスXPは無効になります。

### XPの減衰

減衰はオプションで、デフォルトではオフになっています。オンにすると、12時間ごとにボットが、最後の活動が**減衰までの非活動日数**より前であるメンバーを探し、そのメンバーの総XPの**1日あたりの減衰率**分を差し引きます。これら3つの設定はXP設定レコードに存在しますが、まだコマンドやダッシュボードからは設定できません。

## レベルとカーブ

メンバーのレベルは、**XPカーブの種類**によって決まります。すべてのカーブは、レベル1に必要な36XPを基準としています。

| カーブ | コマンド名 | ダッシュボード名 | レベルnに必要なXP |
| --- | --- | --- | --- |
| 標準 | `Standard` | デフォルト | 36 x n の2乗 |
| 線形 | `Linear` | リニア | 36 x n |
| 加速 | `Accelerated` | 二次 | 36 x n の 1.25 乗 |
| 減速 | `Decelerated` | 指数 | 36 x n の 2.5 乗 |
| カスタム | `Custom` | 提供なし | 標準と同じ |
| レガシー | `Legacy` | レガシー | 各レベルは36に、前のレベルごとに9を加えた値が必要で、合計は累積されます |

標準がデフォルトです。`setxpcurve` でカーブを変更すると、2番目の引数に `false` を渡さない限り、全員のレベルが再計算されます。カーブを変更しても、メンバーの総XPは変わりません。変わるのは、その総XPがどのレベルに対応するかだけです。

## レベルアップ通知

各メンバーは `levelnotif` を使って、レベルアップの通知方法を選択できます。選択肢は `None`、`Channel`、`Dm` です。また、メンバーは `leveluppings false` を実行すると、ボットからのメンションを停止できます。その場合、名前はプレーンテキストで表示されます。

チャンネル通知は、`levelupchannel` でレベルアップチャンネルが設定されていればそのチャンネルに送信されます。設定されていない場合は、XPを獲得したチャンネルに送信されます。ボットには、そのチャンネルでのメッセージ送信権限が必要です。

サーバーにカスタムメッセージがない場合、デフォルトでは、レベルアップのメッセージをタイトルにした埋め込みが送信されます。埋め込みには、メンバーのアバターがサムネイルとして表示され、総XP、サーバー内の順位、新しいレベルのフィールドが含まれます。`addlevelupmessage` でカスタムメッセージを追加している場合は、有効なメッセージの中から毎回ランダムに1つが選ばれます。カスタムメッセージには、プレーンテキストか、埋め込みビルダーで作成した埋め込みのJSONを指定できます。テンプレートは `testlevelupmessage` でテストできます。

### プレースホルダー

以下のプレースホルダーは、カスタムのレベルアップメッセージ内で使用できます。プレースホルダーページにある一般的なユーザーやサーバーのプレースホルダーと併用できます。通知は、チャンネルや、通知の発生元となったユーザーを追跡しないため、`%xp.channel.*%` は「Unknown Channel」、`%xp.triggeruser.*%` は「System」に置き換えられ、`%xp.gained%` は常に 0 になります。

| プレースホルダー | 値 |
| --- | --- |
| `%xp.user%` | ユーザー名とタグ。メンションが無効な場合はユーザー名のみ |
| `%xp.user.mention%` | メンバーへのメンション。メンションが無効な場合はユーザー名のみ |
| `%xp.user.name%` | ユーザー名 |
| `%xp.user.displayname%` | 表示名 |
| `%xp.user.nickname%` | ニックネーム。設定されていない場合はユーザー名 |
| `%xp.user.avatar%` | アバターのURL |
| `%xp.user.id%` | ユーザーID |
| `%xp.user.created%` | アカウント作成日 |
| `%xp.user.joined%` | サーバー参加日 |
| `%xp.level.old%` | レベルアップ前のレベル |
| `%xp.level.new%` | 新しいレベル（`%xp.level.current%` も同じ値です） |
| `%xp.level.next%` | 新しいレベルに 1 を加えた値 |
| `%xp.level.difference%` | 上がったレベル数 |
| `%xp.total%` | 総XP |
| `%xp.current%` | 現在のレベル内で獲得したXP |
| `%xp.needed%` | 現在のレベルに必要な総XP |
| `%xp.remaining%` | 次のレベルまでに必要なXP |
| `%xp.progress%` | そのレベル内の進捗率（パーセント） |
| `%xp.rank%` | サーバー内の順位（数字） |
| `%xp.rank.ordinal%` | 「third」のような、単語で表した順位 |
| `%xp.rank.suffix%` | 接尾辞のみ（st、nd、rd、th） |
| `%xp.guild%`、`%xp.guild.name%` | サーバー名 |

| `%xp.timestamp%`、`%xp.timestamp.relative%` | 現在時刻を表すDiscordのタイムスタンプ形式 |

> [!EXAMPLE]
> `addlevelupmessage %xp.user.mention% just hit level %xp.level.new% and is now %xp.rank.ordinal% on the leaderboard.`

同じ一覧は、Discordで `levelupplaceholders` を実行すると確認できます。

## ロール報酬

`rolereward <level> <role>` は、メンバーが指定したレベルに到達したときにロールを付与します。**排他的なロール報酬**がオフ（デフォルト）の場合、メンバーは自分のレベル以下の報酬ロールをすべて保持し、自分のレベルより高い報酬ロールは失います。オン（`setxpexclusive true`）の場合は、メンバーが到達した最も高いレベルの報酬だけを保持し、ほかの報酬ロールはすべて削除されます。

報酬は、レベルが変わったときに適用されます。報酬を追加した後やXPをインポートした後にロールを揃えるには、`syncmyxproles`、`syncuserxproles`、`syncallxproles` を使用します。全ユーザーの同期は1時間に1回実行できます。ボットには、ロールの管理権限と、すべての報酬ロールより上位のロールが必要です。

## 通貨報酬

`currencyreward <level> <amount>` は、メンバーが指定したレベルに到達したときに、通貨モジュールのサーバー通貨を支払います。0を指定すると報酬は削除されます。`setxp` や減衰などによってメンバーのレベルが下がった場合、失ったレベルに対応する通貨は回収されます。

## 実績

[実績](/wiki/achievements)は、独自のポイントとランクを持つ別のシステムです。そのため、実績のランクはXPレベルとは異なります。両者が関係するのは次の2か所です。XPレベルに到達すると、コミュニティカテゴリの実績が解除されます。また、実績ごとのXP報酬、または実績の設定タブにある**ポイントあたりのXP**によって、実績からXPを付与できます。どちらも、設定するまでは無効です。

## ブーストイベント

`xpboost <time> <multiplier> <name>` は、期間限定のイベントを開始します。例：`xpboost 2h 2.0 Weekend XP Event`。有効なブーストはすべて、ほかの倍率に加えて、メッセージとボイスのXPを倍増させます。`xpboosts` は実行中のブーストを一覧表示し、`cancelboost <id>` は指定したブーストを途中で停止します。

## コンペティション

`xpcompetition <time> <type> [targetLevel] [name]` は、期間限定のレースを開始します。メンバーは、コンペティションの実行中に初めてXPを獲得すると、自動的に参加者として登録されます。

| 種類 | 勝者 |
| --- | --- |
| `MostGained` | コンペティション期間中に最も多くXPを獲得したメンバー |
| `ReachLevel` | 目標レベルに最初に到達したメンバー |
| `HighestTotal` | 終了時に総XPが最も多いメンバー |

賞品は `addcompetitionreward <id> <position> <type> <reward>` で追加します。種類は `Role`、`XP`、`Currency` のいずれかです。ロール報酬は付与され、XP報酬はボーナスXPとして追加され、通貨は通貨モジュールを通じて支払われます。`competitionleaderboard <id>` は現在の順位を表示し、`endcompetition <id>` はコンペティションを途中で終了して報酬を配布します。

## 除外

`xpexclude` と `xpinclude` では、ユーザー、ロール、テキストチャンネルを指定できます。除外されたユーザーや除外されたロールを持つメンバーは、XPを獲得できません。除外されたチャンネルでは、誰もXPを獲得できません。これはボイスチャンネルにも適用されます。`xpexcludelist users|roles|channels` は除外リストを表示します。スラッシュコマンドでは、`/xp admin exclude`、`/xp admin include`（`user`、`role`、`channel` のいずれかのオプションを指定）、`/xp exclude-list` を使用します。ダッシュボードの**サーバーXP除外**トグルを使うと、サーバー全体のXP獲得を一度に無効にできます。

## ランクカード

`rank [@user]` は、PNG形式のカードを生成します。`textrank [@user]` は、同じ情報をスクリーンリーダー向けにテキストで出力します。ボットにはランクがありません。

カードは、サーバーのテンプレートに基づいて作成されます。テンプレートには、背景画像（**カスタムXPカードの背景**で指定した独自画像、または組み込みの画像）と、アバターや名前、進捗バー、サーバーのレベル、サーバー内の順位、現在のレベルでの経過時間、付与されたボーナスXPのレイヤーが含まれます。各レイヤーは、表示・非表示の切り替え、移動、サイズ変更、色の変更が可能です。進捗バーは角丸、セグメント分け、円形にでき、任意の方向に塗りつぶせます。

**テンプレート**タブを開くと、ビジュアルエディターが表示されます。画面幅が768ピクセル未満の場合、ダッシュボードはタッチ用エディターに切り替わります。同じレイヤーを扱え、プロパティは下部のシートで編集でき、位置とサイズは簡単な操作で調整できます。画面が広い場合は、フルエディターが表示されます。レイヤー一覧、グリッド、スナップ、定規、元に戻す・やり直す、ズームが利用できます。

## リーダーボード

`leaderboard [page]` は、サーバーのランキングを表示します。サーバーで通貨モジュールも使用しており、通貨が流通している場合、引数なしの `leaderboard` を実行すると、XPと通貨のどちらを表示するか確認されます。ページ番号を指定した場合は、常にXPが表示されます。ダッシュボードの**リーダーボード**タブにも同じランキングが表示されます。そこには**XPを調整**の操作があり、メンバーのXPを追加、設定、リセットできます。ボーナスXPも同時に消去するかどうかを選べます。

## 設定

ダッシュボードには6つのタブがあります。**設定**、**統計**、**リーダーボード**、**報酬**、**テンプレート**、**除外**です。以下の設定は、**設定**タブにあります。

| 設定 | デフォルト | 制御する内容 |
| --- | --- | --- |
| サーバーXP除外 | オフ | サーバーでのXP獲得をすべて停止します |
| メッセージごとのXP | 3 | メッセージごとの基本XP。上限は50 |
| メッセージXPのクールダウン | 60秒 | メンバーごとの、メッセージXPの付与間隔の最小値 |
| ボイスXP（1分あたり） | 2 | 有効なボイス1分ごとの基本XP。上限は10。0でボイスXPを無効化 |
| ボイスXPのタイムアウト | 60分 | 1回のボイスセッションで報酬の対象となる最大分数 |
| グローバルXP倍率 | 1 | すべての獲得量に適用されます |
| XPカーブの種類 | デフォルト | XPをレベルに対応させるカーブ |
| カスタムXPカードの背景 | なし | ランクカードの背後に使われる画像のURL |

**報酬**タブではロール報酬と通貨報酬を管理し、**除外**タブでは除外するチャンネルとロールを管理します。**統計**タブでは、総ユーザー数、総XP、平均レベル、最高レベル、最近のXP活動を確認できます。

以下の項目も `GuildXpSetting` レコードに存在しますが、コマンドでのみ設定します。`FirstMessageBonus`、`ExclusiveRoleRewards`（`setxpexclusive`）、`LevelUpChannel`（`levelupchannel`）、`LevelUpMessage`、および減衰の項目である `EnableXpDecay`、`InactivityDaysBeforeDecay`、`DailyDecayPercentage` です。

## セットアップの手順

1. ダッシュボードで**XPシステム**を開き、**サーバーXP除外**がオフになっていることを確認します。
2. **設定**タブで、まずはメッセージとボイスの値をデフォルトのままにしておきます。カーブを選択してから、**変更を保存**を押します。
3. **除外**タブで、botのコマンド用チャンネルと、ミュートされたロールやbotのロールを除外します。
4. **報酬**タブで、いくつかの節目のレベルにロール報酬を追加します。botのロールがそれらのロールより上に配置されていることを確認してください。
5. Discordで `levelupchannel #level-ups` を実行し、1つか2つの `addlevelupmessage` テンプレートを追加します。`testlevelupmessage` でテストします。
6. **テンプレート**を開き、背景をアップロードして、カードをレイアウトします。`rank` を実行して結果を確認します。

## ヒントと注意点

- ロール報酬とロールの同期には、botにロールの管理権限が必要です。また、botの最上位ロールがすべての報酬ロールより上にある必要があります。`syncallxproles` と `syncuserxproles` は、この条件を満たさない場合には実行されません。
- ボイスXPを獲得するには、チャンネルに、ミュートおよびスピーカーオフになっていない人間が少なくとも2人必要です。一人でいる、またはミュートされているメンバーは、どれだけ長く滞在しても何も獲得できません。
- XPの獲得は一括処理され、バックグラウンドで書き込まれます。そのため、`rank` の結果は最後のメッセージから数秒遅れることがあります。
- `setxp` や `resetxp` でメンバーのXPを下げると、レベルが下がる場合があります。その結果、ロール報酬が削除され、失ったレベル分の通貨報酬は回収されます。
- `Custom` カーブは標準と完全に同じ動作をし、ダッシュボードには表示されません。古い設定から移行していて、既存のレベルを揃えたい場合にのみ、レガシーを選択してください。
- カスタムのレベルアップメッセージは、デフォルトの埋め込みを完全に置き換えます。すべてのカスタムメッセージを無効にすると、デフォルトの埋め込みが再び使われます。
- ブーストイベントとコンペティションはコマンドでのみ管理されます。ダッシュボードには表示されません。
