## Що це робить

Модуль NSFW отримує зображення для дорослих з image board-ів і Reddit на запит. Кожна команда в ньому має вимогу Discord щодо NSFW: вона працює лише в каналі з увімкненим прапорцем NSFW, а більшість команд image board також працюють у особистих повідомленнях з ботом. В іншому каналі команда мовчки відхиляється.

Персонал керує двома речами. `nsfwtoggle` (у модулі Administration) перемикає прапорець NSFW поточного каналу, що саме відкриває в ньому ці команди. `nsfwtagbl` веде список тегів, які видаляються з кожного пошуку на image board на цьому сервері, тож сервер може дозволити модуль і водночас виключати небажаний контент.

Учасники запускають команду джерела з необов'язковими тегами і отримують одне зображення з його рейтингом, джерелом і першими тегами. Варіанти «bomb» публікують одразу чотири. Модератори також можуть запустити таймер, який постить нове зображення в канал щоразу через задану кількість секунд.

## Навіщо це потрібно

- Сервер для 18+ хоче обмежити команди із зображеннями відміченими каналами.
- Персонал хоче блокувати певні теги на всьому сервері, не вимикаючи модуль.
- Окремий канал має отримувати нове зображення за таймером без того, щоб хтось писав команду.

## Вимога каналу

Прапорець NSFW в Discord встановлюється для кожного каналу окремо. Запусти `nsfwtoggle` у каналі, щоб увімкнути або вимкнути його; для цього потрібен дозвіл Керувати каналами як для тебе, так і для бота. Бот відповідає, підтверджуючи новий стан. Той самий прапорець можна встановити в налаштуваннях каналу Discord.

Якщо команду використано в каналі без NSFW, нічого не відбувається. Учасники іноді вважають, що бот зламаний, тож примітка в каналі з правилами допоможе.

## Джерела

| Команда | Джерело | Примітки |

| `hentai [tags]` | Об'єднані борди, лише explicit | Затримка п'ять секунд |

Теги розділяються пробілами. На e621 і Derpibooru тег `yuri` автоматично перекладається на відповідник цього борду. На сервері може одночасно працювати лише один `hentaibomb` і один `pornbomb`.

## Чорний список тегів

`nsfwtagbl` без аргументів показує заблоковані теги. `nsfwtagbl <tag>` додає тег, або видаляє його, якщо він уже в списку. Результати, що містять тег із чорного списку, пропускаються для кожної команди image board на сервері. Потрібен дозвіл Керувати повідомленнями.

## Автопостинг

`autohentai <seconds> [tags]`, `autoboobs <seconds>` і `autobutts <seconds>` запускають таймер у поточному каналі. Інтервал має бути не менше 20 секунд для `autohentai` і `autobutts`; для `autoboobs` мінімуму немає. Якщо запустити команду з `0` або без інтервалу, таймер для цього каналу зупиняється. Для `autohentai` розділяй альтернативні набори тегів символом `|`, і бот щоразу обирає один навмання; без тегів отримуватимуться випадкові зображення. Для цих команд потрібен дозвіл Керувати повідомленнями, а канал має бути NSFW. Таймери не переживають перезапуску бота.

## Налаштування

Для цього модуля немає сторінки в панелі керування.

| Налаштування | За замовчуванням | Що контролює |
| --- | --- | --- |
| Прапорець NSFW каналу | вимкнено | Чи працюють у каналі ці команди |
| Чорний список тегів | порожньо | Теги, які виключаються з результатів image board на цьому сервері |
| Таймери автопостингу | немає | Таймери для каналів, запущені командами `auto...` |

## Покрокове налаштування

1. Обери канал і запусти в ньому `nsfwtoggle` або встанови прапорець у налаштуваннях каналу Discord.
2. Використай Дозволи команд, щоб тримати модуль подалі від усього іншого, наприклад `srvrmdl nsfw disable`, а потім `chnlmdl nsfw enable #adult`.
3. Додай теги, яких не хочеш бачити, командою `nsfwtagbl <tag>`, по одному тегу за раз.
4. Перевір роботу командою `hentai` або `rule34 <tag>` у каналі.
5. За бажанням запусти `autohentai 300 <tags>`, а пізніше зупини його командою `autohentai 0`.

## Поради та підводні камені

- Вік обмежується прапорцем NSFW каналу Discord і чорним списком тегів бота. Бот не перевіряє вік учасників чи їхні ролі; для цього використовуй Дозволи команд.
- Власники бота також можуть вимкнути модуль глобально, тоді в меню довідки він показується як заблокований.
- Image board-и мають ліміти частоти запитів і іноді нічого не повертають для вузьких комбінацій тегів; тоді бот повідомляє, що зображення не знайдено.
- Таймери налаштовуються для кожного каналу окремо і зберігаються в пам'яті. Після перезапуску запусти їх знову.
