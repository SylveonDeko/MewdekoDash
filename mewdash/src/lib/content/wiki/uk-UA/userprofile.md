## Що це робить

Кожен учасник має профіль, який діє на всіх серверах, де є бот. Команда `profile` публікує його у вигляді embed: аватар учасника як мініатюру, біо як опис, потім поля з займенниками, знаком зодіаку, днем народження, кількістю спільних із ботом серверів і кодом друга Nintendo Switch, якщо він його вказав. Власний колір і велике зображення внизу завершують картку.

Учасники заповнюють профіль кількома командами `set...` або на сторінці **Мої налаштування** панелі керування. Ніщо не прив’язане до сервера: вказавши біо один раз, ти бачитимеш його скрізь.

Приватністю керує сам учасник. Профіль можна зробити приватним, щоб відкрити його міг лише власник, день народження можна обрізати до місяця або приховати повністю, а учасники можуть відмовитися від збору статистики команд і від привітальних особистих повідомлень.

Займенники трохи особливі. Якщо учасник не вказав їх у боті, бот шукає їх на PronounDB. Учасники можуть перевизначити їх власним текстом, а будь-хто може поскаржитися власникам бота на образливе перевизначення.

## Навіщо це потрібно

- Учасникам потрібна швидка картка «про мене» без окремого каналу для знайомств.
- Спільнота, яка ділиться кодами друзів Switch, може тримати їх в одному місці, а не закріплювати повідомлення.
- Займенники можна автоматично показувати з PronounDB, тож більшості людей їх не доведеться вписувати самим.
- Персонал може перевірити займенники командою `pronouns @user` перед відповіддю.
- Учасники, які не хочуть привітальних особистих повідомлень або збору статистики, можуть вимкнути це самі.

## Embed профілю

`profile` без аргументів показує твій власний профіль. `profile @user` показує чужий, якщо тільки власник не зробив його приватним; тоді бот відповідає, що профіль приватний.

| Частина embed | Звідки береться |
| --- | --- |
| Заголовок | "Profile for" і користувач |
| Колір | `setprofilecolor`, інакше типовий колір бота |
| Мініатюра | Аватар учасника в Discord |
| Опис | Біо з `setbio` (показується лише якщо задано) |
| "Pronouns" | Твоє перевизначення, інакше PronounDB, інакше "Unspecified" |
| "Zodiac Sign" | `setzodiac`, інакше "Unspecified" |
| "Birthday" | `setbirthday`, показується згідно з режимом приватності дня народження, інакше "Unspecified" |
| "Mutual Bot Servers" | Скільки серверів є спільними для тебе і бота |
| "Switch Friend Code" | Показується лише якщо задано |
| Зображення | URL із `setprofileimage` |

## Поля профілю

### Біо

`setbio <text>` приймає до 2048 символів. Довший текст відхиляється. Команди очищення немає; якщо хочеш прибрати біо, постав коротке, наприклад одну крапку.

### Знак зодіаку

`setzodiac <sign>` приймає один із дванадцяти західних знаків: Aries, Taurus, Gemini, Cancer, Leo, Virgo, Libra, Scorpio, Sagittarius, Capricorn, Aquarius, Pisces. Регістр не має значення. Усе інше відхиляється.

### Колір і зображення

`setprofilecolor <colour>` приймає колір у будь-якому форматі, який розуміє парсер кольорів бота, наприклад шістнадцятковий код. `setprofileimage <url>` потребує прямого посилання на файл зображення; бот перевіряє, що URL схожий на зображення, перш ніж зберегти його, і показує його тобі.

### День народження

`setbirthday <date>` зберігає дату. Оголошення модуля Birthday використовують те саме значення, тож якщо встановити його тут, воно буде і там. Як він відображається у профілі, залежить від `setbirthdayprivacy <mode>`:

| Режим | Що показує профіль |
| --- | --- |
| `Default` | Повну дату |
| `MonthOnly` | Лише назву місяця |
| `YearOnly` | Лише рік |
| `MonthAndDate` | Місяць і день без року |
| `Disabled` | "Private" |

### Код друга Switch

`setswitchfc <code>` має відповідати формату `SW-XXXX-XXXX-XXXX` (по чотири цифри в кожній групі; `SW` без урахування регістру). Запусти команду без коду, щоб прибрати його з профілю. Модуль Nintendo Switch до цього поля не має стосунку; код потрібен лише для відображення.

### Приватність

`setprivacy public` або `setprivacy private`. Приватні профілі видно лише власнику. Типово профіль публічний.

## Займенники

`pronouns [@user]` показує займенники для тебе або для когось іншого. Порядок пошуку:

1. Текст, який учасник встановив командою `setpronouns`.
2. Англійський набір займенників учасника на PronounDB, якщо він прив’язав свій акаунт Discord там. Стандартні набори показуються у звичній формі, наприклад `he/him`, `Any pronouns` або `Ask me my pronouns`.
3. "Unspecified".

`setpronouns <text>` зберігає перевизначення. Запущений без тексту, він показує твоє поточне перевизначення з двома кнопками: **Overwrite** відкриває форму для введення нових займенників, а **Очистити** видаляє перевизначення, щоб знову використовувався PronounDB.

Коли показані займенники походять із власного перевизначення учасника (а не з PronounDB), відповідь містить кнопку **Report**. Скарги надходять у канал, яким керують власники бота; там вони можуть очистити перевизначення, вимкнути займенники для цього користувача або додати його до чорного списку. Користувач, для якого займенники вимкнено, бачить причину щоразу, коли намагається використати команди займенників.

> [!NOTE]
> Команда власника бота `pronounsforceclear` — це спосіб, яким обробляються такі скарги. Персонал сервера не може очистити займенники іншого учасника.

## Відмова від збору даних

- `greetdmoptout` перемикає, чи можуть сервери, які використовують привітальні особисті повідомлення бота, писати тобі. Це стосується лише привітань, які надсилає цей бот.
- `userstatsoptout` перемикає збір статистики команд для твого акаунта. Вміст повідомлень ніколи не збирається.
- `deleteuserstatsdata` видаляє вже збережену для тебе статистику команд після підтвердження. Можна запускати раз на годину.

## Налаштування

Серверних налаштувань немає. Усе зберігається на рівні учасника. На сторінці панелі **Мої налаштування** (`/me`) є розділ **Профіль** з кнопкою **Редагувати** та розділ приватності з перемикачами.

| Налаштування | Типове значення | Що контролює |
| --- | --- | --- |
| Біо | порожньо | Опис у твоєму профілі |
| Займенники | порожньо (використовується PronounDB) | Твоє перевизначення займенників |
| Зодіак | немає | Знак зодіаку в профілі |
| День народження | немає | Дата в профілі та для оголошень про день народження |
| Часовий пояс | UTC | Часовий пояс, який модуль Birthday використовує для твого оголошення |
| Код друга Switch | порожньо | Поле коду друга в профілі |
| Колір профілю | типовий для бота | Колір embed |
| Зображення профілю | немає | Зображення внизу embed |
| Приватність профілю | Публічний | Чи можуть інші відкривати твій профіль |
| Режим показу дня народження | Типовий | Які частини дня народження показуються |
| Блокувати привітальні ПП | вимкнено | Те саме, що `greetdmoptout` |
| Блокувати відстеження повідомлень | вимкнено | Те саме, що `userstatsoptout` |
| Оголошення про день народження | вимкнено | Чи модуль Birthday оголошує твій день народження |

На цій самій сторінці також є перемикач, який вимикає отримання займенників для твого акаунта.

## Покрокове налаштування

1. Запусти `setbio Hi, I run the art channel.`, щоб додати опис.
2. Запусти `setpronouns she/her` або пропусти цей крок, якщо твій акаунт PronounDB уже прив’язаний до Discord.
3. Запусти `setbirthday 1998-04-12`, а потім `setbirthdayprivacy MonthAndDate`, якщо не хочеш показувати рік.
4. Запусти `setprofilecolor #ff66aa` і `setprofileimage https://example.com/banner.png`, щоб оформити embed.
5. Додай `setswitchfc SW-1234-5678-9012`, якщо хочеш, щоб люди могли знайти тебе в Switch.
6. Запусти `profile`, щоб перевірити результат. Якщо не хочеш, щоб його бачив хтось інший, запусти `setprivacy private`.

## Команди

Виконуй ці команди з префіксом свого сервера (`.`, якщо ти його не змінював). Слеш-версії існують для більшості з них під назвами на кшталт `/profile`, `/setbio`, `/setcolor`, `/setbirthday`, `/setbirthdayprivacy`, `/setswitchfriendcode`, `/setprofileimage`, `/setprivacy`, `/setzodiac`, `/pronouns`, `/setpronouns`, `/statsoptout` і `/deletestatsdata`.

| Команда | Псевдоніми | Потрібно | Призначення |
| --- | --- | --- | --- |
| `profile [@user]` | `userprofile` | Нікому | Показати твій профіль або чийсь інший |
| `setbio <text>` | | Нікому | Встановити біо, до 2048 символів |
| `setpronouns [text]` | `pronounsset` | Нікому | Встановити перевизначення займенників або переглянути його з кнопками очищення та перезапису |
| `pronouns [@user]` | `getpronouns` | Нікому | Показати займенники, з кнопкою скарги для перевизначень |
| `setzodiac <sign>` | | Нікому | Встановити твій знак зодіаку |
| `setprofilecolor <colour>` | | Нікому | Встановити колір embed |
| `setprofileimage <url>` | | Нікому | Встановити зображення, яке показується в профілі |
| `setbirthday <date>` | | Нікому | Встановити твій день народження |
| `setbirthdayprivacy <mode>` | | Нікому | `Default`, `MonthOnly`, `YearOnly`, `MonthAndDate` або `Disabled` |
| `setprivacy <Public|Private>` | `profilepricvacy` | Нікому | Зробити профіль публічним або приватним |
| `setswitchfc [code]` | `setfc`, `setswitchfriendcode`, `setfriendcode` | Нікому | Встановити або очистити твій код друга Switch |
| `greetdmoptout` | `gdmoptout` | Нікому | Перемкнути отримання привітальних ПП від цього бота |
| `userstatsoptout` | `ustatsoptout` | Нікому | Перемкнути збір статистики команд |
| `deleteuserstatsdata` | `deluserstatsdata` | Нікому | Видалити збережену статистику команд (раз на годину) |
| `pronounsforceclear <@user or id> <true|false> <reason>` | `pnfc` | Власник бота | Очистити займенники учасника й за бажанням вимкнути їх |

## Поради та підводні камені

- Профіль глобальний. Зміна на одному сервері змінює його скрізь.
- `setbirthday` читає дату парсером дат бота, тому найбезпечніший однозначний формат, як-от `1998-04-12`.
- Якщо URL зображення профілю перестане працювати, embed усе одно надсилається, але Discord не показує зображення. Щоб виправити це, встанови новий URL.
- Запити до PronounDB потребують, щоб учасник прив’язав свій акаунт Discord на pronoundb.org. Без цього профіль показує "Unspecified", доки учасник не запустить `setpronouns`.
- Приватні профілі все одно відповідають на `profile @user`, але з помилкою про приватність профілю, щоб люди розуміли, що він існує.
- `deleteuserstatsdata` видаляє лише статистику команд. Поля профілю очищаються перезаписом.
