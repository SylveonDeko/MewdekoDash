## Що це робить

Раз на день, у годину, яку сервер обирає у своєму часовому поясі, бот публікує слово в обраному каналі. Допис показує слово, його вимову, частину мови, визначення і, коли він є, приклад речення. Роль можна пінгувати з кожним дописом.

Слова беруться зі словника Datamuse і фільтруються трьома налаштуваннями: **тема**, до якої мають тяжіти слова, **частина мови** та **складність**, яка визначається тим, як часто слово трапляється в писемній англійській. Бот уникає повторів того, що вже публікував за останні дев'яносто днів.

Сервери також можуть скласти **власний список** за допомогою `wotdadd`. Якщо визначення не вказано, бот шукає його сам. **Режим джерела** визначає, чи дописи беруться зі словника, зі власного списку, або спершу зі власного списку, а коли він закінчується — зі словника.

## Розклад за днем тижня або місяцем

Правила можуть перевизначати тему, частину мови та складність для конкретного дня тижня або місяця. Правило змінює лише ті поля, які задані, тож правило для понеділка лише з темою все ще використовує базову частину мови та складність. Коли діють обидва, правила для дня тижня мають пріоритет над правилами для місяця, а правила для місяця — над базовими налаштуваннями.

Приклади:

- `wotdday monday science` робить слово понеділка тематичним для науки.
- `wotddayfilter friday adjective rare` робить п'ятничні слова рідкісними прикметниками.
- `wotdmonth october spooky halloween` задає тему для всього жовтня.
- `wotdschedule` показує всі правила і те, які фільтри діють сьогодні.

## Тред обговорення

Якщо це увімкнено, бот створює публічний тред під кожним щоденним дописом і додає початкову підказку, яка запрошує людей використати слово в реченні. Назва треду береться з шаблону (за замовчуванням `Word of the day: %wotd.word%`), який підтримує `%wotd.word%`, `%wotd.date%`, `%wotd.pos%` і звичайні плейсхолдери сервера. `wotdthread` вмикає або вимикає тред, `wotdthreadname` встановлює, показує або очищує шаблон назви, а `wotdthreadarchive` визначає, як довго тред залишається відкритим до автоматичного архівування (1 година, 1 день, 3 дні або 1 тиждень).

## Команди

| Команда | Що робить |
| --- | --- |
| `wotd` | Показує сьогоднішнє слово або попередній перегляд, якщо ще нічого не опубліковано. |
| `wotdchannel #channel` | Встановлює канал і вмикає публікацію. |
| `wotdtime 9` | Встановлює локальну годину для публікації. |
| `wotdtimezone Europe/London` | Встановлює часовий пояс. |
| `wotdtopic space` | Встановлює базову тему. |
| `wotdpos noun` | Обмежує частину мови. |
| `wotddifficulty rare` | Встановлює складність. |
| `wotdmode mixed` | Обирає словник, власний список або змішаний режим. |
| `wotdadd word [definition]` | Додає власне слово. |
| `wotdmessage` | Встановлює власний шаблон повідомлення з плейсхолдерами або JSON embed. |
| `wotdthread` | Вмикає або вимикає тред обговорення під кожним дописом. |
| `wotdthreadname [template\|clear]` | Встановлює, показує або очищує шаблон назви треду. |
| `wotdthreadarchive 1h\|24h\|3d\|7d` | Визначає, як довго тред залишається відкритим до автоматичного архівування. |
| `wotdpost` | Публікує нове слово просто зараз. |

## Плейсхолдери повідомлення

`%wotd.word%`, `%wotd.definition%`, `%wotd.pos%`, `%wotd.example%`, `%wotd.phonetic%`, `%wotd.date%` і `%wotd.ping%` доступні у власному шаблоні разом із звичайними плейсхолдерами сервера.
