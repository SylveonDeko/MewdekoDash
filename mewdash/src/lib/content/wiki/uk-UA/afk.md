## Що це робить

Учасник виконує `afk` з необов'язковим повідомленням. Відтоді, коли хтось його згадує, бот відповідає в цьому каналі повідомленням і вказує, як довго його немає. Коли учасник повертається, статус знімається, публікується коротке повідомлення «welcome back», яке видаляється через п'ять секунд, а нікнейм відновлюється.

Поки учасник відсутній, бот також намагається перейменувати його на `[AFK] name`, обрізаючи назву до ліміту нікнеймів Discord, щоб статус було видно у списку учасників.

Якщо виконати `afk` без повідомлення, команда працює як перемикач: якщо ти не відсутній, вона вмикає AFK з порожнім повідомленням, а якщо відсутній, вимикає його.

## Навіщо це потрібно

- Учасників на активних серверах не смикають постійно ті, хто не бачив їхнього «brb».
- Персонал бачить із першого погляду, хто є на сервері, а кого немає.
- Таймер AFK покриває «повернуся через дві години» без того, щоб хтось мусив пам'ятати про скидання.

## Як завершується статус

**Тип зняття AFK** визначає, що бот вважає поверненням. Це найважливіше налаштування на сторінці.

| Тип | Статус знімається, коли |
| --- | --- |
| Self disable | Учасник знову виконує `afk` або персонал прибирає статус. Нічого автоматичного. |
| On message | Учасник надсилає повідомлення будь-де на сервері. |
| On type | Учасник починає друкувати в будь-якому каналі. |
| Either | Повідомлення або друк, що станеться раніше. |

**Час до AFK** — це пільговий період, що відлічується від моменту встановлення статусу. Протягом цього вікна друк або надсилання повідомлення не знімають статус, тож саме повідомлення «afk, brb» не завершує AFK одразу. Типове значення 0, тобто пільгового періоду немає; задати його можна командою `afktimeout` або на вкладці **Додаткові налаштування** сторінки панелі керування.

Таймер AFK працює інакше: він триває, доки не спливе таймер, незалежно від типу. Розмови між цим не завершують його. Коли таймер спливає, статус знімається і нікнейм відновлюється без повідомлення в каналі.

Редагування повідомлення протягом п'яти хвилин після публікації враховується так само, як надсилання нового.

## Відповідь на згадку

Коли хтось згадує відсутнього учасника, бот перевіряє до п'яти згаданих користувачів в одному повідомленні, ігнорує ботів і самозгадування, ігнорує повідомлення, які починаються з префікса команди, і пропускає канали зі списку вимкнених. Для кожного відсутнього учасника, якого знаходить, він публікує відповідь.

За замовчуванням відповідь є embed: рядок автора говорить «user is currently away» з їхнім аватаром, в описі — їхнє повідомлення AFK, а у футері вказано, як довго їх немає. Якщо бота налаштовано показувати кнопку запрошення, вона додається.

Замість цього можна вивести власне повідомлення або embed через `customafkmessage` або редактор **Власне embed-повідомлення AFK** на панелі керування. Текст обробляється парсером embed, тож працює все, що створює конструктор embed. Щоб повернутися до стандартного embed, встанови `-`.

### Плейсхолдери

Вони замінюються у власному повідомленні AFK. Загальні плейсхолдери зі сторінки плейсхолдерів тут недоступні; працює лише цей набір.

| Плейсхолдер | Значення |
| --- | --- |
| `%afk.message%` | Повідомлення AFK, із нейтралізованими згадками й обрізане до максимальної довжини |
| `%afk.user%` | Ім'я користувача відсутнього учасника |
| `%afk.user.mention%` | Згадка відсутнього учасника |
| `%afk.user.avatar%` | URL аватара відсутнього учасника |
| `%afk.user.id%` | ID користувача відсутнього учасника |
| `%afk.triggeruser%` | Ім'я користувача, який його згадав |
| `%afk.triggeruser.mention%` | Згадка того, хто його згадав |
| `%afk.triggeruser.avatar%` | URL аватара того, хто його згадав |
| `%afk.triggeruser.id%` | ID користувача того, хто його згадав |
| `%afk.time%` | Як довго його немає, словами, наприклад «2 hours» |

> [!EXAMPLE]
> Текстова відповідь: `%afk.user.mention% is away (%afk.time%): %afk.message%`

## Налаштування

Усі ці налаштування розташовані на сторінці AFK, на вкладках **Основні налаштування** і **Додаткові налаштування**.

| Налаштування | За замовчуванням | Що контролює |
| --- | --- | --- |
| **Час автовидалення** | 0 (ніколи) | Секунди, через які відповідь бота на згадку видаляється сама |
| **Максимальна довжина повідомлення** | 128 | Найдовше повідомлення AFK, яке учасник може встановити, від 1 до 4096; довші відхиляються |
| **Тип зняття AFK** | Self disable | Один із чотирьох типів вище |
| **Час до AFK** | 0 (немає) | Пільговий період після встановлення AFK, до двох годин |
| **Вимкнені канали** | немає | Канали, де згадка відсутнього учасника не отримує відповіді |
| **Власний embed AFK** | стандартний embed | Твоя відповідь із плейсхолдерами вище |

> [!TIP]
> Постав автовидалення близько тридцяти секунд. Той, хто згадав, бачить відповідь, а канал не заповнюється застарілими повідомленнями AFK.

Вкладка **Керування користувачами** показує кожного учасника, який зараз відсутній, і дозволяє персоналу очистити статус для однієї або кількох людей одразу.

## Покрокова інструкція з налаштування

1. Відкрий **Система AFK** на панелі керування.
2. Обери **Тип зняття AFK**. «On message» — найбезпечніший варіант за замовчуванням; «Either» — найзручніший.
3. Постав **Час автовидалення** на 30. Залиш **Максимальну довжину повідомлення** 128, якщо не хочеш довших статусів.
4. На **Додаткових налаштуваннях** додай канали для команд бота та канали оголошень до **Вимкнені канали**.
5. За бажанням створи власну відповідь у редакторі embed, використовуючи плейсхолдери вище.
6. Перевір: виконай `afk testing`, згадай себе з іншого акаунта, а потім надішли повідомлення і подивись, як статус знімається.

## Команди

Запускай їх з префіксом свого сервера (`.`, якщо ти його не змінював).

| Команда | Псевдоніми | Потрібно | Призначення |
| --- | --- | --- | --- |
| `afk [message]` | | Нікому | Встановити своє повідомлення AFK або перемкнути AFK без повідомлення |
| `timedafk <time> <message>` | `tafk` | Нікому | AFK, який сам завершується, наприклад `timedafk 2h dinner` |
| `getactiveafks` | `activeafks` | Нікому | Показати всіх, хто зараз у статусі AFK |
| `afkview [@user]` | `viewafk` | Керування повідомленнями | Показати поточне повідомлення AFK когось |
| `afkremove @user...` | `afkrm` | Керування повідомленнями | Очистити статуси одного або кількох учасників |
| `afkdel [seconds]` | `afkdelete` | Керування сервером | Показати або встановити автовидалення відповіді |
| `afklength <number>` | `maxafklength` | Адміністратор | Обмежити довжину повідомлення AFK |
| `afktype <type>` | | Адміністратор | `selfdisable`, `onmessage`, `ontype` або `either` |
| `afktimeout <time>` | | Адміністратор | Встановити пільговий період, наприклад `30s` |
| `afkdisable #channel...` | | Керування каналами | Додати канали до списку без відповідей |
| `afkundisable #channel...` | | Керування каналами | Прибрати канали зі списку без відповідей |
| `afkdisabledlist` | | Керування каналами | Показати список без відповідей |
| `customafkmessage <text>` | `afkmessage` | Адміністратор | Встановити власну відповідь або `-`, щоб скинути |

## Поради та підводні камені

- Немає команди, яка очищає лише твій власний статус. Виконай `afk` ще раз без повідомлення або дочекайся, поки статус зніме правило типу.
- Зміна нікнейму потребує, щоб роль бота стояла вище за найвищу роль учасника, і дозволу Керування нікнеймами. Нікнейм власника сервера бот змінити не може, тож власники зберігають своє ім'я, але статус усе одно працює.
- Служба AFK завантажує свій кеш незабаром після запуску бота. Доки це не сталося, команди відповідають, що AFK ще запускається.
- Згадки в повідомленні AFK нейтралізуються у відповіді, тож учасники не можуть використовувати свій статус, щоб пінгувати ролі або @everyone.
