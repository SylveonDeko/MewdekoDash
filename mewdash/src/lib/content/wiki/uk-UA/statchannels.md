## Що це робить

Статистичний канал — це заблокований голосовий канал, який стоїть угорі списку каналів і показує число у своїй назві, наприклад "Members: 12,480". Бот переписує назву за розкладом, тож число завжди актуальне. Учасники не можуть приєднатися до такого каналу, він існує лише для перегляду.

Ти обираєш тип лічильника, шаблон для назви, стиль числа та те, як часто його оновлювати. Бот підтримує кілька десятків лічильників: факти про сервер, присутність, бусти Nitro, слоти для емодзі, цілі за кількістю учасників і відліки, а також значення з інших функцій Mewdeko, як-от тікети, пропозиції, giveaway, XP, підрахунок, зоряна дошка та підключені сервери Twitch або Minecraft.

Discord дозволяє перейменовувати канал лише двічі за десять хвилин. Статистичні канали обходять це обмеження: можна обрати механізм оновлення, зокрема такий, що видаляє канал і створює його заново, тож він може оновлюватися щохвилини.

## Навіщо це потрібно

- Показувати кількість учасників, людей і ботів угорі сервера.
- Відстежувати прогрес до цілі за кількістю учасників у відсотках або на шкалі прогресу.
- Відраховувати час до події, запуску чи річниці.
- Показувати статус стріму Twitch і кількість глядачів для стрімера на сервері.
- Дати персоналу живий огляд відкритих тікетів або пропозицій, що очікують рішення, без відкриття панелі керування.
- Показувати статус сервера Minecraft і кількість гравців поруч із посиланням-запрошенням.

## Типи лічильників

Повний перелік нижче — це те, що показують команда `statchanneltypes` і розділ **Доступні лічильники** на панелі керування. Кожен тип приймає спільні плейсхолдери, а деякі додають власні. Типові шаблони наведено так, як вони виглядають за замовчуванням.

## Стилі відображення

**Стиль лічильника** визначає, як відображається `%count%`. Він застосовується лише до числових лічильників. Текстові лічильники, як-от `NewestMember`, виводять текст як є, а лічильники типу так/ні, як-от `TwitchLiveStatus`, виводять текст на кшталт "LIVE" або "Offline".

| Стиль | Приклад для 1234 | Примітки |
| --- | --- | --- |
| `Plain` | `1234` | Звичайні цифри |
| `Comma` | `1,234` | Роздільники тисяч. Типовий стиль. |
| `Compact` | `1.2K` | Суфікси K, M, B, T, типово з одним знаком після коми |
| `Padded` | `1234` | Доповнення нулями до фіксованої ширини, типово чотири цифри, тож 42 стає `0042` |
| `Ordinal` | `1,234th` | Додає st, nd, rd або th |
| `Percent` | `61.7%` | Значення як відсоток від цільового значення, типово з одним знаком після коми |
| `ProgressBar` | шкала з десяти клітинок | Заповнені та порожні клітинки відносно цільового значення, типово десять клітинок |
| `EmojiDigits` | цифри у вигляді емодзі-клавіш | Кожна цифра як емодзі-клавіша |
| `Roman` | `MCCXXXIV` | Римські числа від 1 до 3999, інакше повертається стиль Comma |

Стилі `Percent` і `ProgressBar` потребують цільового значення для порівняння. Без нього вони показують `0%` або порожню шкалу.

## Механізми оновлення

| Механізм | Мітка на панелі | Як це працює |
| --- | --- | --- |
| `Rename` | Лише перейменування | Змінює назву каналу. Discord дозволяє два перейменування на канал за десять хвилин, тож інтервал оновлення примусово не менший за 5 хвилин. ID каналу ніколи не змінюється. |
| `Recreate` | Видалити і створити знову | Створює новий канал з тією самою назвою, категорією, позицією та перевизначеннями дозволів, а потім видаляє старий. Може оновлюватися щохвилини, але ID каналу змінюється під час кожного оновлення, а кожне оновлення залишає два записи в журналі аудиту. |
| `Auto` | Авто (рекомендовано) | Перейменовує, доки дозволяє бюджет на два перейменування за десять хвилин. Коли бюджет вичерпано і інтервал менший за 5 хвилин, натомість перестворює канал. Коли інтервал 5 хвилин або більше, просто чекає наступного слота для перейменування. |

Типовий механізм для нових статистичних каналів — **Авто** з інтервалом **5 хвилин**. Інтервали обмежені діапазоном від 1 хвилини (5 для Rename) до 1440 хвилин. Бот кожні 30 секунд перевіряє канали, у яких минув інтервал.

> [!WARNING]
> Recreate змінює ID каналу. Усе інше, що посилається на канал, як-от налаштування дозволів в інших ботах або закріплені посилання, ламається під час кожного оновлення. Використовуй цей механізм лише там, де швидке оновлення важливіше за стабільний ID.

## Налаштування

Сторінка має три вкладки: **Статистичні канали**, **Додати** і **Типові значення**, а також кнопку **Оновити** у заголовку. У вкладці **Статистичні канали** показано всі налаштовані канали з кнопками **Редагувати** та **Видалити**.

**Додати статистичний канал** пропонує **Створити новий канал** або **Використати наявний канал** з вибором **Голосовий канал**, а потім:

| Налаштування | Типово | Що керує |
| --- | --- | --- |
| Категорія (необов'язково) | немає | Де розміщувати новостворений канал |
| Лічильник | немає | Тип лічильника з переліку |
| Шаблон | типовий для типу | Назва каналу з плейсхолдерами; клацни на плейсхолдер, щоб вставити його, а попередній перегляд оновлюється під час набору |
| Стиль лічильника | Comma | Стиль відображення з таблиці вище |
| Механізм оновлення | Авто | Rename, Recreate або Auto |
| Інтервал оновлення (хвилини) | 5 | Як часто оновлюється назва |
| Роль | немає | Показується для `RoleMembers` |
| Цільова дата | немає | Показується для `Countdown` |
| Цільове значення | немає | Показується для `MemberGoal` і використовується в стилях у відсотках та шкалою прогресу |
| Назва лічильника Twitch | немає | Показується для `TwitchCounter` |
| Канал підрахунку | немає | Показується для типів підрахунку |
| Сервер Minecraft | немає | Показується для типів Minecraft |

**Типові значення для нових статистичних каналів** задає **Типовий механізм**, **Типовий стиль лічильника** і **Типовий інтервал (хвилини)** для каналів, які будуть додані пізніше. У вкладці **Типові значення** також є довідкові розділи **Стилі лічильника** та **Доступні лічильники**.

Новостворений канал забороняє Connect для `@everyone`, тож працює як напис. Канал, який ти додаєш сам, зберігає дозволи, які вже має.

## Покрокове налаштування

1. Відкрий **Статистичні канали** на панелі керування і перейди до вкладки **Типові значення**. Залиш **Типовий механізм** на Авто і встанови інтервал, який тебе влаштовує.
2. Перейди до **Додати**, обери **Створити новий канал** і вибери **Категорію**, якщо хочеш згрупувати лічильники.
3. Обери **Лічильник**, наприклад Total Members. Зміни **Шаблон** і стеж за попереднім переглядом.
4. Вибери **Стиль лічильника** і збережи.
5. Повтори для кожного лічильника. Для цілі за кількістю учасників обери `MemberGoal`, встанови **Цільове значення** і спробуй стиль `ProgressBar`.
6. Перетягни нові канали на початок списку каналів у Discord, якщо вони не опинилися там самі.
7. Почекай один інтервал оновлення і переконайся, що назви оновлюються.

## Команди

Виконуй їх із префіксом свого сервера (`.`, якщо ти його не змінював). Типи, стилі та механізми — це назви з таблиць вище, наприклад `TotalMembers`, `Compact`, `Recreate`.

| Команда | Псевдоніми | Потрібно | Призначення |
| --- | --- | --- | --- |
| `statchannelcreate <type> [template]` | `scnew` | Керування каналами | Створити новий заблокований голосовий канал, що показує цей лічильник |
| `statchanneladd #voice <type> [template]` | `sca` | Керування каналами | Перетворити наявний голосовий канал на статистичний |
| `statchannelrole #voice @role [true] [template]` | `scr` | Керування каналами | Додати лічильник учасників з роллю; `true` враховує лише тих, хто не в офлайні |
| `statchannelcountdown #voice <date> [template]` | `scc` | Керування каналами | Додати відлік до дати |
| `statchannelgoal #voice <number> [template]` | `scg` | Керування каналами | Додати лічильник цілі за кількістю учасників |
| `statchanneltwitchcounter #voice <counter> [template]` | | Керування каналами | Відображати іменований лічильник чату Twitch |
| `statchannelmechanism #voice <mechanism> [minutes]` | | Керування каналами | Встановити rename, recreate або auto, а за бажанням інтервал |
| `statchannelstyle #voice <style>` | | Керування каналами | Встановити стиль відображення |
| `statchanneldefaults [mechanism] [minutes] [style]` | | Керування каналами | Встановити типові значення для нових статистичних каналів |
| `statchanneltypes [category]` | | Нікому | Переглянути всі лічильники з прикладом, за бажанням за категорією |

## Поради та підводні камені

- Боту потрібне право Керування каналами, щоб перейменовувати або перестворювати канал.
- Голосовий канал може бути лише одним статистичним каналом. Додавання його вдруге завершується помилкою "already a stat channel".
- Лічильникам Counting, Minecraft і Twitch потрібно спершу налаштувати відповідні функції. Цілі для Counting і Minecraft обираються на панелі керування; для них немає команди.
- `statchannelremove` лише припиняє відстеження. Якщо канал більше не потрібен, видали голосовий канал самостійно.
- Живі значення, як-от глядачі Twitch або відкриті тікети, однаково дотримуються інтервалу каналу. Зменш інтервал саме для таких каналів, а не для всіх.
- Стилі `Percent` і `ProgressBar` використовують власне цільове значення каналу. Якщо задати їх лічильнику без цілі, завжди показується нуль.
